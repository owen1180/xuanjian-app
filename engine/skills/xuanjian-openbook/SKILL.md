# 开源研习与口径治理

**这一层不加断法。** 它只做一件事：把外部开源世界能站得住的工程机制搬进来，让本馆原有的断法**口径更硬、出处更实、结论可回测**。断法归 `xuanjian-kb` 与 `shizhan-pai`，本技能不产断语、不改判档、不替成员读盘。

三阶段研习（2026-11-04 完成，逐项目一手取证）的结论只有一句：**开源给的是算式、契约与边界，不是断语，更不是权威**。因此本层落地的是「口径卡 + 引证闸门 + 评测闭环」，不是任何一家的解读文本。

## 三、八条硬规矩

1. **口径由主理人一人裁定，成员不得自改**。派单前主理人生成唯一口径卡，全体成员只读该卡；`calendar_type`、时区、真太阳时、晚子时、闰月、亮度流派、四化基表，一律不许成员另定或另向用户重复问询。这是「各安其位」的卷子，不是答题。
2. **先独立、后互通**。成员各自出完结论并交内部结果卡，才允许主理人主持交叉核对；派单时不得让成员看到他人结论。**禁止任何"总 skill 亲自跑多门再归一"的架构**（`OB99` §2）。
3. **口径不一致，结论不许互证**。两张卡的共用基础开关只要有一项不同，交叉印证册只列分歧、不加权、不写「互相印证」（`OB96` §4）。
4. **事实归工具，解读归成员**。干支、十神、节气交接、闰月、真太阳时、命宫安星、四化落宫一律取确定性工具；成员不得口算、不得凭记忆补造、不得在工具结论外自补结论。工具没给的写「工具没给」。
5. **引一句、查一句**。称「倪师说」必须能拼出集数与分秒链接；称古籍必须能在冻结语料逐字反查。查不到出处的引文**删掉或换成逐字可查的原话**，禁止「古书云」「命书有言」。
6. **敢断与不武断不冲突**。定案级要求的「六亲／感情／财富／事业敢断有无、断厚薄、点具体人」照断不误；禁的是「必发／必离／某年必病／注定／必然／绝对」这类期限与绝对化措辞。**倪师论紫微六亲局限只作用于紫微那一册的核对精度说明，不构成全馆「不敢断」的挡箭牌**——本馆六亲断在四柱、命卦与双盘交叉上（`OB95` §5）。
7. **白话规范不压缩四册报告**。「300–600 字、一句一事」只作用于轻量答复；凡「完整分析／详细报告」一律按 `61` 出四册九项，每项含流年大运后天变化，不受字数约束。
8. **只借机制，不搬实现**。AGPL-3.0-only（含 §13 网络源码提供义务）、Swiss Ephemeris AGPL、三个未声明许可的 vendored 引擎、倪师原话 CC BY-NC-SA 4.0 非商用、`yuan` 无许可——决定了本层所有规则句、schema 与脚本均为**本馆自撰**，只做机制借鉴并注明思想来源，不复制任何源码、README 段落或解读文本。

## 四、四个脚本

```bash
cd skills/xuanjian-openbook/scripts

# 派单前：生成口径卡（可覆盖任一开关）
python3 kauding.py new --tech ziwei --school tianji --preset tianji-default --out /tmp/card.json
python3 kauding.py new --tech bazi  --school kou-jing-fa --preset xuanjian-default --out /tmp/bazi.json

# 交叉核对前：两张卡能不能互证
python3 kauding.py check /tmp/card.json /tmp/bazi.json

# 自检：七铁律公式、时辰索引、四化白名单、非法日期拒绝
python3 kauding.py selftest

# 发出前：引证 / 措辞 / 四化 / 免责 机械闸门
python3 source_gate.py --draft /tmp/draft.txt --facts /tmp/facts.json
cat /tmp/draft.txt | python3 source_gate.py --draft -
python3 source_gate.py --selftest

# 全库册号命名空间闸门：改册页 / 加新册 / 改成员挂载后必跑（TR108）
python3 book_registry.py --strict
python3 book_registry.py --out book_registry.json

# 口径卡 ↔ 外部引擎 dump 逐格对拍（上游无 dump 导出时如实报 unavailable）
python3 engine_align.py --schema
python3 engine_align.py --dump <dump.json> --card <card.json> --out align_report.json
```

**册号命名空间（`TR108`）**：`1`–`94` 默认属 KB 可裸写；**95 及以上一律带前缀**——`KB95` 是四柱格局专论、`OB95` 是本层核验总表，两者撞号已裁决但不得靠裸号猜。`book_registry.py` 管四件事：未登记的新撞号、95+ 裸号、悬空带前缀引用、成员引用了本层册页却没挂载本技能，任一命中即 FAIL。**成员层已全部挂载 `xuanjian-openbook` 并带派单契约八条**；规矩只写在主理人身上而成员读不到，等于没写。

`check` 返回 `conflict=true` 时：**交叉印证册只列分歧，禁止加权**。`source_gate.py` 有 `error` 时先改再发，有 `warning` 时在成品中说明未核内容；**通过不等于语义正确**，分寸仍归主理人。

## 五之一、本层五个脚本

| 脚本 | 管什么 | 命令 |
|---|---|---|
| `book_registry.py` | 册号命名空间（1–94 裸号、95+ 必带前缀），裸号歧义判错 | `--strict` |
| `kauding.py` | 口径卡 schema、十项开关、冲突检出 | `check` |
| `source_gate.py` | 引证可查与措辞边界 | `check` |
| `engine_align.py` | 两套引擎事实层对齐 | `check` |
| `selftest_gate.py` | **自检的审计**：假自检／恒真断言／失败不落地／无自检欠账 | `盘点`／`欠账`／`跑`／`--strict` |

`selftest_gate.py` 是 v1.57.0 新加的（册 `TR111`）：它不测业务，只测**那些「全绿」是不是真绿**。
报自检结果时必须连它一起跑——`跑` 会给出「跑了几个脚本、哪几层、多少条」，分子分母一起报；
**只报分子不报分母的口径，视为未报**。

## 四·补 两个闸门各管什么（v1.65.0 起）

| 闸门 | 管什么 | 什么时候跑 |
|---|---|---|
| `kb_gate.py`（`xuanjian-kb`） | **红线**：禁词八类、十八规则、经方通道、兜底扫描 | 任何成品发出前 |
| `source_gate.py`（本技能） | **出处与措辞**：绝对化、四化白名单、工具外数值、未判说成定格、免责、外加**引证核对**（书目在不在引证库／白名单、该版能不能引原文、引原文有没有给定位、**行号指的地方有没有那句话**） | 任何成品发出前，与上一道**都要跑** |

`source_gate.py` 的引证核对读 `命理档案/引证库/索引.json`（`xuanjian-archive/scripts/quote_index.py` 生成）。**只提书名不拦，有引号内原文才查**；索引找不到只给 warning，不静默。
古籍（本馆无电子本）走 `命理档案/引证库/书目白名单.json`，引原文只警告不拦；
`#L行号` 会回读产物核内容，对不上即 `CITATION_LOCATOR_MISMATCH`。规程见 `OB97` §四·补 与 `TR117`。
