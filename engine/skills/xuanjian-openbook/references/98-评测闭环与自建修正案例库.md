## 二、评测解耦（可执行的四步）

借 `MingLi-Bench --astro` 的思想，把**排盘**与**推理**分开测，避免「排错盘」被记成「推错理」：

1. **预排注入**：把命盘（四柱／紫微）预先由确定性工具排好，评测时只注入盘面，不让被测环节自行排盘。
2. **思维链留痕**：允许逐步推演并保存原始响应，逐题存档，不只看最终选项。
3. **防位置偏差**：选项顺序随机打乱；同一题重复跑时固定随机种子并记录 seed。
4. **Exact Match 标局限**：选择题评分只用于**相对比较**，报告里必须写「不代表实际咨询效果」。

本馆评测集自建，题面优先取自**已归档、已有定案的真实命例**（`xuanjian-archive`），每题附：档号、口径卡版本、定案结论、依据册号、参与成员、是否含已知分歧。**不许用模型自己生成的题考模型自己**。

## 三、自建修正案例库（因为外部无可用来源）

档案结构（建议放 `命理档案/修正案例/`，与本馆归档同库、按八字为档号）：

```json
{
  "case_id": "八字档号-序号",
  "chart_key": "八字",
  "kauding_version": "口径卡 v1.0 + hash",
  "engine_version": "xuanjian-1.51.0",
  "frozen_at": "事前冻结时间",
  "original_assertion": { "member": "", "statement": "", "basis": ["册号"], "confidence": "内部" },
  "predicted_window": "大运/流年区间（不给具体日）",
  "actual_feedback": { "reported_at": "", "what_happened": "", "source": "用户自述/回访" },
  "verdict": "hit|partial|miss|unverifiable",
  "revision": { "reason": "", "changed_rule": "", "保留原判断": true },
  "counted_as_hit": false
}
```

**六条硬规矩**：

1. **事前冻结、事后记录**：判断须在得知结果之前写入并留时间戳；仅在用户明确授权跟踪时启用。
2. **保留原判断与修订理由**，不许把改口后的版本覆盖掉原案——否则永远「测得准」。
3. **已知经历不计命中**：用户事后补述的既往事件，一律标 `counted_as_hit=false`，只作背景。
4. **用户纠正留痕**：记录纠正内容、订正原因；若是**订正**（新规则发现旧结论错），改档案卡片与分析记录再刷新基准；若是**回归错误**（新改动破坏原本对的结论），修引擎、基准不动。**把基准改掉来消红色＝拆警报器**（`xuanjian-evolve` 铁律一）。
5. `unverifiable` 是合法结论，不许为了凑命中率硬判。
6. 出生资料属敏感数据：示例与评测一律用虚构资料；档案本地/沙盒保存，需用户确认，支持查看／更正／删除。

## 四、口径变更 → 历史结论重算

`mingpan` 0.1.8 有一份教科书级公告：修正互变卦取法后，「64 卦 × 6 动爻中 256 个变卦结果、64 卦中 60 个互卦结果需纠正……**依赖旧互变卦的解读需重新计算后复核**」。`ziwei-doushu` 也声明 v4.0 数据集按旧亮度默认生成，与 2026-10-20 后新默认不一致。

**本馆规则**：

- 每个归档结论必须绑定 `engine_version` + **口径卡 hash**；只写「哪年算的」不够。
- 任一基础开关（历法、晚子时、闰月、真太阳时、亮度、四化流派、定年界线）发生变更 → 列出受影响的档号清单 → 逐个重算 → 在档案里并排保留**旧结论／新结论／变更原因**，不静默顶替。
- 分歧面用 `regress.py 分歧` 常摆出来看；**分歧项变了才需要介入**，不变就是已知分歧。
- 工具侧订正层（`dingzheng.ts`）与专家团定案口径本来就可能相反，这是**已知分歧不是故障**，不许静默顶替。

## 五、接回 `xuanjian-evolve` 的两道回归

本轮新增的维度必须进回归基准，否则又是「假绿灯」：

| 道 | 新增要测的维度 |
|---|---|
| 第一道（专家团 `score.py`） | 总分、天干分、地支分、档位、岁运要点 —— 不变；**新增：口径卡 `judging_basis` 是否仍为 `score-py`、是否出现第二判档数** |
| 第二道（工具 `engine-dump.ts`） | 四柱／大运签名／紫微签名／用神／五合／降档／格局数／神煞数／订正层 —— **新增：口径卡 hash、四化白名单合法性、宫位逆时针铁律、日期存在性拒绝** |
| 第三道（本技能） | `kauding.py selftest`（7 铁律公式／时辰索引／四化白名单／非法日期）＋ `source_gate.py --selftest`（引文、措辞、免责）＋ `kb_audit.py --strict`（册号、悬空引用、表格列数） |

**跑不动的维度报「未回归」，不许并入「全部通过」。** 改完册页先跑 `kb_audit.py`，改完引擎先跑 `regress.py 检查`，再对外说「更新完了」。
