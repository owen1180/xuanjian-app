# 97 · 引证可追溯与确定性分层

> 思想来源：`ziwei-doushu` v4.0 逐句校正、`chinese-fortune` 的 `passage-id` + `answer_check.py`、`mingpan` 的 Facts only、真一 `MODEL_INTEGRATION.md` 的幻觉抑制条款、`Horosa` 技法依据卡。**规则句与脚本均为本馆自撰。**

## 一、引证四段结构与「查一句」

每条知识条目固定四段：**定调 / 论断 / 依据 / 出处**。四层内容分开标注，不许混为同等可靠的事实：**盘面事实**（工具算出）／**传统规则**（典籍或师承）／**解释性推断**（成员推理，标 `〔本馆归纳〕`）／**现实建议**（可执行的动作）。

| 引什么 | 必须附什么 | 查不到怎么办 |
|---|---|---|
| 倪师原话 | 《天纪》第几集 + 几分几秒 + 可回放链接（B 站 `?p=&t=`）；语料是讲课口语转写，照抄可标〔sic〕，**不许改顺** | 删掉，或换成逐字可查的原话；只能说「有人这么整理」 |
| 古籍原文 | 书名 + 段落编号，能在冻结语料逐字反查；**不得以「古书云」「命书有言」代替** | 删掉 |
| 本馆归纳 | 显式标 `〔本馆归纳〕`；新概念须 ≥2 个独立来源才立 | 标「待验证」，不标「确证」 |
| 通则推理（无出处） | 明说「此为通则推理」 | 不得包装成典籍或师承 |

`xuanjian-kb` 铁律 13 与本册一致：两份倪师语料 CC BY-NC-SA 4.0 非商用，全量只放工作区，**不入插件包**。

## 三、程序算，AI 讲（确定性事实／经验解读严格分层）

| 层 | 谁产 | 硬规矩 |
|---|---|---|
| 确定性事实 | 工具 | 干支、十神、藏干、纳音、节气交接、闰月、真太阳时、夏令时、命宫安星、四化落宫、大运流年序列、五格数理、黄历六栏——**只从工具输出取** |
| 经验性解读 | 成员 | 取用神、断语、取象、分寸；不得包装成科学证明，不得虚构星曜／宫位／格局／用神 |
| 现实建议 | 主理人收束 | 落在可执行动作，断「凶」必须同时给「避」 |

**四条不许**：不许口算或凭记忆补造成功结果；不许在工具结论外自补结论；不许把工具写的「没判／未接入／给不出／不判」改写成判断；不许把并列说成「唯一最好」、不按条数投票。工具没给的字段，成员写「工具没给」。

这条的现实依据很硬：某开源技能 v5.6 真实回答评测里，**答错的主因是宿主在工具结果之外自己补结论**；另一排盘引擎的用户反馈「天机天梁在财帛宫被说成夫妻宫」，排查结论是**算法层全对、AI context 文本歧义**。所以解读与盘面打架时，**先查文本歧义，不要去改排盘核心**。

## 四、发出前机械闸门（`source_gate.py`）

```bash
python3 source_gate.py --draft draft.txt --facts facts.json
```

逐项机械核对（对齐 `answer_check.py` 的核对思想，本馆自撰实现）：

| 级别 | 检查项 |
|---|---|
| `error` | ① 引文声称有出处但无链接/册号/段落号；② 绝对化与期限词（必发／必离／必病／注定／必然／绝对／哪一年一定）；③ 白名单外四化组合；④ 工具未给出的分数或数值；⑤ 把未判格局说成定格、把并列说成唯一最好；⑥ 缺免责声明；⑦ 健康诊断、病名、方药剂量；⑧ 本人寿元字样；⑨ **引证库里没有这本书**（`CITATION_UNKNOWN`）；⑩ **该书是「仅指认／近空」却出现引号内原文**（`CITATION_INVENTED`）；⑪ **可逐字引却引了原文、没给 `#L行号`／页号／册号**（`CITATION_NO_LOCATOR`） |
| `warning` | ⑫ 未标明本馆归纳；⑬ 未标 AI 辅助生成；⑭ 六亲三维（父母／兄弟／子女）紫微册缺局限注；⑮ 未标口径卡版本；⑯ 白话答复超 600 字（仅轻量答复适用）；⑰ **同名多版本、可引档位不同**（`CITATION_AMBIGUOUS`）；⑱ **草稿引了书名但找不到引证库索引**（`NO_QUOTE_INDEX`） |

**有 error 先改再发；warning 须在成品中说明未核内容；通过不等于语义正确**——分寸仍归主理人，闸门只报告、不替你改结论（与 `57` 的 `kb_gate.py` 同一纪律，两者都要跑：`kb_gate.py` 管红线，`source_gate.py` 管出处与措辞）。

### 四·补 引证核对（v1.65.0 起，与引证库耦合）

上表 ① 只管**形式**——「说有出处却没给链接」。它管不到更根本的一件事：
**这本书到底存不存在、这一版到底能不能引原文。** 引证库（`命理档案/引证库/索引.json`，
由 `archive/scripts/quote_index.py` 生成）建起来之后，这个核对才第一次可做。

四条判据，方向都是「不许编」：

| 判据 | 触发 | 级别 | 为什么 |
|---|---|---|---|
| `CITATION_UNKNOWN` | 草稿出现《书名》，引证库里查不到 | error | 凭记忆引一本不存在的书，是本馆最不能出的东西 |
| `CITATION_INVENTED` | 该版是「仅指认／近空／散图」，却出现引号内原文 | error | 扫描件没 OCR 就没原文，那句原文只能是人补的 |
| `CITATION_NO_LOCATOR` | 该版可逐字引、确实引了原文，却没给 `#L行号`／页号／册号 | error | 无法反查，等于没出处 |
| `CITATION_AMBIGUOUS` | 同名多版本、档位不同 | warning | 须写明是哪一版，否则同一个书名指两本不同的书 |

三条配套规矩：

1. **只提书名不引原文，一律放行。** 「《可书甲》讲过此事」是正常叙述，不是引文；
   只有引号内的内容才受 ⑩⑪ 约束。否则闸门会把正常行文全拦掉。
2. **课程语料不按书核。** 《天纪》《人纪》《地纪》按「集数 + 分秒」核（见 §一），
   不走引证库——它们不是书。
3. **索引找不到只给 warning，不给 error。** 闸门要能在没库的环境里跑；
   但「引了书名却没法核」必须出声，静默跳过正是本馆栽过跟头的地方。

**引证库自己的档位定义在 `TR116` §四**（可逐字引／仅指认／近空／散图）。
两册分工：`TR116` 定「怎么分档」，本册定「分档之后闸门怎么拦」。

> 一处实录：这个函数第一版改完就藏着一个 `NameError`（循环变量换名后残留旧名），
> 而自检照样全绿——因为旧自检的草稿只引了《天纪》，在「课程语料」那个 `continue`
> 处就跳走了，整段从未执行。**没跑到就等于没测**，现在每条判据都有独立用例（16 条），
> 另做 7 组变异验证灵敏度。

### 四·补二 书目白名单与行号校验（v1.66.0 起）

`CITATION_UNKNOWN` 上线一天就被实测打回：拿册页里真实出现过的 204 个书名去对引证库，
**176 个（86%）查不到**——多是《撼龙经》《青囊经》《协纪辨方书》这类本馆无电子本的古籍。
判据把「本馆没有」当成了「这本书不存在」。故补两层：

**一、书目白名单**（`命理档案/引证库/书目白名单.json`）。`《》` 里不都是书：

| 类别 | 例 | 处置 |
|---|---|---|
| 典籍 | 《撼龙经》《滴天髓》 | 允许引；本馆无电子本，引原文不可反查 → `CITATION_CLASSIC_UNVERIFIED`（warning） |
| 丛书 | 《四库全书》《正统道藏》 | 同上 |
| 篇名／卦名 | 《乾为天》《素问·脉要精微论》 | 同上 |
| 非书 | 《红番区》《满城尽带黄金甲》 | 不按书判 |
| 馆内文件 | 《档案卡片》《命主记录》 | 不按书判 |

判据变为三段：引证库 → 白名单 → 才判 `CITATION_UNKNOWN`。种子只从册页已引书名取，分类人工可改、重跑不覆盖。

**二、行号内容校验**。原先只查「引原文有没有给 `#L行号`」，不查「这个行号指的地方有没有这句话」：

| 结论 | 依据 | 级别 |
|---|---|---|
| 对 | 引文最长连续汉字（≥8）在该行 ±2 行内出现 | 放行 |
| 不符 | 找不到 | `CITATION_LOCATOR_MISMATCH`（error） |
| 读不到 | 产物不在盘上／行号越界 | `CITATION_LOCATOR_UNREADABLE`（warning） |

配套三条：**带 ±2 行**（语料按 30 字硬换行，单行会误判）；**不足 8 汉字不比**
（否则短引文天天误报）；**校验对象取 `取舍=首选`**（同名两版都标可逐字引时，
取列表首个会核到乱码版或插空格版）。

**三、乱码档**：`/G[0-9A-F]{2}` 与 Unicode 私有区字符占比 >20% 的产物判「乱码」、不可引——
字数够不等于内容对（《零起点学中医》PDF 版 86.5% 是 CID 码）。

## 五、话术边界与「敢断」的边界（防互相削弱）

- 措辞用「**倾向、常见、容易、建议关注**」；禁用「注定、必然、绝对」。
- **但定案级 R-033 照旧**：六亲／感情／财富／事业要断有无、断厚薄、点具体人（如「能托一把的是年长那位」）、配偶倾向、库守不守得住、有没有位／名分实不实／封顶几层。这些是**倾向性定论**，不是绝对化措辞，闸门不得把它们误拦为「武断」。
- 唯一红线不变：**本人终点永不可断**；「断生死」只断六亲存亡、不落本人。
- 倪师论紫微六亲局限，只在紫微册六亲三项附一句口径注（见 `OB95` §5），不构成全馆降档理由。

## 六、白话输出规范（适用范围有限）

轻量答复采用固定段落结构「**白话结论 → 必要盘面 → 短原文与出处 → 紧跟白话解释**」：默认 300–600 字、一句一事、术语首现即解释且**不得用另一串术语解释它**；开头一至三句先给没学过术数的人也能看懂的直答与限制，**不许先堆「杂气正官、透干有根」再翻译**；默认最多三条主判断。

> **适用边界（必须写死）**：该规范只作用于轻量答复与单成员短答。凡「完整分析／详细报告／全面评测」一律按 `61` 出四册九项，每项含「流年大运带来的后天变化」，**不受字数与「最多三条主判断」约束**；用忌神落地章节照旧十类事物逐栏写实。白话简洁不得成为压缩四册的理由。

## 七、固定免责与标识

成品末尾固定：「以上为传统术数文化分析，供参考；不构成医疗、法律、财务、婚姻、职业等专业建议；不保证准确性，决策权在你。」AI 生成或辅助生成内容须显式标识。涉及急症、自伤念头、传票、人身伤害时先给现实帮助，不在命盘上找原因。
