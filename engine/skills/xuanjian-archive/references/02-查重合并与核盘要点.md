# 查重合并与核盘要点

## 一、查重四步

```bash
# 第一步：精确查四柱是否已有档
python3 find_chart.py 命理档案 丁酉己酉丙午辛卯

# 第二步：时辰不明时查同日前六柱
python3 find_chart.py 命理档案 庚寅己卯戊午 --fuzzy

# 第三步：命中 → 打开该档《命主记录.md》比对性别与出生地，确认是否同一造
# 第四步：未命中 → 按 01 模板新建；禁止跳过查重直接建档
```

查重要看三样：**四柱八个字、性别（顺逆不同）、出生地（真太阳时不同）**。三者全同才算真正同盘；只有八字同而性别不同，虽同档但大运相反，必须分记。

## 二、合并判定表

| 输入 | 判定 | 处置 |
|---|---|---|
| 四柱全同，性别也同 | 高度疑似同造 | 并入一档，核对是否为同一人；命理部分**不重写** |
| 四柱全同，性别不同 | 同盘异运 | 并入一档，命主记录分两行，大运分记 |
| 四柱全同但出生地跨经度大 | 可能跨时辰 | 先核真太阳时，确属同时辰再合并 |
| 同年月日，时辰不同 | **不同八字** | 另立新档，两档互链注明"同日异时" |
| 只知年月日，时辰不明 | 待补时档 | 目录加「待补时」后缀；补齐后重命名并修三处链接 |
| 用户生日记错，前后差一天 | 可能跨月柱 | 必须用脚本回算，不能以用户口述为准 |

## 三、核盘要点（每次必做）

### 1. 真太阳时

排盘用出生地真太阳时，不用北京时间。修正公式：

```
当地时间差（分） = (出生地经度 − 120) × 4 + 当日时差修正
```

经度每差 1 度差 4 分钟。西部城市若出生时刻紧贴时辰交界（如卯辰之交），务必用此法判定，否则时柱全错。判断依据记录到卡片第一节。

### 2. 五鼠遁推时柱（缺软件时的手算）

按日干起时：

| 日干 | 子时起 |
|---|---|
| 甲、己 | 甲 |
| 乙、庚 | 丙 |
| 丙、辛 | 戊 |
| 丁、壬 | 庚 |
| 戊、癸 | 壬 |

例：丙日 → 子时起戊子，顺推到卯时为辛卯。

### 3. 起运折算（三日为一岁）

- **顺排**：阳年男、阴年女 → 出生后**下一个**节令，算相隔天数
- **逆排**：阳年女、阴年男 → 出生后**上一个**节令（即回溯），算相隔天数
- 折算：**三日折一岁，一日折四月（一百二十天），一个时辰折十天**

阳年阴年看年干：甲丙戊庚壬为阳，乙丁己辛癸为阴。

### 4. 缺时柱也能算大运

**年干定顺逆、月柱定序列、日数定起运**——三者都不依赖时柱。所以只有年月日时，十年大运仍可精算，只是起运时刻略有误差，须在档内写明"时辰待补，起运误差在月内"。

## 四、常见错排清单

| 错误 | 后果 | 防范 |
|---|---|---|
| 用北京时间直接定时辰 | 西部出生者时柱整柱错 | 必做经度修正 |
| 农历闰月没换算 | 月柱错，格局全错 | 用万年历库回算，不信口述 |
| 节气当天出生未查交节时刻 | 月柱可能上一／下一月 | 脚本输出交节精确到分 |
| 顺逆排错 | 大运全盘倒序 | 对照年干阴阳两遍 |
| 五鼠遁起错 | 时柱天干错 | 用脚本交叉验证 |
| 用户自报的八字不加核对 | 直接继承错误 | **任何由用户提供的八字，都必须用脚本独立复算一遍** |

## 补：同组撞盘（v1.72.0）

`find_chart.py` 现在会带出 `档案索引.json` 里的**分组与称呼**；加 `--组 客户` 只筛该组。

**同组撞盘要当成「可能重复归档」处理，不是「巧合同盘」。**
同一片关系圈（比如同事）里出现两个一样的八字，先问三件事：

1. 性别同不同（同八字不同性别的命完全不同）；
2. 出生地同不同（真太阳时差半小时就可能换时柱）；
3. 称呼是不是同一个人（张先生／老张／张总，很可能是同一人三次开口）。

三项里有两项对不上，才是真的两个人；否则**追加到原档，不新建**。
不同组撞盘（家人 vs 客户）也要核，但两种情况都成立的概率更高——照常核对后各档并列即可。
