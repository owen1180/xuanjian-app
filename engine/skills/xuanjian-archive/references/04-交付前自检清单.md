# 交付前自检清单

> 交付之前，逐项打勾。任何一项不过，不许交出。

## 一、命理内容自检

- [ ] **四柱已用脚本独立复算**，与师傅结论一致（不能只信用户自报）
- [ ] 农历、闰月、节气交节时刻已核对，尤其生日落在节气当天或闰月的
- [ ] 出生地经度已做真太阳时修正，交界时辰写明了判定依据
- [ ] 格局、用神、层次有据可查（打分能报出加减来源）
- [ ] 大运顺逆对过两遍（年干阴阳 + 男命女命）
- [ ] 缺时柱的，已写明局限，且没有假排对方的本命大运
- [ ] 每一项颜色、方位、数字类建议，都源自用神而非拍脑袋

## 二、分寸自检

- [ ] 无疾病诊断、无病名、无方药穴位
- [ ] 无"死""夭""必凶""必发""必离"一类铁口词
- [ ] 健康议题一律转为风险语言 + 建议体检
- [ ] **九项每项都有「年份（区间＋主年＋依据）」**——只写「这几年／将来」不过关（`61` §3.4）
- [ ] **九项每项都有「去留（象／窗口／建议）」**——只写「看情况／顺其自然」不过关（`61` §3.5）
- [ ] 关系去留：给到窗口与代价，**签字权仍在当事人**；涉及人身安全时年份作废、先走
- [ ] 涉及第三人的盘，只做与提问相关的最小解读
- [ ] 结尾带了"以上为传统术数文化分析，供参考"一类声明

## 三、归档自检

- [ ] 已查重，没有重复建档
- [ ] 四件套齐全（卡片、命主记录、分析记录、报告）
- [ ] 索引页四项计数已刷新
- [ ] 关联档案的相对链接有效
- [ ] 本次测算已作为一条追加进《分析记录.md》
- [ ] 新的判读方法已写入规则库，或在本档注明"无新增"
- [ ] 当日日志已写

## 四、文字自检（跑脚本）

```bash
python3 check_cn.py 命理档案
```

输出列出每个文件的英文残留；有残留时退出码非零，修完再跑一遍：

- [ ] 结果为「全部纯中文」
- [ ] 文件名本身也尽量用汉字（再加「待补时」一类后缀）

> 历史教训：报告正文曾混入两个英文词（一处是"非必要择期手术"写成了英文形容词，一处是"子女安排"写成了英文短语），用户当场指出。**此后再犯属不该。**

## 五、交付动作

1. 用 `present_files` 把索引页、卡片、规则库一并呈给用户，让他能自己翻
2. 口头汇报只讲三件事：**这次多知道了什么、什么时候动、还剩什么没确定**
3. 主动提示用户回填真实情况，说明回填能让后续测算更准——这是校准通道，不是客套
