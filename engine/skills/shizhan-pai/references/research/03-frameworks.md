## 一、奇门遁甲

### 1.1 起局十步（张志春《神奇之门》纸上快速起局法）

#### 第一步：阳历转干支
- 查万年历，把公历年月日时换成**年干支、月干支、日干支、时干支**。
- 时干支用**真太阳时**校正（跨时区、边远地区、夏令时尤其要校正）。
- 输出：四柱八字。

#### 第二步：定阴阳遁
- **冬至后 → 阳遁**；**夏至后 → 阴遁**。
- 口诀：冬至阳生，夏至阴生。

#### 第三步：定局数
1. 找**日干支的符头**（甲/己为符头；日干支往前推到最近的甲日或己日）。
2. 按符头定**上元/中元/下元**：
   - 符头地支为**子午卯酉** → 上元
   - **寅申巳亥** → 中元
   - **辰戌丑未** → 下元
3. 查**节气用局表**：每个节气管三局（上/中/下元），得「阳遁几局」或「阴遁几局」。

> **拆补法**：按日干支符头定元，遇甲换排；简单、可查表。
> **置闰法**：超神、接气、置闰，节气交界处会与拆补差一局。
> **本协议用拆补**；用置闰须事先声明，不可混用。

#### 第四步：布地盘（三奇六仪）
- 画九宫格（1–9 宫，洛书方位：上九下一、左三右七、二四为肩、六八为足）。
- 从**戊**起，按局数落宫：
  - **阳遁：逆布三奇（丁丙乙）、顺布六仪（戊己庚辛壬癸）**
  - **阴遁：顺布三奇、逆布六仪**
- 永定序：**戊、己、庚、辛、壬、癸、丁、丙、乙**（九宫一圈）。

#### 第五步：找旬首，定值符值使
- 时辰属于哪一旬（甲子/甲戌/甲申/甲午/甲辰/甲寅）。
- 旬首所隐的六仪 → 该仪在地盘哪一宫 → **该宫对应的天盘九星＝值符**，**人盘八门＝值使**。

#### 第六步：值符随时干
- 看**时辰天干**在地盘哪一宫。
- 把值符（九星）写到该宫；同时把该宫原地盘的三奇六仪一并带过去。

#### 第七步：布九星
- 值符落宫既定，其余八星按**顺时针**依次布入。
- 每颗星连带它原地盘携带的奇仪一起走。

#### 第八步：值使随时宫
- 从值使**原宫**起，按**阳遁顺行、阴遁逆行**，数到时辰（第几个时辰）。
- 数到哪一宫，值使（八门）就落哪一宫。

#### 第九步：布八门
- 值使落宫既定，其余七门按固定顺序布入。
- 八门顺序：**休、生、伤、杜、景、死、惊、开**。

#### 第十步：布八神
- 小值符随大值符（值符落哪宫，小值符就在哪宫）。
- 顺序：**值符 → 螣蛇 → 太阴 → 六合 → 白虎（勾陈）→ 玄武（朱雀）→ 九地 → 九天**。
- **阳遁顺时针、阴遁逆时针**。

> 完成后，每宫都有「天盘星 + 地盘奇仪 + 人盘门 + 神盘神」，四盘合一。

### 1.2 断事五步（杜新会系）

#### 第一步：定人
| 角色 | 用神 |
|---|---|
| 求测人 | **日干** |
| 事体 | **时干** |
| 当事人（代问） | **年命**（生年天干） |
| 领导/上级 | 值符 |
| 同辈/对手 | 月干 |
| 小辈/下属 | 时干（有时） |

#### 第二步：定专占用神
| 问事 | 用神 |
|---|---|
| 婚姻 | 乙（女）、庚（男）、六合（婚） |
| 财运 | 戊（资本）、生门（利润）、甲子戊（本金） |
| 事业 | 开门（工作）、杜门（技术）、值符（领导） |
| 疾病 | 天芮（病）、天心（医）、乙奇（药） |
| 官司 | 景门（文书）、惊门（讼）、开门（官） |
| 失物/逃犯 | 天蓬（盗）、六合（逃）、杜门（藏） |
| 考试 | 丁（成绩）、景门（文书）、年命（考生） |
| 出行 | 开门（车/路）、九天（远行）、时干（事） |
| 店铺/生意 | 开门（店）、生门（利润）、戊（本金）、日干（店主） |
| 租约/房东 | 值符（房东/上级）、时干（合约）、景门（文书） |
| 前手/转手 | 月干（前手/同行）、庚（阻隔）、杜门（旧账） |
| 同行竞争 | 月干（同行）、庚（对手）、惊门（争讼） |

#### 第三步：看落宫状态
逐项检查（**顺序不能倒**）：
1. **空亡**：用神落空 → 事「悬着」，不是「没有」
2. **击刑**：用神落宫与地支相刑 → 别扭、反复
3. **入墓**：用神入墓 → 被困、藏着、不动
4. **门迫**：门克宫 → 事情顶牛
5. **旺衰**：月令对用神的生克 → 有力/无力
6. **格局**：十干克应、门星神组合

#### 第四步：看格局（常用十干克应）
| 格局 | 含义 |
|---|---|
| 辛加乙「虎猖狂」 | 凶险猖狂 |
| 庚加辛「远行车辙马死」 | 出行/远事不利 |
| 甲加甲「双木成林」 | 伏吟，万事闭塞，宜静守 |
| 甲加丙「青龙返首」 | 大吉，但逢迫墓击刑则吉事成凶 |
| 甲加丁「青龙耀明」 | 谒见贵人、求名逐利皆吉 |
| 甲加己「贵人入狱」 | 公私皆不利 |
| 甲加庚「值符飞宫」 | 吉事不吉，凶事更凶 |
| 甲加辛「青龙折足」 | 逢吉门生动方可谋；逢凶门招灾失财 |

> 十干克应版本多，本协议只列常用；**以原书表格为准**。

#### 第五步：看生克关系
- 用神与日干：谁克谁 → 事克人（压力）、人克事（可控）、比和（顺）
- 用神与时干：同上
- 用神与用神：如乙（女）与庚（男）→ 合/克/冲
- **单看生克容易错**：还要看「谁与用神同宫」（杜新会商战案：谁与金牌同宫谁得）

### 1.3 应期三法

| 方法 | 用法 | 例 |
|---|---|---|
| **值使法** | 值使落宫数 + 行程 → 几天/几月 | 惊门落兑七宫 → 七天左右 |
| **庚格法** | 庚为阻隔；逢庚格「有阻可破」；双庚格「必破、较快」 | 庚加癸为月格又时格 → 双庚格 |
| **填实/冲空法** | 空亡待填实或冲空之日；入墓待冲墓之时 | 空亡地支对应的日/月 |

> **应期给「窗口」不给「某日必发」**：说「七月下旬到八月上旬这个窗口，出现 X 现象」，不说「8 月 3 日一定」。

### 1.4 商业问事（石定坤系）

1. **定用神主次**：
   - 主用神：直接代表「事」的那一个（如投资看戊+生门）
   - 参考用神：代表环境/对手/时间的
2. **看成功条件**：不是「成/不成」，而是「成需要哪几条，缺哪条」
3. **标误差成因**：
   - 时间判定偏差（真太阳时、起局法）
   - 用神取错（主次颠倒）
   - 信息不全（不知道对方底细）
4. **给决策建议**：可做/不可做/何时做/找谁做

### 1.5 商用与租约的补充规则（本协议约定）

1. **营业起始日**以「首次实际营业日」为准，不以签约/装修/试营业日为准。
2. **转手承继**：未换招牌、未大改装修 → 承前手气运，须问「前手为何走」；换招牌/重做门面灶位 → 以新开业日为新起点；只换老板不换装修 → 按承继处理，前手作独立用神（月干/庚）。
3. **换运**：2023 入伙、2024 起九运，未大修/未换天心 → 以原入伙元运为主盘，九运流年星叠加；大修 → 以大修年重排。**各派有异，须标注。**
4. **商用形峦映射**：向＝门面开口；明堂＝门前街道；玄武＝后楼后墙；青龙/白虎＝左右邻铺；朱雀/案山＝对面楼/招牌；火＝灶/烤炉/排烟；水＝水槽/卫生间/鱼缸；财位＝收银台/进门对角。
5. **短应期转奇门**：风水长于元运/年尺度；「今年冬天/这个季度」用奇门定应期，风水只给方向。
6. **经营基线**：必问日均客流/流水/毛利；「好转」指哪个指标；无基线不给「好/不好」。

## 二、紫微斗数

### 2.1 安星四层（王亭之中州派）

#### 第一层：定命宫、身宫
- **命宫**：寅宫起正月，顺数到生月；再从生月宫起子时，**逆数**到生时，即为命宫。
- **身宫**：同上，但从生月宫起子时**顺数**到生时。
- 口诀：命宫逆数，身宫顺数。

#### 第二层：定五行局
- 由命宫干支 → 纳音 → 五行局：
  - 水二局、木三局、金四局、土五局、火六局。
- 五行局决定「紫微星从哪起、几步到」。

#### 第三层：安紫微系与天府系
- 按五行局与生日定**紫微**位置。
- **紫微系**（顺行）：紫微、天机、太阳、武曲、天同、廉贞。
- **天府系**（逆行）：天府、太阴、贪狼、巨门、天相、天梁、七杀、破军。
- 天府位置由紫微推出（紫微与天府在寅申同宫，其余按对宫关系）。

#### 第四层：安辅佐煞、四化、杂曜流曜
- **六吉**：左辅、右弼、天魁、天钺、文昌、文曲。
- **四煞**：擎羊、陀罗、火星、铃星。
- **禄存、天马**。
- **四化**：依生年干（本命）、大限干、流年干分层安。
- **杂曜**：地空、地劫、三台、八座、天刑、天姚、红鸾、天喜、孤辰、寡宿等。
- **流曜**：流年三系星、流禄、流羊、流陀、流马等。

> **中州派三细节**：
> 1. 不分甲乙丙级星；一颗「丁级」天月也能改星系性质。
> 2. 戊、庚、壬三干四化与各派不同，遇差异必须标注。
> 3. 用真太阳时；闰月前半月算上月、后半月算下月。

### 2.2 断盘五层

#### 第一层：命宫星系
- 先看命宫是**哪一组星系**：
  - 紫微系六组：紫府、紫杀、紫破、紫贪、紫相、紫微独坐。
  - 其他：机月同梁、杀破廉贪、阳梁昌禄、巨日、太阴、天同、天府独坐等。
- 再看**庙旺落陷**：同一颗星，庙旺与落陷是两个故事。
- 例：紫微独坐午宫＝极向离明（贵）；落陷加羊陀＝自负孤僻。

#### 第二层：三方四正
- 命宫 + 财帛 + 官禄 + 迁移。
- **吉星相会成格，煞忌冲破破格**。
- 常见格局：机月同梁（稳定）、杀破廉贪（动荡开创）、阳梁昌禄（考试功名）、紫府同宫（稳重）、火贪/铃贪（横发）、石中隐玉（巨门子午）。

#### 第三层：十二宫互涉
- 田宅 ↔ 财帛（不动产与现金流）
- 迁移 ↔ 事业（外出与工作）
- 福德 ↔ 情绪/财运（心态影响决策）
- 夫妻 ↔ 事业（伴侣影响事业）
- **不单看一宫**：论事业不能只看事业宫，论疾病不能只看疾厄宫（紫云「打破十二宫」）。

#### 第四层：四化引动
- **本命四化**：定先天底色。
- **大限四化**：定十年起伏。
- **流年四化**：定当年祸福。
- 看四化**飞入哪一宫、冲哪一宫**：
  - 化禄入财帛 → 财源机会
  - 化权入官禄 → 掌权竞争
  - 化科入命 → 名声贵人
  - 化忌入夫妻 → 感情阻滞

#### 第五层：条件输入（太岁入卦七层）

**基础操作**：需要对方**生年**（年干 + 年支）；取对方年干四化、禄存、羊陀，代入其**生年地支所在宫**；看四化落入我命宫/三方/相关宫——化禄有助、化权支配、化忌有碍。

| 层 | 名称 | 做什么 | 文献/难度 |
|---|---|---|---|
| 1 | 入卦起手式 | 代入对方年干四化、禄存、羊陀，看与我命宫/三方 | 入门 |
| 2 | 时间差变式 | 同一组人，因介入先后不同，结果不同 | 中 |
| 3 | 空间挪移式（同步行限） | 两人是否同一大限相遇，同步则互动深 | 中高 |
| 4 | 借盘观虎式（相对行限） | 借对方盘看其父母/兄弟/朋友/姻缘 | 高 |
| 5 | 斗转星移式（变盘） | 「帝星动，则列宿奔驰」；入卦后整盘变盘，再叠基本资料、相对/同步行限 | 极高；门人自述3–7年+上千盘 |
| 6 | 太极八卦式 | 太极生两仪…生八卦；分辨同年认识的三四人；衍生庖丁解牛式/乾坤变法 | 极高；需易经理学 |
| 7 | 乾坤大挪移式 | 门人自述「三分实七分虚，尚无完整心法」；只登记存在 | 文献不足 |

**八条「同年同角色怎么分」**（门人整理）：
1. 入卦对象须与案主密切互动，越密越显。
2. 同年次但角色不同，基础宫不同，吉凶不同。
3. 同年次、同角色、性别不同：南斗应男、北斗应女。
4. 同年次、同角色、同性别：应验在案主较有感觉者。
5. 喜欢程度也一样：以出现先后分；北斗应验先者，南斗后者。
6. 出现时间也一样：以性格刚柔分；北斗应验较刚强者。
7. 连性格也一样：门人称「仍有办法」，但「顾及师门规定，有所保留」——到此为止，不猜。
8. 铁律：入卦是「加参数」，不是「换命盘」；本命盘仍是主盘。

> **取舍**：1–4 层可教可用；5–6 层只讲结构、不教操作；7 层只登记。引用 5 层以上须标「门人整理，非紫云原文逐字」。
>
> **紫云铁律**：命身宫为表，太岁宫为里；打破十二宫固定看法。

## 三、风水堪舆

### 3.1 形峦五步（杨筠松—林来锦系）

#### 第一步：寻龙
1. **祖山**：龙从何处起（远祖/少祖）。
2. **过峡**：龙脉束气处；看护从、土色（五色土为贵）。
3. **剥换**：凶星（禄文廉破）剥换成吉星（贪巨武辅弼）。
4. **入首**：最后一段落脉；看是「直来/横来/回龙」。

> 口诀：「龙若真时穴亦真，龙不真兮少真穴。」

#### 第二步：认星（九星形体）
| 星 | 形体 | 吉凶 | 结穴 |
|---|---|---|---|
| 贪狼 | 如笋、如笔 | 吉 | 乳头 |
| 巨门 | 如覆钟、如屏 | 吉 | 窝中 |
| 禄存 | 如顿鼓、有脚 | 凶（可转吉） | 梳面/覆金/顿鼓 |
| 文曲 | 如蛇行、如波浪 | 凶 | 坪中/掌心 |
| 廉贞 | 如火焰、尖耸 | 凶（可作祖） | 犁头 |
| 武曲 | 如覆釜、圆净无脚 | 吉 | 钗钳 |
| 破军 | 如走旗、歪斜 | 凶 | 戈矛 |
| 左辅 | 如幞头、如驼峰 | 吉 | 燕窝 |
| 右弼 | 隐迹、如惊蛇入草 | 吉 | 坦平 |

> **五吉四凶**：贪巨武辅弼吉，禄文廉破凶；廉贞作祖、剥换出五吉，可结大地。

#### 第三步：点穴
1. 按后山星体定「结穴位置」（见上表）。
2. 用**窝、钳、乳、突**四象校验穴形。
3. 用**吞、吐、浮、沉**定深浅：
   - 阳刚太过 → 深藏（吞）
   - 阴湿 → 高浮（吐）
4. 看**证佐**：前朱雀（案朝）、后玄武（垂头）、左青龙（蜿蜒）、右白虎（驯服）。

#### 第四步：察砂
- **四兽**：青龙（左）、白虎（右）、朱雀（前）、玄武（后）。
- **要求**：龙虎比和、不逼不压、不反背；玄武垂头、朱雀翔舞。
- **再看**：官星（朝山后）、鬼星（穴后）、禽星（水口）、曜星（龙虎外）。
- **现代映射**：左邻楼、右邻楼、前方明堂/道路、后方靠楼。

#### 第五步：观水
- **水口**：收得紧则气不漏，收得松则气散。
- **水形**：环抱有情为吉，反弓直冲为凶。
- **平洋**：「高水一寸即是山，低水一寸水回环」「两水夹处是真龙」。

> **形家口诀**：「有形必有灵，有象必有应」；不用罗盘、不涉八卦，仅凭双眼观形辨势（林来锦）。

### 3.2 玄空飞星七步（蒋大鸿—章仲山—沈竹礽系）

#### 第一步：判元运
- **三元九运**：每运 20 年，三元共 180 年。
- 近期：七运 1984–2003；八运 2004–2023；**九运 2024–2043**。

#### 第二步：排运盘
- 当运星入中，**顺飞**九宫（洛书轨迹：中→乾→兑→艮→离→坎→坤→震→巽）。
- 例：九运 → 9 入中，顺飞。

#### 第三步：测坐向
- 罗盘定**二十四山**；每山 15°。
- **正向**：每山中间 9°。
- **兼向**：靠左/右各 3°（如子山午向兼癸丁）。
- **空亡**：压两山交界线＝小空亡；压两卦交界线＝大空亡（大凶，不可用）。

#### 第四步：排山盘、向盘
1. 取**坐宫运星**入中 → 山星。
2. 取**向宫运星**入中 → 向星。
3. 按该山**三元龙**（天元/地元/人元）的阴阳定顺逆：
   - 阳顺飞，阴逆飞。
4. 山星或向星为 **5** 时：5 无二十四山阴阳，按运盘测出的山向定阴阳。

#### 第五步：兼向替卦
- 兼向时，用**替星**代替本星入中。
- **沈氏替星诀**：
  > 子癸并甲申，贪狼一路行；
  > 壬卯乙未坤，五位为巨门；
  > 乾亥辰巽巳，连戌武曲名；
  > 酉辛丑艮丙，天星说破军；
  > 寅午庚丁上，右弼四星临。
- 替星对应：贪狼 1、巨门 2、武曲 6、破军 7、右弼 9。
- 顺逆仍依原山阴阳。
- **中州派替卦诀**略异（省重复山），遇差异标注。

#### 第六步：判格局
| 格局 | 条件 | 吉凶 |
|---|---|---|
| **旺山旺向** | 当令山星到山、当令向星到向 | 大吉（需背山面水） |
| **上山下水** | 当令山星到向、向星到山 | 大凶（形合可缓解） |
| **双星会向** | 山星顺飞、向星逆飞 | 旺财不旺丁 |
| **双星会坐** | 山星逆飞、向星顺飞 | 旺丁不旺财 |
| **合十** | 山向运三星两两相加为 10 | 吉 |
| **伏吟/反吟** | 飞星与元旦盘同位/对冲 | 凶（主停滞/反复） |
| **三般卦** | 一四七、二五八、三六九 | 逢凶化吉 |
| **七星打劫** | 双星会向 + 离/坎宫父母三般卦 | 争议极大，存目 |

#### 第七步：收山出煞 + 城门 + 入囚
- **收山**：山上旺星/生气星宜高处（实物：柜、床、山）。
- **出煞**：山上衰死星宜低处/水；向上衰死星宜高处。
- **城门**：向首两邻宫若有水口/路口，可借旺；同元龙者为正城门。
- **令星入囚**：当运旺向星落中宫 → 宅运终，需改向/换天心。
- **一四同宫**：一白与四绿同宫 → 文章科甲。

### 3.2B 罗盘实测七步（梁兴扬《罗盘使用教学》实操）

> 只取测量法，不取断语/化解物。兼向阈值：课程 ±5°，沈氏 ±3°，须标注。

1. **立极**：规则房取对角线交点；不规则房拆规则块，按面积加权求中心。
2. **避磁**：远离冰箱、微波炉、金属家具、高压电塔；罗盘水平（气泡居中）。
3. **定基准**：天心十道线与后墙平行；磁针与海底鱼线（子午线）重合。
4. **读坐山**：子午线压哪一山即坐山；对应后天卦（子壬癸坎、戌乾亥乾、丑艮寅艮、辰巽巳巽、丙午丁离、未坤申坤、庚酉辛兑、甲卯乙震）。
5. **判正兼**：每山中间 9° 正向；左右 3° 兼向（沈氏）；课程以偏离中线 ≥5° 为兼向。
6. **高低层**：低层站门外 3 步（1.5m），以门所在墙体中线为准；高楼站正门 7 步（3.5m），以大厦主结构为准，单元加偏角；不在楼内测（钢筋干扰）。
7. **记录**：度数、二十四山、正/兼、测量位置、天气与干扰源。

**该课错版（已核）**：
- 艮卦段落误抄离卦（写成「艮卦五行属火、丙午丁三山」；实为土、丑艮寅）。
- 七运坐壬向丙例：标准洛书飞星七入中得坎三、离二，课程写坎二、离三。
- 结论：只取测量法，不取案例与断语。
