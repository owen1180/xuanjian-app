# 01 · 著作与理论体系

> 记录三家实战派可查证的著作、核心主张与理论骨架。
> 可信度标：★★★ 一手著作/本人公开案例；★★ 权威转述/辞书；★ 网络综述（需交叉验证）。

---

## 一、奇门遁甲

### 1.1 张志春《神奇之门》
- **可信度**：★★★（多篇独立文章转引同一套「纸上快速起局法」，步骤一致）
- **核心贡献**：把奇门起局从「查表/师传」变成**可纸面复现的十步流程**；以「科学视角」解释奇门，推动通俗化。
- **起局十步**（原文转引，见 `03-frameworks.md`）：
  1. 阳历转干支；2. 定阴阳遁与局数；3. 画九宫；4. 布三奇六仪；5. 找旬首定值符值使；6. 值符随时干；7. 布九星；8. 值使随时宫；9. 布八门；10. 布八神。
- **定局**：拆补法（按日干支符头定上/中/下元），另有超神、接气、置闰之说。
- **局限**：书中案例偏「原理演示」，商业/现代分类不如杜新会、石定坤细。

### 1.2 杜新会《奇门遁甲现代实例精解》《周易与商战》
- **可信度**：★★★（本人及研究会的公开案例，含完整局盘与分析依据）
- **核心贡献**：
  - **用神分类**：日干＝求测人；时干＝事体；年命＝当事人；六亲/专占用神另取。
  - **现代场景分类**：婚姻、事业、财运、疾病、官司、升学、破案、商战。
  - **断案体例**：先列局盘（时间、阴阳局、旬首、值符值使），再逐条「分析依据」，最后复盘。
- **代表案例**：难产案（2009-07-04）、破案（1996-05）、商战降 300 万（1999-01-01）、升学（2021-06-04）。
- **局限**：案例多为「断验后公开」，缺失败案例统计。

### 1.3 石定坤《奇门遁甲对商业预测的指导性研究》《奇门遁甲对商业投资的指导性研究》
- **可信度**：★★★（著作信息、出版社、ISBN、公开活动可查）
- **核心贡献**：
  - 师承张志春；分**数理奇门**与**法奇门**，本协议只取数理。
  - 用**西方统计学/归纳法**研究奇门商业预测：成功概率、用神主次、案例共性、**误差成因（时间判定偏差等）**。
  - 商业应用：投资、事业、人生决策；剑桥哈默顿学院「奇门遁甲商业应用」研讨会（2019）。
- **局限**：具体样本量、成功率、误差分布未读到原文；本协议不引用其数据，只取思路。

### 1.4 霍斐然《斐然数术集》
- **可信度**：★★★（目录、出版社、生平可查）
- **结构**：奇门遁甲实用基础、太乙式、大六壬、中六壬参易辨方、中六壬天罡掌诀、黄帝阴符经、飞宫小奇门（附占例）、周易小成图。
- **核心贡献**：三式（太乙/六壬/遁甲）融会；独创**小成图**——只用象数、不涉五行、不换算日历，以「阖、辟、往、来」断吉凶。
- **本协议用法**：只作旁证与「另一条路」的参照，不展开小成图排法。

## 二、紫微斗数

### 2.1 王亭之（谈锡永）中州派
- **可信度**：★★★（《紫微斗数讲义》《安星法及推断实例》等，原文段落可查）
- **核心主张**：
  1. **重星情，不单星断**：先吃透星曜本性 + 庙旺落陷，再看宫位与搭配。
  2. **六十星系**：十四主星固定组合成六十组，格局是星系互动的结果，不是死口诀。
  3. **四化流转**：本命四化定底色，大限/流年四化定引动；化禄机遇、化权掌权、化科名声、化忌阻滞。
  4. **三方四正 + 宫垣互参**：命宫定性格，三方四正定格局，十二宫互涉定六亲事业。
- **技术细节**：
  - 三系星曜共 145 颗，常用 115 颗；分正曜/辅佐煞/化曜/杂曜/流曜五类。
  - **不分甲乙丙级**：一颗「丁级」天月也能改变星系性质（如廉贞贪狼守疾厄，见天月主鼻敏感）。
  - **安星掌诀**：数手指安星，不依赖查表。
  - **戊、庚、壬三干四化与各派不同**。
  - 用**真太阳时**；闰月前半月算上月、后半月算下月。
  - **不认宿命**：只说「某年会发生什么性质的事」，不说「某年一定离婚」。
- **局限**：中州派口诀有师传成分，公开版本与口传可能有差异。

### 2.2 紫云「太岁入卦法」
- **可信度**：★★★（门人整理七层心法、著作导读可查）
- **核心贡献**：
  1. **太岁入卦**：取对方生年干四化、禄存、羊陀，代入其生年地支宫，看与我命宫/三方的作用。
  2. **命身宫为表，太岁宫为里**：真正行事作风常在太岁宫。
  3. **打破十二宫固定看法**：论疾病不只看疾厄宫，十二宫都可能；论事业不只看事业宫。
  4. **条件输入**：论疾病需父母资料（体质遗传）；论子女需配偶与子女生年；论关系需双方生年。
  5. **斗数可看风水**：加入方位思考，技巧与斗数原则相同。
- **七层心法**（门人整理）：入卦起手式 → 时间差变式 → 空间挪移式（同步行限）→ 借盘观虎式（相对行限）→ 斗转星移式（更高层，本协议不展开）。
- **局限**：七层为门人整理，非紫云原文逐字；高层技法争议大。

### 2.3 慧心斋主 / 紫微杨
- **慧心斋主**：20 世纪 80 年代台湾，以浅白白话著作推广紫微，降低入门门槛。可信度 ★★。
- **紫微杨（杨君泽）**：香港，著《紫微径》《紫微闲话》，港台有影响。可信度 ★★。
- **本协议用法**：只作「白话解释」的参照，不取其断语。

## 三、风水堪舆

### 3.1 杨筠松《撼龙经》《疑龙经》
- **可信度**：★★★（原文可查；作者归属有争议，四库提要已指出）
- **核心贡献**：
  - **九星分类**：贪狼（如笋）、巨门（如覆钟）、禄存（如顿鼓有脚）、文曲（如蛇行）、廉贞（如火焰）、武曲（如覆釜无脚）、破军（如走旗）、左辅（如幞头/驼峰）、右弼（隐迹）。
  - **五吉四凶**：贪巨武辅弼为吉，禄文廉破为凶；廉贞作祖剥换出五吉，可结大地。
  - **《撼龙经》认龙**：高山认星峰，平洋看水势；「两水夹处是真龙」。
  - **《疑龙经》点穴**：上篇干中寻枝（关局水口为主）、中篇寻龙到头（面背朝迎）、下篇结穴形势（疑龙十问）。
  - **穴形四象**：窝、钳、乳、突；深浅用吞、吐、浮、沉。
- **局限**：作者归属存疑；版本多，注解差异大（叶九升、高其倬等）。

### 3.2 蒋大鸿《地理辨正》— 章仲山《地理辨正直解》《心眼指要》— 沈竹礽《沈氏玄空学》
- **可信度**：★★★（著作、师承、刊刻年代可查）
- **章仲山**：
  - 无常派创始人，师承蒋大鸿，清代玄空六大派（无常/滇南/苏州/上虞/湘楚/广东）之佼佼者。
  - **核心主张**：「峦头为体，理气为用」「眼以形言，体也；心以理言，用也」；形气并重，因形求气。
  - 著作：《地理辨正直解》（1821）、《心眼指要》（1836）、《天元五歌阐义》、《玄空秘旨批注》、《阴阳二宅录验》。
- **沈竹礽**：
  - 靠研究蒋大鸿著作自学，后以重金借阅章仲山后人秘藏《阴阳二宅录验》，手抄悟得挨星，成《沈氏玄空学》。
  - **核心框架**：三元九运、运盘、山盘、向盘、挨星、替卦（坤壬乙诀）、旺山旺向/上山下水/双星会向/会坐、城门、七星打劫、收山出煞、令星入囚。
- **王元极**：清末民初四川名家，三元玄空，被誉「蒋大鸿、章仲山后第一人」。
- **局限**：玄空派别多，替卦诀沈氏与中州派略异；七星打劫争议极大。

### 3.3 林来锦《形家长眼法》
- **可信度**：★★（书目、目录、讲义公开；属当代商业课程，需注意营销成分）
- **核心主张**：
  - 「有形必有灵，有象必有应」；不用罗盘、不涉八卦，仅凭双眼观形辨势。
  - 以**四兽（青龙/白虎/朱雀/玄武）**为核心，配合龙法、水法、形煞；大成篇加勾陈、螣蛇。
  - 结构：四兽总断 → 逼龙逼虎/龙虎比和 → 明堂/案山/朝山/水口 → 水法砂法 → 看地四诀窍 → 五步断地 → 阳宅四法则 → 各类断法。
- **局限**：课程营销色彩重；「断病」类内容需严格转译为「查什么科」。

### 3.4 王瑞民「时空风水」/ 杨潇
- **王瑞民**：提「时空风水」，形势与理气、空间与时间结合。可信度 ★★。
- **杨潇**：国际易学联合会，侧重形峦讲授推广。可信度 ★★。
- **本协议用法**：只作「现代融合」的参照，不取具体断语。

## 四、三家共同的「实战派」特征

1. **可复现**：起局/安星/排盘都有固定步骤，不靠「灵感」。
2. **重条件**：先要数据（时间、坐向、生年），数据不够不断。
3. **重验证**：案例要能复盘，断错要写「为什么错」。
4. **重边界**：不包治百病，不越医疗/法律/投资。
5. **重流派标注**：知道自己用的是哪一派，不把一家当唯一。
