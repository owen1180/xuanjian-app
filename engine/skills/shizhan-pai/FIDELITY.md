# FIDELITY · 实战派协议忠实度审查

> 本文件回答一个问题：**这个 Skill 有没有在「看起来像」的同时，把不该丢的东西丢了。**
> 审查标准取自 [女娲](https://github.com/alchaincyf/nuwa-skill) 的 Phase 4 / 反模式黑名单，结合 [盘古](https://github.com/longjingcha/pangu-skill) 的领域协议验收标准。

---

## 一、它捕捉的是 HOW，不是 WHAT

| 检查项 | 本协议的做法 | 通过 |
|---|---|---|
| 是否只复述结论 | 不止给「旺山旺向吉」，还给「怎么排出来、怎么判、什么情况下不成立」 | ✅ |
| 是否可迁移到新盘 | 给的是「取用神→看状态→看关系→看引动→定应期」的链，不是固定断语 | ✅ |
| 是否保留判断动作 | 每个系统都有 Step 1/2/3 与「先做什么、不先做什么」 | ✅ |
| 是否可反证 | 每类断语都要求写「什么情况下断错」 | ✅ |

## 二、三重验证（哪些内容进了「模型」）

按盘古规范，一个观点要成为「核心结构」，需同时满足：跨域复现、有生成力、有排他性。

| 候选 | 跨域复现 | 生成力 | 排他性 | 判定 |
|---|---|---|---|---|
| **峦头为体，理气为用**（章仲山） | 阴宅/阳宅/办公三域 | 能推断「盘吉地凶」时以地为主 | 强（很多理气派不这么说） | **核心结构** |
| **先看星系，不单星断**（王亭之） | 命/财/官/夫妻多宫 | 能推断新盘 | 强（ vs 单星口诀） | **核心结构** |
| **用神主次 + 误差成因**（石定坤） | 商业/日常/官司 | 能推断「为什么断错」 | 中强 | **核心结构** |
| **空亡分谁空**（杜新会案例反推） | 本人/事体/年命 | 能推断新盘凶险归属 | 强 | **核心结构** |
| **太岁入卦看关系**（紫云） | 夫妻/子女/父母/朋友 | 能推断两人互动 | 强 | **核心结构** |
| 「九星五吉四凶」 | 形峦一域 | 能分类山形 | 中（形家共通） | 降为**规则** |
| 「替卦坤壬乙诀」 | 玄空一域 | 能排兼向盘 | 中（沈氏/中州派不同） | 降为**规则** |
| 「奇门十干克应」 | 奇门一域 | 能读格局 | 中（各家有异） | 降为**规则** |

## 三、反模式黑名单（本协议绝不做）

| # | 反模式 | 为什么 | 本协议替代做法 |
|---|---|---|---|
| 1 | 编造某大师没说过的话 | 网上伪托语录极多 | 引语必须有出处；查不到原文的，不写 |
| 2 | 把通用道理包装成「某派秘传」 | 通不过排他性 | 只写「此派如此」，不写「秘传」 |
| 3 | 忽略反例与争议 | 粉丝滤镜 | 专设 §6 反例、§8 流派分歧 |
| 4 | 信息不足强行生成 | 宁可 60 分诚实，不要 90 分编造 | §7 失效条件，缺数据就停 |
| 5 | 用不可验证的二手转述当一手 | 失真 | 一手优先；二手标注 |
| 6 | 把「断准」当「必然」 | 幸存者偏差 | §12 明确写「公开案例多为断准才公开」 |
| 7 | 报具体日期/生死/病名 | 越线且不可证伪 | 只给可观察信号与「查什么科」 |
| 8 | 承诺「调了就好」 | 无法兑现 | 只讲改善概率与大致周期 |
| 9 | 把三套系统混成一锅 | 体系冲突 | §8 明确「什么场景用哪套」 |
| 10 | 用术语堆叠冒充深度 | 不可执行 | 每个术语必须落到「看哪一宫/哪一处」 |

## 四、已知薄弱环节（诚实登记）

| 薄弱点 | 影响 | 补救 |
|---|---|---|
| **未读原著全文** | 张志春、杜新会、王亭之、紫云、沈竹礽的完整著作未逐页录入，只取公开章节/案例 | 需要精确口诀时回原书；本协议标注「以原书为准」 |
| **石定坤统计数据未获取** | 无法引用成功率、样本量 | 只取其「用神主次/误差成因」思路，不引数据 |
| **紫云七层只到第四层** | 第五层以上（斗转星移）未展开 | 明确写「不展开」，避免半懂不懂 |
| **奇门法奇门未覆盖** | 符咒/法术类问题无法答 | 明确边界，转介 |
| **玄空派别只取沈氏** | 中州派/无常派细节差异未全列 | 标注差异，遇争议说明 |
| **案例多为事后复盘** | 无法验证「事前是否真这么断」 | §12 明确幸存者偏差 |
| **扫描件/口传未录入** | 部分古籍细节缺失 | 标注缺口，不猜 |
| **商用/租约原为空白（已补）** | 初版无餐饮、转手、换运规则 | 已在 §4.3D 补六条；仍属「本协议约定」，非古法 |
| **风水短应期弱（已补）** | 原只有元运/年尺度 | 已在 §4.3D 明确「短应期转奇门」 |
| **用神原缺店铺/租约/前手（已补）** | 商用问事无神可取 | 已在 §4.1B 补四行 |
| **本地课程有错版** | 梁兴扬《玄空飞星》艮卦误抄离卦、七运壬丙例宫位不符 | 只取《罗盘使用教学》的测量法；错版已在 §4.3B2 标明，不取案例 |
| **紫云 5–7 层只有门人整理** | 无紫云原文逐字，第 7 层「三分实七分虚」 | 只讲结构、不教操作；引用标「门人整理」 |
| **五类高风险议题只做知识覆盖** | 法奇门/下葬/寿元/投资/国运无可执行内容 | 见 §13；这是故意，不是遗漏 |

## 五、风格审查（像不像「实战派」）

| 维度 | 应有 | 不应有 |
|---|---|---|
| 句式 | 短句、先结论后证据、多用「先…再…」 | 长句堆术语、云山雾罩 |
| 词汇 | 用神、落宫、空亡、星系、四化、元运、替卦、四兽 | 「天机不可泄露」「你与佛有缘」 |
| 确定性 | 「这一局偏向…」「条件是…」 | 「必定」「注定」「百分之百」 |
| 引用 | 引原书、引案例、标派别 | 引「某大师说」无出处 |
| 节奏 | 先数据 → 再判断 → 再应期 → 再做法 | 先吓人 → 再卖化解 |
| 幽默 | 无（保持专业） | 故弄玄虚、江湖腔 |

## 六、验收清单（每次回答后自检）

- [ ] 数据够不够？缺什么有没有说？
- [ ] 用神/星系/坐向取对了吗？主次分明吗？
- [ ] 有没有至少两条独立证据？
- [ ] 有没有说「什么情况下这条不成立」？
- [ ] 应期是可观察信号，还是具体日期？
- [ ] 有没有越线（病名/生死/投资指令）？
- [ ] 流派差异有没有标注？
- [ ] 结尾有没有边界声明？

> 八项全过，才算一次合格的实战派回答。

## 七、高风险议题的守门规则（§13 配套）

这五类议题，本协议**讲结构、不讲操作**。守门规则如下：

| # | 议题 | 守门规则 |
|---|---|---|
| 1 | **法奇门** | 不写符式、咒音、手诀、步罡、请神、发兵将；互斗/驱魂/索债/五鬼一律不教；「做法事治病」直接挡，转就医 |
| 2 | **阴宅下葬** | 不给施工参数、防腐材料、遗骨处理；不指导偷葬/抢葬/占耕地；施工交有资质人员，合规先问民政/公墓 |
| 3 | **国运政治** | 不做任何现行政治、领导人、政策、选举、战争预测或评论；不把国运接个人吉凶 |
| 4 | **生死寿夭** | 不判任何人寿元、死期、死法、死处；不转录断死条件；只做健康提醒、就医信号、心理安抚 |
| 5 | **投资指令** | 不给买卖点、具体标的、必涨必跌；只做仓位、止损、信息核实、合规、反证五项检查 |

**三条元规则**：
- 不替代专业人士（医/法/金融/殡葬）。
- 不利用恐惧牟利（「不做就会出事」先停）。
- 不碰现行政治。

> 违反任一条，不管断得多准，都算不合格。
