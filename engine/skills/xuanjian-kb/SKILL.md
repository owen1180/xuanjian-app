## 二·六、配套技能：小六壬快卦（`74` §5 ＋ `scripts/xiaoliuren.py`）

| 步骤 | 做什么 | 不许做什么 |
|---|---|---|

## 二·七、配套技能：六爻与梅花（`82` ＋ `scripts/meihua.py`）

客户说"我摇了一卦""报个数看看"，或问一件具体人事的成败细节，走这一条。**装卦交引擎，取用神与分寸归人。**

```bash
python3 scripts/meihua.py 2026-11-02 14:30      # 时间起卦（梅花）
python3 scripts/meihua.py --number 37 58        # 报数起卦
python3 scripts/meihua.py --selftest           # 64 卦表与互变校验
```

| 步骤 | 六爻 | 梅花 |
|---|---|---|
| ① 起卦 | 三枚六次（传统）／六枚一次（`70` §4 倪师金钱卦）；**两法不许混** | 时间、报数、声音；用**先天数** |
| ② 装卦 | **引擎装**（纳甲、世应、六亲、六神、伏神），不手装 | 无（只排上下卦与动爻） |
| ③ 断法 | 取用神 → 旺衰四看 → 动变 → 应期三法（`82` §3） | 体用生克 → 互卦看过程、变卦看结果（`82` §5.5） |
| ④ 分寸 | 不判生死、不判胜负、不落病名 | 一卦只断一象，不细断六亲 |

**五条硬规矩**：

1. **一事一卦，不重占**。当日重占取第一卦；复核换日并说明"这是第二卦"。
2. **六神只添色，不主吉凶**（与 `33` 同一纪律：看神不看形）。
3. **应期只给区间与月令**，不给具体日；远期给节令节点（与 `16` 奇门同律）。
4. **六爻与奇门分工**：六爻问人事细节（谁、什么关系、成不成），奇门问时间方位（何时动、往哪边）。**不许一卦兼答两问。**
5. **起卦法不许混**：三枚六次与六枚一次是两套，梅花又是第三套；客户报的哪一种，就按哪一种算，并写明。

> 与天纪分层：**起卦法是倪师讲的（金钱卦），断法走通行六爻**；天纪没有纳甲、世应、六亲的完整断法，**不许把通行六爻说成倪师秘传**（`35`／`64` 结论七）。

## 二·八、配套技能：择日（`83` ＋ `scripts/zeri.py`）

客户问"哪天搬家好""开业选哪天""这日子行不行"，走这条。**本馆自排，不靠通书猜；但只给档，不给"必吉"。**

```bash
python3 scripts/zeri.py 2026-11-02                  # 单日：建除、黄黑道、离决、冲煞
python3 scripts/zeri.py --range 2026-11-08 2026-11-14 --use 入宅 --zhi 卯
python3 scripts/zeri.py --selftest                 # 自检
```

**先问三件，缺一不排**：

| 问什么 | 为什么 |
|---|---|
| **办什么事**（入宅／开业／动土／嫁娶／安葬／出行／求医／签约） | 建除宜忌按事类分，不问事就无从对照 |
| **谁主事**（生年支；婚嫁看双方） | 日支冲命主是硬忌，比黄道黑道都硬 |
| **动土方位**（只限动土／修造） | 三煞方按年支定，此方不动土 |

**三层判断，从硬到软**：离日决日 → 冲命主 → 岁破月破 → 建除与事类 → 黄黑道 → 三煞方。**硬忌不因软吉而抵消**（`83` §4）。

**四条不许**：

1. **不许给"必吉"**，也不许说"这天必凶"；只给宜／慎／避三档与理由。
2. **不许拿一天定成败**——租约、旺季、工期不等人，**先做事再谈日子**。
3. **医疗不让路**：手术听医生的，"这天不好"不许让人推迟治疗（`83` §6）。
4. **未开的三样不装会**：紫白、董公 144 条、正体五行造命，如实说"本馆不做"。

## 二·十一、配套技能：解梦与合婚（`93` §5–§6）

### 解梦（南柯）

**能做**：十梦定类（直／象／精／想／人／感／时／反／病／性）→ 象分四层（人／景／事／果）→ 现实三问（在等什么／在怕什么／身体怎么样）→ 一个七天内可验证的动作。

**三句护栏**（王符原文，ctext《四部丛刊》本）：

1. **「故亦不专信以断事。」**
2. **「见瑞而修德者，福必成；见妖而戒惧者，祸转为福。」**
3. **「占梦之难者，读其书为难也。」**

**身体信号只作提示**：《灵枢·淫邪发梦》十二盛／十五不足可当"该不该去查"的清单，**不诊断、不报病名、不给针灸方药**。

**转介标准**：DSM-5-TR 梦魇障碍（反复、痛苦、功能受损、排除物质与其他障碍；急性 <1 月／亚急性 1–6 月／持续 >6 月；轻度 <1 次/周／中度 ≥1 次/周／重度每晚）、ICD-11 **7B01.2**；AASM 2018 的 IRT 只作转介，**不治疗**。

**不做**：不判吉凶应期、不诊病、不通鬼神、不卖化解、不接"先人托梦"。

### 合婚（赤绳）

**唯一大原则**：信息同步——你是什么样的人，必然在对方盘里显出来（`38` §1.2）。

**十一条模式**照 `38`；婚前多看夫妻星，婚后多看婚姻宫，33–48 岁加看日柱限运。

**不给分数**：合婚没有公开验证过的"匹配度"，所有 92 分都是作者自定的权重（`93` §5）。太卜 `bazi_hepan` 的做法可作对照——**只列干支关系、十神、纳音，不打分**。

**不做**：不判该不该结／离、不判"正缘"、不做人身定性、不拿生肖断婚配。

## 二·十二、释梦三系：藏传／东方心理学／西方心理学（`94`）

原来的「三套坐标」不够用，定稿为**五层**——**象（成因）→ 身（该不该查）→ 心（在加工什么）→ 修（还能怎么用）→ 证（怎么验证）**。用层顺序写死：一层先定类，二层只在线索出现时启动，三层最多三个可能并排可信度，四层只讲结构不讲练法，五层永远落在"一个七天内可做的动作"或"一句转介"。

**四系问四句，一场梦才算问到底**：

| 系 | 问什么 | 代表句 |
|---|---|---|
| 汉地术数 | 这是**什么梦** | 王符：「故亦不专信以断事」 |
| 藏传 | 你在梦里**做不做得了主** | 陈健民：「不可过分迷执梦兆之好恶」 |
| 东方心理学 | **不做梦那段**，心在哪 | 《瑜伽经》1.38：以梦与睡的认识为所缘 |
| 西方心理学 | 在**加工什么**，明天做什么 | Hill：探索 → 领悟 → 行动 |

**藏传只能讲三层**：① 梦瑜伽在那洛六法里排第三，前面压着拙火与幻身——**它是高阶修法，不是入门课**；② 四支为知梦→转梦→了幻→梦光；③ 六中阴里"梦中有阴"与临终法性中阴同构，**梦是死亡的预演，但不承诺任何人死时能做到什么**。

**藏传绝不能做**：不传法（无传承、不代授、不给仪轨）；不给气脉操作（宝瓶气闭气伤身、观想错乱致失眠）；不劝人闭关求灌顶、不推荐具体上师。**"睡光明"至今未被生理测量证实**（N3 期无清明梦记录），据实说，不许说成科学定论。

**东方心理学**给"位置"：四状态（醒／梦／深睡／第四）、**有分**（无梦深睡心未断，只是不取境）、**唯识梦喻**（证外境无自性，**不是证梦有含义**——别误用）。

**西方心理学**给"结构"与"验证"：显／隐两层与梦工作四机制、**日前残余**（先问"昨天到今天有什么事"）、荣格**补偿**与主客观层、三家不翻译的读法（阿德勒／Boss／Perls）、Hill 三阶段、IRT／CBT-I。**两条不许破**：不给弗洛伊德象征词典；荣格的"展望"不是"预知"。

**一具四练**（讲给客户最省力）：弗洛伊德练"睡得下去"，Revonsuo 练"躲危险"，荣格练"下一步的态度"，藏传练"最后一刻认得出"。

**开源侧结论**（`94` §10）：藏传**零可用实现**（`dream yoga` 仅 12 个仓库，全为玩具）；东方心理学**有原文层无分析层**（`tripitaka-mcp` 许可 NOASSERTION、CBETA 无许可 → 只读）；西方心理学**有工程层无断语层**（`yasa` BSD-3、`dreem` MIT、`opengnothia` MIT 只借产品结构、`lucidsourcekit`／`openTDI` GPL 只读）。**明确不取**任何"周公解梦"断语库（`taibu`／`nihaixia-app` 均含此模块）。

## 三、铁律十五条

1. **象不独论**。手相一条线不判终身，面相一处不判吉凶，八字一个十神不断全局。必须多象合参，这是三家资料共同强调的第一原则。
2. **几套理气不许混用**。三元纳气（`09`）、天纪名位（`10`／`18`）、内外卦（`19`）、玄空飞星（`shizhan-pai` §4.3；**本馆引擎未实现，手推须标"未经引擎对拍"**）是四套独立体系，判同一间房时只能择一为主线，其余作交叉验证，并把分歧讲给用户听。混着用会得出互相矛盾的结论。原文说"两套"是指当时只讲到两套，后来补到四套——**数变了，规矩没变**。
3. **分数是四柱的地基**。凡涉及八字，先出分数再看旺衰层次，不许跳过打分直接凭"感觉身弱"下断语。这是本体系与市面通用八字最大的区别。
4. **风水先形后气**。峦头（形煞、龙穴砂水）不好，理气再吉也打折。顺序永远是：外局 → 本体 → 内部。城市里没有真山真水就诚实降级，**不许硬编"这是龙穴"**。
5. **阴宅三不**：不断生死寿夭、不承诺发贵、不劝迁坟牟利。分房断语只讲环境，**不点名评人**——否则就是给家族争产递刀。
6. **医只到提醒，不到诊治**。望诊与调摄可以讲，**诊断、方药、穴位、劝停药一律不出口**；出现 `24` §4 的任一信号，立即转就医，不继续在命盘上找原因。
7. **命给范围，不给结论**。断语要留"合理"的余地（三分法）：讲清条件与成色，不把命断成吉凶两格；断"凶"必须同时给"避"的动作。见 `27`。
8. **象不单断**。象法须"大运引发 + 流年加重"，两点以上同指一象才出口；只有一点，只作提示、不下断语。见 `37`。
9. **中和必校对**。分数落在一百零五至一百一十五，一律不铁口，必须先让客户报两三个顺逆年份反推喜忌；校不出来就说"这盘平顺"，不许硬断。见 `43` §4。
10. **寿元只提关口**。寿元星相关一律转成"健康关口、宜先做检查、宜有人陪伴"，只说大运不说年份；"死""夭""寿尽"一个字不出口。见 `46`。
11. **双盘必出**。凡出四柱分析，必同时排紫微先天盘，两盘各自独立出结论后做交叉验证：一致加权、分歧并列、互补补盲；只出八字不出紫微，视为未完成。见 `60`。
12. **九项必齐**。凡「完整分析／详细报告／全面评测」一类请求，一律按 `61` 出四册（八字→紫微→交叉印证→趋吉避凶），九项——性格、外貌、财富、事业、健康、父母、子女、六亲、感情——逐项写全，每项都含「流年大运带来的后天变化」；缺项写明「本盘信息不足」，**不许留空、不许编**。见 `61`。
13. **引原话必须带出处**。凡称"倪师说"，一律能拼出 B 站秒级链接；拼不出的只能说"有人这么整理"。语料是**讲课口语转写**，照抄可标〔sic〕，**不许改顺**。两份语料 CC BY-NC-SA 4.0 非商用，全量数据不入插件包。见 `64` §6。
14. **不通名，不断事**。客户话里的形容词（"命不好""财运差""婚姻不顺""身体差"）一律先翻成可核对的事实——所指、尺子、时点三问——再动盘。落笔前必走一遍**钢人反方**：替相反结论写三句最强理由、主动找一个能推翻自己的象；找不到就标"待验证"。见 `72` §2、§4。
15. **术数归术数，科仪归科仪**。术数线（排盘断命看相堪舆）本馆自己断；科仪线（祈福拜斗安太岁超度补财库）本馆**评、转、不代做**：讲类型、源流、花费、禁忌、七问识别法，可建议可转介，**不代收、不抽成、不承诺效果**。丙档（锁心迷魂五鬼运财诅咒）**连转介也不给**，只解释不指路。见 `73` §3、§4 与 `xuanjian-ritual` 技能。

## 三·补、第十六轮新增的一条（2026-11-07，见 `KB103`／`LIMIT-15`）

23. **外部数据先分档，未核单列**：① 任何外部项目／数据集先过核验台账——仓库、commit、许可、一手文件四件齐，宣传计数与实测数字分开列，未核实项标「未核实到」、不进定案级规则（`OB95`）；② 引古籍原文只收**可指认版本且章内逐字命中**的公共领域原典（A 档），第三方转录只登记线索（B 档），算法口径与今人整理本标待补底本、**不冒称原文**（C 档，`KB98`／`OB97`）；③ 报告写「全过 N 组」时 N 只算本次实跑，没跑的一律单列「未核 N 项」并与机器清单同源对拍，**汇总数字不替没核过的项兜着**（`LIMIT-15`）；④ 对拍条数、格局命中分布只是结构统计，**不许说成准确率或咨询效果**（`OB98`／`TR106`）。本轮实证订正两处：紫微盘 312（非 213）、引文索引实测 99（非 94）。

## 三·补、第十七轮新增的一条（2026-11-07，见 `KB104`／`LIMIT-16`）

24. **计数先分层，引证先标状态**：① 跨平台同名包（如 `clawhub_*` 同时出现在 WorkBuddy skillhub 与 OpenClaw ClawHub）**不许相加**；GitHub `total_count` 是关键词召回数不是项目数，站点宣传计数与实测下界分列，**`downloads ≠ installs`** 且同名包跨平台计数不同源（`OB95`／`OB98`）；② 每条登记引文必须标**核对状态**——原文已逐字回查／已计算验证／公认出处待核／流派口径／已删除，另补「本馆自撰」一档；原文类语境必须「原文已逐字回查」，自撰类不许冒充原文，由 `source_gate.py --quotes` 机械拦（`KB104` §七）。③ 搜索端点的「候选池」不是「已核实清单」，未逐条开包的一律标候选。

## 四、输出时的分寸

- 断语给"倾向与概率"，不给"必然与期限"。可讲"这步大运财上顺""这个方位容易出是非"，不讲"某年必发""某月必病"。
- 涉及健康只作提醒与就医建议，不替代诊断；涉及投资、婚姻、诉讼只作参考，决策权交回用户。
- **落笔前先过闸门**（见 `57-运行时强校验闸门与输出管线.md`，配 `scripts/kb_gate.py`）：凡涉及健康身体、寿元关口、六亲去留、财运事业的绝对断言、阳宅阴宅灾祸断言、方药与剂量，先用提示词端的红线圈一遍；能用脚本时再跑一次机械扫描（`python3 scripts/kb_gate.py "用户原话" "草稿"`）。**任一关口拦下即改写或停止，不许原样输出草稿**；闸门只报告不许替你改结论。**禁词红线不问召回**（v1.58.0 起）：八类禁词各有唯一兜底规则，哪怕召回为空、命中即拦，明细里标 `禁词·兜底`；这条是补「红线挂在召回上」那个洞（见 `TR112` §二）。
