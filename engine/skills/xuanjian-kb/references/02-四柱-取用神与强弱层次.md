# 二、取用神与强弱层次

## 0. 总方针（先记住这一句）

> **强抑弱补，通关调候，顺势化泄。**

看八字先找病，有什么病治什么病。不是套公式，是抓原局的关键点。

## 1. 六层次的取用路线

### 1.1 偏强（115 – 272 分）

| 成因 | 第一用神 | 说明 |
|---|---|---|
| 比劫导致 | **官杀** | 有官较强时最好不出现七杀；官杀混杂格局一般 |
| 印多导致 | **财** | 财能克印，先制印这个"病" |
| 食伤与官杀混杂 | **财** | 通关 |
| 身强、官杀亦强 | **食神制杀** | 制比化官更优 |
| 身强、官杀明显强过日元 | **印** | 用印化官杀，格局一般 |
| 身强无财、只有食伤 | **财** | 食伤要落到财上才有用 |
| 身强、财亦强 | **官** | 财旺需官护 |

### 1.2 太旺（272 – 435 分）

1. 比劫导致的太旺 → **食伤**为第一用神（顺势化泄）
2. 印多的太旺 → **比劫**（用比劫化印，仍是顺势）

### 1.3 专旺（435 分以上）

满盘生扶（不含中气余气）。**以生扶为第一用神，哪个生扶力量更强就取哪个**。专旺最忌逆势，克泄反而激怒。

### 1.4 中和（105 – 115 分）

真正的中和最难取用。中性特征：顺的时候顺得平淡，不顺的时候也不至于大波折，五行均衡，身体多不错，但成就往往一般——**格局高的人基本都出自五行不平衡**。

三条经验（课程明确标注"未完全成熟"，用时要说明是经验判断）：

1. 月令生扶（比劫、正偏印）→ 以偏旺论，用泄耗
2. 月令泄耗（官、财、食伤）→ 以偏弱论，用生扶
3. 前两条不适用 → 生扶大运用泄耗，泄耗大运用生扶

**实操区间：100–120 分都可看作中和带。**

> ⚠️ **这一句管"宽读"，不管"判档"**。判档仍以 **105–115** 为界（`01` §5、`43` §1 同此口径）。落在 100–105 或 115–120 的盘，属于"带边"，处理办法是：**仍按原档判、但结论降一档，先走 `43` §4 的校对五步再定**。不因为落在 100–120 就直接报"中和"——那一档是全库唯一不许铁口的档（`43` §3）。

### 1.5 偏弱（45 – 105 分）

原则：**生扶为主**。

- 45–55 分：不稳定带，随时可能滑向太弱
- 60 分以下：都要警惕是不是太弱
- 70–110 分：相对稳定，只有稳定带里才敢用生扶

### 1.6 太弱 / 弃命从弱（45 分以下）

- **太弱（假从）**：有一点生扶，但够不到偏弱，十分弱
- **真从（弃命从弱）**：全局无一个字、一个藏干加分，全减分
- 从弱者顺势，不可扶。扶之则反噬。

## 2. 用神的三个级别

| 概念 | 含义 |
|---|---|
| 扶抑用神（格局用神） | 抑强扶弱，平衡五行 |
| 调候用神 | 冬生用火、夏生用水，调气候之偏 |
| 通关用神 | 两强相战，取中间通关之物 |

**用神级别判定**：若调候用神与扶抑（格局）用神一致——比如原局用火、调候也需火——那么走到火的大运，**富贵层次最高**。二者不一致时，以扶抑为主、调候为调。

**调候大运的禁忌**：调候大运不能直接冲克扶抑用神，一旦冲克，层次就降下来了。

## 3. 什么情况下用神会变

稳定度分档：

| 层次 | 稳定性 |
|---|---|
| 太旺、专旺、偏旺（115 以上） | 稳，不易变 |
| 弃命从弱（无一生扶） | 稳，不易变 |
| 太弱 | 不稳，大运再削 → 滑向真从 |
| 偏弱 | 不稳，大运再削 → 滑向太弱 |
| 中和 | 不稳，上下浮动 |

**结论：流年改变不了格局，大运能改。** 一步大运是十年的状态，一个流年达不到改格局的量级；流年只能让某一五行当年偏旺偏弱。

## 4. 断盘顺序（团队统一口径）

1. 排四柱、定真太阳时
2. 打日元分数 → 出层次（`01` 文件）
3. 定病：比劫多？印多？官杀混杂？食伤无财？
4. 按层次取用神，标注级别（扶抑/调候是否一致）
5. 校大运：看哪步大运让层次跨档
6. 校流年：在跨档大运里找应期
7. 落到具体事项：财富（`03`）、事业（`03`）、婚姻（`03`）、六亲（`03`）、健康（`03`）
8. 若用户同时提供手面相照片或户型，交主理人做合参（`14`）

## 5. 常见误用

- ❌ 见身弱就补、见身强就泄，不看"病"在哪。印多的身强补财才是治本。
- ❌ 中和八字硬取一个用神就下重断。中和本来波动小，断语要相应收敛。
- ❌ 把调候当万能。冬天生人一律用火是错的，得看扶抑是否也要火。
- ❌ 用流年去改格局结论。流年只断当年顺逆，不改层次。
