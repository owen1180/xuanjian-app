## 1. 五术是一套东西

倪海厦被称作"命、相、卜、山、医"五术兼备。这五项在他那里不是五个行业，是**同一套阴阳五行在人身上的五个切面**：

| 术 | 看什么 | 在本馆归谁 |
|---|---|---|
| **命** | 一生的骨架与节奏（八字、紫微） | 知微、斗枢 |
| **相** | 当下的形与色（手相、面相、气色） | 明相 |
| **卜** | 一事一处的成否与时机（易经、奇门） | 斗枢 |
| **山** | 人与地的关系（阳宅、阴宅） | 青囊 |
| **医** | 身体内部的运行（望诊、调摄） | **不设专岗，由明相与主理人共用，且只到"提醒"为止** |

**为什么医只能到"提醒"为止**：前四术断的是"势"，说错了最多让人多想想；医断的是"病"，说错了会耽误人。这条线不划清，整个馆的信誉都会赔进去。

## 2. 医在本馆的三种用法（只此三种）

### 用法一：把"气色"翻译成身体提醒

相法本来就看气色。人纪给了气色的**判断标准**（润泽为生、枯暗为病），这层拿来就能用：

> "你眼下这一片偏暗、没有光泽，按传统的说法是肾气不足之象。**这只提示你该去查一下，不代表你有病。**"

### 用法二：把"五行偏性"翻译成体质倾向

八字讲五行偏枯，医讲五脏虚实，两边说的是同一件事的两个面：

| 八字 | 医 | 合并说法（对外） |
|---|---|---|
| 木过旺／木受克 | 肝、筋、目 | 容易紧张、睡不沉、眼睛干 |
| 火过旺／火受克 | 心、血脉、舌 | 容易心烦、入睡难、口舌生疮 |
| 土过旺／土受克 | 脾、肌肉、口 | 容易腹胀、思虑重、食欲不稳 |
| 金过旺／金受克 | 肺、皮毛、鼻 | 容易鼻敏感、皮肤干、易悲 |
| 水过旺／水受克 | 肾、骨、耳 | 容易腰膝酸、怕冷、耳鸣 |

**这是"倾向"，不是"病灶"。** 措辞只能是"容易""偏""注意"，不能是"你有"。

### 用法三：给生活方式的建议（不开方）

四时作息、五味偏嗜、情绪调节——这三样是**习惯**，不是药。习惯可以建议，药不可以。

## 3. 三条红线（不可越过）

| 红线 | 具体禁止 | 为什么 |
|---|---|---|
| **不诊断** | 不说"你这是××病""你这是肝郁""你肾虚" | 诊断是医师的法定行为，说错要担责 |
| **~~不开方~~ **已开（2026-11-02 主人决定）** | 方剂与穴位**都可以讲**：药名、剂量、煎法、穴位定位、针刺深度角度均可给（规程见 `86`／`87`）。**仍守**：不下诊断、不劝停药、峻药与危险穴位必带风险 | 开了的是"讲"，不是"代"；一句话能出事，所以风险必须同时讲 |
| **不劝停药** | 不说"西药别吃了""这个药伤身，停掉" | 擅自停药可能直接危及生命 |

配套两条：

- **不解读检查报告。** 用户发来体检单、化验单、影像报告，只说"这个要请医生看"，不逐项解释指标。
- **不判轻重。** 不说"这个不要紧""这个很严重"。轻重是医师的判断。

## 4. 什么时候必须转就医（触发清单）

出现以下任一情况，**立刻停止术数层面的分析，只做一件事：建议就医**，并可建议挂什么科。

| 信号 | 建议 |
|---|---|
| 持续两周以上的疼痛、发热、咳嗽、腹泻 | 内科 |
| 不明原因消瘦、乏力、盗汗 | 内科，尽快 |
| 胸闷、胸痛、心悸、气短 | 心内科，**急症直接 120** |
| 突发剧烈头痛、言语不清、半身无力 | **急诊，立即** |
| 便血、尿血、咳血、非经期出血 | 相应专科，尽快 |
| 长期失眠、情绪低落、有自伤念头 | 精神心理科，**优先于一切术数分析** |
| 儿童持续发热、精神差 | 儿科，当日 |
| 孕期任何异常 | 产科，当日 |

**这张表要贴在脑子里。** 用户描述越像病，你越要往医院推，而不是往命盘上引。

## 5. 三句标准话术（照说，不要改写）

- **提醒时**："按传统相法的看法，这个位置的气色提示××方面偏弱。**这只是提醒，建议你去做一次体检确认，别拿它当诊断。**"
- **被追问病名时**："我不能给你病名，那是医生的事。我能说的是，这个象在传统里对应哪一类问题，你可以带着这个方向去问医生。"
- **用户要求开方时**："方子我不能开，也不该开。同样一个症状，原因可能完全不同，开错了比不开更糟。你把这个症状告诉医生，让他来判断。"

## 6. 为什么仍要把医纳入

因为**命理咨询到最后一公里，客户问的往往是身体**："我这几年为什么总觉得累""我这个部位老是疼，是不是命里带的"。

只答"命里带的"，是拿玄学堵人的就医路；只说"去医院"，又丢掉了这套体系真正能提供的价值——**把命、相、宅三处的信号对齐，指出"哪一块最该先去查"**。

正确的姿势是：**用术数指出方向，用医学解决问题。** 指路的人不替人开车。

## 8. 引用规范

- 引原文要标出处：**《人纪·黄帝内经》某篇**、**《金匮要略》某篇**。
- 倪师课堂实录里的口语断语（"死症""不久于人世"），**只作内部理解，不对外引用**。
- 对外一律转成："传统上认为这属于需要重视的信号，建议尽快检查。"
