## 1. 五句结论（先给答案）

1. **卜**：有确定性排盘基线（太卜 `taibu-core`，MIT；命盘 MCP，Apache-2.0），**没有断法基线**——断法仍归人。
2. **时**：奇门与择日都有可对拍的引擎，但**流派口径必须先钉死**（拆补／茅山、转盘／飞盘、子初换日）。
3. **名**：**官方字表与姓名统计可用**（8105 字表、公安部姓名报告），生成器不可抄，五格仍不断命。
4. **婚**：**没有一个公开验证过的"匹配度"**；最流行的 Python 八字库，合婚模块是生肖合婚——正是本馆判为误用的那一类。太卜 `bazi_hepan` 只列事实不打分，与本馆同律。
5. **梦**：**没有可用的中文解梦引擎**；能借的是古典分类（十梦、六梦、十二盛十五不足）与临床转介标准（DSM-5-TR、ICD-11 7B01.2）。

## 2. 卜：六爻、梅花、小六壬

### 2.1 可用基线

| 项目 | 许可 | 能借什么 | 不能借什么 |
|---|---|---|---|
| `hhszzzz/taibu` → `packages/core` | **MIT**（仓库根为 AGPL-3.0-only，`packages/core`／`mcp`／`mcp-server` 单独 MIT） | `liuyao`、`liuyao_line`（纳甲六亲六神、日月作用、空破暗动、化变伏神）、`meihua`、`xiaoliuren` 的**排盘事实** | 断语、吉凶判词、AI 解读模板 |
| `ChesterRa/mingpan` | **Apache-2.0** | `liuyao_basic`、`meihua_basic`；README 自述 **"Facts only — interpretation is left to..."** | 同上 |
| `Johnson-Jia/liuyao-divination` | 未核（`82` 只借它的十一章目录作检查表） | 形态清单（暗动、日破、三合、墓库、四神、反伏） | 代码与文本 |

### 2.2 读到的三条差异（必须写进断法）

1. **六枚法没有动爻。** 外部引擎多按三枚六次设计；客户给"六个铜板撒一排"的结果，不能直接套三枚法的动变层（`82` §1）。
2. **梅花互卦，各家不一。** 命盘 MCP 明确写：对乾、坤仍按常法取互，**未采"乾坤无互，互其变卦"**这一支。本馆遇到乾坤互卦要说明"此处两说并存"，不裁断（`82` §5.4）。
3. **小六壬事类不参与计算。** 太卜把事类与课式分开，与 `74` §5.5 同律；凡"按事类调宫"的实现，不是小六壬。

### 2.3 本馆取舍

- **能借**：排盘字段、空破暗动口径、互卦分歧的写法、`facts only` 的边界声明。
- **不能借**：任何"某爻主吉／主凶"的断语库；任何把六神直接当吉凶的写法。

### 3.1 对拍前必须先钉三件事

1. **拆补还是茅山**（置闰法不同，局数会差）。
2. **转盘还是飞盘**（星门排布不同）。
3. **子初换日还是子正换日**（23:00–24:00 的日柱与时柱会差一天）。

**这三件不写清，两个引擎对不上不是谁错，是问的不是同一件事。**

### 3.2 本馆的边界不变

- 奇门走**时家、转盘为主**；用到别家就标明。
- 择日仍按 `90` §6 的**七层次序**：离决 → 冲命主 → 岁破月破 → 建除 → 黄黑道 → 三煞 → 黄历三栏。
- 外部引擎只作**第 7 层参考与事实对拍**，不进硬忌层；**硬忌不因软吉抵消**这一条不改。

## 4. 名：三才五格与取名

### 4.1 官方依据（这一轮最实的补强）

| 来源 | 关键事实 | 怎么用 |
|---|---|---|
| **《通用规范汉字表》**（国发〔2013〕23号） | 共 8,105 字：一级 3,500／二级 3,000／三级 1,605；"社会一般应用领域的汉字使用应以本表为准" | **表外字一律不用**——上不了户口、打不出登机牌，名字再好也是麻烦 |
| **公安部《全国姓名报告》**（2019／2020／2021） | 2020 年新生儿 1,003.5 万；名字用字前五"梓、子、宇、辰、一"；男名榜首"奕辰"、女名榜首"一诺"；三字名占比 >90%，二字名降至 6.3%。2021 年前五字"泽、梓、子、宇、沐"；男"沐宸"、女"若汐" | **避开近十年高频字**有了官方依据，不再只凭"起名 APP 都在推"；重名风险可当场举证 |

> 引用口径：只引统计事实与排名，**不把"热门"说成"好"**。热门字的反面不是冷僻字，是**有来历、能解释、不撞车**。

|---|---|---|---|
| `breezyreeds/kangxi-strokecount` | **MIT** | 康熙笔画对照表（已在 `88` 用过） | — |

### 4.3 结论

- **字表与统计能用，生成器不能抄，五格仍不断命**（`84` 的立场一个字不改）。
- 五格照算：客户拿 App 分数来问，仍按 `84` §4.2 的**三层回答**；简繁两版三才会变这个例子继续用。
- 新增一条可执行动作：出候选前先查**近三年高频字**（公安部报告前 50 字），撞车的直接标风险。

| 项目 | 许可 | 它怎么做 | 本馆怎么判 |
|---|---|---|---|
| `taibu` → `bazi_hepan` | **MIT** | 两人各排四柱，列两盘干支关系、日主互见十神、日柱与年柱关系、年命纳音与五行互补；**明确"只给事实不打分"** | **同律**。这正是"两造事实表"该有的样子 |
| `china-testing/bazi` | **无许可证** | 1.5k★ 的 Python 八字库，合婚模块是**生肖合婚**（`shengxiao.py`） | **明确不取**。年支只是加分项，拿生肖断婚配是 `38` §4 列的误用 |
| `sxin0/Bazi_Hehun` | **无许可证** | 只有"八字合婚"四字，无文档、无基准 | 只读；不作依据 |

### 5.1 一个必须说出口的行业事实

**合婚没有公开验证过的"匹配度"。** 所有打分都是作者自定的权重；同一对八字，换个库就换个分。

所以本馆：
- 只讲**信息同步**（`38` §1.2）与**十一条配对模式**；
- **不给总分、不给百分比、不排"最佳配对"**；
- 用太卜的字段清单做**两造事实表**的对照（干支关系、十神、纳音），解释仍归赤绳；
- 去留由当事人决定，这一条不改。

## 6. 梦：解梦

### 6.1 古典三层（这一门真正的底）

| 来源 | 内容 | 本馆怎么用 |
|---|---|---|
| **王符《潜夫论·梦列》**（ctext／维基文库，底本《四部丛刊》本） | 十梦：直、象、精、想、人、感、时、反、病、性。原文并说：**"故亦不专信以断事"**；"见瑞而修德者，福必成……见妖而戒惧者，祸转为福"；"占梦之难者，读其书为难也" | **分类用十梦；断事不专信**——这是本门最重要的一句护栏，连王符自己都写了 |
| **《周礼·春官·占梦》** | 六梦：正、噩、思、寤、喜、惧；"以日月星辰占六梦之吉凶" | **只取分类，不取星占**（本馆无星占层，也不装会） |
| **《灵枢·淫邪发梦》**（第四十三篇） | 十二盛：阴盛梦涉大水、阳盛梦大火、阴阳俱盛梦相杀、上盛梦飞、下盛梦堕、肝盛梦怒、肺盛梦哭、心盛梦笑、脾盛梦歌、肾盛梦腰脊分离……十五不足：客于心梦丘山烟火、客于肺梦飞扬金铁…… | **只作身体信号清单**，不作诊断；持续躯体症状转南阳或就医 |

> **王符那三句要背下来。** 客户拿"梦见掉牙是不是要死人"来问，最有力的一句不是"这是迷信"，是"写《梦列》的人自己说：不专信以断事"。

### 6.2 临床标准（只作转介，不作诊断）

| 标准 | 要点 | 用法 |
|---|---|---|
| **DSM-5-TR 梦魇障碍** | 反复、延长、极度痛苦且记得清楚的梦（多涉及生存、安全、身体完整）；醒后迅速定向；显著痛苦或功能受损；排除物质／药物／其他精神障碍；病程急性 <1 月、亚急性 1–6 月、持续 >6 月；严重度轻度 <1 次/周、中度 ≥1 次/周、重度每晚 | 命中三条以上 → 建议心理科／睡眠专科评估，**不诊断** |
| **ICD-11** | **7B01.2 梦魇障碍**（REM 睡眠相关异态睡眠） | 只用于说明"这是一个有编码的临床问题"，不用于自诊 |
| **AASM 2018 立场声明** | 意象排演疗法（IRT）为梦魇障碍的推荐治疗 | **只转介，不治疗**；本馆不给 IRT 操作步骤 |

### 6.3 语料与开源侧

| 来源 | 性质 | 能借什么 |
|---|---|---|
| **DreamBank**（UCSC） | 两万余份梦报告（2008 年论文 22,000+，站点自述 20,000+），Hall／Van de Castle 编码 | 研究视角与编码维度；**不抄报告文本** |
| **Dream Commons Aggregates**（Zenodo，**CC BY-NC 4.0**） | 月度去标识聚合数据，含主题／情绪／重复梦等分布 | 只作背景参照；**非商用**，不复制数据 |
| `hhszzzz/taibu` 的"周公解梦"模块 | 只读 | **不采其断语**——与 `84` 对五格的态度同律：可以算给你看，不拿它断命 |
| 其它 GitHub "dream interpretation" | 多为图像生成或无关项目 | 无可用的中文解梦引擎 |

### 6.4 结论

解梦只做四件事：**分类（十梦／六梦）→ 现实映射（三问）→ 身体信号（十二盛十五不足，只提示）→ 转介（DSM-5-TR／ICD-11）**。

**不判吉凶、不判应期、不诊病、不通鬼神、不卖化解。** 噩梦频繁且白天受影响，转心理科，不在命盘上找原因。

## 7. 合规与引用纪律

| 许可 | 能做什么 | 不能做什么 |
|---|---|---|
| **MIT / Apache-2.0** | 读、对拍、借字段与算法，保留版权声明 | 不把作者背书写成"本馆认证" |
| **AGPL-3.0 / GPL-3.0** | 只读、只对拍 | 不抄代码、不并入插件包、不摘长段文本 |
| **无许可证 / NOASSERTION** | 只读事实（有什么功能、输出什么字段） | 不抄代码、不抄文本、不抄词库 |
| **官方文件**（国务院、公安部、WHO、APA） | 引条目与统计事实，注明出处 | 不整段复制、不篡改口径 |
| **古典文本** | 公有领域，可引原文 | 注明底本（ctext《四部丛刊》本／维基文库） |

**一句老规矩**：**事实可以比对，文本与代码不可复制。**
