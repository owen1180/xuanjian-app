## 1. 三才与三纪总纲

### 1.1 天纪三才（借 `jonhnsonzz/nihaisha-tianji`、`bianyuan456/nihaixia`）

天纪不是一门，是**三道并列**：

| 道 | 讲什么 | 本馆落点 | 外部项目的叫法 |
|---|---|---|---|
| **天机道**（天道） | 紫微斗数、命盘十二宫、十四主星、四化、大限 | `11`、`15`、`22` | 天道 |
| **人间道**（人道） | 易经六十四卦的处世哲学、知命改运 | `13`、`62`、`34` | 人道 |
| **地脉道**（地道） | 阳宅六十四卦名位、地脉方位 | `10`、`18`、`19` | 地道 |

**三才一体**：天命 1/3 ＋ 人事 1/3 ＋ 地理 1/3，地理＋人事 ＞ 天命（`13` §5 已立此规）。`jonhnsonzz` 把它做成"天道／人道／地道"三文件导航，`bianyuan456` 的讲义清单也正好是 `天机道 75 页 / 人间道 146 页 / 地脉道 65 页`。

> **本馆的用法**：主理人分诊与合参时，先判这一问落在**三才的哪一层**，再决定叫谁。命盘问天道、处世问人道、房子问地道；三才同问才走三线合参。别把三道混成一句"算命"。

> ⚠️ **同名异义提醒**：曾仕强另有一个"**三才**"，指的是**公司的三个阶层**（基层／中层／高层，配不易／简易／变易），与本节的**天纪三道**不是一回事。两处都叫"三才"，但一个讲宇宙三才、一个讲组织三层，**不许互相解释**。曾式那一套的详说见 `77` §5.6。

### 1.2 三纪与《地纪》的真相（借 `hoverfu/NiShiSanJi`）

| 纪 | 内容 | 状态 |
|---|---|---|
| **天纪** | 易经六十四卦、紫微斗数、四柱命卦、堪舆、手相面相 | 已完成 |
| **人纪** | 针灸大成、黄帝内经、神农本草经、伤寒论、金匮要略 | 已完成 |
| **地纪** | 倪师生前**只写了序言与极少量开篇**，存世 8 篇文稿 | **未完成，世上不存在完整版** |

**人纪班的学习顺序**（倪师定的）：`针灸大成 → 黄帝内经 → 神农本草经 → 伤寒论 → 金匮要略`。对应"怎么扎针 → 中医原理 → 认识药物 → 辨证大法 → 杂病方剂"。

## 2. 六十四卦：图易读法与人间道（借 `wh149728915-stack/nihaixia-64gua`、`jonhnsonzz/nihaisha-tianji`）

本馆 `62` 已把 64 卦做成"一卦四用"的**断语层**，缺的是**怎么读卦图、以及 64 卦作为处世法则**这一层。

### 2.1 倪师讲易的四条核心理念（整理层）

1. **图为易之神**：文字是障碍，图是共通语言。倪师重编 64 卦象图，以图示法教学，"从图中读出吉凶与应对之道"，**重传神不重传形**。
2. **象只有一次**：时机稍纵即逝，象出现时必须立刻判断、果断行动。
3. **以果决行**（与 `13` §3 同一句）：占卜是为看到结果、以结果决定行动，不是探究原因。
4. **读图三要素**：看图中**人、物、景**，逐项对应占问之事的吉凶与建议。

> 倪师原话（转述层）：「易则易知，简则易从」——学易不应死背爻辞，要从图中悟神韵，一图胜千言。

### 2.2 每卦的四层结构（借该项目 `explanations/` 的组织）

一卦 = ① 六爻爻变及爻辞 ② 人间道详解（倪师解读）③ 卦象读图要诀 ④ 阳宅化解方法（部分卦）。

**与 `62` 的分工**：`62` 管"先天／后天／值年／阳宅"四层**断语**；本册 §2 管"图怎么读、这一卦教人怎么处世"。两者不冲突，但**不许拿人间道的处世哲理去当流年断语**（`62` §2 四层不许串）。

### 2.3 64 卦人间道要点的索引结构（整理层，只取结构不取全文）

该项目给出 64 行"卦名／卦象／人间道要点"索引。本馆**只借这个索引骨架**，用于斗枢答"这一卦教我怎么处世"时定位方向；要点一律用本馆自己的话重述，并标"整理归纳"：

| 例卦 | 人间道方向（本馆归纳，非原话） |
|---|---|
| 乾为天 | 刚健中正，六个阶段从潜到亢；居上不骄才吉 |
| 坤为地 | 厚德载物，先迷后得，柔顺守正 |
| 水雷屯 | 初生艰难，守正待时，不宜硬进 |
| 地天泰／天地否 | 通极转塞、塞极转通，与 `13` §7「吉处藏凶」同一条 |
| 水风井 | 井养不穷，修德不懈；取之不竭、存之不盈（`62` 有原话断语） |
| 水火既济／火水未济 | 事已成守成防衰／事未成慎终如始 |

> **分寸**：人间道讲的是"这一卦教人怎么走"，不是"你今年会怎样"。用户问流年，回 `62`；问处世，才用本册。

## 3. 六经辨证理论补遗（借 `bianyuan456/nihaixia` v2.1.0、`jonhnsonzz/nihaisha-renji`）

本馆 `63` 的六步与四道闸不变，这里补的是**辨证时可用的理论工具**（只作定位与鉴别，不给剂量指令）。

### 3.1 七步走（比本馆六步多两步，整理层）

`定表里 → 分阴阳 → 辨寒热 → 判传变 → 审体质 → 选方剂 → 精细加减`

本馆 `63` §2.2 的六步把最后两步合在"落方证"里。**口径不改**：仍守六步顺序，但第 6 步内部要能说清"选了哪一方、为什么加减"，不许跳到方名就停。

### 3.2 六经传变图与欲解时（整理层）

```
太阳（表）→ 阳明（里热）→ 少阳（半表半里）
         ↓ 失治误治
太阴（脾寒）→ 少阴（心肾阳虚）→ 厥阴（阴阳逆乱／上热下寒）
```

**欲解时**：六经各有其"欲解时"（某经气旺、病易解的时辰段）。南阳可用于**解释"为什么这个时辰症状明显"**，只作观察项，**不据此定方、不据此给服药时间**。

### 3.3 真寒假热／假寒的八维鉴别（整理层，最该补的一块）

寒热判反是六步里第 3 步最致命的错。八维鉴别法从八个面互勘，避免被单一假象带偏：

| 维 | 看什么 |
|---|---|
| 面色 | 泛红是浮在表面还是满面通红 |
| 口鼻气 | 气热／气冷 |
| 舌形 | 舌质润燥、苔色真假 |
| 脉象 | 有力无力、沉取是否空 |
| 胸腹 | 胸腹扪之凉热、喜按拒按 |
| 小便 | 清长／短赤 |
| 口渴 | 渴而能饮／渴不欲饮 |
| 大便 | 溏／结 |

> **用途**：八维里有两项以上指向"真寒假热"，**立即标危重、转诊**，不给方（`63` §3 第二道闸）。这正好补上本馆"辨寒热"一步过去只讲原则、没有可操作鉴别面的短板。

### 3.4 合病／并病与诊断公式（整理层）

- **合病／并病速查**：11 种组合 + "先治哪一经"的先后原则。南阳遇到"两经症状同时出现"时，先判是合病还是并病，再定先后；**不许两经方一起堆**。
- **8 个诊断公式**：太阳／阳明／少阳／太阴／少阴／厥阴／少阴热化／合病并病，每条是 `IF 症状群 THEN 经 + 分型鉴别 + 代表方`。本馆**取其"分水岭问题"的写法**，不取其自动出方的部分（越过四道闸）。

## 5. 知识库工程纪律（借 `xiaojian94xiaojian/nihaixia-tcm-wiki` 的 karpathy 方法论）

这是本轮**最该补的专业性短板**：本馆册页多、纪律多，但缺一套"知识是怎么被造出来的"自证机制。

### 5.1 三层结构

| 层 | 角色 | 本馆对应 |
|---|---|---|
| `raw`（原始资料，只读） | **依据** | 工作区 `.workbuddy/data/nihai/` 语料、`65` 的 `entries.jsonl` |
| `wiki`（导航／概念／专题／索引） | **导航** | 本库 68 册 references |
| `derived`（切片） | **派生** | `nihai_query.py` 的检索结果与摘录 |

**"Wiki 是导航，raw 是依据"**：任何事实回答必须能回到原始资料核对；册页之间互相转引不算依据。

### 5.2 五条设计原则（本馆全盘照收）

1. **推理必须隔离标注**：本馆归纳／推理一律显式标 `〔本馆归纳〕` 或"整理认为"，**不得伪装成资料原文**（与 `66` §1 四层证据对齐）。
2. **医学边界不可省略**：凡涉疾病／方药，必带"不替代医生诊疗"（`24`、`63`）。
3. **自下而上创建**：一个新概念／新册页，**须 ≥2 个不同来源支撑**才立；单来源只作"待核"（补 `65` §3 门禁四"双源冲突标待核"）。
4. **宁缺毋滥**：宁可不写，不可写错；宁可漏掉，不可让推理伪装成资料。
5. **输出三要素**：`资料原意 + 综合标注 + 医学边界`，三者缺一不算完整回答。

### 5.3 覆盖范围自评表（诚实边界）

该知识库公开自评"充分／不足／不覆盖三档"，并明说"非倪师体系观点覆盖不足、现代医学指南不覆盖"。本馆照做，**每份完整报告可选附一行覆盖自评**：

| 域 | 本馆覆盖 | 边界声明 |
|---|---|---|
| 四柱打分法、紫微三合、堪舆、手面相、六经辨证 | 充分 | 方法论自洽，但仍属传统术数文化分析 |
| 倪师语料原话的秒级回放 | 不足（依语料到位程度） | 语料在工作区，未到位时只给框架不给原话 |
| 现代医学指南、其他医家体系、临床疗效数据 | 不覆盖 | 不对照、不背书、不引用成功率 |

> **取长补短点**：过去本馆只会说"这个不归我管"，现在能明确说"这一块我覆盖到哪一档、哪一块根本不覆盖"。**承认不覆盖，比含糊带过更专业。**

## 6. 分领域问事路由与输出契约（借 `strawberrynine/ZiWeiDouShu-Master`）

### 6.1 主题路由（斗枢专用）

用户问的不是"帮我排盘"，而是"我今年感情怎么样"。先把问题**路由到专题框架**，不要一律全盘通讲：

| 用户问 | 路由到 | 主看宫位 |
|---|---|---|
| 感情／婚姻 | 夫妻专题 | 夫妻宫 + 命宫 + 福德宫 + 迁移宫 |
| 事业／跳槽 | 事业专题 | 官禄宫 + 命宫 + 三方四正 |
| 财运 | 财富专题 | 财帛宫 + 福德宫 |
| 健康 | 健康专题 | 疾厄宫（只作提醒，转 `24` §4） |
| 学业／考试 | 学业专题 | 官禄宫 + 文昌文曲 |
| 迁移／移民／外出 | 迁移专题 | 迁移宫 |
| 六亲（父母／子女／兄弟／交友） | 六亲专题 | 对应宫 |
| 某一时段 | 时间专题 | 大限 / 流年 / 流月 |

### 6.2 输入校验：资料不全就降精度，**不补造星曜**

先核历法、时辰、命宫、身宫、十二宫是否齐全；缺项**降低置信度**，不许凭空补一颗星来把盘凑圆。与 `22` §3"看不清就说看不清"是同一条纪律。

### 6.3 输出契约（六段，补 `22` 与 `57` 的输出侧）

```
【结论】   ……（不说"必"、不说确定预言）
【依据】  [原文] 册·h2·h3 @时:分:秒 ／ [盘面] 某宫某星某四化
【反证】  [待核] 哪一宫资料不足、哪一条因此不能精断
【置信度】 高／中／低（附理由）
【时间范围】 这一宫管的是哪一段（十年／一年），越界不谈
【现实观察点】 一两个可以自己验证的具体信号
```

### 11.1 本轮立住的三条

1. **道藏不收命理与相法，殆知阁收。** 两条谱系各有各的边界：道藏收"与修道相关"的术（宅经、择日、六壬、太乙、星占、丹道），殆知阁的"易藏·术数"收子平、星命、相法、卜筮、堪舆、择日、符咒。**引用时必须说清是哪一条谱系里的书**。
