# 七十五、阳宅·居家办公十八讲：定坐向、形煞成立条件、形理关系

> 来源：移动硬盘「文档／命理课程／居家办公专题直播录音+记录／居家办公专题直播笔记」001–018 讲及六次答疑（约 22 万字，2021 年专题课）。
> 本册只取**判据与条件**，不取课程中的个案断语。凡是"多久见效""多远有效"这类数字，均为课程所给的经验值，**不是自然常数**，用时须说明是经验口径。
> 与既有册页的分工：形煞清单与室内硬规则见 `08`；三元纳气见 `09`；名位与内外卦见 `18`；办公选址见 `19`。**本册补的是三样东西——坐向怎么定、煞在什么条件下不成立、形家与理气谁压谁。**

## 1. 先定坐向：这是全部判定的前提

课程反复强调：**向定错，全盘皆错**。城市住宅尤其容易错，因为多数人拿入户门当向。

### 1.1 三条定向律

| 律 | 内容 | 理由 |
|---|---|---|
| **客厅优先** | 客厅与卧室都有大玻璃时，以**客厅**定向 | 客厅面积大、连通各房、日常开窗时间最长，纳气量最大 |
| **临街为向** | 两侧窗户差不多大时，以**临街、热闹、动态**的一面为向，静态一面为坐 | 阳光进入比例与气流交换量大；动者为向 |
| **一屋一太极** | 整栋房以**人常待的屋子**为核心太极点；单间屋内以**人常待的位置**为核心 | 气随人聚，无人之处不论吉凶 |

### 1.2 三种典型情形怎么定

- **高层公寓**：不以入户门为向。以**室内窗户面积最大、经常开窗的一面**为向。
- **一层带院**：以落地窗连接小院的那道门为向。
- **无院的一层**：仍以最大窗户面为向。
- **两窗一大一小、小的临街**：课程明确答"**临街更重要**"——即临街优先于面积。
- **客厅两面临街**：取更繁华、人流更旺的一面为向。

> 这条与市面软件冲突最多。软件多按入户门或阳台朝向取值，**没有现场确认的坐向，软件结论一律不作数**（`74` §6.3）。

### 1.3 龙虎仍以"向"定

坐向定出后，站在屋内面向"向"方，**左手为龙边、右手为虎边**。龙虎高压、龙空虎实的断法见 `08` §3，此处不重复。

## 2. 形家与理气：不抵消，各显各的

这是本册最要紧的一条观念，课程讲得很直白：

> **"形家有形家的准确，不和理气抵消，两个都准。"**

展开成四种组合：

| 形 | 理 | 实际表现 |
|---|---|---|
| 有外煞（主破财） | 纳旺气（主进财） | **赚钱也赚钱，破财也破财**。收入大于破财则为吉论 |
| 有外煞 | 理气亦衰 | 破大于入，最差 |
| 无外煞 | 纳旺气 | 顺 |
| 形煞发凶之年 | 命格大运流年皆好 | 赚的多破的也多，**持平已是不错** |

三条推论：

1. **不能用"理气好"去安慰一个正在犯形煞的人**，也不能用"形煞"去否定一个正在走好运的人。两套各说各的，要分开报。
2. 判断吉凶要**给两条线**：形家这条线什么年头发凶，理气这条线什么阶段纳旺。合成一句"整体偏好或偏坏"，比单说一条诚实。
3. 课程特别提示：**命理派的布局（按八字喜忌摆件）帮助有限**，理由是"一套锁用一套钥匙，解命局的钥匙解不开风水的锁"。本馆采此说——`19` 里办公布局用内外卦与形法，不用八字喜忌配方位。

## 3. 形煞成立的条件（比 `08` §8 更细的四项）

### 3.1 路冲

| 判定 | 内容 |
|---|---|
| **假路冲** | 有路直对，但道路两旁**没有任何能凝聚气流的物体**（无树、无建筑、无围墙）→ 对住宅无影响。**唯一例外：宅内供神或供牌位，假路冲也算** |
| **真路冲** | 道路两旁有树木、建筑或其他可夹道聚气的物体，气流被压缩成一条，冲入宅内 |
| **宽窄** | **路冲要比房子窄**才算路冲；若路比房子宽，那是**明堂**，明堂可大吉也可大凶，另论 |

**凶应分区**：

- 前冲 → 注意血光
- 后冲 → 意外、车祸、犯小人、遭陷害
- 侧冲 → 与后冲同类

**"冲起旺宫无价宝"的四个前提**（缺一不可，课程原话是"敢用路冲，前提是"）：

1. 路**比房子宽**；
2. 方位属**旺方**（课程给的时间窗：2043 年之前，西北、西、东北、南四个方位冲来尚可发吉——**此为该课程所用元运口径，非普适结论**）；
3. 被冲房屋**左右都有房子、后面也有房子**，不能是孤楼；
4. 路的两旁能聚气。

四项齐备，路冲可发；缺一项，仍按凶论。**这一条不许简化为"路冲也有好的"。**

### 3.2 壁刀

四项细节（`08` 只写了形态与凶应，这里补成立条件）：

| 项 | 判据 |
|---|---|
| **高度** | 壁刀建筑须**与自宅等高或更高**。比自宅低的，不影响 |
| **距离衰减** | 要考虑对面建筑与自宅的距离。**三米约等于一层楼**：若自宅五楼、对面壁刀也在五楼、距离三米，则该壁刀只影响到四楼，不影响五楼 |
| **整栋同族** | 若整栋楼都是一家人（或一家公司），**不论影响几层，整栋都算** |
| **加重条件** | 距离越近、壁刀纵深越长、壁刀建筑背后越空旷，凶应越明显 |

凶应：前壁刀 → 血光、意外、破财、犯官司、子女脾气差；后壁刀 → 血光、意外、破财、犯小人；两侧 → 身体两侧易受伤。

解法与路冲同：种树分散气流、筑墙、该房间不住人、造水池（**不推荐**，须先算纳气）。课程原话："最好是搬走。"

### 3.3 距离阈值：多远之外可以不论

这是课程给的一套**按居住结构分档**的经验值，本馆照录并标明是经验口径：

| 居住结构 | 形煞有效距离 | 超出之后 |
|---|---|---|
| 自己与子女同住 | **15 米以内**有影响（另一处讲 20 米以外即不影响） | 影响很小 |
| 三代同堂（父母、自己、子女） | **25 米以内**有影响 | 25 米以外凶应较小，不影响屋内人 |
| 四代同住 | 仍对第四代产生不利 | —— |
| 宅内**供神明或牌位** | **不论距离远近都影响** | —— |
| 宗族祠堂、祖宅 | **不在此范畴** | 另论 |

> 两处数字（15 米／20 米）在课程里都出现过，属不同讲次的表述差异。本馆取**保守值 15 米起算、25 米收口**，并明说是经验值。
> 高压电塔一类，课程的处理是"**买电磁测试仪实测，不超标就没影响**"——这是把玄学问题转成可测指标，本馆照此办。

### 3.4 应期：多久会应

| 对象 | 起应时间 |
|---|---|
| 阳宅·新房（装修后入住） | 半年以上 |
| 阳宅·老房 | 约三个月 |
| 宅内供神 | **非常快**（课程未给具体数，只说"会非常快"） |
| 阴宅 | 三年以上起应，比阳宅慢 |

> 用法：客户说"搬进来一个月就不顺"，先问是新房还是老房、有没有供神。**一个月内出的事，不能归给形煞**，要另找原因（这一点比断煞本身更重要）。

## 4. 风水师的两条禁忌（课程原话，本馆采为执业规范）

### 4.1 不请不说

> "别人不请、不找，绝不主动去出头说出别人风水的不足，切忌强出头、逞能出风头。"

课程给的理由是业力观：一个人困在自己的运与局里时，不会主动想摆脱；此时外人强出头去调，往往适得其反，还要分担对方一部分业力。

**本馆的转译**（去掉业力表述，保留可执行的部分）：

- 不在饭局、朋友圈、亲戚聚会上主动点评别人家风水；
- 客户没问的方位，不主动判凶；
- 客户只想听好话时，不硬塞坏消息——先问"你想解决哪一个具体问题"。

### 4.2 必收润金

> "一定要收润金。这是行业规则，也是建立契约的一种方式。"

**本馆的转译**：免费的建议不被执行，也不承担责任。收不收、收多少是执业者的事，但**"白送的风水建议"既害客户也害自己**——客户不当真，出事反怪你。

> 这两条与 `40` 执业规范、`73` 科仪边界同属一类：**管的是"该不该出手"，不是"出手准不准"。**

## 5. 流派定位：课程自己怎么说

课程把市面常见流派列了一遍，并明确本门取哪一支。这张表的价值不在褒贬，而在**客户拿别派结论来问时，知道该怎么接**。

| 流派 | 主要依据 | 课程评语（照录其态度，不作褒贬） |
|---|---|---|
| 形势派（形家） | 外观形状、室内摆设、布局 | **本门两支之一**，与理气并行不抵消 |
| 三合派／二十四山头派 | 坐宅配山，与宅外山峰建筑论五行生克，配水与十二长生 | 对行星能量变数参考不多 |
| 八宅派 | 宅命相配 | 课程列为理气派之一，未展开 |
| 玄空飞星派 | 空间方位 + 正神零神 + 山水配合 | "理论是比较不错的"，但本门"更简单实用" |
| 三元纳气派 | 旺衰之气的判断法 | **本门理气取此支**（详见 `09`） |
| 翻卦派（辅星、黄石公） | 纳甲起卦，配九星断吉凶 | 课程自陈"研究不多" |
| 乾坤国宝（龙门八大局） | 先天为体、后天为用，收山收水 | 日后讲一部分 |
| 八字风水（命理派） | 按命主八字喜忌配二十四山五行布局 | **收效很小**；"解命局的钥匙解不开风水的锁" |
| 奇门风水、金锁玉关、紫微斗数派等 | 各有所宗 | 课程只列名，未展开 |

**接客户话的三句**：

1. 先问"这是哪一派的结论、坐向是怎么测的"；
2. 没有现场实测坐向的，一律说"不作数"；
3. 别派结论与本门冲突时，说"两派口径不同，各自成立"，**不贬别派，也不改本门口径去迁就**。

## 6. 本册新增的四条硬判据（可直接用于断事）

1. **定向**：高层看最大常开窗面，不看入户门；客厅优先于卧室；临街优先于面积。
2. **形理分开报**：形家发凶与理气纳旺各说各的，不许互相抵消，也不许拿一条盖另一条。
3. **距离与楼层**：壁刀按"三米一层"折减；形煞按 15／25 米分档收口；供神者不论距离。
4. **应期下限**：阳宅老房三个月内、新房半年内的事，不归形煞。

## 7. 分寸（本册最容易越界的三处）

- **不给"必出人命""必破财"**。形煞讲的是概率与倾向，`08` §7 的原则原样适用。
- **"冲起旺宫"不许拿来鼓励客户买路冲房**。四个前提要一项项核，核不过就说核不过。
- **业力、润金一段只作执业视角的说明**，不对客户讲"你不给钱就有因果"这类话——那是施压，不是术数。
