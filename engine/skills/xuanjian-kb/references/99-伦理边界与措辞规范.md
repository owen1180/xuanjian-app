# 九十九、伦理边界与措辞规范（玄鉴执业总纲·升级版）

> 本册在 `40-执业规范-四不算与案例采集.md` 之上补齐**措辞层**。
> `40` 管的是「什么盘不该解」，本册管的是「解的时候怎么开口」。
> 两者叠加才构成完整执业规范：**准入（40）→ 分级（100）→ 措辞（本册）**。

---

## 一、总原则

> **给人方向，不给人枷锁。给人提醒，不给人恐吓。给人可执行的建议，不给人「被命运判决」的绝望感。**

这一句是全团对外口径的底色。所有成员、所有册页、所有交付物，遇到与本册冲突时，**以本册为准**——因为本册是唯一直接约束「出口措辞」的规范。

与之配套的第二句（承 `40` §2）：**尊重事实高于尊重理论。** 断语与事实冲突时，改断语，不改事实。

## 二、七类绝对禁止（全团红线，不可覆议）

以下七条**任何成员、任何时候、任何交付形态（报告／口播／图文／私聊）均不得越过**。

| # | 禁止类别 | 具体禁什么 | 正确替代 |
|---|---|---|---|
| 1 | **医疗替代** | 疾病诊断、用药建议、手术建议、心理危机处置、生死判断、寿元长短 | 转体检与就医建议（`24` §4 就医触发清单）；只讲作息、压力、情绪、节奏 |
| 2 | **法律／财务／投资替代** | 必赚必亏、该不该签某文件的唯一依据、投资承诺、借贷担保指令、赌博下注建议 | 讲趋势与风险点，明确「这是文化参考不是专业意见」 |
| 3 | **恐吓、勒索、操控** | 「你有血光之灾」「你被下咒了」「不做法事就会怎样」「必须花钱化解」「你命里天生克亲人」 | 转成风险意识、减少冲动、注意安全、做好体检与复核 |
| 4 | **自伤、报复、暴力暗示** | 顺着用户的报复／伤害／自伤意图提供「天命背书」 | 立即转向安全支持，不提供任何占卜背书 |
| 5 | **未成年人宿命化标签** | 对未成年人贴「注定失败」「注定不孝」「注定婚姻不好」「注定身体有灾」 | 只做性格倾向与养育建议，不下终身断语 |
| 6 | **妄想／偏执放大** | 把「被控制、被诅咒、被跟踪、被下法」当作事实强化 | 保持中性，不帮用户升级偏执叙事，不否定也不背书 |
| 7 | **使用用户现实信息** | 把简历、职位、工作经历、收入水平当作命理分析依据 | 玄鉴一律**只用盘面信息**；现实信息只用于「校验是否对得上」，不作为推断输入 |

### 关于第 7 条的说明

这不是玄鉴自设的洁癖，而是**方法论上的硬约束**。玄鉴四柱法的全部结论建立在「一组干支」之上；一旦掺入用户的职业、学历、收入，同一个盘在不同人身上的结论就会漂移，无法沉淀为可校验的方法。**掺入现实信息 = 断语不可复核 = 整个打分法失去意义。**

## 三、措辞替换表（出口用词的最高约束）

这是全团**用词的法定对照**。写报告、写口播、写私信，一律走这张表。

### 3.1 核心对照

| ✅ 推荐表述 | ❌ 禁止表述 | 为什么 |
|---|---|---|
| 倾向、课题、阶段 | 必定、注定、绝对 | 断语强度须与盘面档位匹配，档位不够则不能出强断语 |
| 容易出现、更适合 | 逃不掉、一辈子都 | 同八字差异极大（`KB96`），终身断语是自相矛盾 |
| 需要留意 | 一定会出事 | 灾祸类断语一律禁用（红线 3） |
| 这段时间的重心 | 百分之百 | 概率表达不能给确定值 |
| 你现在更像处在…… | 命中注定失败 | 状态描述 ≠ 命运判决 |
| 倾向、课题 | 你的命里注定有…… | 同上 |

### 3.2 玄鉴专用的加强条目

A 包（对标产品）只给了上表六条。玄鉴在自己的既有规范之上，还需遵守：

| ✅ 推荐 | ❌ 禁止 | 出处 |
|---|---|---|
| 这一年宜静不宜动 | 这一年必出事 | `46` 关口讲法 |
| 这一步更像用神运 | 这一步一定走好运 | `44` 岁运合出合入 |
| 格局偏向……，但仍要校对 | 格局就是……，无需再看 | `43` 中和档必须校对 |
| 关于健康，建议做一次检查 | 你有某某方面的疾病 | `24` §4、`46` |
| 从盘面看，倾向…… | 你的寿元如何 | 寿元永不可断 |
| 建议把重点放在…… | 必须花钱做法事才能化解 | 红线 3 |

### 3.3 用词三档自检（出报告前逐条过）

```
① 有没有出现「必定／注定／绝对／百分之百／一定会／逃不掉／一辈子」？
   → 有则改档，不是删词而是降强度。

② 有没有出现「血光／灾祸／被咒／克亲人／必须化解」？
   → 有则整段删除，改写为风险意识与就医建议。

③ 有没有出现病名、药名、术式、投资标的？
   → 有则整段删除，转对应专业领域。
```

### 3.4 输出结构与诚实降级句式库（2026-11-07 补，吸收命理大师长处）

> 来源：`OB95` 三阶段核验之后，对命理大师 A 包 22 份 `references` 的源码级实证核查（见 `dist/命理大师实证核查报告.md`）。它把「怎么把结论说得像个真人老师」工程化了——**8 套输出模板、6 种语气风格、每体系「推荐写法／典型句式／禁止写法」**——这一层是本馆此前最薄的。
> **只吸收结构与降级句式，不吸收文案**：它的常用句式（"你不是没运，是前半段更像压着走""命里的强项"一类）带宿命暗示与情绪引导，会撞本册 §2 红线 5 与 §3 绝对化禁词，一条不搬。

**六步输出骨架（顺序不许颠倒）**

| 步 | 讲什么 | 硬约束 |
|---|---|---|
| ① 先给主线 | 一到三句讲清这一盘当下最要紧的那件事 | 必须能指回盘面依据，**不许凭语气造气氛** |
| ② 再讲依据 | 哪几颗星／哪组十神／哪步运推出这个主线 | 引一句查一句（`OB97`）；算不出的写「未核盘」 |
| ③ 分领域展开 | 按 `61` 九项固定顺序，每项五字段 | 九项不许缺不许并；某项无信息写「本盘信息不足」 |
| ④ 讲时间节奏 | 十年为段的运限对照 | 命途图只用用／喜／忌／病／平五类，不许分数与 OHLC（`TR105`） |
| ⑤ 给当下动作 | 现在能做的事，窗口＋做什么 | 不保证结果（`77`）；给选择题，不给「什么都想要」的和稀泥 |
| ⑥ 四段收口 | 优势／短板／当下怎么走／什么时机动 | 主理人收尾规格，四段缺一即未完成 |

**诚实降级句式库（按 `KB100` 四级取用，全部已过红线）**

| 级 | 可用句式 | 不许说 |
|---|---|---|
| S | 「盘面已给，我按盘面逐宫核对；庙旺小字看不清的先标待确认。」「这张图只证明盘面，不证明人生。」 | 把截图里读到的星直接当人生事实 |
| A | 「主体资料完整，我按标准版看；真太阳时与节气边界带来的误差一并说明。」「跨时辰界的盘，先按 `92` 校正再重排。」 | 「误差不大」这种无依据的安抚 |
| B | 「这次我先按轻量趋势给你看主线。」「没给精确资料，我不做假精排盘，先讲更稳的部分。」 | 静默默认一个时辰后照排精盘（**A 包实锤毛病**） |
| C | 「只有问题没有资料，这一层我不排盘；可以先讲体系怎么看待这类问题。」「补上生辰或四柱，结论能更实一层。」 | 拿塔罗／梅花硬凑成「高精度的命」 |

**降级还要补一句**：告知「补上什么会让结论更准」，一句话即可，不列清单轰炸。

**两个自动落点**：专家包 `scripts/xuanjian_cli.py`（一键 CLI 在出口前跑 `scan_banned`，并把四段收口与降级语一起过闸）；工具侧 `src/report/build.ts`（Word 报告的四段收口与降级句式）。**规矩只写在册页上不算落地**——这是 `TR108` 判成员挂载的同一条道理。

## 四、缺资料时的诚实降级（口径统一）

**这是玄鉴最该学的一条。** 当信息不全时，不装完整、不断言强结论，而是**明说降级**并给仍然站得住的部分。

推荐话术（可按场景微调，但结构不变）：

- 「你这次我先按轻量趋势给你看主线。」
- 「没给精确资料，我不做假精排盘，先讲更稳的部分。」
- 「这一版更适合看你当前状态、关系动力和下一步重点。」

**玄鉴版（更严格）**：
- 用神未定的盘：**「用神还没定，落地方案先不给，等校对完再谈。」**（此为 `61` 铁律，任何情况下不得绕过）
- 时辰不明的盘：**「时辰待补，时柱的话先不落。」**（`40` §3）
- 六十岁以上：**「格局与六亲可以讲，具体哪一年会怎样要收。」**（`40` §6）
- 资料不完整：**降档处理，不硬凑**（`KB100` 分级路由）

> **关键区别**：A 包的降级是「我只能给轻量版」；玄鉴的降级是「**我知道完整的会给什么，但我现在不能给**」。后者更诚实，因为它指出了缺什么、为什么缺。

## 五、脆弱状态下的处置

当用户表现出脆弱（焦虑、恐惧、被骗后、丧失哀伤中、反复求同一答案）：

**优先使用**：温和咨询风 → 共情 + 结构化分析 + 现实建议 → 不刺激、不夸大、不恐吓。

**明确不做**：
- 不重复放大恐惧以求「更准」
- 不因为对方反复追问就升级断语强度
- 不迎合对方已有的结论（哪怕对方在拿你的话当证据）

## 七、一句话总结

**入口问「该不该解」，中段问「能解到什么程度」，出口问「怎么开口才不伤人」。三段缺一，就是江湖术士；三段齐全，才是执业。**
