# 五十六、历法口诀与健康取象

> 来源：第十课（入门技巧 阶段复习），兼收第八课的月令与寒热燥湿。
> 分工：历法是排盘的地基，健康只作**方向与体检提醒**，不诊断、不给病名——红线见 24 §4。

## 1. 用哪套历

- 命理用**干支历**，以**立春**为新年分界，不是正月初一。老师举例：二零一四年农历正月初一生的小孩，仍然属蛇。
- 民间说的「农历」正确称呼是**阴阳历**，不是阴历。**农历和生肖其实没有关系**，生肖跟着节令走。
- 十二节令即十二地支，也就是月令：寅卯辰、巳午未、申酉戌、亥子丑。
- 六十甲子以甲子、甲戌、甲申、甲午、甲辰、甲寅六组为开头。**年与日按六十甲子循环，月与时另有口诀不循环。**

## 2. 两组口诀

**年上起月法**：甲己之年丙作首，乙庚之岁戊为头，丙辛之岁寻庚上，丁壬壬寅顺水流，若问戊癸何处起，甲寅之上好追求。

**日上起时法**：甲己还加甲，乙庚丙作初，丙辛从戊起，丁壬庚子居，戊癸何方法，壬子是真途。

排盘一律过工具（36 册），口诀留在这里是为了校对——工具给出的月柱时柱，用口诀能对上才算排对。

## 3. 月令管两件事

月令「掌管着一个八字的温度」，影响强弱与寒热燥湿两个层面。分数定完之后必须拿月令校正一次：月令通透、干支比和一气的盘，按偏强论。

## 4. 神煞：点缀，不是主角

第十课给了两条常用的：驿马（寅午戌见申、巳酉丑见亥、亥卯未见巳、申子辰见寅）、将星（寅午戌见午、巳酉丑见酉、亥卯未见卯、申子辰见子）。

老师的定位很清楚：**神煞大部分不参与运算，是独立的一种信息取象。** 原话：「神煞不参与原局运算，所以准确概率高的神煞不多。所以现在多数命理师，不以神煞作为主要推导。神煞作为参考。」

这条与 45 §4 同一口径：神煞不单独定吉凶，只作点缀，必须结合原局喜忌与大运流年。

## 5. 身体取象：地支口诀

子属膀胱水道耳，丑为胞肚及脾乡。寅胆发脉及双手，卯本十指内肝方。
辰土胃皮及胸肋，巳为咽齿下为肛。午火精神司眼目，未为胃腕隔脊梁。
申金大肠经络肺，酉为精血小肠藏。戌为命门腿为足，亥水为头及肾囊。

四宫配体征：年柱头部、月柱胸部、日柱腹部、时柱腿部；天干主外面与上身，地支主内在与下身。

## 6. 健康速判（入门级，只作提醒）

老师说这套入门判法「约百分之七十的概率」。落到服务里，全部转成**体检建议**，不转成诊断。

- 辰戌丑未互冲 → 肠胃方面易不适。
- 原局木被克被冲 → 头发少、发质差；木的多少决定毛发疏密。
- 八字无火 → 疲倦乏力；水多无火 → 冬日手脚冰冷。
- 水多土少 → 腹泻、肠胃偏弱。
- 火旺土燥而无水 → 皮肤出油或干燥。
- 金受火克、火金交战 → 心肺、咽喉方面多留意。
- 火在年柱被克 → 近视或眼疾方向。
- 食伤生财 → 易发胖；无比劫无财星而印贴近日主 → 也会发胖。
- 官主粉刺暗疮，杀主疤痕，杀为忌时更明显。
- 失眠分两型：**七杀旺**是事情多、自己给自己压力而睡得晚；**食伤旺**是躺下就是睡不着。
- 卯酉冲且金水旺 → 肝的代谢与过敏体质方向留意。
- 七杀旺（尤其在月令或多见）→ 睡得晚。

### 6.1 伤病体征补充（第二十九课）

> 老师原话：这些「不是绝对唯一标准，只是补充性标准」，须「几个特征结合到一起、结合大运」才断。以下一律只作提醒，不作诊断。

**近视**（三条，年上被克更易）：火被水克；火土旺而癸水（非常）弱；天干庚辛与丙丁同现。

**腰痛**（三条，一般三十岁以上显）：卯辰相害；金木交战；壬癸水弱、戊己土重。

**肠胃不好**（三条）：戊己土被木克；偏印多；食神遇枭（偏印）。偏印夺食在天干上现，还有「表达不清楚、有些磕巴」；在地支现，严重者会出现自闭倾向。

**易发胖**（六条）：食神有力或为喜用（享受美食、吸收好）；食神暗藏又逢食伤大运；食伤生财；正印贴身有力或正印化杀生身（身材圆润）；癸日干身强；四柱纳音水多或火多（两条以上）。食伤是「心情好时反而吃得多」，一遇焦虑反而不爱吃。

**易瘦**（八条）：偏印有力；食神逢枭；比肩强旺缺食伤（结实壮硕）；劫财强旺缺食伤；七杀强旺；官杀混杂而身弱；子未相害（脾胃不好）；水多土荡。

**妇女生产**（多为概率统计，待补充）：男命日支七杀或偏印 → 妻子有小产、经血不调之征；女命偏印多 → 难产概率大（比劫化泄则轻）；女命日时卯酉冲 → 堕胎克子之征；女命时柱偏印通透或偏印克食伤在时柱 → 流产堕胎、生育不顺；女命无食伤而七杀成势 → 不喜子女；女命时柱食伤见官杀 → 剖腹产、流产之征。

**血糖／血压**：金火交战多、火土太旺、水弱土多 → 血糖不稳；水土交战多 → 血压高、血淤（四十岁以上明显）。

### 6.2 找病症五思路（第二十九课）

病理探究分两层：①先天五行组合里藏的隐患；②后天行运的五行变化把隐患体现出来、加重、或带来新隐患。找症从五个入口下手：

1. 过弱被克的五行；
2. 过旺的五行；
3. 被冲克的五行；
4. 被合化的五行；
5. 调候寒暖。

引邵伟华《四柱预测学》一句（作迹法，不当作病名依据）：「木气属青而生风，火气属红而生热，土气属黄而生燥，金气属白而生寒，水气属黑而生湿……十干受克属六腑，十二支受克属五脏。」

## 7. 分寸三条

- **年龄要一起看**。老师原话：「比如这个人刚刚十五岁，你能判断说这个人心脏病吗？如果这个人四十五岁以上，我会判断心脏不太好。」
- **只给方向不给病名**。说「肝胆这一块偏弱，建议做一次体检确认」，不说「你肝有问题」。
- **健康与用神无关**。第九课明说过：健康寿命、感情和睦、生活舒适度与用神不存在必然关系。用神管的是思想境界、人脉关系、社会成就三项。用神好不等于身体好，也不等于婚姻好。

## 8. 接口

历法两组口诀已由排盘引擎实现（36 册），覆盖映射标已编码。身体口诀与健康速判**不进工具**——它需结合年龄、症状时长与就医情况由成员判断，且必须过 24 §4 就医触发清单后才能出口。工具只在象义模块（50 册）给出五行脏腑对应，不给断语。
