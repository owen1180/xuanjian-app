# 九十七、寿元星引动与暗合级别（引动叠加的计级法）

> 来源：四柱理学第五十二课「案例补充 象法补充」（2022.01.01，原文 6,743 字，`.workbuddy/learning/raw/2022.01.01_第52课_案例补充_象法补充.docx.md`，行号见文中标注）。
> 本册补的是**「引动」这件事的计量**：不是「有没有引动」，而是**叠了几重**。授课老师反复用的判断语是「引动的越多，级别就越高」（`L58`），本册把它落成可数的条目。
> **红线先行（2026-11-07 覆议后）**：本册全部内容**可算、可给年份**——按 **R-035** 输出寿元星识别、引动计级、健康关口区间＋主年、该先查哪一科、宜有人陪伴的时段；说法一律走 `46` §1.1 合规对照表，出口仍过 `57` 闸。**唯一不可断的是本人终点**（R-033 收窄后），对外不出任何存亡断言。六亲存亡可断，只到运段或哪几年，不给具体日。

## 1. 暗合：六组，级别最低的一层

### 1.1 六组暗合（`L5`–`L6`）

| 暗合 | 实为 | 本课评语 |
|---|---|---|
| **亥午** | 亥中壬（本气）× 午中丁（本气）、己（中气）→ 壬丁五合、甲己五合 | 被反复提起，**最常用** |
| **寅丑** | 寅中甲 × 丑中己 | 有一定引动作用，但**寅木不克丑土**，只是象法引动 |
| **寅午** | 本身是半三合、生合 | 有明显引动，**不靠暗合也成立** |
| **巳酉** | 本身是半三合 | 有引动，同上 |
| **子巳** | —— | **实际运用不明显** |
| **卯申** | —— | **级别也不高，不明显** |

### 1.2 定级（`L14`）

**暗合的级别在三会、三合、六冲、六合、刑、害之后**，**不在主体系中提及**——因为多数时候只有部分内容好用。

> 〔本馆归纳〕用法上给两条：① **能在主体系（三合六冲六合刑害）里说清的，不要拿暗合去说**，否则是拿最弱的一层去担最重的断语；② 暗合只用于**「悄悄引动、不公开的关系」**这一类象（`L8`：暗合代表秘密的、不外露的相合），不用于定吉凶轻重。

### 1.3 半三合的位置：级别在六合之后

`L124`：「因为寅午是半三合级别在六合之后，寅生午，午生未。」

这一句补上暗合之外的另一层排序——**合的强弱不是「三合 > 六合」那么简单**：

| 次序 | 关系 | 说明 |
|---|---|---|
| 1 | 三会 | 方局，力量最整 |
| 2 | 三合（全） | 三支齐，成局 |
| 3 | 六冲 | 冲力最直接 |
| 4 | 六合 | 一对一紧合 |
| 5 | **半三合** | 三合缺一，**在六合之后** |
| 6 | 刑、害 | 结构性摩擦 |
| 7 | 暗合 | 最弱，见 `1.2` |

**用法**：同一个字同时被六合与半三合牵动时，**先论六合、再论半三合**，不要把半三合
提到六合前面去抢重断语。半三合本身仍带引动，只是引动的量级低一档（`L124` 后半句
「寅生午、午生未」讲的是半三合同时含生的一面，故称「生合」，见 `44`）。

## 2. 「没有怕出现」：本课最硬的一条判据

授课老师多次用同一个说法：**原局没有的星，大运或流年出现，就是「没有怕出现」，一旦出现即引动、即改变原局状态**（`L24`、`L26`、`L66`、`L74`）。

| 情形 | 判断 |
|---|---|
| 原局寿元星不现 | 大运出现 → **引动**；出现两重且都有力 → 级别更高（`L24`–`L26`） |
| 原局财星不现 | 大运见财 → 父／妻方向被引动（`L66`、`L71`） |
| 「什么样才算有」 | **起码要有 60 分或以上的力量**（`L74`）——不到 60 分不算「有」 |

**藏怕透**（`L82`）：星藏在地支、大运把它透到天干，也是一重引动。**阴阳不一定要相同，关键是那颗六亲星本身**。

## 3. 引动计级表（本册的核心工具）

把课中五个案例的引动逐条拆开，得到一张可数的表。**级别越高＝越要提前提示，不等于越必然发生。**

| # | 引动条目 | 案例出处 | 是否计入 |
|---|---|---|---|
| 1 | 原局缺该星，大运出现（没有怕出现） | 案例一、五、六 | ✓ |
| 2 | 该星**两重**出现且都有力 | 案例一（`L26`） | ✓ |
| 3 | 大运与原局成**三刑 / 三合 / 六合 / 冲 / 害** | 案例一、四、五 | ✓ |
| 4 | 大运与原局成**象法三合**（无实合之名，有引动之实） | 案例四（`L51`） | ✓（级别低于实合） |
| 5 | 流年**解开**大运与原局的合／刑（解即引动） | 案例一、四、六 | ✓ |
| 6 | 流年**夺合**（把大运刚合走的那颗再夺回来） | 案例五（`L76`） | ✓ |
| 7 | 流年**强冲**，直接打破大运与原局的合 | 案例五（`L78`「不是夺走了，是直接冲灭」） | ✓✓（级别最高） |
| 8 | **阴阳转化**（原局只有偏印，大运见正印） | 案例四（`L54`） | ✓ |
| 9 | **交运年** | 案例四（`L55`） | ✓ |
| 10 | 流年牵动原局**多个宫位** | 案例四（`L56`：丑土同时刑戌、害午、暗合寅、破三合） | ✓ |
| 11 | 六亲星**偏强怕生扶**，流年又生扶 | 案例四（`L57`） | ✓ |
| 12 | 三冲一 / 一冲三 | 案例七（`L90`） | ✓ |

**计级口径**（〔本馆归纳〕，非课程原话）：

- **0–1 条**：不作提示。
- **2 条**：可提「这一段要留意」。
- **3 条**：提示具体方向（哪个系统、哪位六亲），并建议体检。
- **4 条及以上**：本课原话是「四个引动条件显现……引动的越多，级别就越高」（`L58`）——此时**只提示强度与方向，仍然不给日期、不给结论**。

## 4. 案例拆解：同一套判据在五种局面下的用法

### 4.1 案例一：三重叠加（`L24`–`L36`）

- 原局**无寿元星**；2013 入乙亥大运，乙木正财、亥中壬水食神——**两个寿元星同时出现，一实透一为本气**。
- 2020 庚子：子水伤官**冲破寅午戌三合**（象法三合），忌神冲局 → 引动病灾。
- 2021 辛丑：丑土**暗合寅木**，虽暗合级别不高，但**流年级别高于大运**，撬开了大运亥水与原局两寅的六合 → **一合一解，解开即引动**。

> 本课在此处给了一句极重的判断（`L37`）：当事人当年「不去好好看病，找大师治疗」，若好好治疗，2021 那一年「或许是大病一场，但是没有那么严重」。**这句是执业伦理，不是技法**——见 §6。

### 4.2 案例三：只泄不合，级别低（`L41`–`L45`）

原局寿元星亥水，大运寅木，**寅亥合而泄损**，且**大运没有强力引动**——所以只落到「肾虚、泌尿系统、较轻的肾结石」。

**判据**：寿元星被泄损 → 该星所代表五行对应的身体系统出小问题；**没有状态改变，就没有大事**（`L45`）。

### 4.3 案例四：四重引动落在六亲（`L48`–`L62`）

2012 壬辰，交运年、正印流年，原局偏印无正印 → **阴阳转化**；大运戌与原局丑未成**三刑**、与寅午成**象法三合**；流年辰**冲戌**，把三刑与象法三合**一起解开**；印星偏强怕生扶，辰土又生扶。四条件齐 → 落在**母亲**。

> 〔本馆归纳〕**同样的四重引动，落在本人是健康关口，落在六亲是六亲的事。** 判「落谁身上」看的是被引动的是谁的星、谁的宫——这是本课最实用的一层，不看清就一律说「你要注意」，是把六亲的事按到自己头上。

### 4.4 案例五：夺合与冲灭（`L66`–`L79`）

- 原局午戌合、亥午暗合；庚戌大运，**戌夺走原局的午火**，改变父母宫状态。
- 2019 己亥：亥**暗合午火**，把午从大运手里往回夺 → 再一次引动。
- 2020 庚子：**子午冲**，直接打破夺合状态——「这就不是夺走了，是直接冲灭了」；加庚金透出（父亲的象）。
- **冲 > 夺合 > 暗合**，三级力量依次递减。

### 4.5 案例六：藏怕透（`L82`–`L86`）

财星原藏地支，2011 己卯大运**透到天干**（一重）；大运与原局成**卯辰害、子卯刑**（子卯刑又解开子辰半三合）；2012 壬辰，流年**解开卯辰害** → 引动。**「大运合，流年解；大运冲，流年解」**——这是本课给的一句口诀式判据（`L86`）。

## 5. 月令权重：分数不稳时，以月令定档

`L127`–`L145` 一段把「分数不是绝对标准」讲透了：

| 条件 | 倾向 |
|---|---|
| 得令（生在当令之月，如夏生燥土月） | **偏强**概率大 |
| 失令（冬生） | **偏弱**概率大 |
| 春、秋 | 中和或偏弱 |
| 月令为子水、未土在时柱 | 百分百偏弱（`L135`） |
| 丑、辰、戌月 | 可能中和——**只能用事情、大运流年反过来校对**（`L138`） |

两条配套：

- **月令的季节五行难以空亡**（`L144`）：温度、季节的影响很难进空亡，但**对应的十神与人物关系可能受影响**。
- **部位服从五行**（`L171`–`L172`）：时支丁亥、丁火受损，先按**五行**（心脏、精神）判，再按部位（腿）；五行优先，部位在年月时概率更大、级别更高。

## 6. 执业伦理：这一课自己给出的三条

1. **有病治病，不找捷径**（`L37`）：「有病治病，找到靠谱的医生，遵循医嘱，不要相信捷径，不要迷信。」本馆照录，且**优先级高于任何技法**。
2. **不答会加剧当事人处境的问题**（`L103`、`L112`）：两处问婚姻，授课老师的回答是「我没办法回答」「回答后会出现问题」——**拒绝作答本身是专业判断，不是无能**。
3. **婚姻宫主张静态不主张动态**（`L113`）：「动不是好事」，而且要结合大运，不能只看原局三刑。

## 7. 用这一册的硬约束

1. **不出本人终点、不出病名**（R-033 收窄后）：引动级别按 R-035 转成「提示强度 + 关口区间与主年 + 建议体检 + 哪个系统」，给的是动作不是结果。
2. **六亲只到「这几年多留意」**：可以断六亲存亡的方向与时段，**不落到具体年份的具体事件**。
3. **暗合不许担重断语**：级别在刑害之后，只用于象法引动与不公开关系。
4. **暗合不是万能的补充**：课中原话是「大家在日后的运用中可以自己查漏补缺寻找自己的经验」（`L15`）——本馆不把它写成定则。
