# 十、天纪·地脉道：名位与六十四卦阳宅断法

> 倪海厦《天纪》三书之一《地脉道》。核心一句话：**名不正则位不顺，位不顺则运不通。** 阳宅断的不是房子好坏，是"谁住在哪个位置"。

## 1. 八卦配家人（一切推断的地基）

| 卦 | 象 | 家人 | 方位 |
|---|---|---|---|
| 乾 | 天 | 父亲／男主人 | 西北 |
| 坤 | 地 | 母亲／女主人 | 西南 |
| 震 | 雷 | 长子 | 正东 |
| 巽 | 风 | 长女 | 东南 |
| 坎 | 水 | 次子 | 正北 |
| 离 | 火 | 次女 | 正南 |
| 艮 | 山 | 三子 | 东北 |
| 兑 | 泽 | 少女 | 正西 |

**天地定位，长幼有序。** 家里每个人都有自己的卦位，住对了位，名分正，念头正，运就顺；住错了位，性格、想法、运势、健康都会被那个位置的能量改造。

## 2. 三个核心"象"

| 空间 | 象 | 含义 |
|---|---|---|
| 厨房 | **刀象** | 凶，主伤、主血光。厨房落在谁的卦位，就伤谁 |
| 客厅 | **如客** | 主人不在家、把家当旅馆、关系疏离 |
| 卫生间 | 是非、口舌、官司 | 秽气所聚，落在谁的位，谁多口舌 |

**客厅放在坤位最好**（母亲位，承载、待客两合）。

## 3. 六条最重的铁断（先记这六条）

| 格局 | 断 |
|---|---|
| 西北（乾）是厨房 | **死先生**（火烧天门，刀象伤乾） |
| 西南（坤）是厨房 | **死太太**（刀伤坤） |
| 正东（震）是厨房 | **长子夭折**（解法：把东边厨房改为卧房，让长子住东） |
| 西北（乾）是客厅 | 丈夫把家当旅馆，**夫妻生离** |
| 正东（震）是客厅或餐厅 | **缺东宫，生不到儿子**；已有儿子则如客，在家时间极少 |
| 厕所在房子正中间 | 主**心脏病**，夫妻死别之宅 |

配套两条：
- **无子宅**：正东是客厅／餐厅造成缺东宫；另一种是东边房间床头又靠东墙——"负负得正"，反而更缺。床头宜靠北或靠西。
- **命上有灾，再加运上有灾，才会呈现。** 风水不是单独致灾，是"命里有 + 宅上催"。

## 4. 名位组合的六十四卦断法

一个家庭里"谁住了谁的位置"，就构成一卦。以下为《地脉道》讲义逐条笔记的核心条目（卦名 → 结构 → 断语要点）。

### 4.1 各归其位（吉）

## 5. 阳宅调整的几条实操

| 事项 | 天纪说法 |
|---|---|
| 转运周期 | 位置改变一般**一个季度（三个月）**开始转 |
| 厨房吉位 | 正北或正西最佳 |
| 厨房可在西 | 若家中无三女，西方无人居住，"无人区"可放厨房 |
| 正北卧室 | 一般不住人，可放祖先牌位 |
| 两代人同住 | 年轻夫妻住西北，父母住东北——家和万事兴 |
| 山居 | 房子**不可盖得比后面山高**（强龙压主）；不可盖在龙脉陵线上，宜在侧边 |
| 阴宅 | 葬龙穴；阳宅不可压龙穴、不可正朝陵线 |

## 6. 断语分寸（团队必须做的转化）

《地脉道》讲义用的是"死先生""长子夭折""必凶"这类铁口措辞，是其讲课风格。**作为对外服务，必须转成风险语言：**

| 原讲义 | 对外表述 |
|---|---|
| 西北厨房死先生 | 西北属乾、主男主人，厨房火气与刀象压乾，男主人头部、血压、事业压力易出问题，宜改位置或加隔断 |
| 正东厨房长子夭折 | 正东属震、主长子，厨房在此对长子健康与成长不利，建议改卧房 |
| 山地剥大凶 | 此格局不利家运，主破耗与是非，建议调整居住分配 |

**永不照搬"死""夭折"这类词。** 讲师可以说，服务不能说——这是行业底线，也是这门学问能长期做下去的前提。

## 7. 与三元纳气的分工

天纪地脉道用**名位／卦象**断人，三元纳气用**气口／方位**断气场。两者结论可能冲突。

团队规则：**先问用户要解决什么**——问"家里人谁不顺"走天纪名位；问"这房子气顺不顺、财位在哪"走三元纳气。**一次只走一条主线**，另一条只作补充提示，并说明"两套体系侧重不同，结论若有出入属正常"。
