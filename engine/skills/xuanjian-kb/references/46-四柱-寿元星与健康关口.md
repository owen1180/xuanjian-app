# 四十六、寿元星与健康关口

> 本册是全库最需要守分寸的一册。技术要写清楚，话要说得住。
> 体例来源：第四十九课「死亡关口·技术补充」、第五十三课「课程总结·寿元星引动」。
> **对外一律不出口"死""夭""寿尽"，只讲"健康关口""宜先做检查""宜有人陪伴"。**

## 1. 先说清楚这门技术是什么

课程开篇自己就定了调：寿数是一段**波动的、概率偏高的时间段**，不是定数。清代人均寿命四十余，今日七十余，同一套干支在不同时代落出的结果完全不同。所以这一套的正式名称应当是——**有健康风险的时间段识别法**。

课程另立两条禁则，我们照抄并加严：

1. **至亲不算，生死不断。** 替外人推死期，是要背因果的；替自己家人推，是给自己添烦恼。
2. **寿元只在大运层面提，不具体到哪一年、哪一月。** 原话："我们目前更多的是在一个大运范围内注意关口，而不用具体到哪一年。在这个大运内多做注意，每年保持体检。"

   **本馆读法（2026-11-06 加，防两处混用）**：这条限的是**死亡关口**——即「本人终点」那一类判断。**健康事件**（哪年该查、哪年是关口、哪年宜安排择期处置）**不受此限**，按 §3 三种引动的两段式可以给到年，写法见 `61` §3.4。两件事必须分开。

   **【2026-11-07 主人覆议 · R-033 收窄 / R-035 新立】**

   旧表述「本人寿元永不可断」把「寿元星识别 → 引动计级 → 健康关口」**整套技术**一并封住，造成「代码算到了、规矩却说不算」的口径过宽。现**废止这一刀切表述**，拆成两条各管各的：

   | 规则 | 管什么 | 状态 |
   |---|---|---|
   | **R-033（收窄后）** | 本人能活多久、哪一年是生命终点、任何形式的存亡断言 | **永不可断，不可覆议** |
   | **R-035（本日新立）** | 寿元星识别、引动计级、健康关口区间＋主年、易出岔的身体系统、体检优先级、宜有人陪伴的时段 | **可算、可给年份、可写进报告** |

   R-035 **不是新开口子**：它把 11-06 已定案（`TR120`）与 `61` §3.4 的既有做法升格为独立规则号，并补齐可输出清单与合规说法。**不给人判终点**与**不给人算健康关口**是两件事，此前把第二件也封了，属口径过宽，本日更正。

   | 问的是什么 | 能不能给年份 | 依据 |
   |---|---|---|
   | 本人能活多久、哪一年是生命终点 | **永不给**（R-033 收窄后） | 本条＋§1 第 1 条 |
   | 寿元星是哪一颗、引动叠了几重 | **给**（结构事实，属盘面不算断语） | §2／`KB97` |
   | 哪年该查、哪年是健康关口 | **给**（区间＋主年） | R-035＋§3 三种引动两段式 |
   | 该先查哪一科、哪段宜有人照应 | **给**（只到「查哪一科」，不给病名） | R-035＋§6 |
   | 六亲谁还在、谁已走 | 给到运段或哪几年，不给具体日 | R-033／`61` §3.6 |

   **不许拿本条当「健康项不写年份」的挡箭牌**，也不许拿 R-035 当「可以判终点」的通行证。

### 1.1 R-035 合规说法对照表（对外只许用右栏）

> 用户覆议时要求「换成合理合法的说法」。这张表就是答案：**判终点这件事没有合法说法，只有不做；健康关口这件事有合法的讲法，就是「窗口＋该查什么＋谁陪着」**。左栏是内部技术判断，右栏是唯一允许的出口措辞，出口前仍须过 `57` 闸。

| 内部技术判断 | 对外说法（合规） | 绝不出口 |
|---|---|---|
| 寿元星被冲、引动 3 级 | 「这一步运在身体这一块要当心，建议每年做一次体检，尤其查某系统」 | 任何存亡断言、任何终点年份 |
| 引动集中 2029–2031，主年 2030 | 「2029–2031 是健康关口，2030 年宜把体检排在前面，家里最好有人照应」 | 把「关口」说成「终点」 |
| 禄神作寿元被冲 | 「这步运容易消沉，遇事容易往窄处想，宜有人陪着说话」 | 任何自伤暗示 |
| 五行偏枯指向某系统 | 「这一块负担偏重，建议做该系统的常规筛查」 | 病名、诊断、用药、停药建议 |
| 找不到明显寿元星 | 「本盘不硬找寿元星，改从五行失衡与健康象上看，先讲能稳住的部分」 | 为凑结论硬指一颗 |
| 用户直接问「我还能活多久」 | 「这一问我不答，也算不准。我能给的是哪一段路要多留意、哪一块该先去查、什么时候该有人陪」 | 顺着问法给数字、给年份、给暗示 |

**四条配套铁律**（与 R-033 同级，不可覆议）：① 象法三道闸照旧（`37` §7）——大运改局、流年加重、两点同指，缺一条只写「注意某方面」；② 不诊断、不给病名、不替代医生，体检与用药一律回专业人士（`24` §4、`63`）；③ 出口禁词表一字不动，`kb_gate.py` K046 与工具侧 `redline.ts` 生死禁词仍全量拦截；④ 报告里给的是**动作**（查什么、何时查、谁陪），不是**结果**。

## 2. 寿元星有四种

**食伤、印绶、禄神、财星。** 其中最核心的是正财、正印、食神、禄神。

### 三条选取标准

1. **过旺的不算。** 出现次数太多、力量太旺的，不能当寿元星——太旺的东西不怕波动，拿它当"命根"没意义。
2. **贴身的优先。** 靠近日元、或在月令的优先；原局里已经被克得无力的，不算。
3. **要有根。** 必须有本气根或实透；虚透无根的，不算。

一个盘可能同时有几颗寿元星，取有力的那一颗为主，其余作参考。若一个盘找不到明显的寿元星，**不必硬找**——可以改从五行失衡与健康象上去看，不必勉强下结论。

禄神作寿元，一般用在**身弱**的盘：身弱靠禄撑住命根，禄被冲则意志先垮，多表现为抑郁、消沉、遇打击想不开。身强而印禄过重的，禄不作寿元看。

## 3. 三种引动，缺一不算

寿元星被引动才出事，而"引动"只有三种形态：

| 形态 | 说法 | 例 |
|---|---|---|
| 藏怕透 | 原局藏在支里的寿元星，大运把它透到天干，状态改变一次 | 辰中戊土为正财，戊寅运透出 |
| 合而被解 | 大运把寿元星合住，流年再把合解开，一按一松 | 大运寅合亥，流年巳冲寅，合解 |
| 直接受冲 | 流年之力百分百传到原局，冲寿元星 | 巳火流年冲亥水寿元 |

**两段式才算应期。** 大运引动一次只是"状态改了"，流年再次引动才是"事落地"。三次同指（大运改状态、流年再引动、又有冲或刑叠加），概率最高。

这一条与主理人的象法三道闸完全一致：大运是否真改了原局状态、流年是否加重、是否有两点以上同指。缺一条，只能说"注意某方面"，不许说"这一年会怎样"。

## 4. 太旺怕犯众怒

第五十三课给的另一种形态，专对太旺与专旺之盘：

- 太旺的盘讲究**气势专一**，最怕被逆。
- 当一步大运与原局**多个宫位同时发生克合**，就叫"犯众怒"——不是一处受损，是整个系统同时别扭。
- 这种状态下，**每被解开一次，就应一次**。大运把全局按住，流年松开一处，那一处出事；再松一处，再出一处。
- 太旺第一忌官。官星进来最容易引发系统性对冲。

对外表述：不说"这步运要出大事"，说"这步运动得厉害，家里几处事情会一起来，宜提前把身体、老人、居所三件事安顿好"。

## 6. 从命局落到身体：五行走，落到病名级排查（`OB100`）

健康断法只有一条路：**看哪个五行被克得最重、哪个五行过旺而克他者**，落到对应的系统，再按 `OB100` §3.1 给 **2–3 个病名＋检查项**（「需排查脂肪肝、胆囊息肉，查肝功能＋肝胆超声」）。**病名要写，诊断不写**——不用「你有／你这是」。

| 五行 | 对应系统 | 常见表述 |
|---|---|---|
| 木 | 肝胆、经络、眼、筋、头发 | 肝气偏旺、易郁、经络不通、掉发 |
| 火 | 心、血脉、眼、小肠 | 心火偏旺、血压、睡眠浅 |
| 土 | 脾胃、肌肉、运化 | 脾胃弱、湿重、吸收差 |
| 金 | 肺、呼吸、咽喉、鼻、大肠 | 呼吸系统、鼻炎咽炎、肠道 |
| 水 | 肾、膀胱、泌尿、生殖、耳、腰 | 肾气弱、腰、泌尿、妇科 |

三条实战提醒：

- **水被克得狠**：肾与泌尿、妇科；女性尤注意妇科炎症类筛查。
- **金受克**：呼吸、咽喉、鼻、肠道；儿童期多见感冒发烧反复。
- **旺神过劳**：火太旺见眼、心、血液；木太旺见肝胆与经络。

## 7. 转译对照表（背下来，出口前过一遍）

| 内部判断 | 对外表述 |
|---|---|
| 某步大运寿元星被冲 | 这步运身体上要当心，建议每年做一次体检，尤其查某系统 |
| 寿元星藏怕透，流年再引动 | 这一年宜把身体的事排在前面，别硬撑；家里最好有人照应 |
| 太旺犯众怒，多宫位同动 | 这步运动得大，身体、老人、住处几件事可能一起来，宜提前安排 |
| 禄神被冲，意志受挫 | 这步运容易消沉，遇事容易往窄处想，宜有人陪着说话 |
| 五行缺水而肾气弱 | 传统上这一块偏弱，建议做一次泌尿系统常规检查，具体听医生的 |
| 火旺血压 | 血压这一项宜定期量，别等有感觉才查 |

**一个字都不许出现的**：死、亡、夭、折、寿尽、大限、凶灾、绝症、必有大病。

## 8. 遇到客户追问"我还能活多久"

标准答法三句：

1. "这个我不算，也算不准。命理看到的是哪一段路难走，不是终点在哪。"
2. "我能给的是：哪一步运身体容易出岔子，哪一块该先去查，查了没事就安心。"
3. "真正决定这件事的是体检和医生，不是八字。"
