# 三十二、问诊单：身体情况自述、舌诊与八纲

> 出处：`快乐生活的问诊单.doc`（收在 移动硬盘「倪海厦电子文案／天纪 人纪 地纪」）；八纲定义引自 `一个月学中医辨证（孙理军）`（收在「中医电子书籍」）。
>
> **改造原则**：原表是给中医师辨证用的。本馆拿它来干两件事——**① 让"身体提醒"有据可依；② 让客户带着一张写清楚的纸去看医生。** 不辨证、不下诊断。

## 1. 为什么本馆需要这张表

`25`（望诊）只能看"色"，`29`（手诊）只能看"形"。**色与形都是"看起来怎样"，问诊单补的是"他自己感觉怎样"**——而后者权重最高（`29` §7 已定：本人主诉 > 气色 > 掌色 > 指甲）。

**没有这张表，身体提醒就只能靠看图猜；有了它，提醒才有落点。**

## 2. 原表的十栏（本馆照用，只改口吻）

| 栏 | 问什么 | 关键点 |
|---|---|---|
| 一、基本情况 | 主症、起因、病程、既往史、家族史、手术史 | 先问"最难受的是哪一件"，不要一次问十件 |
| 二、寒热 | 恶寒／畏寒、发热的时段与类型 | **见 §3.1，这是全表最重要的一问** |
| 三、汗出 | 平时、睡时、醒后、但头汗、手足心汗、半身汗 | 睡时汗出＝盗汗；但头汗出＝热郁于上 |
| 四、疼痛 | 部位 + 性质 | **性质比部位更能定方向**（见 §3.2） |
| 五、饮食口味 | 食欲、口味、口渴、口感 | "口渴但不欲饮水"是最有价值的一项 |
| 六、二便 | 次数、性状、排便感；夜尿次数 | 大便"先干后稀""粘腻下坠"各有含义 |
| 七、睡眠 | 入睡／易醒／惊醒／多梦；晨起精力；嗜睡 | "睡后易醒、醒后再难入睡"与"时时惊醒"是两回事 |
| 八、劳逸情志 | 胖瘦、易疲劳、腰膝酸软、动则气喘；性格与情绪 | 爱叹息＝气郁的典型 |
| 九、月经带下 | 时间、量、色、块、经前胀痛；带下色质味 | 女性必问，男性跳过 |
| 十、发病规律 | 季节／时段／诱因／情绪相关性 | **这一栏最能验证前面的判断** |

## 3. 三处关键辨析（照原表原意）

### 3.1 恶寒对畏寒（全表最值钱的一问）

原文把两者分得很清楚：

> **恶寒**：虽近火、加衣被**不能**缓其寒。
> **畏寒**：近火、加衣被**可**缓其寒。

**区别在于"加衣烤火管不管用"。**
- 加衣能缓 → 多属里寒（阳虚、内寒）
- 加了也不管用 → 多属表寒（外邪在表）

**对外话术**：
> "你是加了衣服就舒服，还是加了也不管用？——这两个在传统上是两回事，去看医生时**一定要这么讲**，说不清，医生容易走弯路。"

### 3.2 疼痛性质十种（比部位有用）

原表列：胀痛、刺痛、冷痛、灼痛、隐痛、绞痛、重痛、空痛、酸痛、固定痛、走窜痛。

| 性质 | 传统含义（只作描述，不作诊断） |
|---|---|
| 胀痛、走窜痛 | 气滞，位置会跑 |
| 刺痛、固定痛 | 血瘀，位置固定 |
| 冷痛 | 寒 |
| 灼痛 | 热 |
| 隐痛、空痛、酸痛 | 虚 |
| 重痛 | 湿 |
| 绞痛 | 实、急 |

**用法**：客户说"我这儿疼"，追问一句"怎么个疼法"——**一句追问，胜过看十张图**。

### 3.3 "口渴但不欲饮水"

原表四档：口渴饮水较多／**口渴但不欲饮水**／饮水多而不解渴／饮水多反而更渴。

**第二档最值得留意**：想喝又不想喝，传统认为是"湿"或"瘀"阻着，水到不了该去的地方。
**话术**："你是真渴得想喝，还是嘴里干但不想喝？"——这一问常能把人问住，因为他从没这么分过。

## 4. 舌诊（原表有，而且照片能拍）

原表第九栏就是舌诊，分三项：

| 项 | 选项 |
|---|---|
| **舌体** | 正常／瘦小／胖大或满口齿痕 |
| **舌质** | 正常／淡／红／青紫／绛红／舌尖红／舌边尖红 |
| **舌苔** | 薄／厚／无苔／花剥／白／黄／灰／黑／水滑／干燥／腐腻 |

### 4.1 拍照要求（不达标就别看）

1. **自然光**，不要开美颜、不要用暖光灯（会让白苔显黄）。
2. **刚喝完咖啡、茶、可乐、吃了莓果、抽了烟**——半小时内不拍。
3. **舌头自然伸出**，不要用力绷，不要伸太久（久了会变红）。
4. **两张**：舌面一张（正面平视）、舌底一张（看舌下静脉）。
5. 说明"有没有刮过舌苔"——刮过就不判苔。

### 4.2 三条最稳的读法

- **舌体胖大 + 齿痕** → 传统认为是"水湿偏重"，转成"容易困倦、身体沉、大便不成形"。
- **舌质淡** → 偏虚偏寒；**舌质红、舌尖红** → 偏热，且多在心上（舌尖属心）。
- **苔厚腻** → 湿浊；**苔花剥（一块一块没苔）** → 胃气弱，**这种要建议去查，不要自己调**。

> **舌下静脉（舌底两条青筋）**：明显增粗发紫，传统认为与血瘀有关，转成"建议查一下血脂与循环"。**只说这一句。**

## 5. 八纲：四对坐标（用来描述，不用来定性）

原书定义：

> 八纲辨证……根据病位的深浅、病邪的性质及盛衰、人体正气的强弱，归纳为**阴、阳、表、里、寒、热、虚、实**八类。
> 疾病的类别，不属于阴，便属于阳；病位不在表就在里；性质不属于寒便属于热；邪正盛衰，不是正虚便是邪实。
> **阴阳为八纲的总纲。表、热、实证属阳；里、寒、虚证属阴。**

| 坐标 | 两端 | 从问诊单里怎么看 |
|---|---|---|
| **表 / 里** | 病在皮毛对在脏腑 | 恶寒加衣不缓、起病急 → 偏表；病程久、症状杂 → 偏里 |
| **寒 / 热** | 怕冷对怕热 | 畏寒喜暖、喜热饮、小便清 → 偏寒；怕热、喜冷饮、小便黄 → 偏热 |
| **虚 / 实** | 正气不足对邪气有余 | 隐痛空痛、易疲劳、舌淡 → 偏虚；胀痛刺痛、便秘、苔厚 → 偏实 |
| **阴 / 阳** | 上面三对的总结 | 表热实＝阳；里寒虚＝阴 |

### 5.1 本馆怎么用这四对（关键）

**只用来"描述"，不用来"定性"。**

| 可以这样说 | 不可以这样说 |
|---|---|
| "你这个情况偏寒，喜暖怕冷、喜热饮，这是方向" | "你这是寒证" |
| "按四对坐标看，你偏虚偏寒，去看中医时把这个讲给医生" | "你这是脾肾阳虚" |
| "你偏实偏热，最近是不是熬夜加吃辣？" | "你这是湿热下注" |

**"偏"字是唯一的护身符。** 加了"偏"，就是描述；去掉"偏"，就是诊断。

## 6. 从自述到提醒：三步

```
第一步：收（照表问，只问最相关的 5–8 项，不要一次问十栏）
第二步：归（把这几个症状归到八纲的一两对上，用"偏×偏×"表述）
第三步：给（三个动作：作息一条、饮食一条、该查什么一条）
```

**每步只做一件事。** 客户答不完十栏，就只问"寒热、汗、二便、睡眠、情志"这五项——**这五项已能定八成**。

## 7. 输出模板

```
【身体情况整理】（不作诊断，供你就医时参考）

一、主诉
   最难受的是：……
   多久了：……　起因：……

二、关键几项
   寒热：畏寒（加衣可缓）／恶寒（加衣不缓）→ 偏……
   汗：……
   二便：……
   睡眠：……
   情志：……
   舌象：舌体……／舌质……／舌苔……（照片条件：……）

三、归纲（只作描述）
   按八纲四对看，你偏……偏……

四、三个动作
   ① 作息：……
   ② 饮食：……（减什么、加什么，各一句）
   ③ 该查什么：……（说科室，不说病名）

五、带去给医生
   把上面"二、关键几项"抄一份给医生看，比口头讲清楚。

以上为传统术数文化分析，不构成任何医疗建议。
```

## 8. 分寸

1. **不问全套十栏。** 问得越多越像看病，越容易越界。**五到八项足够。**
2. **不给证型名。** "脾虚湿盛""肝郁化火""肾阳虚"这类词一律不用。
3. **不写方、不推荐中成药、不建议穴位。**
4. **舌象只描述，不判断。** 说"舌体胖大、有齿痕、苔白厚"，不说"你这是湿气重"。
5. **出现 `24` §4 的红线信号，立刻停问，直接建议就医。**
6. **做成"给他带去给医生的东西"**——这是这份表最大的价值：它把"算命先生说的话"变成"病人能复述的症状"。
7. **原表的红色标注法可以借用**：让客户在选项上打勾，比让他自由描述准确得多。
