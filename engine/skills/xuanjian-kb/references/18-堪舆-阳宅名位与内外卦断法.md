# 十八、堪舆·阳宅：名位、内外卦与室内细部

> 这是 `10-天纪-地脉道名位与六十四卦.md` 的**补全篇**。`10` 给了六十四卦断语表，这一份补三样它没有的东西：**成格条件**、**内外卦推法**、**室内细部（床／桌／神位／门／缺角）**。

## 1. 阳宅在命运里的权重：三分之一

倪海厦反复讲的一句话，团队必须原样记住：

> **"阳宅部分它只占了三分之一。必须你命上有灾。"**
> 命（天）占 1/3，运／宅（地）占 1/3，人间道（人事）占 1/3。

推论三条，全部对外表述都要带上：

1. **命里没有的灾，宅一般不单独造出来。** 宅是把命里已有的倾向**放大或削弱**。
2. **命里有灾 + 宅上有应，才会呈现。** 这是"为什么同样户型，有人出事有人没事"的唯一解释。
3. **只调宅不改人事，等于只做了三分之一。** 所以每次给方案都要落到"人怎么做"。

## 2. 核心原则：名位相符

| 关系 | 做法 | 结果 |
|---|---|---|
| **名 = 位** | 让母亲住西南坤位、父亲住西北乾位、长子住正东震位 | **家和** |
| **位 = 名** | 主卧在正东（长子位），就用长子的名字注册公司、挂长子名 | **万事兴** |

反过来，**位不正则名不顺，名不顺则运不通**。这是全套阳宅断法的地基。

### 2.1 九宫配家人（再列一次，因为一切从这里出发）

| 卦 | 方位 | 家人 | 五行 |
|---|---|---|---|
| 乾 | 西北 | 父亲／男主人 | 金 |
| 坤 | 西南 | 母亲／女主人 | 土 |
| 震 | 正东 | 长子 | 木 |
| 巽 | 东南 | 长女 | 木 |
| 坎 | 正北 | 次子 | 水 |
| 离 | 正南 | 次女 | 火 |
| 艮 | 东北 | 三子 | 土 |
| 兑 | 正西 | 少女 | 金 |
| — | 中宫 | 心脏／气机枢纽 | 土 |

**"家里没有这个成员"的方位叫无人带**——可以放厨房、厕所，"压凶"。（例：家中无三女，正西可放厨房。）

## 3. 三个象，四条硬规矩

| 空间 | 象 | 含义 |
|---|---|---|
| 厨房 | **刀象** | 主伤、血光。落在谁的卦位就伤谁 |
| 客厅 | **如客** | 主人把家当旅馆，关系疏离 |
| 卫生间 | **是非、口舌、官司** | 秽气所聚 |

**四条硬规矩（不可妥协）：**

1. **厨房不入有人之宫位。** 首选**正北（坎）或正西（兑）**；**忌西北（乾，火烧天门）、西南（坤）、正东（震）**。
2. **厕所不入中宫，也不入有人之宫位。** 中宫见厕主心脏、中风、气喘（象：心脏被闷住）。宜在**正北或正西**，忌对卧室门、客厅门。
3. **客厅首选坤位（西南）。** 忌正东（缺东宫，儿子不念家）、忌西北（丈夫把家当旅馆）。
4. **正北卧室一般不住人**，可放**祖先牌位**。

### 3.1 六条铁断（对照 `10`，此处只记"怎么对外说"）

| 格局 | 讲义原话 | **对外表述（唯一允许的说法）** |
|---|---|---|
| 西北厨房 | 死先生 | 乾位属男主人，火气与刀象压乾，男主人**头部、血压、心血管与事业压力**易出问题；建议改位置或加强隔断与排烟 |
| 西南厨房 | 死太太 | 坤位属女主人，**妇科、脾胃、情绪**易受影响；同上处理 |
| 正东厨房 | 长子夭折 | 震位属长子，**对长子健康与成长不利**；优先把东边改为卧房让长子住 |
| 西北客厅 | 夫妻生离 | 丈夫易把家当旅馆，**夫妻相处时间与亲密度下降** |
| 正东客厅／餐厅 | 缺东宫、生不到儿子 | 东宫缺位，**求子较费力**；已有儿子则在家时间少、关系疏 |
| 厕所居中宫 | 心脏病、夫妻死别 | 中宫见厕，**全家健康与情绪易受累**，尤以心血管为要；务必加强通风与干湿分离 |

**"死""夭折""生离""死别"这四个词，永不输出。**

## 4. 六十四卦断法：先验"成格"

**这是 `10` 缺的关键一步。** 讲义里每一卦前面都有一串条件，条件不成立，卦就不成立，**不许硬套断语**。

### 4.1 成格三查

1. **人物是否在场**（这个卦需要的人是否住在这个家里）
2. **婚否状态**（多数卦明确区分"未婚／已婚"，如风天小畜要"未婚长女"、雷天大壮要"长子未婚"）
3. **是否同住**（"两个儿子不住同一屋檐下则不成格"）

**举例**：

- **水雷屯**（次子居长子位）：需**两个儿子都住家里、都住正东卧房**；长子已婚、或本人已婚、或两人不同住 → **均不成格**。
- **火天大有**（次女居父位）：需**次女未婚且姐姐未嫁**。
- **山天大畜**（三子居西北）：需**长子、次子皆未婚**。
- **地天泰**（母居父位）：需**夫妻同住**西北。**结婚当晚就住进去最好。**

### 4.2 特殊时效卦（住多久有讲究）

| 卦 | 时效 |
|---|---|
| 雷天大壮（长子居西北，未婚） | **不要住超过三个月**；不婚为吉；婚配属兔／猴／羊者，三个月内婚破 |
| 地山谦（母居东北）、天山遁（父居东北） | **65 岁以前住不吉**，65 岁后住吉 |
| 泽山咸（三女居东北） | 婚延一年、**单年结婚** |

### 4.3 断卦的三步输出

1. **定名**：谁（父／母／长子／次子／三子／长女／次女／三女）
2. **定位**：他住哪个方位（八卦）
3. **得卦**：卦名 = "谁占了谁的位置" → **卦义即断语**

> 讲义原话式的提示：**"判断时先定名，再定位，卦自然出来，不必死记。"** 记不住 64 卦没关系，`10` 里有表，查表即可。

## 5. 内外卦法（阳宅的高阶用法，也是办公室的钥匙）

六十四卦 = **内卦（下卦）** + **外卦（上卦）**。用这个结构可以给**任何空间**起一卦。

### 5.1 住宅

| 位置 | 取卦 |
|---|---|
| **宫位**（人住的方位） | **内卦** |
| **人**（住的人是谁） | **外卦** |

### 5.2 办公室／店面（这是倪海厦明确讲过的用法）

| 位置 | 取卦 |
|---|---|
| **办公室所在方位** | **内卦** |
| **门的朝向** | **外卦** |

**原课例子**：门朝**西北 = 乾（外卦）**，老板座位在**西南 = 坤（内卦）** → 坤上乾下 = **地天泰，大吉大利**。

**这就是"办公室风水"在倪海厦体系里的正式解法**，比摆貔貅、放水晶高明得多，而且完全可复算、可验证。详细用法见 `19-风水-办公商业空间与选址.md`。

## 6. 室内细部（讲义散落各处，此处归拢）

### 6.1 床位

| 项目 | 规则 | 理由 |
|---|---|---|
| **床头朝向** | 宜靠**北**或靠**西**；**忌靠东墙** | 东为震位，床头靠东与"东宫"叠象，**负负得正，反更缺东宫**（求子更难） |
| 求男 | 床头靠北或西 | 北坎、西兑…按时辰与卦气取阳 |
| 求女 | 住东南角 | 巽为长女位 |
| 横梁 | 忌压床 | 压迫感，主心神不宁 |
| 镜子 | 忌正对床 | 反射吉气、惊扰睡眠、夫妻口舌 |
| 厕厨门 | 床头床尾忌正对厕所门、厨房门 | 秽气／火气直冲 |
| 炉灶 | **床位与炉灶不可相对** | 火气伤人 |
| 床下 | 保持空旷整洁 | 堆杂物阻气、生湿 |
| 床高 | 起身脚能着地为宜 | 过高不接地气，过低湿气侵 |
| 分金煞 | 床位不压在 24 山分界线上 | 同 §立向的分金煞 |

### 6.2 书桌／办公桌

- **背后有靠**（实墙），前方开阔；**忌背门、忌背窗**。
- 桌面不压梁。
- 书桌／办公桌的纳气按 `09` 的"人坐的位置"定太极点，**不是房间中心**。

### 6.3 神位／祖先牌位

- **必须贴墙靠壁**，不可悬空、不可置于卧室、不可放在随便的架子上。
- 宜在**生旺方或吉方**；忌三煞、五黄方。
- **正北卧室**可安祖先牌位（正北一般不住人）。
- 神像尊数取单数为吉。
- 神位不宜与外界视线直通（开门见神）。

### 6.4 大门

- 大门为**气口之主**，不可正对厕门、厨房门、电梯、楼梯口。
- **穿堂煞**（大门直通后窗／阳台）：气进即出，主聚不住财 → 设玄关、屏风、柜体使气婉转。
- 门口地垫颜色随方位取：如南方忌大红（火上加火）与纯黑（水火相克），宜黄（火生土）。**这类细节属"锦上添花"，权重低，别当主菜讲。**

### 6.5 缺角与户型

- 户型以**方正**为上；缺角即"缺宫"，缺哪一宫，对应家人与该方面运势偏弱。
- 缺角不宜用摆件"补"，**用功能补偿**：缺東宫就在东侧安排长子卧房或书房，缺乾位就在西北加强收纳与稳定感。

### 6.6 厨房与厕所的细节

- 炉灶**忌与水龙头相对**（水火相冲）。
- **开门见灶**：大门一进直对炉灶，火气冲门、气不聚。古法视为耗财之象，实务上先改门向或加隔断；**不许说成"破财必败"**，讲"进门第一口气被火气顶着，家里容易急、容易吵"。
- **灶后无靠**：炉灶背窗、背走道，属"火无靠"，主做事没底气；能移则移，不能移就在窗侧加实体挡板。
- **灶压梁／灶在梯下**：横梁压灶与压床同理，属压迫之象；重点在改位置，不在挂件化解。
- 厨房门忌对厕门、忌对卧室门。
- 厕所**必须有窗或强排风**——"没有窗的厕所，是心脏被闷住的象"。
- **厕所不入中宫**（`18` §5 六条铁断之一）：中宫见厕，全家健康与情绪易受累，尤以心血管为要；化解只有通风、干湿分离、改门向三条，**不靠摆件**。
- 厨房排水要好、保持干燥；厕所忌长期潮湿。

> 这三条（开门见灶、灶后无靠、灶压梁）是本轮查漏补入的**阳宅三要「门·主·灶」缺口**——原册只讲到灶与水龙头、门与厕的相对关系，漏了"门与灶"这一组。补自 `74` §6.4 对开源八条形煞清单的比对。

## 7. 调整方案的优先级（铁序）

```
① 改人（换房间、换床位、换桌位）  ← 效果最快，一个季度（约三个月）见转
② 改隔断（玄关、屏风、柜体、门帘）
③ 改动线（门的方向、走道、开关门习惯）
④ 改使用强度（少用某间、改变功能）
⑤ 其它（通风、采光、干燥、清洁）
```

**摆件永远排不进这个序列。** 课程与《天纪》共同的立场是反对靠摆件化解。倪海厦原话：**"看神，卦就是神，不要被形迷惑。"**

## 8. 转运周期与预期管理

| 项目 | 说法 |
|---|---|
| 位置改变 | 一般**一个季度（三个月）**开始转 |
| 整体改善 | 三个月到三年之间 |
| 无效的情况 | 命里倾向太强、或人事不改、或方位测量错误 |

**不承诺"调了就一定好"。** 讲"改善概率"，讲"三个月左右开始感到变化"，讲"如果三个月无感，回来复测方位"。

## 9. 现代公寓的现实约束（必须诚实）

1. **厨房厕所位置固定**，改不了 → 走"降级方案"：加强排风、常关门、加隔断、调整使用强度，并明确告知"这是减弱，不是消除"。
2. **户型缺角改不了** → 用功能补偿（§6.5）。
3. **租房**：不必大动，讲清"权重大幅下降"，只做可逆调整（床、桌、帘、屏）。
4. **单身／合租**：名位法需要"家庭角色"，单人居住时按**本人对应卦位**（男看乾／女看坤，再看排行）判，并说明"名位法在单人户权重降低"。
5. **坐向测量**：手机指南针误差大，务必请用户用实体罗盘复测，或提供楼盘朝向图。
