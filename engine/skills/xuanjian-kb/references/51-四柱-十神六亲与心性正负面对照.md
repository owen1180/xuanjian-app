# 五十一、十神六亲与心性正负面对照

> 来源：主课笔记 2021.04.04 第六课（十神关系·六亲人物）、2021.04.11 第七课（十神关系·性格特征）。
> 本册与 `47` 的分工：`47` 讲「十神怎么用、取什么路线」，本册讲「十神各代表谁、各是什么脾气」。
> 六亲方向与顺生顺克是**查表即得**的部分，已编码进排盘工具；心性描述属话术素材，留给人。

## 1. 十神怎么定：异性为正，同性为偏

日元为核心，五种关系展开十神：

| 关系 | 十神 | 正偏之分 |
|---|---|---|
| 克我 | 官 | 异性＝正官，同性＝偏官（七杀） |
| 我克 | 财 | 异性＝正财，同性＝偏财 |
| 生我 | 印 | 异性＝正印，同性＝偏印（枭） |
| 同我 | 比劫 | 同性＝比肩，异性＝劫财 |
| 我生 | 食伤 | 同性＝食神，异性＝伤官 |

**地支的十神看本气**（第八课同条）：卯的本气是乙，故庚金见卯为正财；酉的本气是辛，故丁火见酉为偏财。
中气余气也有十神，但只算本地支的杂气，不代表这个地支。

## 2. 六亲方向表（第六课逐条）

「综合代表」是不分男女的笼统说法；分男女时按下表取。

| 十神 | 综合代表 | 男人 | 女人 |
|---|---|---|---|
| 正印 | 母、贵人、师长 | 母亲 | 母亲 |
| 偏印 | 母（枭）、亲属长辈 | 母亲、祖父 | 母亲、孙女 |
| 正财 | 父 | 妻子、兄嫂、弟媳 | 父亲、伯伯、叔叔 |
| 偏财 | 父 | 情人、父亲、叔伯 | 婆婆、兄嫂、弟媳、姑母 |
| 正官 | 上司领导、师长贵人 | 女儿 | 丈夫 |
| 偏官（七杀） | 敌人小人、严厉师长 | 儿子 | 情人 |
| 食神 | 子女、晚辈学生下属 | 女婿、孙子 | 女儿、祖母 |
| 伤官 | 子女、晚辈下属 | 祖母、孙女 | 儿子 |
| 比肩 | 朋友同辈 | 兄弟、姑父 | 姐妹 |
| 劫财 | 朋友同辈（异性） | 姐妹、儿媳 | 兄弟、公公 |

第七课给的简化方向，用作口头概括：**财＝父亲方向、男人的妻子；官＝领导方向、女人的老公、男人的子女；
印＝母亲方向、后天的长辈师长领导；食伤＝晚辈学生、女人的子女方向；比劫＝同性朋友、异性朋友。**

### 2.1 父母星怎么取：有优先，有替补

| 谁 | 母亲 | 父亲 |
|---|---|---|
| 男命 | **正印**优先；无正印有偏印，则偏印看母亲的缘分；两者都有取正印 | **偏财**优先；无偏财则正财也可代表父亲 |
| 女命 | **偏印**优先；无偏印有正印，则正印看母亲的缘分；两者都有取偏印 | **正财**优先；无正财则偏财也可代表父亲 |

为什么这样分：**儿子与母亲是异性关系，故男命母星取异性的正印；女儿与母亲是同性关系，故女命母星取同性的偏印。**
父亲同理——儿子与父亲同性，故男命父星取同性的偏财；女儿与父亲异性，故女命父星取异性的正财。

正偏印都可论母、正偏财都可论父——这是「都可」，不是「都算」。取哪个要看在不在局里。

### 2.2 男人正偏财混杂

男命正财为正妻、偏财为情人。**正偏财混杂**体现的是缘分混杂：不是感情经历多，就是再婚。
古法妻妾之别，放到一夫一妻的今天，容易读作外遇或多段感情。

**成家是分界点**：早年财看父亲的含义大，成家之后八字里财的问题，多数落到妻子身上。

### 2.3 十神可以顺着往下推

六亲不是十张固定标签，是可以顺着五行往下推的链条。课上给了两步推的示范：

- 甲木男，克甲木的同性天干庚金是儿子；把庚金当日元看，克庚金的同性天干丙火就是庚金的儿子，即甲木的孙子。而丙火正是甲木所生的同性天干——**食神**。故食神为男命之孙。
- 丙火女，克丙火的癸水是丈夫；生癸水的庚金是癸水之父。庚金对丙火而言是同五行的异性天干——**劫财**。故劫财为女命之公公。

**男女在先天关系之外的推导路线不同**，别拿男命的链条套女命。这一步要人推，工具不代推。

## 3. 十神顺生顺克（第七课，要求默写）

```
顺生：财 → 官 → 印 → 比劫（含日元） → 食伤 → 财
顺克：财 → 印 → 食伤 → 官 → 比劫（含自身） → 财
```

这两条不是背下来的，是五行关系推出的。举例：庚金，克木为财、土生金为印，而木克土，所以**财克印**；
乙木，水生木为印、木生火为食伤，而水克火，所以**印克食伤**。

**懂得顺克才解得开「财克印」这类象**：财是父亲、印是母亲，不是往死去克，是一种平衡关系。
印克食伤则是——印是保障与荣誉，食伤是自由与幻想，有了印就会失去一部分自由。

## 4. 心性正负面：一副十神两副面孔

**看哪一副，取决于这个十神是用还是忌**（第七课小结）：十神为用则现正面特性，为忌则现负面特性。
这是本册唯一需要带判断的一节——前面查表即得，这里要先定用忌。

| 十神 | 为用（正面） | 为忌（负面） |
|---|---|---|
| 正财 | 现实、保守谨慎、守本分、节俭、专一、不好出风头、不愿惹事 | 抠门、保守、迂腐不化、小气吝啬、爱占便宜 |
| 偏财 | 热情大方、善于交际、喜欢美的事物、会来事、兴趣广泛 | 纵情欲望、不负责任、贪婪、一切向钱看、**无法专心**、懒而只想享受 |
| 正官 | 聪明、保守、自律、利于仕途、为人公道、有责任心 | 流于表面、虚伪、拘束迂腐、不会变通、用小聪明、**胆小而坏** |
| 偏官 | 有魄力、敢想敢干、爱憎分明、掌握实权、进取好胜 | 胆大妄为、冲动好斗、偏激霸道、为达目的不择手段、倔强多疑 |
| 正印 | 有同情心、心软宽容、有修养、喜欢有内涵的事物 | 懒惰、依赖性强、行动力弱、软弱优柔寡断、易压抑 |
| 偏印 | 领悟力强、观察敏锐、精明、有独创性、喜好钻研 | 钻牛角尖、唱反调、观点偏激、标新立异、孤独不合群 |
| 食神 | 思维细腻、斯文有礼、愿意奉献、宽和、人缘好、乐观 | 纵情玩乐、自尊心强、不切实际、自作聪明 |
| 伤官 | 要求完美、敢于批判现状、向往自由、敢表现、常有惊人之举 | 叛逆任性、好批评人、尖酸刻薄、嫉妒心强、不认输、自大傲慢 |
| 比肩 | 刚健果断、自我意识强、有毅力、重朋友 | 好面子、固执己见、心气高、过于自信、自以为是 |
| 劫财 | 口才好、胆子大、敢于冒险、不怕牺牲、热情直率 | 粗鲁野蛮、不讲信用、说大话、举止低俗、侵犯别人、好勇斗狠 |

### 4.1 四条必须讲清的分寸

1. **正面负面不是全有全无**。负面特征「一定有其中的一点或几点，但不是全部」。
   说人坏话式的一口气列完，是对这门学问的糟蹋。
2. **正与偏是价值观的差异，不是好坏**。食神正官正财正印＝传统稳定的价值观；
   伤官七杀偏财偏印＝激进开创的价值观；比劫＝包容热情但有主见。**各有所长**。
3. **环境会修正性格**。伤官特性的人在部队、在公职体系会被同化，高傲可能只在骨子里，不表达出来。
   所以「表面不像」不等于「不是」。
4. **十神有副作用，功大于过即可称正面**。课上举张大千：偏财为用且旺，大方面上重情重义
   （照顾二嫂几十年），小事上不拘小节甚至造假好色——**正面心性大于负面心性，故仍论偏财为正面**。
   不是圣人才算正面，是比例问题。

### 4.2 强弱与流变七条（第七课）

1. 八字中没有的十神，大运流年会补充进来。
2. 八字中空白的六亲缘分，随大运流年到来会强化。
3. 八字中过多的六亲缘分，随大运流年到来**也可能削弱**。
4. 八字中的性格因素，随大运流年改变会有所改变。
5. 正面含义的十神被大运流年制约，会呈现负面性格特征。
6. 负面含义的十神被大运流年制约，**反而会呈现正面性格特征**。
7. 十神特性不是绝对正面或绝对负面，是「正面含义多一些」。

## 5. 对外怎么讲

- 六亲方向可以直说（「你这一造，母星看偏印」），**但六亲缘分深浅不等于关系好坏**——
  课上明说「没有财不代表不好」，星不现不等于缘薄，更不等于克父克母。
- 心性两面**只说其倾向，不说其人品**。说「偏财为忌的人容易不专心」，不说「你就是个不专心的人」。
- 涉及「克妻」「克夫」「难有子嗣」（课上原话：偏印夺食、比劫多克妻）一类铁口措辞，
  一律按 `10` §6 与 `46` 的规矩转成风险语言——**永不照搬**。
