# 五十四、分项断法 · 婚姻与感情

> 来源：第二十课（感情婚姻）、第二十一课（因缘技巧）。
> 分工：本册讲**成色、条件、年份窗口**（`61` §3.4／§3.5），**不替他签去留**。「该不该离」不由命理回答，见 28 §6 与 40。
> 2026-11-06 起加严：**「不给年份、不判去留」不再是本册的免责句**——年份要给（婚动年、宜定年、易散年），去留给到「象／窗口／建议」三层；不给的只有第四层「签字」。
> 主干一句话：**夫妻星主帮助，婚姻宫主感情。** 两个维度交叉成四象限。

## 1. 两个维度

- **夫妻星**：女命看官杀，男命看财（正财偏财）。天干地支本气中气余气都算。它管的是「这个人能给我什么」。
- **婚姻宫**：日柱地支。它管的是「这段婚姻本身是什么状态」。无论婚姻宫是什么十神五行，就代表婚姻内的人与感情。

看盘顺序：一找夫妻星，二看它落在哪一柱、透出还是藏支、是喜是忌，三看婚姻宫本身的喜忌与干支关系（干生支／支生干／比合／干克支／支克干）、有没有被冲被合，四把两者合起来定趋势。

## 2. 四象限

| 夫妻星 | 婚姻宫 | 判据 |
|---|---|---|
| 用 | 用 | 得对方助，婚姻本身也稳 |
| 忌 | 忌 | 结婚会有离婚的趋势 |
| 用 | 忌 | 难结婚，除非婚姻宫被大运流年冲开或合住 |
| 忌 | 用 | 对方给不了助力，但婚姻状态尚可 |

两条补充：**夫妻星为忌而不现，夫妻关系反而平和或不错**；**夫妻星为用而不现，缘分弱、不易结婚**。

## 3. 夫妻星的落点

- 在年柱旺而不受制 → 情窦初开早；透出明显，藏在地支则多为暗恋、想得多做得少。
- 在年柱为喜用且有力 → 容易找比自己大的对象。
- 在年干被克、在地支被冲 → 早年有一段感情破裂或失去。
- 在月柱实透 → 也会早恋，且两人关系近；月干实透有力说明对伴侣的渴望明显。
- 在日柱 → 同事同学、圈内朋友；在月时柱 → 同省市，距离不远；在年柱 → 远方，生活差异大或年纪相差大。
- 男命妻星为忌且实透 → 因配偶破财、另一半开销大；女命官星为忌实透 → 受压制、钱财因对方损失。

## 4. 婚姻宫的四种干支关系

- 支生干 → 配偶对本人好；干生支 → 本人对配偶好；比合 → 好得像朋友，彼此支撑。
- 支克干 → 配偶诸多挑剔，争执由配偶发动；干克支 → 自己对另一半不满，心生间隙。
- 婚姻宫为忌时，上列全部反过来读：谁也不让谁。
- **被冲** → 不利婚姻；**被合** → 有另一种力量介入婚姻。老师原话：「一般婚姻宫被冲合，都会有过一段感情上的失败。」

合的力量排序：**六合最大；半三合次之；墓地半三合忽略不计；三合、三会不算合入婚姻宫**。

## 5. 相貌、年纪、距离

先看婚姻宫地支属于哪一档，再看它是不是用神，两个方向合着看：

- 子午卯酉 → 配偶漂亮有能力；寅申巳亥 → 相貌一般、比较精明；辰戌丑未 → 朴素敦厚。
- 婚姻宫为用神有力 → 长相可以、很有能力有气质，强项能补短板。
- 月支与日支同一地支 → 无论哪个地支，都漂亮或都有能力。
- 日元弱、婚姻宫地支克日元且与月支同字 → 本人被动，被配偶支配。

夫妻星五行叠细节：火主亮丽热情、木主高、水主丰满机灵、土主敦厚个子不高、金主白皙端庄。

年纪：官印的能量多，配偶比自己大；食伤生财多，配偶比自己小；比劫多，年纪相仿。男命日支为食伤或财星，对象多比自己小；为印和官，比自己大一点。老师说这法子**百分之六十到七十的概率，不是绝对**。

## 6. 病与药：婚期七条

心法只有一句：**找到病源，解决病根，集合两三点命理迹象，才可以定应期。只有一点不行。**

病在哪里，药就在哪里：

1. 夫妻星出现的年份（天干实透或地支出现）；
2. 原局不现而出现的流年；
3. 夫妻星被合，来解开合的大运流年；
4. 夫妻星被冲，来合以解冲；
5. 婚姻宫被冲，以合解冲；
6. 夫妻星被克，有通关或克住克星者；
7. 婚姻宫被合，逢冲开的年份。

第八条（逢空出空）老师留待后讲，本册不补。

**伏吟**：原局地支遇流年大运同一地支，即伏吟。**争合**：流年与原局同字来合，原局争不过流年。**拱合**也是婚姻宫之病，需刑或冲来解。

## 7. 分寸五条（这一节比判据更要紧）

1. **不介入别人的婚姻**。老师开课就声明：学了之后不要去推自己和自己老公的事，学习班不介入别人的婚姻感情，「这是非常有损阴德的事情」。
2. **出轨只是迹象，不是必然**。原话：「地支婚姻宫遇到六合，是否一定会出轨？这个不一定。只是有这种迹象。不是百分之百必然发生。」
3. **不给建议、不替人做决断**。只讲成色与条件。
4. **不顺的盘不要为了结婚而结婚**。原话：「婚姻波折的八字，一般建议顺其自然，不要刻意去结婚……为了找一个依靠强行结婚，那么一定会不幸福的。」
5. **不要以婚灾为理由放纵自己**。原话：「不要以自己有婚灾、感情不顺为理由，去放纵自己不负责任的恋爱。」至于择流年结婚，「操作性不是很好，有时候计划赶不上变化」。

## 8. 两条容易错记的

- **不能只看分数**：老师断过一个一百零六分的坤造，因为金水较多，「经过实际推断，按偏旺算」——原话是「这时候不能只看分数」。
- **伤官强的盘慎用官**：伤官已经很强，再用官就会起是非，取用只能走财。这条与 47 §4「取用路线不能并用」是同一件事。
