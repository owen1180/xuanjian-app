# 十七、堪舆·阴宅：寻龙、点穴、察砂、观水、立向、葬法

> 倪海厦《天纪》地脉道后半部（第 16 集起）讲堪舆。他自己说得很清楚：**"台湾很多堪舆学派，比如三元派、三合派。我们没有派，各取其精华，全部纳入易经的体系来谈。"**
>
> 阴宅断的是**生气**，不是逝者。郭璞《葬书》一句话立住全部逻辑：**"葬者，乘生气也。气乘风则散，界水则止。"** 所以全套技术只有一个目的——**找到气聚之处，并且不让它散掉**。

## 2. 寻龙

### 2.1 龙的层级

```
太祖山（一方之主山，如昆仑、天山）
  └ 少祖山（分支起来的高峰）
      └ 父母山（结穴背后那一座）
          └ 过峡（龙脉被两边高山挤压变窄之处 = 龙的脖子）
              └ 入首（龙气入穴前最后一节）
                  └ 结穴
```

**过峡是全套技术最关键的一站**。古法："在过峡处定盘针测来龙最准"；无峡者，在入首后方测。原因见 §3.4 土色验证。

### 2.2 真龙 / 假龙

| 判据 | 真龙 | 假龙 |
|---|---|---|
| 来水 | 水**没有割断**山脉 | 水横切过脉，脉断气绝 |
| 过峡与穴土 | 两处土色**相同** | 过峡青土、穴处红土 → 不是同一条脉 |
| 龙身 | 起伏剥换、有生有收 | 直硬死板、孤露无护 |

**这一条是防骗的核心。** 官星所在处最容易让人误以为是龙穴（"官星假穴"），必须用水与土色双重验证。

### 2.3 龙之"生"与"有情"

- **生**：山上草木高大茂盛 → 雄壮威武之象；草木短而秀 → 秀丽之象；**光秃秃无草木 = 无生气**（如鸣沙山），不葬。
- **有情**：水**弯弯曲曲**入明堂为有情；**直来直去为无情**。
- 好龙脉的样子，在中医里就是**子宫之象**：环抱、有水流出、生生且有情。

### 2.4 来龙类象（用面相打比方）

倪海厦的教法：把来龙过峡当成鼻子看。

| 来龙形态 | 类象 | 主 |
|---|---|---|
| 细长而来、结穴处饱满 | 悬胆鼻 | 大富大贵 |
| 来脉厚大、山势雄壮 | 狮子鼻 | 大富大贵 |
| 侧面看山势倾颓、软弱无力 | 三曲鼻 | 孤坐到老，不成器 |

### 2.5 干龙与支龙

- 主脉为**大龙**，分支为**小龙**。
- 大龙被截住的地方可立首都、首府；小龙结穴只荫一族一房。
- 龙气有**大运**：北龙、南龙、中龙之说，黄河改道断中龙，龙气南移。**这属于历史地理层面的宏观叙事，服务中只在"选址择地"时作背景谈，不用来断个人吉凶。**

## 3. 点穴

### 3.1 结穴的七个先决条件（缺一不可）

1. **左右有水**（不是"有水就行"，要左右夹护）
2. **出水口两边有砂**——最好是**动物象**（狮、象、虎、龟），叫**水口砂**
3. **不见水来，不见水去**（站在穴上，看不到水从哪进、从哪出）
4. **有案山**（近前之山）**与朝山**（远山之有势者）
5. **左右环抱，龙虎相抱**（青龙略高、白虎略矮，如两臂抱穴）
6. **藏风纳气**——站在穴上要**寂静无声、清风徐来**。飞砂走石、朔风扑面，纵有上上之砂水，也**有形无神**，发不久
7. **明堂平广、水聚天心**

> 第 6 条是倪海厦反复强调的"神"：**"如果穴位过高，无法藏风纳气，其发力不过很短暂，甚至有形无神，外表声名远播，内在实空无一物。"** 这一句要原样记住——它解释了为什么"看起来很气派"的墓反而不好。

### 3.2 杖法取穴（水平定位）

1. 用罗经在龙脉上测出立向，画一条直线；
2. 站到**水口**处，朝来龙方向看，取**青龙白虎环抱之中心点**，再画一条线；
3. **两线交点 = 穴位水平位置**。

### 3.3 朝山取穴（垂直定位）

**"上不过眼，下不过心"**——站在穴上，案山／朝山的高度应落在**眼以下、心以上**这个区间。

- 朝山高 → 穴取高；朝山低 → 穴取低。
- 倪海厦的实操说法：案山高低"必须在测量人**脐上肩下**"，微调即得真穴。

### 3.4 土色验证（真穴的硬证据）

| 土色／土质 | 判断 |
|---|---|
| **红黄、光润** | 吉，地气旺 |
| **干枯、色黑** | 凶 |
| **土厚** | 佳 |
| **顽石多、坚硬** | 凶（气不足） |
| 枯发缟素、惨白如盐、无光亮 | **平常之穴**（不是凶，是不出贵） |
| 满山土色与穴土同色 | 平常之穴 |
| 穴土特殊质优、与漫山不同 | **佳穴** |
| 开穴见龟、鱼 | **天然精气所聚，奇佳之穴** |
| 开穴见蛇、鼠、蚁、虫 | **凶穴，弃之** |

**关键规则：过峡处挖出什么色的土，穴处就必须是什么色的土。** 变色即非同一地脉，前面的测量全部作废。

**这一条是可以在现场执行的真技术**：不需要信什么，只需要挖两处土对比颜色。

### 3.5 动物验证：牛眠穴

- 牛耕完放出去，总回同一个地方躺下 → 那块地"恢复疲劳快"，是气旺之地 → **牛眠地**。
- 引申：鸟、鹤来聚之地气旺；**蛇鼠聚集之地不取**。
- 反过来用在阳宅：**家里有动物来聚（燕子、蜜蜂）是兴旺之象；蟑螂老鼠集体迁徙，要防火灾。**

### 3.6 穴形类象

- 自然成穴之地，地表会**凹下一块**，或像虎钳张开，或成小窝。
- 以动物象为多：**像大象有两个鼻孔，则一定有两个穴。**
- 这部分只能靠实践积累，**不许在图上硬套**。

### 3.7 地脉

地气旺处，地表有**水纹一样的纹理**，天然形成，不是人工。地脉如人手上的脉，旺时会"跳动"。

## 4. 察砂

### 4.1 杨公九星（九种山形）

古人把天下山脉归为九类，叫**九星**，也叫**杨公九星图**（唐·杨筠松）。山势、官星、砂都受九星影响。

| 星 | 形 | 五行 | 吉凶 |
|---|---|---|---|
| **贪狼** | 如笋、如笔 | 木 | **吉** |
| **巨门** | 方、如柜、如屏 | 土 | **吉** |
| **武曲** | 圆、如钟、如覆釜 | 金 | **吉** |
| **左辅** | 圆而低、如幞头 | 金／土 | **吉** |
| 禄存 | 如顿鼓、形乱 | 土 | 凶 |
| 文曲 | 蜿蜒如蛇 | 水 | 凶 |
| 廉贞 | 如火焰、尖锐 | 火 | 凶 |
| 破军 | 破碎、如败军之旗 | 金 | 凶 |
| 右弼 | 隐微不现 | — | 隐吉 |

**记不住就画。** 倪海厦的原话：在外面记不住山形没关系，**先把山势画下来，回家再对照**。

**通用凶形**（不分星）：破碎、破烂、不整齐、塌陷、全是砂石、干枯。落在哪个方位都不利。

### 4.2 官星与鬼星

**官星 = 库**，主官贵与家财。

| 官星形态 | 主 |
|---|---|
| 方正圆大、无破裂、无崩陷 | 库足，家庭富裕 |
| 有**官帽**（圆顶）＋**官带**（玉带般薄而齐整的横砂） | 出官贵，可当一方之主（县长、市长级） |
| 官帽上再**有笏板** | 出将入相，天子近臣 |
| 无官带、无笏板 | **偏官**——民选之官 |
| 无官星 | 后代不出官 |

- 穴前官星＝青龙白虎延伸出去的山脚支脉。官星完整、且**使出水口蜿蜒而出**，更吉；无官星护驾则水直射而出，**发也虚花，终致一败涂地**。
- **官星最容易误认为龙穴**，必用 §2.2 真假龙法验证。

**鬼星**在青龙后方、紧邻主脉，是主脉的分枝，象为**旗**（戏台上武将背后插的旗）。

- 鬼星主**武贵**、主杀伐声威。
- **三支分枝的鬼星最吉**（风水以三为吉）。
- 鬼星被破坏 → 人事上必遇小人作梗。

### 4.3 内砂、外砂

| 类型 | 位置 | 作用 |
|---|---|---|
| **内砂** | 明堂之内的水中或近前小山 | **优于外砂**，主近处之贵 |
| **外砂／水口砂** | 出水口两边 | 锁水口，主守财与门户 |

- **内砂方方、头角峥嵘** → 武贵，中流砥柱之象（乱世出名将；若来龙太低则出忠将——末代尽忠报国者）。
- **内砂肥肥圆圆** → 财旺。
- **外砂一定要动物象**（狮、象、龟、虎）为好，动物有"生"之象。桂林象鼻山是标准例子。
- **"狮子顶绣球"**：出水口一侧如狮、一侧如球，为大吉之局。

### 4.4 天星四贵与三吉六秀

**天星四贵**（立国都、大贵之地必看）：在结穴处开罗经，24 坐山中以下四方的**峦头**要好。

| 方位 | 星 | 垣 |
|---|---|---|
| **亥** | 天皇星 | 紫微垣 |
| **艮** | 天市星 | 天市垣 |
| **巽** | 太乙星 | 太微垣 |
| **酉** | 少微星 | 少微垣 |

**三吉六秀**（阳宅阴宅通用）：

- **三吉**：巽、艮、兑
- **六秀**：丙、丁、辛、艮、巽、兑

三吉六秀方若有山势、来龙、巷道、马路、朝山、好砂，皆为吉地。**差一点就变三吉的，用移动位置的办法凑上去——这个动作叫"拨砂"。**

> 注：另一派按来龙不同而三吉六秀随之变化（如坎癸申辰来龙，三吉为巽艮震、六秀为辛丙庚）。倪海厦课上讲的是固定版，**服务中统一用固定版，遇到别派说法不要争，说明"派系不同"即可**。

### 4.5 拨砂（赖公拨砂诀）

**人盘中针二十四山五行**（口诀）：

> 子午卯酉太阳火，甲庚丙壬太阴火，
> 乾坤艮巽本属木，乙辛丁癸便属土，
> 辰戌丑未即是金，寅申巳亥皆属水。

**生克判吉凶**（口诀）：

> 生我食神居两榜，比和人才发科场，
> 我克是财为储禄，克我七杀最难当，
> 泄我文章穷到底，女边功名好又强。

| 关系 | 名称 | 主 |
|---|---|---|
| 砂生坐山 | 食神／生砂 | **发科甲**，读书考试 |
| 砂与坐山同气 | 比肩／旺砂 | **人财两旺**，发科场 |
| 坐山克砂 | 财／奴砂 | **财帛** |
| 砂克坐山 | 七杀／煞砂 | **最凶**，祸绝 |
| 坐山生砂 | 泄砂 | 泄气，渐飘零 |

**例（原课例）**：乾山属木（乾坤艮巽属木）——

- 巽、艮、坤方有高砂 → 同属木，**比肩** → 吉，"比肩人财发科场"
- 丑、未、辰、戌方有山 → 属金，金克木 → **七杀** → 凶
- 甲、庚、丙、壬、子、午、卯、酉方有山 → 属火，木生火 → **泄** → 凶
- 乙、辛、丁、癸方有山 → 属土，木克土 → **财** → 吉
- 寅、申、巳、亥方有山 → 属水，水生木 → **食神** → 发科甲

**形与方位要互参**：生、旺、奴砂得吉形则更吉；泄、煞砂得凶形则更凶。砂以**尖、圆、方**为吉形，**歪、斜、破、碎**为凶形。

> 倪海厦的说法很直接：**"以上相当于给风水批八字。"** 好或不好都要讲出理由，不许含糊。

### 4.6 古代地师论山川与人（可直接引用）

**吴景鸾：**
> 福寿之地，人多福寿；秀颖之地，人多轻清；湿下之地，人多重浊；高亢之地，人多狂躁；散乱之地，人多游荡；尖恶之地，人多杀伤；顽硬之地，人多执拗；平夷之地，人多忠信。

**杨筠松：**
> 山肥人饱，山瘦人饥，山清人美，山浊人媸，山完人喜，山破人悲，山归人聚，山走人离，山伸人寿，山缩人低，山明人达，山暗人迷，山向人顺，山背人欺。

这两段是**形法与人的接口**，讲"环境塑造人"时最好用，比抽象说"气场好"有说服力。

## 5. 观水

### 5.1 好水的六个条件

1. **清**——有鱼有虾最好（浊水出"浊富"之人）
2. **曲**——弯曲有情，直来直去无情
3. **无声**——门前水声夜夜可闻，叫**悲吟之水**（原课断语很重，对外转成"长期水声扰动，主家宅不宁、人丁不旺"）
4. **不见来去**——看不到水从哪进哪出，才是藏风纳气
5. **活**——静中有动，是活水；死水主人丁败绝
6. **聚**——水聚天心，忌泄

**嘉泉**：洁净清澈、微香微甜、冬暖夏凉的水。住在旁边，子孙出笔墨文人。

### 5.2 八路黄泉（看来水去水，主孤寡）

**口诀：**
> 庚丁坤上是黄泉，坤上庚丁不可言。
> 巽向先需防乙丙，乙丙巽向祸当前。
> 甲癸向中忧见艮，艮见甲癸凶事添。
> 辛壬水路乾为祸，乾向辛壬祸连连。

**用法**：立向后看水。例：来龙为**庚龙**，则**坤方（西南）不可有来水或去水**，否则犯八路黄泉。

> 现代住宅区多无天然来去水，**以马路、排水沟、车道动线代水看**，但要说明这是"代水"，权重降低。

## 6. 立向

### 6.1 阴龙立阴向，阳龙立阳向

- 罗经第五层（地盘）24 坐山，**12 个红色为阳龙**，其余为阴龙。
- 站在结穴处测来龙方向：乾方来龙 = 阳龙 → **必须立阳向**（朝向罗经上红色方位）。
- 这叫**净龙**（纯净之龙）。

### 6.2 八煞黄泉（绝对不能立的向）

**口诀：**
> 坎龙坤兔震山猴，巽鸡乾马兑蛇头；
> 艮虎离猪为煞曜，坟宅逢之一旦休。

**翻译成可执行的表**（龙＝来龙所在卦，向＝不可立的向）：

| 来龙卦 | 24 山范围 | **不可立之向** |
|---|---|---|
| 坎 | 壬子癸 | **辰** |
| 坤 | 未坤申 | **卯** |
| 震 | 甲卯乙 | **申** |
| 巽 | 辰巽巳 | **酉** |
| 乾 | 戌乾亥 | **午** |
| 兑 | 庚酉辛 | **巳** |
| 艮 | 丑艮寅 | **寅** |
| 离 | 丙午丁 | **亥** |

- 罗经上第三圈（黄泉煞）直接标出，**不必背**：把罗经转到正南北，子午位是空的（无黄泉煞），其余对应即得。
- 例：测得来龙为**丁山**，第三圈丁对应坤 → **丁山不立坤向**；测得**子山**，对应空白 → 可立向。
- **原理**：立向可转，是为了"吃到来砂"。若左龙处有一座形如天子之山，宁可转向去朝它，不朝水口。

### 6.3 分金煞

24 山每山之间的**分界线**（正中那条线）不可立向，叫**分金煞**。这是最基础的一条，与八煞黄泉并列为"绝对不能立"。

### 6.4 穿山七十二龙（优中选优）

- 24 山 × 3 = **72 龙**，在已选定的来龙里再细分吉凶。
- **测量位置**：过峡处定盘针；无峡则在入首后方，与来龙连成一线处测。
- **罗经看法**：倒数第三层，**红底金圈 = 吉**，金底黑圈或打叉 = 凶；圈＝大吉、三角＝次吉、空白＝凶（12 个地支位空白，因 12／10 最小公倍数 60，故 12 处无字）。
- 遇吉方"阴阳冲合"；不吉方"人财耗散"。**吉则用，不吉则换地方。**

### 6.5 透地六十龙（棺位）

- 透地龙＝**棺材实际放到地下的位置与朝向**，比立向更细。
- 两个坐山管五条透地龙。
- 罗经标注：**"正"＝珠宝线，子孙吉**；**"七三""三七"＝不吉**。
- **火坑线**：十几年后捡骨，一开全是蚂蚁；儿孙淫乱、少亡、孤寡。
- **差错空亡线**：人财耗散、败绝。
- **墓碑要与棺材成 90°**，方便后人复测透地龙。

> 古代有风水师在下葬时偷偷转动方向来报复主家，山势再好，透地吃的气不正，全局皆输。**所以下葬当天必须有人复核透地线——这是行业内的风控动作。**

## 7. 葬法

| 情况 | 方法 | 操作 |
|---|---|---|
| 常规 | 标准葬 | 按 §6 立向、定棺位 |
| 土色太红、地气太热太旺 | **泄葬法** | 下葬后**隔一年取出透气**，再放回去 |
| 龙穴处石头多、气不足 | **补土法** | 大量加土把气**包住**，不让它泄 |
| 无真龙穴、但四周山围成局 | **骑龙葬** | 见下 |

### 7.1 城局与骑龙葬

- **城局**：四周被山围起来、可藏风纳气的密闭地形（有城墙的古城就是标准城局）。
- 城局里，**龙脉＝中间高、两边低**的那条脊。
- 因城局本身藏风纳气，**整条龙脉都可以葬**，不必找真穴——这叫**骑龙葬**。
- 骑龙葬**官带非常大**，后代可做官。
- **禁忌：葬在龙背最高处最凶**，因为不能藏风纳气。
- 高阶用法：骑在龙脉上，远山刚好是紫微星垣之形，且**比眼低、比心高** → 下面出臣民，上面出天子。

### 7.2 地气旺衰的现场判断

| 地气旺 | 地气不足 |
|---|---|
| 石头是龙骨、泥土是龙肉 | 贫瘠、无泥土 = **石龙／干龙／死龙** |
| 地表膨起、地肉饱满 | 地表塌陷 |
| 草木旺盛 | 杂草杂乱或草木枯萎 |

**不能葬的地**：干龙、死龙、草木枯萎之地。

### 7.3 阴宅与阳宅的位置关系（这条最实用）

| 类型 | 规则 |
|---|---|
| **阴宅** | 放进龙穴里 |
| **阳宅（鸟瞰）** | **不可盖在龙穴上，不可正朝陵线**，要盖在**侧边** |
| **阳宅（剖面）** | **房子绝对不要盖得比后面的山高**——压到后面的龙，叫**强龙压主**，地龙被压则"改朝换代"（对外转成：主家运不稳、易生变故） |

## 8. 分房与应期

### 8.1 分房宫位法（这块风水荫哪一房）

| 子女数 | 对应 |
|---|---|
| 1 个儿子 | 满盘应在他一人 |
| 2 个儿子 | **左青龙＝长房**，**右白虎＝次房** |
| 3 个儿子 | 左青龙＝长房，**明堂正中＝中房**，右白虎＝三房 |

- 可配合面相参看（见 `12-天纪-人相与望诊.md`：乾卦位、额头、天庭）。
- **来龙已泄气者，多荫女儿。**

### 8.2 能荫几代

- 看**青龙（长房）**与白虎的大小：龙比虎大，长房吃到的风水好。
- 看**官星支脉伸出多少条**：**一条支脉管十年**。十条支脉 ≈ 一百年 ≈ 三代。
- 古话"富不过三代"，说的就是**能找到超过三代的地利本来就不多**。

## 9. 城市里怎么办（现代落地，必须掌握）

绝大多数客户没有真山真水。**不许硬套龙穴理论，要诚实降级。**

### 9.1 公墓选位（可执行清单）

| 看什么 | 好 | 差 |
|---|---|---|
| 靠山 | 后方有实山／实墙，**但墓不高于后山** | 后排最高处（风大不藏风）、后方空虚 |
| 左右 | 左右有山包或树带环抱 | 左右空缺、被更高墓碑夹压 |
| 明堂 | 前方平广、不积水 | 前方逼仄、排水沟直冲、台阶直下 |
| 水 | 排水缓、曲、暗 | 直冲墓前、反弓、长期积水 |
| 风 | 站得住、无持续强风 | 风口、山脊顶部 |
| 路 | 缓行、有遮挡 | 主路直冲、车道正对 |
| 朝向 | 不犯八煞黄泉、不压分金线 | 犯八煞、骑分金线 |
| 周边 | 草木茂盛、有生气 | 草木枯萎、乱石裸露、紧邻垃圾站／焚烧炉 |

### 9.2 骨灰楼／壁葬／树葬

- 无龙穴可论，**只论位置与环境**：层高、朝向、是否正对通道／电梯／焚烧口、是否有自然光、是否常年潮湿。
- **不硬编"这是龙穴"**。诚实说：这类安放方式，风水权重主要落在"后人祭扫是否安心、家族是否和睦"上。

### 9.3 迁坟与修坟

- 只在两个前提下建议：**明确的结构性问题**（积水、塌陷、树根穿棺、紧邻污染源）与**家族已达成共识**。
- **不因"断出来不好"就劝人迁坟。** 迁坟涉及家族关系、地方习俗与法规，代价极高。
- 建议必须给**替代方案**：修排水、补土、加遮挡、植树挡风、调整祭扫动线。

## 10. 分寸（阴宅服务尤其要守）

1. **不断生死、不承诺发贵。** "葬此必出贵"这类话，讲义里可以说，服务里不能说。
2. **不劝迁坟牟利。** 阴宅是良心事——倪海厦原话：**"绝不可见客户有钱就攀龙附凤，见客户贫穷就嗤之以鼻，这是一良心事业。"** 这句要当作执业守则。
3. **不介入家族争产。** 分房断语（长房如何、二房如何）极易被用来打家族官司，**只讲环境，不点名评人**。
4. **讲义铁口一律转风险语言。** "主绝后""少亡孤寡""出天子"全部不照搬。
5. **尊重法规与公墓管理规定。** 不建议违规扩建、占地、改向。
6. **代理性判断要标出。** 没有到现场、只凭照片和描述时，必须说明"未现场定盘，结论为初步判断"。
