# 二十一、堪舆·古籍谱系与流派辨析

> 这一份解决一个问题：**客户问"你这套是哪一派、出自哪本书"时，怎么答得清楚、答得不心虚。**
>
> 核心原则：**分清哪些是倪海厦课上亲授、哪些是堪舆学通识、哪些是本馆的方法论延伸。三者不许混着说。**

## 1. 倪海厦自己的立场：无派

《天纪》堪舆部分开篇原话：

> **"台湾很多堪舆学派，比如三元派、三合派。我们没有派，各取其精华，全部纳入易经的体系来谈。"**

这句话要**原样引用**。它同时说明三件事：

1. 他**不隶属**三元派或三合派；
2. 他的做法是**取各家精华，用易经（八卦／64 卦）统一**；
3. 因此**不能把他归为"三合派风水师"或"三元派风水师"**——那是误标。

他对自己体系的定位：**峦头沿用传统形法，理气简化为"名位 + 64 卦"**。

### 天纪的体系自述（同书前言）

> "之所以命名为［天纪］，因为它专门运用易经的原理来解释宇宙之间包含天地万物的物性，也就是探讨天地之间的纪律的一套著作，所以包含**八字、紫微斗数、风水地理、面相**等命理，所谓**上知天文，下知地理，中知人事**的一套易经理论。"

> "天纪已经于 1994 年完成。"

**两条用处**：① 印证本馆的"五块"划分不是自创；② 天纪成书早于《人纪》，且他明确说"天纪的知识无法去害人，只有助人"——这是他给自己体系定的分寸，与本馆一致。

### 4.1 读书顺序（给想深入的客户／自学者）

```
第一步 建立观念：《葬书》→《青囊经》→《雪心赋》
第二步 形法实战：《撼龙经》→《疑龙经》→《人子须知》
第三步 理气入门：《地理五诀》→《催官篇》
第四步 阳宅专修：《阳宅三要》→《八宅明镜》
第五步 进阶理气：《沈氏玄空学》（三元）、三合双山五行（三合）
```

> **一本书读十遍，胜过泛览百种速成手册。** 这句话适用于所有想学风水的人。

## 5. 流派辨析

### 5.1 两大阵营

| | **形势派（峦头／形法）** | **理气派** |
|---|---|---|
| 看什么 | 看得见的山水形状：龙、穴、砂、水 | 看不见的方位与时运：卦、星、运、向 |
| 代表 | 杨筠松、曾文辿、廖瑀 | 赖文俊、蒋大鸿、沈竹礽 |
| 核心书 | 撼龙经、疑龙经、雪心赋 | 催官篇、青囊经、沈氏玄空学 |
| 长处 | 可现场验证，不易骗人 | 精细，能解释"同形不同运" |
| 短处 | 城市无真山水时难用 | 流派互斥，各说各话 |

**古法共识：形为体，理为用。** 形不好，理气再吉也无用；形好而理气不合，发力打折。**先看形，再论气**——这个顺序不能倒。

### 5.2 理气派内部

| 派 | 核心方法 | 特征 |
|---|---|---|
| **三合派** | 双山五行、三吉六秀、72 龙／60 龙、八煞黄泉 | 重**立向与来去水**，重静的格局。**倪海厦课上的立向、拨砂、九星，多属这一路** |
| **三元派（玄空）** | 三元九运、飞星、挨星、替卦 | 重**元运与时间**，同一间房不同运吉凶相反 |
| **九星派** | 贪狼巨门等九星配 24 山 | 与三合高度重合，常被视为三合的一支 |
| **八宅派** | 东四宅／西四宅、游年八宅 | 重**人命与宅向的配对**，简单易用，但粗 |
| **形势派** | 纯峦头 | 不看方位，只看形 |

### 5.3 倪海厦的位置（怎么对外说）

一句准确的话：

> **〔本馆归纳〕"峦头沿用传统形法（杨公一路）；理气不入任何一派，简化成'名位 + 六十四卦'，把八卦配家人、把宫位与门向组合成卦来断。立向、拨砂、九星这些技术，取自三合一路的通行之法。"**

**不许说**：
- ❌ "倪海厦是三合派" / "倪海厦是三元派"
- ❌ "倪海厦的独门秘法"（他把方法讲得很明白，不是秘传）
- ❌ "倪海厦的风水最准"（无派系优劣可言）

## 6. 派系冲突怎么处理（团队规则）

同一间房，三合说吉、玄空说凶，是**常态**，不是谁算错了。

**处理四步：**

1. **先声明**："风水有多个流派，同一间房不同派结论可能相反，这是正常的。"
2. **选主线**：按用户的问题选一套（问"人"走名位、问"气"走纳气、问"墓"走形法+三合立向）。
3. **给交叉**：另一套只作提示，标明"另一派会怎么看"。
4. **不裁判**：**不说"那一派是错的"。** 说"两套体系侧重不同"。

**唯一例外**：涉及**安全与法规**（结构危险、违规占地、骗钱敛财），必须明确表态。

## 7. 面对"你这个有科学依据吗"

诚实回答，不硬撑：

> 〔本馆归纳〕"风水是一套**环境与人的经验对应系统**。它有一部分是可以用现代常识解释的——采光、通风、噪音、动线、私密性、空间压迫感，这些确实影响人的情绪与健康；也有一部分是**象数推演**，属于传统文化范畴，无法用现代科学验证。我给你的结论会区分这两类：能讲清道理的讲道理，属于象数推演的我明确标出来。**最终判断权在你。**"

**不要**：编造"量子""磁场""能量波"之类的伪科学解释。这是本馆红线。

## 8. 分寸

1. **引用古籍要给出处。** 说"《葬书》讲藏风聚气"可以；说"古书上都这么讲"不行。
2. **不冒充倪海厦亲授。** 属于通识层的（八宅、玄空、阳宅三要），要说明"这是通行之法，非倪师所讲"。
3. **不贬低他派。** 贬低同行是最快的失信方式。
4. **不神化。** 不称"秘法""绝学""不传之秘"。
5. **不卖书、不卖课、不发展下线。** 咨询就是咨询。
