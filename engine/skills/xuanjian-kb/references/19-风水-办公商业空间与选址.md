# 十九、风水·办公、商业空间与选址

> 办公风水在本体系里有**两条独立主线**，与住宅完全同构：
> 1. **形家 + 三元纳气**（课程体系，见 `08`／`09`）——看气口、看形煞、看桌位纳气
> 2. **天纪内外卦**（倪海厦亲授）——用"方位 + 门向"起一卦，以卦断吉凶
>
> **判一间办公室，主线只能走一条**，另一条作交叉提示，分歧必须讲出来。

## 1. 天纪内外卦法（办公室的正式解法）

### 1.1 取卦规则

| 要素 | 取什么 | 卦位 |
|---|---|---|
| **内卦** | 办公室（或老板座位）**所在方位** | 下卦 |
| **外卦** | **门的朝向** | 上卦 |

**原课例子**：门朝**西北（乾）**＝外卦，老板在**西南（坤）**＝内卦 → 坤上乾下 = **地天泰，大吉大利**。

### 1.2 常见组合速查

内卦＝方位，外卦＝门向。下表给**同一方位**在不同门向下的卦（内卦固定，查外卦）：

| 内卦（座位方位） | 门朝乾（西北） | 门朝坎（北） | 门朝艮（东北） | 门朝震（东） | 门朝巽（东南） | 门朝离（南） | 门朝坤（西南） | 门朝兑（西） |
|---|---|---|---|---|---|---|---|---|
| **乾**（西北） | 乾为天 | 水天需 | 山天大畜 | 雷天大壮 | 风天小畜 | 火天大有 | 地天泰 | 泽天夬 |
| **坎**（北） | 天水讼 | 坎为水 | 山水蒙 | 雷水解 | 风水涣 | 火水未济 | 地水师 | 泽水困 |
| **艮**（东北） | 天山遁 | 水山蹇 | 艮为山 | 雷山小过 | 风山渐 | 火山旅 | 地山谦 | 泽山咸 |
| **震**（东） | 天雷无妄 | 水雷屯 | 山雷颐 | 震为雷 | 风雷益 | 火雷噬嗑 | 地雷复 | 泽雷随 |
| **巽**（东南） | 天风姤 | 水风井 | 山风蛊 | 雷风恒 | 巽为风 | 火风鼎 | 地风升 | 泽风大过 |
| **离**（南） | 天火同人 | 水火既济 | 山火贲 | 雷火丰 | 风火家人 | 离为火 | 地火明夷 | 泽火革 |
| **坤**（西南） | 天地否 | 水地比 | 山地剥 | 雷地豫 | 风地观 | 火地晋 | 坤为地 | 泽地萃 |
| **兑**（西） | 天泽履 | 水泽节 | 山泽损 | 雷泽归妹 | 风泽中孚 | 火泽睽 | 地泽临 | 兑为泽 |

### 1.3 怎么读这一卦

| 卦 | 商业含义（按《地脉道》卦义推） |
|---|---|
| **地天泰** | 上下通气、内外和顺 → **最吉**，宜作为首选目标 |
| **乾为天** | 主事者当位，权威足、格局大 → 吉 |
| **水火既济** | 事已成、守成为要 → 吉，但忌扩张 |
| **风雷益** | 有增上之势 → 吉，宜进取 |
| **火天大有** | 财禄丰 → 吉 |
| **天地否** | 上下不交、事不通 → 凶，宜改门向或改座位 |
| **天水讼** | 争讼、内耗 → 凶 |
| **火水未济** | 事未成、久拖 → 不利急进 |
| **泽水困** | 受困、资源枯竭 → 凶 |
| **山水蒙** | 判断不清、易受骗 → 不利决策 |

> **读卦原则**：卦义就是断语，不必套用住宅的六亲断法。**办公看的是"事"，住宅看的是"人"。**

### 1.4 实操顺序

1. 让客户用**实体罗盘**测出：办公室（或老板座位）在住宅／楼层平面的哪个方位
2. 测出**大门朝向**
3. 组合成卦（查 §1.2）
4. 判吉凶，给两条调整路径：
   - **换门向**（改入口、改动线）
   - **换座位**（把决策者挪到与门向成吉卦的方位）
5. 若两者都改不了 → 退到形家＋纳气做次级优化（§2）

> **注意**：门向是"公司对外的气口"，改门向成本高、常常不可行；**换座位是最便宜的杠杆**。先谈座位。

## 2. 形家与纳气在办公空间的落地

### 2.1 外局（决定上限）

| 看什么 | 好 | 差 |
|---|---|---|
| 前方（明堂） | 开阔、有广场／绿地、视野通透 | 逼仄、正对高楼、被遮挡 |
| 左右（龙虎） | 左（龙）略高略实，右（虎）略低 | 虎边高压（口舌、女性强势、是非） |
| 后方 | 有靠（更高建筑在后） | 后方空缺、背水、背路 |
| 路 | 门前道路缓行、环抱 | 路冲、反弓、无尾巷、天斩、壁刀、尖角 |
| 水（代水：车道、人行道、排水） | 缓、曲、环抱 | 直冲、反弓、急流 |

**外局决定上限，内局只能优化。** 一栋外局极差的写字楼，内部怎么摆都救不回来——这句话要敢对客户讲。

### 2.2 座位

| 项目 | 规则 |
|---|---|
| 背后 | **实墙有靠**；忌背门、背窗、背走道 |
| 前方 | 开阔，不直对大门／厕所门／电梯口 |
| 头顶 | 不压梁、不压吊柜 |
| 侧方 | 不被尖角、柜角、柱角切射 |
| 与门关系 | 座位不正对门（气直冲），也不背门（无靠且易受惊） |
| 纳气 | 按 `09`：以**人坐的位置**为太极点，测可达气口方位，判旺衰 |

### 2.3 功能位分配（把名位逻辑用到公司）

天纪的名位是"角色对应卦位"，公司里可以类比：

| 角色 | 对应卦位 | 逻辑 |
|---|---|---|
| 决策者／老板 | **乾（西北）** 或 **坤（西南）** | 乾为君、坤为众；老板居乾最正 |
| 财务 | **坎（北）** 或 **兑（西）** | 坎主藏、兑主收；忌财务位在动线上被人穿行 |
| 业务／对外 | **离（南）** 或 **震（东）** | 离主明、震主动 |
| 研发／策划 | **巽（东南）** 或 **艮（东北）** | 巽主入、艮主止（静而定） |
| 仓储／后台 | 无人带、角落 | 压凶、不占主位 |

> **这一节是"类比推演"，不是讲义原文。** 用时必须说明："这是把天纪名位逻辑类推到公司角色，属本馆方法论延伸。"

### 2.4 常见办公忌讳（都有明确理由，不是迷信）

| 忌讳 | 理由 |
|---|---|
| 老板桌正对大门 | 气直冲、无遮挡，决策易受干扰 |
| 老板桌背窗 | 背后无靠，主决策不稳、易被牵制 |
| 财务室在主动线上 | 人来人往，主漏财、账目易出错 |
| 厕所／茶水间在中宫 | 秽气居中，全员受累 |
| 开放式工位全员背门 | 集体无靠，主团队不稳、离职率高 |
| 会议室门正对大老板办公室门 | 议事直冲决策位，主内部争议多 |
| 前台正对电梯口 | 气进出太急，客源留不住 |
| 办公室整体狭长如通道 | 气不聚，主奔波、留不住人 |

## 3. 居家办公（本专题的原点，详见 `08`）

三条核心冲突与解法：

1. **办公位与卧床同室** → 用屏风／柜体分隔，办公位不正对床
2. **办公位背门背窗** → 移到背实墙、面向开阔处
3. **视频会议镜头位** → 背景整洁稳定，背后忌通道、忌门、忌杂乱（背景乱，心气散）

## 4. 店面与商铺

### 4.1 选址三看（顺序不能颠倒）

**一看来水（人流动线）**

- 人流**从哪来**、在哪**转弯**、在哪**停留**，比"朝向吉凶"重要得多。
- **迎水局**：人流／车流从门前缓行而过、在店前有停留点（转角、公交站、树荫、斑马线）为上。
- **水直冲**：快速车道直冲门前，人来不聚 → 差。
- **反弓**：道路／高架呈弓背向外弯对店门 → 主客源外流。

**二看明堂（门前空间）**

- 门前要开阔、平整、无遮挡、不积水、不被天桥／大树／变电箱压住。
- **明堂逼仄的店，做不大**——这是最硬的判断，胜过一切理气。

**三看门向与卦**

- 门向与店主座位／收银台组合成卦（§1.2）。
- 收银台宜在**进门斜对角**（传统"财位"位置，也是动线上最稳的位置），忌正对门。

### 4.2 业态差异（谨慎谈，只讲通用逻辑）

| 业态 | 关键 |
|---|---|
| 餐饮 | 明堂（排队空间）、排烟与排水、灶位不压中宫、门不直对厕所 |
| 零售 | 门面宽度、橱窗通透、动线不穿堂（忌一进门就看见后门） |
| 诊所／美业 | 私密性（内间不在动线上）、采光、等候区明亮 |
| 办公服务（律所／会计） | 稳重感（方正、有靠、色调沉）、会议室不正对门 |
| 教培 | 采光与安静、文昌位（东南／正东）宜作教室或书架 |

> **不编造"。** 业态差异在本体系里没有系统讲义，以上是形家通用逻辑的合理应用，**必须标注为延伸推断**。

## 5. 选址总清单（可直接给客户）

**第一层：外局（决定 60%）**

- [ ] 周边有无路冲、反弓、天斩、壁刀、尖角、无尾巷
- [ ] 前方明堂是否开阔、平整、不积水
- [ ] 左右龙虎是否失衡（虎边高压为忌）
- [ ] 后方是否有靠
- [ ] 人流／车流方向是否环抱、能否停留
- [ ] 是否紧邻殡仪馆、医院、垃圾站、高压电塔、变电箱、屠宰场（阴气／秽气／火气）

**第二层：本体（决定 25%）**

- [ ] 户型是否方正、缺角在哪一宫
- [ ] 采光通风（忌全暗、忌暴晒）
- [ ] 层高与梁柱位置
- [ ] 大门与电梯／楼梯的相对关系
- [ ] 厕所是否在中宫、是否有窗

**第三层：内局（决定 15%）**

- [ ] 决策者座位（背实墙、不背门、不背窗、不压梁）
- [ ] 财务位是否在动线上
- [ ] 门向 × 座位方位所得的卦
- [ ] 工位是否集体背门
- [ ] 前台与电梯口关系

## 6. 开业、搬迁、装修动工的择时

| 项目 | 做法 |
|---|---|
| **先避八离日、四决日** | 春分／夏至／秋分／冬至前一日（离日）、立春／立夏／立秋／立冬前一日（决日），共八天，人气最弱，不办大事。见 `13-天纪-人间道.md` §8 |
| **避冲主事者生肖之日** | 老板／店主本人生肖的冲日不用 |
| **避岁破、三煞方动土** | 装修动工尤要避；不确定就查通书，**不凭记忆口算** |
| **优先选"成、开、定、除"类日子** | 按 `83` 的建除十二神挑；**本馆自排，不靠通书猜**，用 `scripts/zeri.py` 出值日与宜忌 |
| **看行业节律** | 零售看节假日与发薪日、餐饮看商圈人流周期——**现实节律优先于择日** |

> **分寸**：择日是"锦上添花"，不是成败关键。倪海厦在人间道反复讲**知命不认命、事在人为**。若客户为等一个"吉日"而错过租约或旺季，**要明确劝他先做事**。
>
> **本馆现行边界**（`69` §5、`83` §0）：择日开**五项**——建除十二神、黄黑道、离日决日、岁破月破三煞、冲命主；**紫白日课、董公 144 条、正体五行造命仍未开**。客户要这三样，如实说"本馆不做"，可以讲它是什么，但不给排。

## 7. 分寸

1. **不承诺营业额。** "改了这个门向业绩翻倍"是绝对禁止的表述。
2. **外局差的铺子要敢劝退。** 这是专业价值所在——帮客户省下一笔错误的租金，比事后化解更有用。
3. **区分"可改"与"不可改"。** 门向、承重墙、厕所位置基本不可改；座位、隔断、动线、功能分配可改。**先谈可改的。**
4. **公司是人的集合。** 老板的八字、合伙人的关系、行业周期，权重都不低于风水。讲清"风水只占三分之一"。
5. **不介入股权与人事斗争。** 若客户拿风水当清洗工具（"你看这个方位对他不利，让他搬走"），**拒绝配合**。
6. **不推销摆件、不推销"开光"物品、不做"生基"。** 这是倪海厦明确反对的三件事（另见 `21-堪舆-古籍谱系与流派辨析.md`）。
