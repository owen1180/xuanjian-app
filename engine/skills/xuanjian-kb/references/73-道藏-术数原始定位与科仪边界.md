## 1. 先认清：道藏是有选择地收，不是"传统大全"

道藏按三洞四辅十二类编次。十二类里，与术数有关的是**众术类**与**方法类**；与宗教实践有关的是**威仪类**（斋醮科仪）、**神符类**（符箓）、**表奏类**（青词章表）。**两类分列，不是一回事。**

### 1.1 一个能直接用的统计结论〔本馆据文本库实测〕

在《正统道藏》＋《续道藏》一千五百零四篇中：

| 有 | 无 |
|---|---|
| 《黄帝宅经》（阳宅）、《儒门崇理折衷堪舆完孝录》（葬法） | **子平八字书**——一部都没有 |
| 《许真君玉匣记》（择日）、《易林》（卦变占辞） | **紫微斗数书**——一部都没有 |
| 《黄帝龙首经》《金匮玉衡经》《授三子玄女经》（古六壬三经） | **五星禄命书**——没有 |
| 《黄帝太乙八门入式诀》三篇（太乙／古奇门） | **相法书**——没有（《太清神鉴》《玉管照神局》《月波洞中记》均不在） |
| 《通占大象历星经》《秤星灵台秘要经》（星占） | **《三命通会》《渊海子平》一类**——不收 |
| 《周易参同契》十二种注（丹道）、《抱朴子》内外篇 | — |

**为什么**〔本馆归纳〕：道藏收的是"**与修道相关**"的术——择地而居（宅经）、择日而入（玉匣记）、择时而行（六壬太乙）、观星候气（星经）、借易言丹（参同契）。而子平、紫微、五星禄命属**世俗禄命**，兴起于五代两宋，不在道藏编纂者的收录范围内；相法同理。

> **三条纪律**：
> 1. **别拿"道藏里有"当"正统"的证明**——道藏本身有取舍，收与不收都不构成价值判断。
> 2. **别拿"道藏里没有"当"不可信"的证明**——子平、紫微自成谱系，与道藏是两套传承（`35`）。
> 3. **引经不等于用经**。查到出处只解决"这话有没有来历"，不解决"这话对不对、能不能断"。

## 3. 道术之辨：术数与科仪在文献里是两回事

道藏里"众术类"与"威仪类／神符类"分列——**这条文献事实不变**。变的是本馆对它的用法：
**分列不意味着只做一半，意味着两条线要分开走、分开算、分开说。**

| 术数线（本馆自己断） | 科仪线（本馆评估、转介、不代做） |
|---|---|
| 排盘、断命、看相、堪舆、择时 | 祈福、拜斗、安太岁、超度、补财库、净宅、开光 |
| 讲方位、形势、纳气 | 讲类型、源流、所需、花费、禁忌、常见骗局 |
| 讲"这段运要当心什么" | 讲"这场该不该做、找谁做、怎么不被宰" |
| 出断语与方案 | 出**评估与转介建议**（交 `xuanjian-ritual` 技能） |

### 3.1 三条界线（不是三条禁令）

1. **知识可以整理，法事不能外包。** 本馆能把科仪讲透、评透，但不代做——仪轨须师承，文本不能代。数据与评估进 `xuanjian-ritual`，操作仍在道长手里。
2. **可以建议，不能承诺。** 说"这场可以做，属民俗通行"可以；说"做了就好"不行。凡承诺效果，一律不做。
3. **可以转介，不能抽成。** 介绍有师承的道长可以；收介绍费不行——收了，断语就不再独立（`40`）。

> **丙档为什么连转介也不给**：锁心、迷魂、五鬼运财、诅咒一类，转介等于参与。**这一档只解释，不指路。**

### 3.2 一句对外表述

> **〔话术示例〕"术数我断，科仪我评。要做法事，我告诉你这是什么、该不该做、大概多少钱、该问对方哪几句；做不做、找谁做，你自己定。我不代做、不代收、不抽成。"**

## 4. 客户问"要不要做场法事"：三步三档

这是高频问题，也曾是本馆最容易失守的地方。**先问清，再分层，最后落到实事。**
完整条目、花费构成、七问识别法与骗局清单，见 `xuanjian-ritual` 技能（`02` 与 `06` 两册）。

### 4.1 三步

| 步 | 问什么 | 为什么 |
|---|---|---|
| **一 · 谁建议的** | 谁说的？道士、算命先生、亲戚、还是网上？ | 分清"信仰需求"与"销售话术" |
| **二 · 承诺什么** | 说了做什么、多少钱、保证什么效果？ | 只要承诺"转运／治病／挽回婚姻"，就进入高风险区 |
| **三 · 你现在最怕什么** | 怕病、怕离婚、怕破产、还是怕"不做会出事"？ | 找到真正的恐惧，才给得了实事 |

### 4.2 三档答法

| 情形 | 答法 |
|---|---|
| **只是求心安**（家里有事、心里不安） | "做不做由你，信仰上的事我不劝也不拦。但别指望它改命——你这盘上真正要处理的是××，这个季度先做××。" |
| **对方承诺效果**（做了就转运／病好／复婚） | "凡是承诺效果的要格外小心。本馆不做这种承诺，也没法验证。你先把钱按住，把话问清：做几次、多少钱、没效果怎么办。" |
| **已付大额** | "先停。收据、转账记录、聊天记录都留好。涉及诈骗可以报警，涉及宗教场所乱收费可以向宗教事务部门反映。" |

### 4.3 三条不许

1. **不许说"都是骗人的"**——否定他人的信仰，既越界又结仇。
2. **不许说"做了也没用"**——你无法证伪，说了就是断言（`66`）。
3. **不许抽成**——转介可以，收介绍费不行；丙档连转介也不给。

> **本馆的立场**：**信仰归信仰，术数归术数，生意归生意。三样分开，才谈得上专业。**

## 5. 天文、地理、因果：能给到什么程度

### 5.1 天文

| 能讲 | 不能讲 |
|---|---|
| 二十四节气与真太阳时（排盘要用，`36` 已算） | 星占断国运、断州郡 |
| 二十八宿与分野的**文化源流** | 用分野断某地吉凶 |
| 七政四余**是另一套体系**（本馆不排） | 拿七政四余断命（无师承、无校准，不出结论） |

> 一句话：**天文用来校时，不用来断事。**

### 5.2 因果

《太上感应篇》讲"祸福无门，惟人自召"，是**道德劝诫**，不是因果计算器。

客户问"我是不是上辈子造了什么孽"——
- 不许答"是"（无据）；
- 不许答"不是"（也无据）；
- 该答：**"这套说法讲的是劝人向善，不是解释苦难的公式。你现在的处境，盘上有盘上的原因，现实有现实的原因；我们能处理的是后者。"**

### 5.3 地理

形峦（`17`）＋理气（`09`／`18`）已经够用。城市无真山真水就诚实降级（`14` 铁律四），**不许硬编"这是龙穴"**。

## 6. 边界

1. **不给科仪操作细节。** 不教画符、不给咒语、不给仪轨步骤、不给手诀。给到"这是什么"为止。
2. **不评宗教高下。** 道教、佛教、民间信仰，本馆不作优劣比较。
3. **不把文献当灵验证明。** 查到出处只说明"有来历"，不说明"有效"（`65`）。
4. **不重分发文本。** 三条文本库中两条未标许可，一条要求署名同许可；本馆只读、只核对、不搬运。
5. **不越界断生死。** 《抱朴子》讲长生、道教讲度亡，本馆一律不接"能不能延寿""走了以后怎样"这类问（`46`）。
