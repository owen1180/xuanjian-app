# 三、断语体系：从分数到具体事项

> 打分与取用神是地基（`01`、`02`），这一份讲怎么落到财富、事业、婚姻、六亲、健康，以及断语时必须守的分寸。

## 1. 断盘的五条基本法

1. **先原局，后大运流年**。原局是第一用神所在，原局不吉，大运再好也是有限度的好；原局吉，大运冲克才叫真凶。
2. **地支是大运吉凶的核心**。大运天干为表象、地支为实质。断一年、断一步运，先看地支把原局哪个字动了。
3. **实透与虚透**。天干有的虚透、有的实透，力量不同，结论不同。地支有根为实透，无根虚浮。天干没有"伏吟"，只有干支同现才叫伏吟（地支相同为地支伏吟）。
4. **反生为克**。印已经够多，再加印不是帮身，是消耗。取用要看"渴什么"，不是看"哪个字名义上生我"。
5. **尊重现实**。若断语与实际明显冲突（例如断父缘厚而实际被父抛弃），以现实为准，回去改判，不许拿理论压事实。这是课上的原话：命理师要尊重基本事实。

## 2. 十神的功能定位

| 十神 | 主事 | 关键分辨 |
|---|---|---|
| 比劫 | 自我、同辈、竞争、分财 | 比劫多而无制 → 破财、合伙吃亏 |
| 食伤 | 表达、才华、产出、子女（女命） | **伤官伤尽**（强旺无冲克）则用伤官；**伤官无制**（为忌而无印制）则惹祸 |
| 财 | 财富、父亲（男命）、妻（男命） | 财要能"落到手上"，虚透之财看得见拿不到 |
| 官杀 | 事业、地位、约束、丈夫（女命） | 官杀混杂格局一般；有官不宜再透七杀 |
| 印 | 学历、庇护、母亲、名声 | 印多反生为克；印为忌而实透，常见"生活有保障但人很累、心态差" |

**十神的"级别"**：日元分数定下来后，用同一套生克加减推出各十神的大致分值。分值高的十神才具备实际支配力，分值虚浮的十神只是"名义上在场"。这是断财富事业层次的量化依据。

## 3. 财富

看四件事：**财的分值、财是否有源（食伤生财）、财是否被劫（比劫夺财）、财能否入库**。

- 身强财弱、有食伤 → 走食伤财运发；无食伤则财源断
- 身弱财旺 → 财多身弱，见财反累，须先扶身
- 财虚透无根 → 有账面收入，难积累
- 比劫成群又无官制 → 财来财去，合伙易破
- 财为忌而大运财实透 → 常见"有车有房但很辛苦、心态不好"，不等于发财

## 4. 事业

看**官杀与食伤的组合**，以及用神落在哪个十神上。

- 用神为官 → 宜体制、管理、有约束的平台
- 用神为食伤 → 宜技艺、创作、专业输出
- 用神为财 → 宜经营、贸易、与钱直接打交道
- 用神为印 → 宜教育、研究、文书、需要资质背书的行当
- 官杀混杂又无制 → 多头受制，职场常遇两难

## 5. 婚姻与感情

1. **先看原局配偶星与配偶宫**（男看财、女看官；日支为配偶宫）。
2. **看分数**：配偶星分值高则配偶"有力"，虚浮则缘分浅。
3. **看冲合**：日支被冲，婚动；被合，婚成或牵绊。
4. **合婚**：以双方分数与用神互补性为主，不以生肖属相为主。
5. **忌**：不因一个"孤辰""寡宿"就断不婚；不断具体结婚年份，只断"这段时间婚动强"。

## 6. 六亲

| 六亲 | 星 | 断法要点 |
|---|---|---|
| 父 | 偏财（男）、正财 | 财星受制或虚浮，父缘薄或父不得力 |
| 母 | 印 | 印被财克，母辛劳或缘薄 |
| 兄弟 | 比劫 | 比劫受制，手足助力少 |
| 子女 | 食伤（女）、官杀（男） | 子女宫与星同看，单看星不判有无 |
| 配偶 | 财／官 | 见第 5 节 |

课上强调：**六亲缘分看"走势"不看"有无"**。断"与父沟通少、聚少离多"是对的；断"克父"是越界。

## 7. 健康

以五行偏枯定位脏腑，以冲克定应期，**只作提醒**。

- 木弱受克 → 肝胆、筋、目
- 火弱受克 → 心、小肠、血脉
- 土弱受克 → 脾胃、肌肉
- 金弱受克 → 肺、大肠、皮毛
- 水弱受克 → 肾、膀胱、骨
- 某五行在局中被反复冲克、又逢大运加重 → 该脏腑易出问题，逢冲之年为应期

**红线：不诊断、不开方、不替代就医。** 只说"这段时间注意哪个系统，建议体检"。

## 8. 象法（高级）

课程后段专门讲"象法"（第 48、50、51、52 课）。要义：

- 象是"取类比象"，把一个干支组合读成一幅画、一件事、一个人。
- 象法建立在分数与用神已经判准之后，是**表达层的精修**，不是替代推理的玄谈。
- 断象要留退路，用"像是""有这种味道"这类措辞，不用"必然是"。

## 9. 断语分寸（团队统一标准）

| 可以断 | 不要断 |
|---|---|
| 倾向、概率、走势 | 必然、铁口、限期 |
| "这步运财上顺" | "某年必发百万" |
| "这个方位易生口舌" | "某月必打官司" |
| "注意肝胆，建议查体" | "你有肝病" |
| "这段婚动强" | "某年某月必离婚" |
| "宜体制内" | "你只能当公务员" |

## 10. 常见误用

- ❌ 拿一个十神断全局。伤官见官只是一个组合，还要看分数、看有无制、看是否伤尽。
- ❌ 天干地支不分轻重。断大运只念天干，是最常见的错。
- ❌ 把"忌神实透"一律断凶。要看原局好坏，原局吉时忌神实透常表现为"辛苦但有保障"。
- ❌ 六亲断生死。这是行业红线，也是这门课明确反对的。
