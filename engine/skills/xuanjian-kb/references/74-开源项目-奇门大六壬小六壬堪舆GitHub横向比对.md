## 2. 先给四个结论

**结论一：这门学问在 GitHub 上，几乎全是"排盘"，几乎没有"断法"。**
441 个仓库里，能确定性排出盘面的（奇门、六壬、玄空、八宅）有一批成熟品；**能给出可核验断语的，一个都没有**。所有带断语的项目，断语来源要么是通行本汇编，要么是大模型生成。→ 本馆继续守"引擎管算得准，成员管断得稳"，**不许拿开源项目的断语当依据**。

**结论二：形法（峦头）在开源世界里是空的，这不是偶然。**
`峦头` 全站 4 条、`形势派` 8 条、`葬法` 13 条、`墓地风水` 3 条，**去掉无关项后实质项目为 0**。原因不神秘：峦头靠眼、靠现场、靠师承口授，写不成规则表。→ **形法不移植、不引擎化**，只借别人的读书账本与看图流程。此条与 `17`／`shizhan-pai` §4.3「形峦五步」互为正反：那五步是人的动作，不是程序的动作。

**结论三：理气（玄空、八宅、三元、紫白）恰好相反，全部可算，且已有可复算的公开锚点。**
这是本册最有用的部分：**本馆引擎目前只有八宅明镜：玄空三盘、替卦、三元纳气三项缺，紫白日课属"候选未决"**（`36` §2.2、`69` §5）。开源里已有四家把这些做全，且公开了校验盘式，可拿来当**对拍基准**（§11）。

**结论四：小六壬是这一轮唯一"可以直接补进本馆"的完整术种。**
起课只有一条取余公式，六宫顺序固定，断语有通行本，且已有项目把"事类不参与计算"写成产品宪法。本馆此前无此术，本轮补入并同时上闸门（§5、`scripts/xiaoliuren.py`）。
（第五轮另补六爻与梅花两门通行之法，见 `82`；那两门**引擎早能装卦、册页不会断**，属另一类缺口。）

### 3.1 用局四法，不要混着说

奇门起局第一道分歧不在断法，在**用局**。开源项目里四种都有人实现：

| 法 | 做法 | 谁在用 | 本馆口径 |
|---|---|---|---|
| **拆补法** | 节气内按日拆补，缺则借补 | `kinqimen` 默认可选、`taobi` | **主线**（通行主流） |
| **置闰法** | 超神接气、置闰补局 | `kinqimen` 可选、`taobi` 标注未完成 | 可提，须说明是另一派 |
| **茅山法** | 另有起元规则 | `taobi` | 可提，须说明 |
| **均分法** | 按节气实际时长三等分定上中下元（`taobi` 原创） | 仅 `taobi` | **只作异说登记**，不混入主线 |

**铁律**：客户拿某个 App 排出的盘来问"为什么和你的不一样"，先问**用局法**，再问**寄宫**（寄坤／寄坤艮／寄四维），最后才谈断法。三样不同，盘必不同，**不是谁算错了**。

### 3.2 节气精度这一项，值得学

`taobi` 把节气算到分钟级（VSOP87D＋章动＋ΔT）。本馆引擎的节气取自历法库（`36` §2），**未按分钟级天文算法校准**。
**影响面**：交节当日、交节时辰出生或起局者，可能差一个节气、差一个元、差一局。
**处理**：凡起局时刻落在交节前后两小时内，**必须回历法库复核交节时刻，并在结论里写明"交节临界，用局存疑"**。这一条进 `16` 与 `ziwei-qimen-master` 的硬规矩。

## 5. 小六壬：本轮补入的术种

### 5.1 它是什么（最短定义）

六壬类里最简的一门，又叫「诸葛马前课」。**不用盘、不用工具，只用手掌六个指节**，以农历月、日、时辰三数推课，几秒得结果。属"快卦"，不属"深卦"——问的是**眼前这件事的起、过程、落点**，不问一生。

### 5.2 六宫与掌位（顺序不能错）

| 序 | 宫 | 掌位 | 五行 | 方位 | 六神 |
|---:|---|---|---|---|---|
| 1 | 大安 | 食指根 | 木 | 东 | 青龙 |
| 2 | 留连 | 食指尖 | 土 | 四角 | 螣蛇 |
| 3 | 速喜 | 中指尖 | 火 | 南 | 朱雀 |
| 4 | 赤口 | 无名指尖 | 金 | 西 | 白虎 |
| 5 | 小吉 | 无名指根 | 水 | 东北 | 六合 |
| 6 | 空亡 | 中指根 | 土 | 中 | 勾陈 |

> **配属只作参考，不参与起课。** 六宫的五行、方位、六神，各本不一（最明显是小吉的水位有作北、有作东北者；留连的方位有作四角、有作东南者）。**宫名与先后次序是硬的，配属是软的**——课式只由宫名与次序决定，配属只影响怎么讲，不影响怎么算。客户拿别本对，说"宫位一致、配属有别"，不作对错之争。
> 本表按本馆取用的通行本登记，出处见 §5.6 三项目；**未逐本核对过刻本**，标"未核"。

### 5.3 起课公式（0 基，已复算验证）

```
月宫 = (农历月 − 1) mod 6
日宫 = (月宫 + 农历日 − 1) mod 6
时宫 = (日宫 + 时辰序) mod 6        # 时辰序：子=0，丑=1 …… 亥=11
```

**复算例一**（`kev1nzh37/liuren` README 自带例）：阴历六月初五辰时。
月宫 = (6−1) mod 6 = 5 → 空亡；日宫 = (5+5−1) mod 6 = 3 → 赤口；时宫 = (3+4) mod 6 = 1 → 留连。
原文结论"六月为空亡月、初五为赤口日、辰时为留连时"——**三处全中**。

**复算例二**（自拟）：农历正月初一子时。月宫 = 0 大安；日宫 = (0+1−1)=0 大安；时宫 = 0 大安。三宫皆大安，属"三安"课。

> 两例足以定式：公式无歧义，**不涉随机数**。凡项目声称"随机起课"，那是另一套（活数起课），须分别标注。

**三条口径，起课前必须定死**（脚本已实现，`--late-zi` 可切）：

| 口径 | 本馆默认 | 另一派 | 影响 |
|---|---|---|---|
| **晚子时**（23:00–23:59） | 算**当日** | 归**次日**（课式移一位） | 只影响跨日那一小时 |
| **闰月** | 按**本月**算 | 按**次月**算（移一位） | 只影响闰月那一个月 |
| **活数取余** | 余 0 作 6 | 余 0 作 0（即不入宫，重取） | 少见，遇之争即说明 |

**为什么这三条要写死**：它们不是流派优劣，是**换日／换月的边界**。同一个人同一件事，晚子时按当日还是次日，宫位差一位，断语全变。**不写死，就会出现"同一时刻两次起课结果不同"——那不叫灵活，叫不可复现。**

### 5.4 三宫怎么读

| 宫 | 管什么 |
|---|---|
| 月宫 | **起因**——事情的来处、根由 |
| 日宫 | **过程**——中间怎么走、卡在哪 |
| 时宫 | **结局**——落点、成与不成 |

**组合优先于单宫**：三宫同气（三安、三速喜）为一类；首尾相冲（大安→空亡）为一类。单看一宫不作断。

### 5.5 断语三档与红线（本馆口径）

通行本断语为六宫各一段韵文（大安事事昌／留连事难成／速喜喜来临／赤口主口舌／小吉最吉昌／空亡事不祥）。这些韵文里**含大量本馆禁语**：

| 原诀字样 | 本馆不出口的版本 |
|---|---|
| "病者出西方""恐怕染瘟殃""病人逢暗鬼" | 改为"身体方面宜先做检查，别拖"——**不给病名、不给方位定生死** |
| "行人有灾殃""官事有刑伤" | 改为"这件事在手续或文书上容易卡，宜先备齐材料" |
| "失物寻不见" | 可留（属可验证的低风险断言） |
| "求财无利益" | 改为"这一趟财上偏薄，宜守不宜进" |

**三条硬规矩**：

1. **事类不参与计算。** 选"求财"还是"婚姻"，只决定给哪一条断语，**不改课式**。任何声称"按事类调宫"的实现，都不是小六壬。
2. **一事先问、不重占。** 同一件事当日重占，取第一课；要复核就换日，并说明"这是第二课"。
3. **不越级。** 小六壬只答"起、过程、落点"，**不答"为什么""该怎么办"**；要后者，转奇门（`16`）或四柱（`01`–`03`）。**不许用小六壬替代命理判断。**

### 7.1 从 `hidefate` 借来的六条工程纪律

这六条不是风水内容，是**怎么把风水做成可核验系统**；与本馆 `57` 闸门、`43` 置信度同向，建议逐条对齐：

2. **每条结论必答三问**：哪几派支持、有多确定、依据哪条古法——写成必填字段，不是可选项。
3. **概率收敛在 3%–92%**，不输出 0% 或 100%，不说"必定"。

→ 意思是：**本馆现在用的历法，在 1900–2100 年这一段够用，出了这一段不保证**；而"交节临界"那两小时的风险，不是历法算错，是**换日规则与取整口径**没定死。

**三条可落地的做法**（比换库更重要）：

1. **先定口径，再谈精度**：换年（立春 vs 正月初一）、换日（早晚子时）、闰月归属（按本月／次月）、节气取整（到日／到分）——四项写死在配置里，逐次显式传入，**不依赖库的默认值**。`hidefate` 踩过这个坑：`iztro` 按"立春当日零时"换年、它的八字层按"立春时刻"换年，生于立春当日者两盘差一位，它的处理是**报出保留意见、不选边**（见 §7.1 第 5 条）。
2. **临界点强制标注**：凡时刻落在交节前后两小时，结论首行写"交节临界，用局存疑"（`ziwei-qimen-master` 硬规矩）。
3. **不必为了 1 秒换库，但要为了对拍留接口**：现有 `lunar-javascript` 够日常用；真要做 1900 年前或 2100 年后的盘（客户拿祖辈生辰来问），先用 `stem-branch` 或 `sxtwl` 复算节气，再起局。**跨出 1900–2100 的盘，不标"历法存疑"就是硬伤。**

> 一句话：**风水四项是"会不会算"，历法一项是"算的那一天是不是那一天"。后者错了，前面全错。**

## 12. 明确不采的东西

| 内容 | 出处 | 为什么不采 |
|---|---|---|
| 任何"AI 看照片自动判风水吉凶／自动点穴" | `Shine2099`、多款小程序 | 图能判形、判不了气；穴要现场（`23`、§6.3） |
| 风水项目的**概率预测**（P＝先验×调节×触发） | `hidefate` | 参数是工程取值而非统计拟合，作者自陈；**不给客户报概率数字** |
| "病名—宫位"映射 | `hidefate` 已自行删除；部分项目仍在用 | `24` 红线：只说部位与提醒，不说病名 |
| 摆件化解（八卦镜、五帝钱、水晶、貔貅） | 多个商业项目 | `yangzhai-master` 铁序：摆件永不入门 |
| 五鬼运财、鲁班尺催吉 | `CompassEx` | 属催财术，非形非气；且其代码 AGPL 不可引 |
| 太乙神数、金口诀、铁板神数 | `kinliuren` 同作者系列、`jkj-rs` | 本馆未开此三术；不因"顺手"就扩科 |
| 停止维护的项目 | `qimen_star`（2023 声明停更） | 风险自担，且无许可 |
| 以"倪海厦"名义捆术数功能 | `nihaixia-app`（见 `64` 结论七） | 非天纪内容，独立标记、不混入 |

## 13. 一句话结论

> **这一门在 GitHub 上，能算的都不难算，难算的一条也没算。**
> 奇门、六壬、玄空、八宅可以借来对拍，**借的是算式，不是断语**；峦头与葬法借不来，**因为那是眼学，不是算法**。
> 新补的小六壬只补"快卦"一格，**不许拿它替代命理**；四缺的理气引擎，先对拍、再落地、断语仍旧归人。
> 最底下还有一层：**历法**。风水四项决定"会不会算"，历法一项决定"算的那一天是不是那一天"。
