# 四十二、同盘分辨与流年应期

> 两件事本来分开讲，但都指向同一个操作：**从「命局说了什么」落到「这一年、这一个人身上怎么发生」**。同盘分辨管人，流年应期管事。

## 1. 同八字的共性与分岔

### 1.1 课程原例

同产房、同地点、同时辰、前后相差不到五分钟出生的两个女婴，八字完全相同，四十三点五分，丙火生秋、假从，食神制杀格。十余年后回访：

| 项 | 甲女 | 乙女 |
|---|---|---|
| 父缘 | 父母离异，父亲此后再无联系，跟母亲生活 | 父母未离异，但与父亲关系不好 |
| 母亲 | 个人能力强 | 能力一般 |
| 性格 | 独来独往，利益心重，不受管束，口舌利 | 脾气躁，爱摔东西，不交朋友，嫉妒心强，但守时守诺 |
| 共性 | 都不得父缘助力；都欲望重、目的性强、不服管 | 同左 |

**结论：命局给的是共性与倾向，家庭给的是分岔方式。**

同一组「用神空位、父星不现」，在甲女身上表现为「父亲彻底消失」，在乙女身上表现为「父亲在身边但关系坏」。**事情的类别一致，形式与程度不同。**

### 1.2 这条读法怎么用

1. **共性可以说满，形式不能说死**。可以说「与父缘薄、不得父助」，不能说「父母必离异」。
2. **同盘对比时，先列共性，再找分岔**。共性越多，说明命局的力量越强；分岔越大，说明环境（家庭、地域、教育）介入越深。
3. **分岔通常出现在三处**：父母是否同在、家境厚薄、受教育程度。这三样决定了同一个命局在哪种「容器」里展开。

### 1.3 与档案体系的接口

八字唯一档的意义正在于此：

- **《档案卡片》写共性**——格局、用神、强弱、六亲的类别、关口的年份。这一份对同盘所有人通用，所以全档只写一份。
- **《命主记录》写分岔**——哪位命主、什么家庭、实际走到哪一步。这一份必须分开，因为同一个八字在不同容器里长出不同的人生。
- **查重不是为了防止重复劳动，是为了防止把别人的分岔套到这个人头上。**

同盘不等于同命，同盘只等于同一个起点。

## 2. 流年吉凶的判法

### 2.1 地支主体，天干主象

**吉凶整体看地支。流年的天干代表外在的迹象**，一般不作吉凶的主判。

有的门派「大运看地支、流年看天干」，本体系不取：**天干表象，地支实质。**

天干只在两种情况下会影响吉凶：

1. **天干受地支生扶，或与地支比合一气**（如壬子、壬申、癸酉、己丑）。此时天干得地，其力真实，吉凶一并显出来。
2. **天干克到原局天干的用神**。此时天干不是「象」，是「伤」，要算进去。

反例：壬戌年。戌土定这一年的吉凶方向，壬水只是外在迹象，不作主判。

### 2.2 地支三重含义

一个流年地支，同时携带三层信息，按序取用：

1. **它本身的十神**——酉为财，这一年主要的事就与财有关。
2. **它与原局的刑冲合害**——酉若冲原局之卯，卯为印：印为忌则得名得位，印为用则失位失名（贪财坏印），或应在母亲长辈身上。
3. **若与原局无反应**，就按它本身的十神概念直断。

**这一条是应期断法的骨**：先看反应，再看本体。有反应时，反应优先于本体。

### 2.3 十神在流年的应象

课程原例给到前三组，后面按通行体例补齐并标注。

**比劫在流年**
- 为忌：口舌是非、争斗、破财、被夺、虚耗、盲目投资
- 为用：合伙、结盟、得同道与手足之助
- 比劫克财：为忌则妻、父一方有事；为用则妻、父一方有耗但利己，**缘分同时变薄**

**印星在流年**
- 为忌：劳累、辛苦、郁闷、工作与居所不稳
- 偏印为忌：饮食不慎、车辆之厄、不利子女
- 为用：车、房、学习、契约、单位、场所向好
- 印克食伤：食伤为用则不自由、受压抑；食伤为忌则收敛散漫

**官星在流年**
- 为忌：官非、小人、名誉地位职务受损
- 为用：任职、受管、责任加身而有序

**财星、食伤在流年**：按同一体例推——财为用主进项与实务，为忌主耗与争夺；食伤为用主表达、技艺、子女之事，为忌主口舌、放纵、与官相战。

### 2.4 出断语的次序

1. 定用神（`02`、`39`）
2. 看大运有没有改掉原局层次（`01` 第七节、`41`）
3. 看流年地支与原局哪一处发生关系
4. 判该处是用是忌
5. 用十神应象落成具体事类
6. 天干只作「迹象」的补充描述

**不可跳步**：直接从流年干支背断语，是市面通病，也是本馆最容易翻车的地方。

## 3. 边界

1. **同盘不作优劣比较**。同八字两个人，只能说共性在哪、分岔在哪，不说谁命好谁命差。
2. **流年只断事类与方向，不断具体事件与金额**。说「这一年因财起争」，不说「会赔多少钱」。
3. **同盘案例涉及第三人时，只讲与提问相关的最小范围**。
4. **同产房、同分钟的极端案例，说明的是「环境分岔」的力量，不是「命不准」**——这一点必须主动讲给用户，否则同盘者拿到两份不同结论会以为算错了。
