# 四十三、强弱七档与校对法

> 本册解决一个最实际的问题：分数算出来了，到底能断到多高、哪一档必须回头问客户。
> 体例来源：第九课「用神形象论」、第十三课「日元分数与强弱层次」、历年答疑五档分类（四十五分以下、四十五至一百零五、一百零五至一百一十五、一百一十五至二百七十二、二百七十二至四百三十五）。

## 1. 七档是七个世界，不是七个形容词

课程把旺衰分七层：**从弱、太弱、偏弱、中和、偏旺、太旺、专旺**。分数只覆盖其中五档（太弱、偏弱、中和、偏旺、太旺），另两档的处理方式**不一样**，用前必须分清：

| 另两档 | 引擎怎么做 | 人还要做什么 |
|---|---|---|
| **专旺** | **自动报**：435 分以上直接判专旺 | 验"是不是真专旺"——气势纯度、有无杂气破格。引擎只认分数 |
| **从弱** | **不判**：0 分与 44 分**都报"太弱"** | **人来看有无一线生助**：一个中气、一处余气都算有；有 → 太弱（假从），全无 → 真从（弃命从弱） |

两档的取用方向不同，别混：**太弱怕生扶、顺势化泄；从弱顺从所从之势**（连化泄都不必，直接顺）。

> **命名统一（本馆口径）**：第三档以上本馆一律用「**偏旺**」「**太旺**」。课程与部分册页另作「偏强」「太强」，是同一档的别名，**不是两个档**。对外只用一个词，报告里不许两种混着写——同一张盘两个先生一个说"偏强"一个说"偏旺"，客户会以为在说两件事。`01` 是打分法的根，本册向它看齐。

| 档 | 分数区间 | 一句话本质 | 取用总方向 |
|---|---|---|---|
| 从弱 | 趋零且无根 | 无所依托，只能依附 | 顺从所从之势 |
| 太弱 | 四十五以下 | 有根而极薄，撑不住 | 顺势化泄；太弱怕生扶，不怕泄耗 |
| 偏弱 | 四十五至一百零五 | 弱而可扶 | 生扶，取印比 |
| 中和 | 一百零五至一百一十五 | 两边都站得住 | 随运而变，动态取用 |
| 偏旺（别名偏强） | 一百一十五至二百七十二 | 强而可泄 | 泄耗，食伤、财、官择一路 |
| 太旺（别名太强） | 二百七十二至四百三十五 | 势成，只可顺 | 顺其旺神，不可硬逆 |
| 专旺 | 四百三十五以上或成格 | 一气专纯 | 顺其气势，看纯度 |

**分数只定强弱，不定吉凶。** 一百分的盘可以过得很好，三百分的盘也可以过得很苦——苦在运不帮忙。把分数当吉凶，是外行最常犯的错。

## 2. 取用总口诀

课程给的总纲是十六个字：**强抑弱补，通关调候，顺势化泄**。前四字管偏强偏弱，中间四字管两头打架与寒暖失衡，后四字管太旺专旺。

三条硬规矩：

1. **取官则不用食伤，取食伤则不用官。** 两路并用，用神互克，等于请两个有仇的人一起办事。
2. **用神要在原局找有力的那一个。** 同一个阵营里，谁有本气根、谁实透，谁当用神；虚透的只是空头承诺。
3. **喜用不能互克。** 生用神者为喜神，克用神者为忌神，生忌神者为仇神。

## 3. 五档的断语力度（决定话能说多重）

| 档 | 能断到什么程度 | 不能断什么 |
|---|---|---|
| 太弱 | 可断"顺着走才顺，硬扶反添乱"；可断忌印比 | 不断"扶起来就发"；不断具体数额 |
| 偏弱 | 可断忌财官食伤；可断宜借力、宜依附平台 | 用神虚透时不断大发，只断温饱与安稳 |
| 中和 | 只给窗口与概率，如"这三年都有可能" | **一律不铁口**。同盘两人可一婚一未婚 |
| 偏强 | 可断忌印比；可断哪一路泄耗最有效 | 不断"必贵"；用神被合出时不断顺 |
| 太旺 | 可断怕犯众怒；可断某运多宫位同动 | 不断死、不断败；只提关口与宜忌 |

### 3.1 引擎不提示、要你自己补的三处

`score.py` 报出档位时会附一段"必做校核"，但那段话**盖不住三种情况**。这三种它不报，不是它算错，是它不认：

| 盲区 | 引擎实际行为 | 你要补的动作 |
|---|---|---|
| **① 阴干判从** | 校核提示只写"**阳**干难从、坐印难从、生扶之月难从"——**阴干一个字没提** | 阴干门槛虽低，**同样要先找一线生助**（`80` §2）。有生助即"太弱（假从）"，不判真从 |
| **② 带边分数** | 100–105 与 115–120 两段，引擎按硬线报原档（100–105 报"偏弱"、115–120 报"中和"），**不说"你正站在档边"** | 认出这是 `02` §1.4 的**宽读带**：仍按原档判，但**结论降一档、先走 §4 校对五步**再定 |
| **③ 从弱** | 0 分与 44 分**都报"太弱"**，不会报"从弱"（见本册开头） | 人来看有无一线生助，决定"太弱（假从）"还是"真从（弃命从弱）"，取用方向随之改 |

**为什么把这三条写在这里**：不是给工具挑毛病，是提醒**别把引擎当判决书**。它算的是分数，分数只覆盖五档；档位之外的判断（从、纯度、带边），本来就是人的活。`36` §3.6 也立了同一条：两种口径并存时要公开分歧，不许静默顶替。

## 4. 校对法：中和档的唯一正解

中和档（一百零五至一百一十五）是最难取用的一档，课程原话是"最难取的是中和的用神"。这一档不许凭分数硬断，必须走校对。

**五步校对法：**

1. **先立假设。** 按分数与月令给一个方向：偏强则用泄耗，偏弱则用生扶，中和则两说并列。
2. **取样本。** 让客户报两三个印象最深的年份，或一步整运（十年）的整体顺逆。样本要"有感觉"的年份——升职、失业、结婚、生病、破财，越具体越好。
3. **对方向。** 顺的年份落在生扶（印比）还是泄耗（食伤财官）？据此反推喜忌。
4. **以事实为准。** 反馈与假设相反时，改假设，不改事实。课程的意思是「以校对出来的事实为准」——**此处是转述，不是逐字原话**（原讲义此段为口语，全量语料中未见该句的逐字稿，`65` §8 的「归纳」一档）。
5. **校不出来就收手。** 怎么问都说不上来、一件明显的事都没有，说明这盘平顺，不必强断。老实说"这盘平顺，看不出大关口"，比编一套更体面。

**三条经验：**

- 疑太弱的，多为偏弱；疑偏弱的，可能是太弱。两头最容易错。
- 阳干难从，坐印难从，生在生扶之月难从。三条里中一条，先按偏弱论。
- 生在夏天而日主属金水、生在冬天而日主属火土，原分数要打二到三成折扣再定档。这是调候对分数的修正，不是另立一套。

## 5. 大运能改档，流年改不了

- **大运能改变原局十年的状态**，可以把偏弱推成中和，也可以把中和压成偏弱。
- **流年改不了格局**。一年的三合只是短暂，不足以让一个盘"变从"。
- 判某步大运是否改档，看三件事：大运地支是否生助根气、是否破坏原局的合、是否引出新的成局。

**假从随大运升降（2026-11-03 补自第二十四课）**：假从盘最不稳——走印运把日元扶起，假从即降为偏弱，**原局用神随之全部转忌**（格局降级：从「用财官」变「忌财官」）；走泄耗运又把偏弱推回假从（用神复位，感情稳、收入起）。所以「从局多富贵」不是必然——一步生扶运足以让假从变穷。报这种盘，**先看下几步大运往哪个方向推，再谈富贵，不许见「从」就说贵**。

## 6. 用神的边界：管什么，不管什么

这一条最容易被越界使用，必须背下来：

| 用神管 | 用神不管 |
|---|---|
| 思想境界、眼界 | 健康与寿命 |
| 人脉与贵人层级 | 感情是否和睦 |
| 事业成就、名望、作品 | 生活是否舒适 |

课程举的例子很硬：霍去病官至大司马，二十四岁去世；一批女星事业极好而婚姻不顺；李嘉诚九十岁前每天六点起床。**好运不等于舒服，坏运不等于倒霉。** 用神到位往往伴随扒皮拆骨般的辛苦，只是事后回看，那几年确实在长。

## 7. 落到嘴边怎么说

- 不说"你这个分数低，命不好"，说"这一局的内耗重，能借的力少，所以走法要变——先依附平台，别急着单干"。
- 不说"你是中和，看不准"，说"这一档两边都站得住，得靠你自己报两个年份来定方向，我才能把话说准"。
- 不说"你走印运发不了财"，说"这步印运衣食不缺，但心里憋，做事有头无尾，是保障够而出口少"。
