# 六十、合参：四柱与紫微双盘交叉验证

> 本册是**常设规程**，不是可选项：**凡出四柱分析，必同时排紫微先天盘，做完交叉再落笔。**
> 单盘能看清「力度」，看不清「领域」；能看清「结构」，看不清「环境权重」。两盘各补对方的盲区。
> 立此册的由来：2026-11-02 孙造一案，八字判「前三十年受压、三十五岁后起势」，紫微在同一阶段给出「命宫空宫借星、身宫落官禄、文星拱命」，两条线在「靠文书资质立身」上完全咬合——这类互证，单看任何一盘都拿不到。

## 1. 为什么必须双盘

| | 四柱能给的 | 四柱给不了的 |
|---|---|---|
| 力度 | 打分法定旺衰、用神级别、断语封顶 | 性格的「形状」、行业的「形态」 |
| 时间 | 大运岁运合冲、应期两段式 | 大限主题、身宫着力点 |
| 六亲 | 星与宫、用忌 | 缘分厚薄的环境成因 |
| 结构 | 官印相生、财旺生官这类关系 | 环境权重（空宫、借星、夹拱） |

紫微反之：星情细、宫位全、环境权重清楚，但**没有分数**，容易把「看着热闹」当成「层次高」。

一句话分工：**八字定「能到多高」，紫微定「从哪条路上去」。**

## 2. 四条铁律

1. **同源同刻**：紫微用农历太阴月与真太阳时，必须与八字同一时刻、同一出生地。真太阳时把时柱推前一格时，两盘一起改，不许一盘改一盘不改。
2. **先各自独立，再交叉**：两位分析师各自出结论，不许一边看对方结果一边凑。交叉由主理人做。
3. **一致加权，分歧并列**：两盘同指＝强，单盘＝弱；冲突时两说并写、标「待验证」，不许用一盘压另一盘。
4. **不许叠煞吓人**：两盘的负面象不许相加成「必凶」。一处象要「命盘有结构 ＋ 紫微有宫位 ＋ 岁运有引动」三点同指，才可提。

## 3. 交叉七法（逐层对照）

### 3.1 定盘层

- **命宫地支 对 日支、时支**：同一位者，该支所主之事权重加倍；命宫落在空亡之支，主「底色靠借、随环境塑形」。
- **五行局 对 日元强弱**：局数只表节奏（二局快、六局慢），**不作强弱**；两者不合时以八字分数为准。
- **命主／身主 对 日元十神**：只作性格补充，不作定论。**命主／身主是星，命宫／身宫是宫，不许混说。**

### 3.2 性格层

- 命宫主星（无主星则借对宫）× 庙旺 → 性格的「形状」。
- 三围十神（月干／日支／时干）→ 性格的「力度」。
- 合参：星性给词，十神给分量。**星吉而十神为忌 → 「有这个心性，但这股劲常被用错地方」**；星弱而十神为用 → 「本事在，性子不显」。

### 3.3 事业层

- 官禄宫主星 ＋ 身宫落宫 ＋ 三方四正 → 行业形态与着力点。
- 八字官杀／印／食伤 → 适配路线与断语封顶。
- 合参：**紫微给「哪一行」，八字给「能不能到高层」。**

### 3.4 财层

- 财帛宫（含禄存、化禄、空劫、旬空）→ 来钱方式。
- 八字财星与食伤、比劫 → 财的分量与忌用。
- 合参：**紫微说「怎么来」，八字说「留不留得住」。**

### 3.5 六亲层（五组必对）

| 六亲 | 紫微 | 八字 |
|---|---|---|
| 母 | 父母宫 | 正印（男命）／偏印（女命） |
| 父 | 父母宫 | 偏财（男命）／正财（女命） |
| 手足 | 兄弟宫 | 比劫 |
| 配偶 | 夫妻宫 | 日支 ＋ 配偶星 |
| 子女 | 子女宫 | 男看官杀、女看食伤 |

三种组合的讲法：

- **两边都薄** → 讲「缘薄、聚少」，不讲「克」。
- **一边厚一边薄** → 讲「星在而位不显」，即「关系在，但日常不密」。
- **兄弟宫薄而交友宫厚** → 明确讲「手足助力少，朋友与同事补得上」。**这是单看八字最容易漏的一条，也是双盘最值钱的地方。**

### 3.6 健康层

- 疾厄宫（星性 ＋ 煞 ＋ 空劫）→ 体质的「形状」。
- 八字五行偏枯 → 体质的「部位」。
- 合参：只说方向与筛查建议，**不落病名**；十五岁以下不作脏腑断语（`52` §7），至亲不谈寿元（`46` §1）。

### 3.7 运限层

- 紫微大限按**虚岁**、八字大运按**周岁**，起运点不同，**不许逐年对齐**。
- 正确做法：以十年为段对照，看这十年「紫微的主题」与「八字的喜忌」是否同向。
- 三档结论：

| 两盘关系 | 结论 | 怎么说 |
|---|---|---|
| 同向（都顺／都逆） | 可加权，断语稍实 | 「这十年两头都指向同一件事」 |
| 一顺一逆 | 外顺内紧／外紧内松 | 「外面看着松，里面绷着」 |
| 错位（紫微安逸、八字受压） | **最有价值的提示** | 「环境看着舒服，人却更累——别顺着舒服走」 |

## 4. 一致的四种形态

| 形态 | 长什么样 | 怎么用 |
|---|---|---|
| **互证** | 两盘同指一事 | 置信度升一级，可写进「定论」 |
| **补盲** | 一盘有、一盘无 | 无的一盘不否定；写「这一块单盘看不出，靠另一盘补」 |
| **加权** | 两盘同指但轻重不同 | 取重的那一盘，另一盘作佐证 |
| **纠偏** | 一盘明显偏乐观／偏悲观 | 用另一盘收口，如紫微吉而八字忌 → 「门路对，力度不够」 |

## 5. 分歧的三种处理

1. **并列**：两说都写，注明各自依据（哪一宫哪颗星／哪一步运哪个字）。
2. **降档**：分歧涉及断语高度时降一档说——不断「必成」，改「有条件成」。
3. **待验**：把分歧写进「待验证事项」，等实际反馈回填。

> **不许现场编一个说法把两边圆上。** 圆得越圆，越容易两头都错。承认分歧，本身就是专业。

## 6. 输出结构（双盘报告固定七段）

> **用户要「完整分析／详细报告／全面评测」时，七段不够用。** 改用 `61-报告模板-通用评测九项双盘.md` 的四册制与九项五字段；本节七段退为「只问一件事、不必九项铺开」时的轻量版。

1. **定盘**：两盘同源的时刻、真太阳时、农历月，以及时辰边界。
2. **四柱**：旺衰（含两套口径）、用神喜忌、格局、断语封顶。
3. **紫微**：命宫／身宫、三方四正、十二宫要点、生年四化、大限。
4. **交叉验证表**：三列——一致项／分歧项／互补项，每行注明两盘各自的依据。
5. **运限对照**：十年为段，与八字大运并列，标同向或错位。
6. **落地建议**：分「改环境 ＞ 改节奏 ＞ 改说法」三层。
7. **边界与待验证**：分寸声明 ＋ 待回填清单。

## 7. 分寸

- 双盘不等于双倍肯定。两盘同指也只说「倾向明显」，不说「必然」。
- 不许把紫微的煞星与八字的忌神相加成灾。
- 紫微的格局名不冒充古籍（`22` §11）；八字的分数不跨盘比较（`43`）。
- 两盘都指向同一健康方向时，仍只作「筛查建议」，不落病名。

## 8. 工具与参数

- **紫微**：`iztro`——`astro.bySolar(公历, 时辰序号, 性别, 闰月取 prev, 'zh-CN')`，时辰序号 子＝0、丑＝1……申＝8……亥＝11。
- **命主／身主 ≠ 命宫／身宫**：前者是星，后者是宫；身宫取 `palaces[].isBodyPalace`。
- **四柱**：`pillar.py`（真太阳时）＋ `score.py`（打分）＋ `yun.py`（岁运合冲）。
