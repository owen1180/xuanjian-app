# 五十七、运行时强校验闸门与输出管线

> 本册把本库散落各处的"分寸红线"**编译成输出前的可执行闸门**，让知识真正约束落笔，而不是靠"这次想没想起来"。
> 配套脚本：`scripts/kb_gate.py`（零依赖，`python3` 直接跑）。知识侧的摘要与本册同源同口径。

## 一、这是什么，为什么需要

本库的红线（铁律五／六／七／九／十、`24`–`28`、`37` §7、`46`）过去是**被动知识**——写在这里，等你想起它。
但同一句话，模型有时想起有时忘，表现就是"时灵时不灵、重复踩坑"。

解决办法是把"被动召回"升级成"**主动约束**"：任何面向用户的文本落笔前，先过闸门。

- **提示词端**（本册 + 下面二/三节）：你自己先默一遍红线，命中即改写。
- **代码端**（`kb_gate.py`）：机械扫描，命中即拦下并给改写方向，不受状态影响。

两道关口任一拦下即改写或停止——这是双保险，不是二选一。

## 二、用法（何时务必调用闸门）

**触发时机**：你准备输出任何涉及"健康和身体、寿元与关口、六亲与婚姻去留、财运事业的绝对断言、阳宅阴宅的灾祸断言、比劫吉凶铁口"的结论之前。

命令行（单条校验）：

```bash
python3 scripts/kb_gate.py "用户的原话" "你准备输出的草稿文本"
```

返回：召回哪些规则、决策（放行／拦截）、违规明细、改写建议。
决策为 `BLOCK_WITH_REWRITE` 时，**不得原样输出草稿**，按建议改写或直接停止该题。

命令行（自测与两侧对拍，两个都该常跑）：

```bash
python3 scripts/kb_gate.py          # 跑内置八条场景，看拦截／放行是否符合预期
python3 scripts/kb_gate.py 对拍      # 脚本与本节 §3·§4 表格逐条对拍，不一致退出码非零
```

> 「对拍」这道是拿教训换来的：这一版册页写到了十八条约束，脚本里却只编了十六条
> （缺 K049 不传播宿命论、K051 理气灾祸不断言），方药剂量表还漏了「不用去医院」一条。
> 靠肉眼对表没发现，是靠同步闸「实现状态文档变更后须重新对拍」的提示才捞出来。
> **漏一条就等于红线漏一条**，所以从此不再靠人记：改完脚本或改完本册，都必须跑一遍 `对拍`。
> 比对时 `.*` 与 `*` 视为同一条（册页给人类看、用通配，脚本给引擎用、是正则）。

程序调用：

```python
from kb_gate import gate
res = gate(user_input, draft)
# res: {"decision": "PASS"|"BLOCK_WITH_REWRITE", "recalled_rules": [...], "violations": [...], "suggestion": "..."}
```

**留痕**：命中即建议留痕——把本次用到的规则编号记入该案的"所用规则编号"（归档四件套要求），供后续反馈回贴与置信度调整。

> 病名表为代表性列举；**任何具体疾病名称、任何方药与剂量、任何"不用去医院"的说法，一律不出口**（`24` §6）。

**后加三类（`KB99` 册《伦理边界与措辞规范》，2026-11-07 同步）**：原表八类管的是「生死／铁口／病名／医疗／道德／宿命／方药／灾祸」，
`KB99` 册七类绝对禁止里还有三类能机械判定，故一并编进闸门——

| 类 | 管什么 | 为什么必须机械拦 |
|---|---|---|
| 恐吓勒索禁词 | 血光之灾、被下咒、不做法事就、必须花钱化解、克父母、被跟踪控制 | 这类话的功能是把恐惧变成收费钩子，**不是措辞偏重，是执业禁区**；不作转译、直接删 |
| 绝对化措辞禁词 | 必定、注定会、绝对会、一定会、逃不掉、一辈子都、肯定能、必然会 | 把倾向说成定论，与「断语封顶」同源；按 `KB99` §3 替换表改成「倾向／更接近／需要留意／一段时间内」 |
| 未成年宿命禁词 | 注定失败、注定不孝、注定婚姻不好、注定身体有灾、天生反骨、没出息 | 给孩子的一生下判词，比给成年人下判词更不可挽回；只讲当下可做的事 |

「百分之百」原属铁口禁词，此处按专家包 `kb_gate.py` 同表**双属**（两侧逐字对齐，不因重复就删），
命中任一归属都拦。**十一类**自此成为唯一口径，旧文档里写「八类」的地方按历史叙述保留，规格以本节为准。

## 四、十八条强制约束（命中即执行）

多规则同时召回时，**安全等级高的先否决**：就医(100) > 寿元(95) > 应期(85) > 望诊/手诊(80) > 方药剂量(78) > 六亲/婚姻(75) > 断语封顶(70/68) > 理气灾祸(60) > 工具纪律(55/50) > 伦理(20)。

| 规则 | 召回信号 | 执行触发（须做什么） |
|---|---|---|
| K024 就医边界 | 疼痛/胸闷/发热/失眠/两周/体检单… | **停止术数分析**，只建议就医；不给病名方药 |
| K046 寿元零禁词 | 还能活/寿元/关口/大限/会不会死 | 一律转"健康关口 + 体检 + 陪伴"，零生死词 |
| K037 象法三道闸 | 哪年出事/应期/引动 | 点数 < 2 只作提示，不许说"这一年会怎样" |
| K025 望诊零病名 | 面色/气色/五色 | 永不言"死色/某病"；零病名零方药 |
| K029 手诊零病名 | 手诊/掌纹/杵状指 | 永不言病名；异常只说尽快就医 |
| K050 方药剂量零承诺 | 每天吃/泡水就好/不用去医院 | 不给任何方药、食疗剂量与停药建议，先就医明确 |
| K003 断语走势 | 六亲/健康/事业/婚姻 | 六亲只讲走势不讲有无生死；零宿命断言 |
| K038 婚姻六亲零词 | 克父/必离/配偶 | 不说必离婚、不讲"克"；去留当事人定 |
| K039 断语封顶 | 必发/必富/必贵/大财 | 含"必X"而层次未达高等 → 改概率表述 |
| K043 中和不铁口 | 中和/档位/分数 | 须提示"需客户报年份校对"，禁铁口 |

| K017 阴宅零禁词 | 阴宅/寻龙/八煞黄泉 | 铁口转风险、不断生死；八煞黄泉绝对不立 |

| K022 紫微纪律 | 紫微盘/盘型/四化 | 盘型认错全篇作废；零寿夭诊断 |
| K041 打分复核 | 日坐羊刃/身强/缺时柱 | 口断须引擎复核；缺时柱不凑分；报分不报小数 |
| K028 不做道德审判 | 不孝/该不该离/劝合劝离 | 零道德审判词；给策略不给谋略，去留当事人定 |
| K049 不传播宿命论 | 注定/孤寡/一辈子没 | 只讲趋势，不给"注定/孤寡"式铁断 |

### 四·补前 断年与去留的分层（2026-11-06 起，v1.73.0）

`61` §3.4／§3.5 起，九项**必须给年份、必须给去留**。这与下面几条闸门**不冲突**，但边界要说清，否则会被拿来互相打架：

| 闸门 | 限的是什么 | **不**限什么 |
|---|---|---|
| K037 象法三道闸 | 点数不足时说「这一年**会**怎样」 | 点数够时给「区间＋主年＋依据」——**这是对的，不是违规** |
| K046 寿元零禁词 | 生死词、能活多久、死关 | 健康关口年、该查哪年（`46` §1 条 2 本馆读法） |
| K038／K028 | 「必离」「克父」、替人签去留 | 给象、给窗口、给两条路的代价——**这是必须给的** |

反过来，两条新毛病要拦：

- **`YEAR_VAGUE`**：只写「这几年／近期／将来／以后」而无四位年份 → 视为没给年份；
- **`NOWHERE`**：把去留推给「看情况／顺其自然／自己决定」→ 视为没给去留。

两条都在 `source_gate.py`（`OB97`），warning 不阻断，但 `preflight`（`TR119`）会把它们列进回执；**报告类稿件出现即返工**。

### 四·补 兜底扫描（2026-11-05 起，v1.58.0）

上表是「召回→执行」的关系：命中召回词，才按该条规则扫它管的禁词类。
这套结构有个致命缝：**召回不到，就一条都不扫**。实测三例整篇穿闸——

| 用户输入 | 草稿 | 旧决策 |
|---|---|---|
| 我最近怎么样 | 你必死，没有救了 | **PASS** |
| 我最近怎么样 | 必死无疑 | **PASS** |
| 我最近怎么样 | 死别之象 | **PASS** |

因为「必死」「死别」不在任何一条的召回信号里（K046 收的是「会不会死／哪年走」）。

**规矩（此后不得再改回）**：禁词红线不问召回，另设一张「禁词类 → 兜底规则」表，命中即拦。
原八类各有唯一归属：生死→K046、铁口→K039、病名→K025、医疗动作→K024、
道德审判→K028、宿命→K049、方药剂量→K050、灾祸断言→K051。
`KB99` 册新增三类（2026-11-07）：恐吓勒索→K039、绝对化措辞→K039、未成年宿命→K049
——挂既有规则，不新增规则条数（仍 18 条）；K039／K049 的 `bannedCats` 与召回信号同步扩了词。
**十一类各有唯一归属，工具侧 `redline.ts` 的 `BANNED_OWNER` 与此处同表**。
兜底违规在明细里标 `禁词·兜底`，与「召回到才拦」区分开；经方通道的方药豁免，兜底同样要守。

**词形撞车窗口**（同日改）：判「处方」「大限」是否为合法词形时，取命中位置**前后各 2 字**判搭配，
正则补 `微`——原窗口只取 1 字，`紫微大限` 的前一字是「微」，取不到「紫」，
于是紫微报告一写「紫微大限」就被当生死禁词拦下。

## 五、经方通道（处方例外，2026-11-02 起）

本馆默认守 `24` 的红线：**方药、剂量、穴位、劝停药一律不出口**。这一条对**除南阳以外的所有人**继续有效。

**唯一的例外**：经方中医师「南阳」在给出"方证与用量"时，可开闸放行——但闸不是白开的。

| 项 | 规定 |
|---|---|
| 谁能用 | **只有 `jingfang-doctor`**。其余成员（含主理人）不得开此通道 |
| 放行什么 | **只放「方药剂量禁词」这一类** |
| 三句硬标记 | 草稿里必须同时出现：`执业医师`、`不可作为处方`、`出处`。**缺一句即不豁免**，按原规则拦 |
| 其余照拦 | 病名、医疗动作（停药／加量／换药）、生死铁口、灾祸断言、道德审判、宿命——**六大类一个不放** |
| 就医提示 | K024 的就医提示在经方通道内"有其一即可"（建议就医／尽快就医／立即就医／去医院／急诊／体检／转诊） |
| 术语掩码 | `太阳中风` 等六经术语、`不可作为处方` 等免责套话，扫描前先抹掉，避免把术语判成病名、把免责判成开方 |

命令行：

```bash
python3 scripts/kb_gate.py "用户原话" "草稿" --rx
```

判断链是死的：**开通道 → 查三句标记 → 齐了才抹术语 → 只放方药一类**。少一步都回到默认拦截。

### 谁不许开方（硬闸）

以下任一情形，**通道关闭，先转诊**：

1. 急症信号：胸痛压榨感、咯血便血、持续高热、意识改变、剧烈腹痛、呼吸困难、单侧肢体无力、突发剧烈头痛。
2. 特殊人群：孕产妇、哺乳期、**十二岁以下**、七十五岁以上、肝肾功能不全、正在服用处方药（尤抗凝、降压、降糖、免疫抑制）。
3. 毒性药与峻药：附子、乌头、细辛、马钱子、巴豆、甘遂、芫花、大戟、水蛭、虻虫——**这十味不给克数**，只讲"这一味在本条里的角色"，用不用由执业医师定。
4. 用户明确说"我不去医院，你就给我开"——**停**。这句话本身就是转诊指征。
5. 十八反十九畏的配伍，一律标注"相反／相畏"，不给合用方案。
