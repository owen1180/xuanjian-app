# 四十九、干支关系总纲（实透虚透、五合边界、地支不随意生克）

> 来源：四柱理学第四课「天干地支关系解读（上）」、第五课（下）、第三课「地支属性 藏干本气」。
> 这一册解决的是**最容易被想当然**的一类错误：把天干那套「相邻就能生克」的用法，原样搬到地支上。
> 本门派的规矩是：**天干主动，地支主静**；地支不在这七种关系里，就当作不发生反应。

---

## 1. 三个层次，别混着用

一组八字里的反应分三层，**每层的规则不同**：

| 层次 | 说的是谁和谁 | 规则 |
|---|---|---|
| 干支关系 | 同一柱内，天干与地支 | 五类：生、被生、比和一气、盖头、截脚 |
| 天干关系 | 天干与天干（跨柱） | 相邻即可生克；另有五合（须相邻、不争合） |
| 地支关系 | 地支与地支（跨支） | **只有七种关系才生效**：六冲、六合、三合、半三合（含拱合）、三会、相刑、相害 |

**地支与地支不在上述七种里，就不发生实质反应。** 哪怕五行上看着是生是克，也只是「有形而无实」。

> 例：寅酉——金克木，看着是克，但寅酉不在七种关系内，**不发生反应**。
> 例：巳辰——火生土，看着是生，实质**不发生关系**。

这条是本门派与市面上许多流派的**硬分界**。别随意让两个地支互相生克。

---

## 2. 柱内五类：实透与虚透

### 2.1 能量比重

**天干的五行能量约为地支的三分之一。** 地支才是这一柱的主力。

所以看一组干支（比如流年干支、某一柱）谁说了算，先判天干在这个柱里是**实透**还是**虚透**。

### 2.2 五类

| 关系 | 术语 | 天干状态 | 例 | 说明 |
|---|---|---|---|---|
| 地支生天干 | —— | **实透有力** | 壬申、乙亥 | 天干得力；地支因生助而被泄耗一部分 |
| 天干地支比和一气 | 比和一气 | **实透有力，力量最大** | 己丑、乙卯、丙午、丁巳 | 上下互助，此柱能量最高 |
| 天干生地支 | —— | **虚透** | 丁未、乙巳 | 天干的能量泄到地支上，天干虚 |
| 天干克地支 | **盖头** | **虚透受损** | 乙丑、丁酉 | 天干克不动地支，反虚 |
| 地支克天干 | **截脚**（截角） | **虚透受损** | 丙子、甲申 | 天干被地支压制 |

### 2.3 怎么用

- 看**流年**给不给力：用金的人，「辛酉」年好过「辛丑」年，更好过「庚子」年。庚子年金生水，金气泄掉，是虚透。
- 看**忌神**到不到得了：忌水的人，「庚子」年比「癸巳」年凶。癸巳年水虽透干却是虚透，那一年真正做主的是巳火。
- 打分引擎的柱型基准正是这套：支生干给分高于干生支，比和一气最高。见 `01` §2、**规则 R-34**。

## 3. 天干五合的边界

五合：甲己、乙庚、丙辛、丁壬、戊癸。合化细节见 `48`；这里只讲**成不成立**。

1. **必须紧邻**。年—月、月—日、日—时。隔一位就不算，这个原则在五组里都生效。
2. **不能争合**。两个天干争一个，不算合。

争合的判定（很容易记错，逐条背）：

| 形态 | 算不算 |
|---|---|
| 甲己乙丙（相邻一对） | 成 |
| 甲乙己丙（隔一位） | 不成 |
| 甲乙丙己（隔两位） | 不成 |
| 甲己甲丙（两甲争己） | **争合，不成** |
| 甲己甲己（两对交叉） | **争合，不成** |
| 甲甲乙己（同干相连再合） | 成，不算争合 |
| 甲己己甲 | 成 |
| 甲甲己 | 成，不算争合 |

一句话：**要有且只有一对，且必须挨着。** 两个夹一个（汉堡包式）才算争合。

> **编者注（二〇二六年十月三十一，反测时挂的待核）**：上表「甲甲乙己（同干相连再合）」一行
> 有歧义。五合只有五组（甲己、乙庚、丙辛、丁壬、戊癸），**乙己不在其中**，按字面判应为无合。
> 若此处想表达的是「同干相连之后再合」，写法应是「甲甲己乙」——两个甲相连、己紧随其后，
> 甲己相邻成合，乙只作干扰。排盘工具按五组硬判，字面写法判无合；此条待回到课程原音核对。

> 五合还有古名：甲己中正、乙庚仁义、丙辛威仪、丁壬淫匿、戊癸无情。
> **这些名号课里明说不参考**——八字里有丁壬不等于「淫」，有甲己也不等于「中正」。对外一个字都不许用，只论化成之后十神怎么变。

## 4. 地支七种关系的力量序

由大到小：

**三会（一个完整季节）＞ 三合 ＞ 半三合**

| 局 | 成员 | 备注 |
|---|---|---|
| 三会木 | 寅卯辰 | 春 |
| 三会火 | 巳午未 | 夏 |
| 三会金 | 申酉戌 | 秋 |
| 三会水 | 亥子丑 | 冬 |
| 三合木 | 亥卯未 | 亥为木长生 |
| 三合火 | 寅午戌 | 寅为火长生 |
| 三合金 | 巳酉丑 | 巳为金长生（**唯一非生助中神的一组**，见下） |
| 三合水 | 申子辰 | 申为水长生 |

**巳酉丑为什么是巳？** 三条理由：一是巳中丙生戊、戊生庚，有炼金之用；二是巳本身多变，遇金变金、遇火变火；三是四季中没有以土为主的季节，土只作过渡。**巳与酉单独相遇时仍是合绊，实质还是克**，只在丑土降温、三字齐聚时才成金局。

**六冲有夹冲**：子午子、申寅申——两个冲一个，力量大于寻常六冲。

**六合分生合与克合**（`44` 判定合出合入即用此分）：
- 生合：午未、寅亥、辰酉
- 克合：子丑、申巳、卯戌

**半三合有拱合**：缺中神的叫墓地半三合（拱合），如巳丑拱金局；**没有「半三会」**。

## 5. 四正、四长生、四库与财库

| 类别 | 成员 | 气性 |
|---|---|---|
| 四正 | 子午卯酉 | 最纯最强的气；三合局里居中为「中神」。命中多者性格一根筋、爱憎分明、易极端；也主桃花（另一种桃花是咸池） |
| 四长生 | 寅申巳亥 | 四正的能量源头，多变，易与他支反应。命中多者适应力强，不像四正那么极端 |
| 四库 | 辰戌丑未 | 辰水库、戌火库、丑金库、未木库。命中多者保守、老实、传统 |

### 5.1 财库怎么查

**日元所克之五行为财，财的五行的库即为财库。**

| 日元 | 财 | 财库 |
|---|---|---|
| 丙、丁（火） | 金 | **丑** |
| 庚、辛（金） | 木 | **未** |
| 壬、癸（水） | 火 | **戌** |
| 戊、己（土） | 水 | **辰** |
| 甲、乙（木） | 土 | **无库**——但辰戌丑未四支**皆为其财**，故财的地支比别人多两个 |

自坐财库＝日支即财库：丁丑、壬戌、戊辰、辛未。

### 5.2 财库的分寸

课程自己把话说得很清楚：

- 「八字中有财库的人不会受穷」——是**大概率**，不是必然。
- 「自坐财库无人不富」——**这句不严谨，不许照搬**。能说的是：自坐财库的人比较节省、能攒得住，甚至有点抠。
- 财库讲的是**守财与聚财的倾向**，不是财富的量级。断语一律转成「攒得住／攒不住」，不许说「富不富」。

## 6. 两条对外分寸

1. **生肖六冲不等于不能结婚，生肖六合也不等于婚姻就好。** 合婚看的是命局模式对不对得上（`38`），不是看属相。谁拿属相来劝分劝合，那是江湖话。
2. **日元五行只在自己的盘里运算，不跨盘论生克。** 「我是木日元、老公是土日元，所以我克他」——错。一组密码一把钥匙，开不了别家的门。见过木日元与金日元相处极好的，也见过火日元与木日元结仇的。
