# 八十五、黄历：一页黄历怎么读

> **黄历是本馆唯一"承认它有用、但坚决不许它做主"的东西。** 倪师用它，用法很窄：查日干支、查离日绝日、看"诸事不宜"三个字什么意思。**他没有拿黄历断过命，也没有教人按黄历挑日子。**
>
> 本册分两层，逐条标清楚：**有原话的**（§1、§3）与**通行之法的栏目算法**（§2）。两层不许混着说——这是 `83` §0 定下的规矩，本册照办。

## 1. 黄历是什么：一本日子的台账，不是命运的判决书

三个定性，全部从原文来：

1. **它是工具书。** 查干支、查节气、查离决日、查"今天写了什么"（第 1、3、4、7 条）。**像查字典，不像看诊断书。**
2. **它是"形"。** 同一页黄历，全国几亿人共用；而命各不同（第 2 条）。**共用的东西定不了各人的命，这是常识层面的反驳。**
3. **它是被"用"的，不是被"信"的。** 倪师在病重一例里翻黄历，是为了确认"明天是不是午日"，断的是**卦象**（`70` §4）；黄历只提供了一个日期事实（第 3、6 条）。

## 3. 「诸事不宜」到底什么意思（本册最值钱的一节）

很多人看到这三个字就慌，或者反过来拿它当万能挡箭牌。倪师在火山旅一卦里把它讲透了：

> 「黄历上面常常有诸事不宜……**那到底什么叫做诸事，就是你很倒霉了之后，不要去做事就好，这要守。**」（天纪 09-hexagrams，火山旅·人间道）

三层意思：

1. **它是"宜守"的信号，不是"凶"的判决。** 意思是当天**别主动出击**——不开新局、不摊大事；不是"出门会死"。
2. **它对应的卦是旅**（火山旅：失所、漂泊）。**"诸事不宜"是卦象的语言，不是气象预报。** 所以同一天里，有人诸事不宜，有人照常办事——**看的是各人的局，不是那一页纸。**
3. **它最容易被两种人用坏**：一种拿它吓客户（"你今天诸事不宜，得做个法事"），一种拿它拖自己（"今天不宜，明天再说"，一年拖成三年）。**本馆两种都不做。**

## 4. 黄历不能干什么（四条）

| 不能 | 为什么 |
|---|---|
| **不能替代命理** | 同一天全国同一页，命各不同；黄历给的是"日子的公共属性"，不是"你的处境" |
| **不能用来断生死** | 天纪小畜那一例，黄历只提供"明天是午日"这个事实，断的是**卦与面相**（`70` §4）。**拿黄历断寿元，是把台账当判词** |
| **不能拿来择医** | 人纪里翻黄历是取干支、辨脏气法时；**手术与用药听医生的**，不许因"这天不宜"推迟治疗（`83` §6） |
| **不能压过现实约束** | 租约到期、工期、考试、签证不等人。**先办事，再谈日子**（`19` §6） |

## 5. 客户拿黄历／APP 来问的三种情形

| 客户说 | 怎么答 |
|---|---|
| 「手机黄历说明天不宜出行，我机票要不要退」 | **不退。** 现实安排优先；真要避，避的是"主动开新局"，不是"坐飞机"。可以顺手查两样：明天是不是离决日（那才是硬忌）、忌里有没有"出行"（`90` §3）——即便都有，也不构成退票理由 |
| 「黄历说今天诸事不宜，我能不能签合同」 | **能签，但看条款。** "诸事不宜"是宜守，不是禁签；**合同的风险在条款，不在日子**（`83` §7） |
| 「上面写胎神在厨房，我今天能不能修水管」 | **能修。** 胎神只作提醒、不作禁令（§2、`90` §4）：该处少动、要动先清场；**关水阀比看黄历有用**。不替客户解，也不推"安一安" |

## 6. 与 `83` 的分工

| 册 | 方向 | 干什么 |
|---|---|---|
| **`85`（本册）** | **正向读日** | 给定一天，读出它的事实栏：农历、干支、建除、黄黑道、冲煞、纳音、旬空、离决 |
| **`83`** | **逆向选日** | 给定用事与主事者，扫一段日子，出宜／慎／避三档与理由 |

两册共用同一套底层（`zeri.py` 的建除与黄黑道），**口径必须一致**：本册报"破日＋青龙"，`83` 就按"破日为主、黄道为辅"判"慎"——**同一件事，两册不许给出两个说法。**

## 7. 脚本

```bash
python3 scripts/huangli.py 2026-11-02              # 一页黄历（事实栏，默认不出三栏）
python3 scripts/huangli.py 2026-11-02 --hour 10    # 加时柱（五鼠遁）
python3 scripts/huangli.py 2026-11-02 --xiu        # 只印值宿宿名
python3 scripts/huangli.py 2026-11-02 --xiu-luck   # 宿名＋吉凶＋宿诀
python3 scripts/huangli.py 2026-11-02 --taishen    # 胎神占方
python3 scripts/huangli.py 2026-11-02 --yiji       # 全本宜忌
python3 scripts/huangli.py 2026-11-02 --full       # 三栏全出
python3 scripts/huangli.py --range 2026-11-04 2026-11-08   # 区间速览
python3 scripts/huangli.py --selftest              # 自检（十一项锚点）
```

脚本报事实与通书栏，**不给成败断语**；末行固定打印"三栏系通书口径：不作本馆判决、不承诺成败；与建除冲突按 `83` §4 讲，硬忌不因软吉抵消；医疗听医生的"。三栏默认不出，加 `--full` 或分项参数才出——**默认克制，不是不会**（`90` §0）。

## 8. 一句话结论

**黄历是一本公共台账：它告诉你今天是什么日子，不告诉你今天该不该做事。** 会用它的人，拿它对干支、避离决、认出"诸事不宜"只是"守一守"；不会用它的人，被一页纸牵着走一年。

> 2026-11-03 起，值宿吉凶、全本宜忌、胎神占方三栏已开（册九十）。**开的是"材料"，不是"判决"**：三栏给全、给准、给清依据，合看次序与硬忌不动。台账补全了，读台账的人还是得自己拿主意。

> 与 `83` §7 同一条：**日子是条件之一，不是开关。** 台账可以查，判决得自己做。
