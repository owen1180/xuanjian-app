# 七十二、李敖·审名查据与钢人反方

> **本册位置**：`65` 管"自己的话要能回放"，`66` 管"证据分几层"，`64` 管"外面的倪海厦项目可不可信"。三册合起来是**不做假**。本册补另一半：**别人说假话时怎么拆，自己断错时怎么查**。
>
> **来源与等级**：
> - 主源一 `dingyucanada/li-ao-rhetoric`（`MIT`，方法论提炼，明标"非官方、不冒充本人、不收录原著全文"）。其方法链与证据纪律属**二手提炼**，本馆采其结构，标〔外部整理〕。
> - 主源二 `whatot/leeao`（大李敖全集，十八类五百六十件，约二百兆，标 `CC0-1.0`）。**只作定位与核对**：查某篇是否真有其文、某说法出自哪一篇。
> - **许可提醒**：`CC0` 是上传者对**整理工作**的放弃声明，**不覆盖原著著作权**（李敖 2018 年去世，著作权未到期）。故本馆**不摘长段、不重分发、不仿写**，只做篇目定位与短引评论。
>
> **一句话**：**学他的举证，不学他的立场；学他的锋利，不学他的刻薄。**

## 1. 七步方法链：从材料到结论

原项目的链条是：**原始材料 → 审名 → 查据 → 钢人化反方 → 反证 → 有限结论 → 成稿**。〔外部整理〕

本馆改成**断案七步**，与现有流程对接：

| 步 | 本馆动作 | 对接册页 |
|---|---|---|
| 一 · 原始材料 | 排盘结果、照片、户型图、客户原话——先落成文字 | `23`／`36` |
| 二 · 审名 | 客户问的那个词，到底指什么 | 本册 §2 |
| 三 · 查据 | 这一断出自哪一册哪一节，属第几层证据 | `65`／`66` |
| 四 · 钢人反方 | 替"相反结论"找最强理由 | 本册 §4 |
| 五 · 反证 | 主动找一个能推翻自己的象 | 本册 §4.2 |
| 六 · 有限结论 | 断到证据撑得住的那一级，不多走一步 | `43`／`66` |
| 七 · 落笔 | 过闸门，再说人话 | `57`／`71` |

> **顺序不能跳。** 最常见的事故是"一到手就有结论，然后回头找证据"——这不是断命，这是自我确认。

## 2. 审名：不通名，不断事

李敖式的起手不是反驳，是**先拆关键词的口径**："你说的'进步'是谁的进步？用什么尺子量？"〔外部整理〕

本馆把这条立成硬规矩：**客户话里的形容词，一律先翻成可核对的事实，再动盘。**

### 2.1 三问

| 问 | 作用 | 例 |
|---|---|---|
| **一问所指** | 这个词指向哪件具体事？ | "财运不好"→ 是收入降了、还是不涨、还是跟人比觉得少？ |
| **二问尺子** | 拿什么标准判的？跟谁比？ | "婚姻不顺"→ 是吵架、冷淡、还是有人介入？跟谁的婚姻比？ |
| **三问时点** | 从什么时候开始？ | "最近总累"→ 三个月还是三年？换过工作／搬过家没有？ |

### 2.2 六个高频词，先翻再断〔本馆归纳〕

| 客户说 | 不许直接接 | 先翻成 |
|---|---|---|
| "我命不好" | "你这盘确实弱" | 是钱、是身体、是关系，还是三样都赶在一起了？哪一年开始觉得不对？ |
| "我财运差" | "你财星无力" | 现在月入多少、三年内最高多少、欠不欠债？（只问区间，不记数字） |
| "我婚姻不好" | "你夫妻宫破" | 现在是没对象、处不好、还是已经分开？ |
| "我身体差" | "你某脏偏弱" | 哪个具体症状、多久、看过医生没有（`24` §4 先过） |
| "我孩子不听话" | "你子女宫××" | 几岁？是哪件事不听？学业、交友、还是作息？ |
| "我这房子是不是不好" | "你这户型犯××煞" | 住多久了？谁住？睡哪间？最近什么事不顺？ |

> **审名的收益**：一半的"命理问题"，在审名这一步就解决了一半——因为客户问错了问题。剩下的一半，才是盘上的事。

### 2.3 反用：客户被江湖先生"定了性"

客户常带着别人的断语来："有人说我命里带煞，一辈子存不住钱。"

**审名同样先走一遍**：这话是谁说的？哪一年说的？他说的时候你在场吗？他要你不要钱？——**先分清是判断还是生意**，再谈盘。

## 3. 查据：内容身份与载体等级

`66` 的四层（原文／转述／整理／外部参考）解决"这话是谁说的"；本册补第二维：**这句话载在什么东西上**。〔外部整理＋本馆归纳〕

### 3.1 内容身份（谁在说）

| 代号 | 含义 | 本馆例 |
|---|---|---|
| **P** | 一手原文／本人亲述 | 倪师讲课转写、客户本人原话 |
| **I** | 亲历者说法（在场，但非本人） | 学生记的课堂笔记、家属转述 |
| **J** | 他人转述／研究判断 | 某公众号"倪师说"、某书作者的解读 |
| **N** | 网络整理／二手摘要 | 短视频、百科、机器生成摘要 |

### 3.2 载体等级（载在哪）

| 级 | 载体 | 可信度 | 本馆用法 |
|---|---|---|---|
| **A** | 影印原件、官方档案、判决书、原始录音 | 最高 | 可作硬依据 |
| **B** | 正式出版物（有社、有版次、有页码） | 高 | 可引，须标版本 |
| **C** | 转写稿、整理本、讲义 | 中 | 可作依据，须标"转写" |
| **D** | 二手摘要、短视频、聊天截图、机器摘要 | 低 | **只能作"有人说"，不进断语** |

### 3.3 两条硬规矩

1. **D 级不进断语。** 客户发来一段短视频说"某大师讲今年属龙的要出大事"，这只能进"有人说"，不能进你的判断。
2. **身份与载体要同时交代。** "据倪师讲课转写（P／C）"是合格标注；"倪师说"（无身份无载体）是不合格标注。

> **本馆的旧病**：把"整理认为"写成"资料原文"。`68` §5 已立"输出三要素"，本册再加一道：**写不出身份与载体，就标〔本馆归纳〕，别冒充。**

## 4. 钢人化反方：治确认偏误的药

原项目最硬的一条：**先呈现对方最强的解释，再反驳**（不是挑最弱的对手打）。〔外部整理〕

命理师最常见的病，是**只在盘上找支持第一印象的象**。看到"伤官"就讲叛逆，看到"七杀"就讲压力——这不叫断命，叫贴标签。钢人化反方就是解药。

### 4.1 三个固定动作〔本馆归纳〕

| 动作 | 怎么做 | 做不到说明什么 |
|---|---|---|
| **一 · 替反方写三句** | 写下"这盘不该这么断"的三条最强理由（用盘上的字，不用形容词） | 写不出，说明你没想清楚，只是跟着感觉走 |
| **二 · 找一个反证** | 主动找一个**能推翻自己**的象（一个反例的支、一次不合的流年、客户一句对不上的反馈） | 找不到，标"待验证"，不许标"确证" |
| **三 · 把反方写进报告** | "这盘也可以读成××，但我不取，因为××" | 不写，客户就无法判断你的判断 |

### 4.2 一条自检口令

落笔前问自己一句：

> **"如果我是客户的对手，我会从哪里攻这一断？"**

攻得动的地方，就是你要降档的地方。

### 4.3 与"双盘交叉"的分工

`60` 的双盘交叉是**两个体系互查**（八字查紫微）；钢人反方是**同一体系内自攻**（这一断自己拆自己）。两者不能互相替代：

- 双盘一致，只说明"两个体系都这么说"，不说明"这一断没错"——两个体系可能共享同一个盲区。
- 钢人反方走一遍，才知道"一致"是真一致，还是**一起错**。

## 5. 江湖话术识别清单

从"审名"派生出的实战用法。**每条给：该反问什么、本馆怎么答、依据哪册。**〔本馆归纳〕

| 话术 | 该反问 | 本馆怎么答 | 依据 |
|---|---|---|---|
| "你命里带××煞，必须化解" | 这个煞出哪本书、哪一页？谁定的吉凶？ | 神煞只作点缀，不单独定吉凶；真正定事的是旺衰、用神与岁运 | `45` §4 |
| "你今年犯太岁，诸事不宜" | 太岁跟你这盘是什么关系？冲还是合？ | 太岁是流年关系之一，不是全局否决；该做的照做，只是节奏放慢 | `42`／`37` |
| "你祖坟有问题，得迁" | 积不积水？塌没塌？树根穿没穿？ | 无可验证的结构性问题，不建议迁；先做排水、补土、清障 | `17` §6 |
| "你身上有阴气／被人下了咒" | 谁说的？有物证吗？ | 这一类本馆不接；若有身体不适先就医，若涉威胁可报警，不做术数解释 | `24` §4／本册 §7 |
| "大师说你家西北角不能作厨房" | 方位怎么定的？罗盘还是手机？ | 先核方位怎么测；再讲乾位主男主人、火气加压的现实对应，不给"死先生"这种话 | `18`／`08` |
| "这是倪海厦秘传／亲授奇门" | 哪一课、第几分钟？ | 倪师自己说"我们没有派"；《天纪》没有传奇门，奇门走主流时家奇门 | `35`／`64` |
| "你这盘必须做场法事才能转" | 谁做？多少钱？承诺什么效果？ | 本馆不做科仪、不代点灯、不判冤亲债主；承诺效果的要格外小心 | `73` |
| "你八字克夫／克妻，不能结婚" | 克在哪一柱？凭什么说克？ | "克"是关系紧、耗损大，不是"不能"；讲条件与做法，不讲禁婚 | `54`／`28` |
| "你今年必有血光之灾" | 哪几步同指？有几点引动？ | 象法要"大运引发＋流年加重＋两点以上同指"；只有一点只能提示，不能断灾 | `37` §7 |
| "我一眼就看出你……" | 看出的是哪一处？ | 相不独论；一处不判终身，须多象合参 | `04`／`23` |

> **答的姿态**：**不说"都是骗人的"**——那是砸人饭碗，也否定了客户的信仰；只说"**我不做、我不能验证、这不在术数范围**"。三句话，立场清楚，不结仇。

## 6. 表达：锋芒向内，不向外

李敖的文风可以学一半。〔本馆归纳〕

| 取 | 不取 |
|---|---|
| 短句，一句一个意思 | 长篇排比、以气势代论证 |
| 断言必带据 | 断言靠形容词 |
| 先给结论，再给理由 | 绕三层才说正题 |
| 对公共言行可以尖锐 | 对私人生活、身体、家人下手 |
| 自嘲与留缺口 | 羞辱客户、揭客户的短 |

**本馆的落点**：

- **锋芒向内**——对自己的判断苛刻（钢人反方、标待验证、承认不知道）。
- **不向外**——不嘲讽客户的处境、不评判客户的选择、不拿客户的失败当案例讲给下一个人听（`40`）。

> 客户来找我们，不是来挨刀的。**锋利要用在结论上，不是用在人身上。**

## 7. 边界

1. **不取政治立场与历史评价。** 李敖的政论、诉讼、人物评断，全部不作本馆依据。
2. **不冒充、不仿写。** 不生成"李敖说"的句子，不写"李氏风格"的评论文。
3. **`CC0` 不等于原著授权。** 全集只作篇目定位与短引，不摘长段、不重分发。
4. **"审名"不是抬杠。** 目的是把问题问准，不是把客户问到哑口。**问三句就够，问十句就是审问。**
5. **钢人反方不是自我否定。** 走一遍是为了降档与补条件，不是把结论推翻重来；走完仍成立的，可以更硬地说。

## 8. 一句话收口
