# 八、阳宅：形家形煞与室内布局

> 风水两大板块：**形家**（看得见的形势、外局、形煞）与**理气**（看不见的能量变数，三元纳气一类）。这份只讲形家，理气见 `09`。

## 1. 形家看什么

从大到小四级：**外局 → 建筑本体 → 门窗气口 → 室内布局**。

- **外局**：龙边虎边、明堂、水口、案山朝山、周边建筑高低
- **本体**：户型方正度、缺角、层高、采光通风
- **气口**：大门、窗、阳台的朝向与相对关系
- **室内**：房间分配、床位、桌位、厨卫位置

## 2. 形煞清单（课程逐一答疑过的）

| 煞 | 形态 | 影响 |
|---|---|---|
| 凹风煞 | 两侧高、中间凹，风从凹口灌入 | 气散不聚，人易不安 |
| 天斩煞 | 两栋高楼之间的窄缝正对本宅 | 直冲之气，主急事、意外 |
| 断头煞 | **两栋高建筑夹一栋矮建筑** | 受压、事业受阻 |
| 壁刀煞 | 邻楼墙面侧棱正对本宅门窗 | 主血光、手术、意外 |
| 尖角煞 | 尖角／屋脊／塔尖正对 | 主是非、官非、身体刺痛 |
| 屋脊煞 | 对面屋脊正对本宅 | 同上，力更缓更久 |
| 路冲 | 道路直冲大门 | 主急、主变，未必全凶，看方位与流量 |
| 反弓煞 | 道路或水流呈弓背向外弯对本宅 | 主破财、人散 |
| 无尾巷 | 巷底死路，气不通 | 主困顿、事业无出口 |
| 棺木煞 | 建筑形如棺木正对 | 主压抑、久病 |
| 大树煞 | 大树贴宅、遮光、根穿地基 | 主阴湿、健康、家运滞 |
| 光煞 | 玻璃幕墙／强光反射入宅 | 主心烦、失眠、口舌 |
| 声煞 | 持续噪音干扰 | 主心神不宁、易怒 |

### 三条关键判定原则（课程答疑反复强调）

1. **成煞要有"形"和"感"两个条件**。声煞最典型：听不到、不影响休息就不算声煞。同理，光煞要看是否真的照进屋、是否刺眼。**不因为"书上有这个煞"就判凶。**
2. **多栋高低不齐的建筑不是断头煞**。断头煞必须是"两个高夹一个矮"的明确结构；成片的、阶梯式的高矮建筑，应按**龙边虎边高压或空**来论，不是断头煞。
3. **凹风煞与天斩煞常叠加**。凹口上加盖的建筑，既是凹风煞也带断头煞性质，一处多煞要合并论，不重复计凶。

## 3. 龙边虎边

以**向**定左右：站在屋内面向大门（或面向马路）为向，左手边为**龙边**，右手边为**虎边**。

| 格局 | 判断 |
|---|---|
| 龙边高压 | 左侧建筑明显高 → 贵人助力强，但压制感也强 |
| 虎边高压 | 右侧建筑明显高 → 女强、口舌、是非 |
| 龙空虎实 | 左空右实 → 男丁弱、女掌权 |
| 虎空龙实 | 左实右空 → 男主外、家业可立 |

**要点：先定"向"，再分龙虎。向定错，全盘皆错。** 城市公寓以主要采光面或大门所对方向为向，须与户主确认。

## 4. 明堂

明堂即宅前空地／客厅。

- 明堂要**平整、宽广、明亮**，不堆杂物
- 明堂狭窄压抑 → 住在里面的人眼界受限，事业只看眼前
- 明堂堆放杂物 → 气滞，家运不畅
- 客厅（内明堂）代表一个人的心胸与远见，**客厅务必留白**

## 5. 室内布局的硬规则

| 项目 | 规则 | 理由 |
|---|---|---|
| 厨卫 | **不占中宫**（房屋几何中心） | 中宫为气机枢纽，秽气火气居中，全家受累 |
| 厨卫 | **不压西北**（乾位） | 天纪称"火烧天门／水淹天门"，主男主人 |
| 门 | 大门不正对厕门、不正对厨房 | 气口对秽气／火气 |
| 穿堂 | 大门直通后窗／阳台为穿堂煞 | 气进即出，聚不住财；宜设玄关屏风使气婉转 |
| 卧室 | 床头宜靠实墙，忌靠窗、忌对门、忌横梁压顶 | 安神定气 |
| 书桌／办公桌 | 背后有靠，前方开阔 | 决策稳、视野宽 |
| 采光 | 忌全暗，忌暴晒 | 阴阳失衡 |

## 6. 居家办公的特殊考量（本专题的落点）

居家办公把"住"与"业"压在同一空间，冲突集中在三处：

1. **办公位与卧床同室**：工作气与休息气互相干扰。宜用屏风／柜体分隔，办公位不可正对床。
2. **办公位背门背窗**：背后无靠 + 气口直冲，主决策犹豫、易受干扰。调整到背实墙、面向开阔处。
3. **会议／镜头位**：镜头背景宜整洁稳定，背后忌通道、忌门、忌杂乱。这不是风水迷信，是"象"的直观——背景乱，心气散。

## 7. 断形煞的分寸

- 先问清朝向、楼层、周边实际环境，**没有照片与朝向不判煞**。
- 煞有轻重：距离、遮挡、楼层高低都能化解或减弱。**能化解的煞不说成绝症。**
- 化解优先用"调整位置、加遮挡、改动线"，不推销摆件。课程与天纪都明确反对靠摆件化解。
- 不承诺"化解后必然如何"。风水是概率调整，不是开关。

## 8. 形煞成立的总判据（专题答疑提炼）

**一切形煞以"是否实际影响到人"为准，不以形状像不像为准。** 这是整套形家最容易被学歪的地方——只看形似就断煞，是吓人不是看风水。

| 煞 | 成立条件 | 不算的情形 |
|---|---|---|
| **声煞** | 经常性、非偶然，已造成精神或生理困扰（影响休息、心神不宁） | 五十米外的铁路、平时听不到、居住者无感 → 不算。低频长期噪音也算 |
| **光煞** | 刺眼、影响视力或必须关门办公 | 光线充足但舒适 → 不算 |
| **断头煞** | **两栋高建筑夹一栋矮建筑** | 阶梯式高低不平的多栋建筑 → 不算断头，应按**龙边虎边高压**论 |
| **凹风煞** | 气流被两侧建筑夹击灌入；即便上方加了顶盖，气流仍从此过 → 仍算 | —— |
| **无尾巷** | 指**建筑外部**的纳气空间秽气沉积 | 楼内走廊尽头、办公室有窗且窗外开阔 → 不算 |
| **铁叉路** | 指**大楼外部**的道路分叉 | 大楼内部的通道 → 不算 |
| **棺木煞** | 空间狭长、窗少、排风差，秽气积聚 | 窗户多、换气设备足 → 影响很小 |
| **路冲／反弓** | 分清是犯**院门**还是**宅门**；只犯院门者，气流仍会随院门入宅 | —— |
| **空中楼阁**（不接地的建筑） | 传统认为影响子嗣；**办公楼不算**，住宅且常住才算，也不宜在此供神 | 不长住 → 影响小 |

**化解次序**：先调整位置与动线，再加密实遮挡（花坛、绿篱、屏风、玄关），最后才是其他。门窗隔音、降噪耳机对付声煞，比任何摆件都实在。

**分寸**：影响子嗣这类说法，只作"传统上如此认为"的说明，不作断言，更不点名评人。
