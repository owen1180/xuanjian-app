# 九十八、古籍版本核验与合法取书

> 这一册不讲课，讲**书在哪、哪个版本、能不能引**。
> 起因：客户问「这些书有没有电子版」，而本馆的规矩是「引一句查一句」——
> 那就得先能**定位到版本**。定位不到，引证无从谈起；定位错了，引了也白引。

## 1. 为什么单列一册

`OB97` 定的引证规程是「称倪师说，要能拼出集数与分秒；称古籍，要能逐字反查」。
前半句本馆有语料可查，后半句一直缺一张**版本底账**：

- 同一本书有多个版本，字句不同（《太清神鉴》四库本与坊刻本即有出入）；
- 同一书名下可能是两种书（见 §5「道藏本《紫微斗数》≠《紫微斗数全书》」）；
- 有些书根本就没有可指认的版本（见 §4《河洛神数》）。

没有这张底账，「查不到」与「没这本书」会被混为一谈。

## 2. 各家库的性质（决定能做什么、不能做什么）

| 库 | 能给什么 | 限制 |
|---|---|---|
| **中国哲学书电子化计划（ctext.org）** | 影印善本（Library 区）＋ 全文检索（Wiki 区），如《太清神鑑》六卷四库本、哈佛燕京 500 万页扫描件 | **明令禁止爬取**，且页面自述「识别出爬虫时会故意返回损坏数据」。**本馆纪律：只在站内阅读、只引它的版本著录，不抓正文** |
| **维基文库（zh.wikisource.org）** | 公版古籍全文（《太清神鉴》四库本、《紫微斗数全书》等），可逐句引用并给链接 | 属 CC BY-SA 整理本，转引须注来源；校勘水平参差，异文不能当定论 |
| **国家图书馆·中华古籍资源库** | 善本影像（需注册） | 影像为主，无全文检索；部分需到馆 |
| **Wikimedia Commons** | 国图扫描件的公开转存（如《太清神鑑》NLC416-06jh007408-1829 整本 PDF） | 公版才可整本下载，页序与装帧随原件 |
| **日本国立国会図書館デジタルコレクション** | 公版汉籍整本下载、书志著录精细 | 需按其分级（インターネット公開／館内） |
| **archive.org** | 公版 PDF／全文 | 中文术数类覆盖率低，检索须用繁体 |
| **大学图书馆** | 《四库全书》《续修四库全书》电子版 | 需机构订阅，个人走馆际互借 |

**一句话用法**：要**读原文**去维基文库；要**看影印**去 ctext Library 或 Commons／NDL；要**引版本**查国图与 NDL 书志；**哪一家都不许批量抓**。

## 4. 查不到、也不该给的

- **《河洛神数》**：`31` 册记的是倪师在古寺"找到"邵康节所写二书。学界通说这批托名邵雍的术数书多为明清人所作，**没有可指认的可靠版本**。客户问起，答"无可指认版本"，不编书目。
- **铁板条文表（一万二千条）**：公版的只有道光刻本**条文**，且散在民间影印；坊间"十几万条"是后人增补（倪师原话见 `34` §3.1）。**本馆不查条文号、不给条文**（`34` §5.4）。
- **徐宇农《铁板神数大公开》《铁板神数》（宋林）、周进谅《神机妙算铁板神数》等**：均为**在版权期内**的现代书，网络流通版本是未授权扫描。**不给链接、不代找**。合规路径只有二手书与图书馆馆际互借。

## 5. 两条容易踩的坑

**① 同名不同书。** 道藏本《紫微斗數》（ctext `res=979714`，十八飞星一系）与《紫微斗數全書》（陈抟托名、罗洪先序）是**两种体系**，星名与安法都不同。引"紫微斗数原文"而不说版本，等于没引。

**② 版本不同不能混引。** 四库本经馆臣改字，坊刻本多俗字与增附。同一句在两本里不同时，**以所注版本为准**，不许"取顺的那本"。

## 6. 一个互证（本轮顺带核出）

铁版神数的通行评价是：**推六亲极验，推财运流年不准**——理由是「数」属先天，而后天之运含趋避改造（见各家书目提要）。
这与 `11` 册录倪师的十字评价**完全同调**：

> 铁板神算｜**核对六亲最准**｜**难用于改运**

两个来源、两套说法、同一结论。这种互证比单方引用硬，本馆遇到"铁板到底准不准"的问法，可以据此答：**准在六亲，短在改运**，且给出两处出处。

另一层须分清：文献谱系上说铁版条文源自明《皇极分经数》；倪师说"一万二千条通通由六十四卦条文变出来"。**一说版本来源，一说数理生成，两者不冲突但不能混讲**。

## 7. 待办

1. 《续修四库全书》子部术数类中《神機妙算鐵版數》的**确切册号**未落实（须查总目），现行只有"收入该丛书"这一层。
2. 《麻衣神相》《相理衡真》等五种坊刻本尚未逐一核版本与馆藏，现只有"有公版影印"的判断。
3. 维基文库各本的**校勘质量**未评估，引文前应抽查与影印本对校。
4. ctext 的 Library 区可看影像但不可抓取，本馆若需长期引用，应走其订阅 API 而非页面抓取。
