# 七十八、经方·倪师病案的结构与读法

> 来源：移动硬盘「文档／倪海厦电子文案／倪醫師08年病案紀錄358篇」全 358 篇（平均 542 字，合计约 19 万字），另参「天纪 人纪 地纪」中医案集与汉唐文章全集。
> 定位：`63` 讲六经辨证与开方四道闸，`32` 讲问诊单，`25` 讲望诊五色。**本册以读案为主：讲"这 358 篇病案是怎么记的、怎么读的、能读出什么"**；方剂本身见 `86`——因为病案里最有价值的不是药，是**判断的形成过程**。
>
> ⚠️ **方剂部分自 2026-11-02 起已开**（主人决定）：剂量、煎法、炮制可讲，规程见 `86`；**但诊断与停药两条仍守**，见 §8。

| 段 | 内容 | 出现率 |
|---|---|---|
| 表头 | 初诊日期、姓名、性别、年龄及体型、来诊日期、编号 | 100% |
| **来诊原因** | 患者自述或转述的主诉 | **100%** |
| **问诊** | 编号列出的一串固定问项（见 §2） | **98%** |
| 望诊 | 面色、形态、精神 | 87% |
| 脉诊 | 脉象（常只记一两个词） | 94% |
| 舌诊 | 舌质、舌苔 | 92% |
| 眼诊 | 眼白／虹膜分区反应（见 §4） | **58%** |

> 值得注意：**"解说"出现率 93%**，比处方本身更稳定。这说明这批病案的价值重心在"为什么这么判"，不在"用了什么"。

## 2. 问诊九项：频次自己排出了一个次序

对 358 篇逐篇统计问诊子项的出现次数，得到一个**实证的问诊优先级**：

| 序 | 问项 | 出现率 |
|---:|---|---|
| 1 | **大便** | 84% |
| 2 | **胃口** | 77% |
| 3 | **小便** | 68% |
| 4 | **口渴** | 65% |
| 5 | 痛处 | 63% |
| 6 | 睡眠 | 50% |
| 7 | 汗 | 48% |
| 8 | 体力 | 39% |
| 9 | **手足温度** | 38% |

另有低频项：痰（24%）、胸（24%）、腹（22%）、月经（22%，女性案中实际更高）、寒热（12%）、恶心（12%）。

**怎么读这张表**（本馆归纳）：

- 前四位是大便、胃口、小便、口渴——**全部关于"里"与"津液"**。这说明倪师问诊的重心不在"哪里痛"，在**中焦运化与寒热真假**。
- **手足温度**虽只排第九，但它是**寒热定位的关键一项**：手足冷＝阳虚／里寒，手足温＝阳气尚可。频次低是因为它常被并入"头身"或"寒热"栏，不代表不重要。
- 传统"十问歌"以寒热、汗为首；这 358 篇的次序是**脾胃在前、寒热分散**。**两种次序都对，但混用会漏项**——本馆采病案的次序（`32` 问诊单据此调整）。

## 3. 虚实演变链：这 358 篇里最值钱的一句话

病案中反复出现一条**四阶段演变链**，是本馆见过对"由实转虚、由虚转积"讲得最清楚的一句：

> **阳实 → 阴虚 → 阳虚 → 阴实**

原文（病案 · 大肠头破裂案）："阳实若不赶快治好，会产生阴虚，再不治疗会成阳虚，再不治疗就成阴实。"

四个阶段的意思（本馆归纳，配六经定位）：

| 阶段 | 含义 | 六经对应 | 外部表现 |
|---|---|---|---|
| **阳实** | 邪盛而正气未衰，正邪剧烈相争 | 太阳／阳明实证 | 发热、便秘、脉实、烦躁 |
| **阴虚** | 津液被耗，物质基础亏 | 阳明转少阳／太阴 | 口干、瘦、眠差、舌红少苔 |
| **阳虚** | 功能衰退，推动无力 | 太阴／少阴 | 手足冷、倦怠、便溏、脉沉弱 |
| **阴实** | 有形之积已成，阳气不能入 | 少阴／厥阴 | 固定痛块、夜间身热、消瘦、脉沉细而实 |

**三条用法**：

1. **这是"进程"不是"分类"**。客户问"我现在什么阶段"，要按这条链找位置，不是直接给一个病名。
2. **阴实的标志之一是"夜间身热"**（病案原话："阴实之夜间身热演变顺序：一定时间身热 → 跨时间身热 → 整晚身热"）。这条只作**就医提醒**，不作诊断。
3. **反向也成立**：阴实被打散、阳气回头时，会出现"睡不好、没胃口"——这是**排病反应**，与恶化方向相反。区分这两者，是临床的事，**本馆只解释原理，不指导判断**。

## 4. 眼诊：这 358 篇里最独特的一诊

倪师除脉、舌之外，大量用**眼诊**（58%），且有分区：

| 区 | 看什么 | 病案原话举例 |
|---|---|---|
| **瞳孔** | 大小、对光反应 | "瞳孔仍较大，肾阳尚未完全回来""瞳孔反应好 → 肾阳回复" |
| **肾区** | 反应强弱、有无变形 | "肾区反应差（右好于左）→ 左肾较萎缩""肾区变形" |
| **肝区** | 圈纹、白点、破洞、颜色 | "肝区有损伤及圈纹""肝区圈纹，有白点破洞""肝区较松、颜色佳" |
| **心区** | 大小、是否凸起 | "心区偏大（阳不足则无法固守阴）""心区已明显改善，心区已凸起，心功能回" |
| **肺区** | 黄块、黑点 | "左眼肺区黄块，中有黑点" |
| **脾区／胰区** | 过大／过小 | "脾区过小 → 土不能制水""胰区尚好" |

**本馆怎么用**（严守 `29` §2 的转译规则）：

- 眼诊分区**可作为"望诊的一个观察点"**，与传统五色诊并列，用于"哪一块最该先去查"。
- **凡病案原文里的病名（肿瘤、结石、心脏肥大、萎缩），一律只说"该系统的负担偏重，建议做该系统的常规检查"**。
- **不教人自己看眼睛下结论**。眼诊须训练，且照片条件差时误差极大。

> 另两诊：**耳诊**（耳穴压痛，12%）与**触诊**（背部俞穴压痛，5%）。耳穴属操作层，本馆按 `24` §3 只作了解，**不给定位、不给按压方法**。

## 5. 传变与治则：只取思路，不取方

病案"解说"里反复出现一组**跨脏腑的处理次序**。这些是思路，不含药，可以讲：

| 判据 | 病案原话 | 意思 |
|---|---|---|
| 治肺先治肝 | "治肺必先治肝且要顾脾土""治肺要治肝，病则不再进" | 肺病防其传肝、再传脾（五行相侮与相乘） |
| 治肾先治心 | "治肾先治心" | 心阳为下焦阳之源 |
| 治肝要治大肠 | "治肝要治大肠" | 肝与大肠相通，腑气通则肝气疏 |
| 胀气从脾治 | "胀气要从脾治，脾主少腹" | 腹满责脾 |
| 吸入困难责肾 | "吸入问题主要责之于肾""金不能生水，故呼吸困难" | 呼出于肺、吸入于肾 |
| 治肝要用白芍 | "治肝病一定要会用白芍，白芍可把血酸收回肝" | 柔肝体 |

**这六条的价值**：它们是**"这个症状该往哪个脏去找"的路线图**，正好补 `63` §2「先定位再谈方」的定位环节。

> 但注意：**知道路线不等于能开方**。这六条只用于"跟医生沟通时问对问题"，或"体检时该查哪一科"。

## 6. 多点交叉：医学版的"共振法则"

病案里判断依据几乎从不单一。最典型的一例：

> "查其耳穴肾区有压痛，再查其右踝肾石点有压痛，加上小便淡黄无血尿，故知此肾区痛乃肾结石引起的痛；若是肾脏癌则会有血尿。"

三点同指（耳穴 + 踝点 + 尿象），且**用一条反向证据（无血尿）排除了更重的可能**。

这与 `76` §5 手相"三个象同指才提概率"、`14` 三盘同指，是**同一条认识论**在三个领域的同一个做法：

| 领域 | 一象 | 二象 | 三象以上 |
|---|---|---|---|
| 手相 | 提示 | 留意 | 可入报告 |
| 命理合参 | 单盘为弱 | 两盘同指为强 | 三盘同指为极强 |
| 医案 | 不作判断 | 存疑 | 可下判断，并找反向证据排除 |

**反向证据这一步是本册新增的**：三点同指之后，还要问"如果是更重的那种，应该还有一个什么象？现在有没有？"——**没有，才敢定轻的**。这一步应当回填到 `66` 证据分层里，作为"同指之后仍须排除"的补充。

## 7. 调摄与反应：可以讲的部分

病案"解说"里有若干**不含药**的调摄判据，安全可用：

| 判据 | 原话／意思 |
|---|---|
| **忌口** | "须忌口，避免如肉、奶制品等含荷尔蒙之物"；另处"禁食咖啡及人工甘味食品"；"建议停止喝咖啡及糖" |
| **可食** | "可多食葡萄、海藻、茶及黑糖水"（个案所嘱，非普适） |
| **运动** | "须每日运动汗出以锻炼阳气" |
| **节气** | "5/5 日节气为立夏，对阳气恢复极有利"——**节气参与判断，是运气学在临床的落点** |
| **情志** | "此患者个性开朗，也是使病情好转的重要原因——**无惧则不伤阳**" |
| **服药反应** | "服阳药后病人阳气渐复，表示身体能受药"；"吃药后中午肚子会饿就代表好了" |
| **守方** | "药力已到，前方无需更动，守方"——**有效不更方**，是经方的一条纪律 |

**"无惧则不伤阳"这一句，本馆用得最多**：它把"情绪—正气"的关系讲成了一句可复述的话，且不需要任何医学判断就能说。

## 8. 本册的边界（2026-11-02 起调整）

原来的"四条不碰"，**前两条已由主人开锁**（见 `86`），后两条不动：

| 原条目 | 现状 | 说明 |
|---|---|---|
| ① **不录剂量** | **已开** | 病案里的克数、钱数、几付、几碗水煎几碗，可录可讲。讲方按 `86` §4 六要素，别只报药名与克数 |
| ② **不给抓法** | **已开** | 炮制、先煎后下、服法可写；**峻毒药须同时讲中毒表现与解救方向**（`86` §5） |
| ③ **不劝停药** | **仍守** | 原文多处"禁食西药""嘱停所有西药"，一律改为"**用药调整须问主治医生**"。这条最危险：患者自行停降压、降糖、抗凝药，出事是本馆责任 |
| ④ **不下病名** | **仍守** | 眼诊、舌脉、问诊所得，只转"建议查某系统"，不落诊断（`29` §2） |

**另加一条**：

⑤ **丁类不背书**。民间传抄的方（秘方文本那 150 篇一类）可以讲，但每讲必标"**民间传抄、无出处、未验证**"（`86` §2）。

> 一句话：**药与量可以讲，诊断与停药两个字归医生。**

## 10. 分寸

- 本册是**读案方法**，不是诊疗手册。任何一条都不能拿去给人看病。
- 病案是**单个医师的个人记录**，未经对照研究，**不作疗效背书**（`66` 证据分层：这是"个人经验"层，不是"指南"层）。
- 客户拿病案来对号入座时，第一句必须是"这个要请医生看"。
- 结尾三句硬标记，缺一句不算完（`63` §8）。

> 以上为传统术数文化分析，供参考；涉及身体，不替代医生诊疗。
