# 十一、天纪·天机道：紫微斗数

> 倪海厦《天纪》的命理主干。**流派属三合派，不是飞星派。** 用法要旨："以果决行，消灾解厄"——算命不是认命，是提前知道结果再决定怎么走。
>
> **编者注（与古籍的出入，照录不改）**：倪师安星时把紫微一组称"北斗星系"、天府一组称"南斗星系"；按《紫微斗数全书》卷一星问答与卷二安身命例，**有六颗不合**（天机、太阳、天同、太阴、破军、贪狼）。
> 本册照录倪师讲法，**不擅改原文**；对外表述如需严谨，说"倪师一派的分法"，不称"古法"、不称"《全书》原文"。出处与核验过程见 `64` §3 结论四。

## 1. 天纪对三种算命法的定位

| 法 | 特点 | 短板 |
|---|---|---|
| 铁板神算 | 核对六亲最准 | 难用于改运 |
| 子平（八字） | 重日柱，与斗数殊途同归 | 结果难化解 |
| **紫微斗数** | 重年柱，融合天文地理，**有化解法**，最精妙 | 易学难精 |

**核心比例：天命占三分之一，地理占三分之一，人事占三分之一。** 地理＋人事 ＞ 天命。这是天纪整个体系的世界观，一切断语都要挂在上面。

## 2. 十二宫

顺序：命宫 → 父母宫 → 福德宫 → 田宅宫 → 官禄宫 → 朋友宫（仆役）→ 迁移宫 → 疾厄宫 → 财帛宫 → 子女宫 → 夫妻宫 → 兄弟宫。

| 宫 | 主事 |
|---|---|
| 命宫 | 先天命格：长相、个性、行为模式、一生成败 |
| 财帛宫 | 私企、从商 |
| 官禄宫 | 公家、从政 |
| 迁移宫 | 外出发展 |
| 福德宫 | 一生福禄、财禄、事业（与夫妻宫同看） |
| 夫妻宫 | 婚姻（须与福德宫合看，福德差则夫妻难长久） |
| 兄弟宫 | 手足（斗数批六亲不精准，须配面相） |
| 父母宫 | 父母；黯淡无光者主庶出或螟蛉子 |
| 田宅宫 | 祖业、置产吉凶 |
| 子女宫 | 子女，宜夫妻合看；论子女将来最好看子女八字 |
| 疾厄宫 | 身体，只作参考 |
| 朋友宫 | 朋友、合伙 |

### 三方四正

**命宫 — 财帛宫 — 迁移宫 — 官禄宫**，四宫互看，是命盘的基本结构。

**宫性**：流年落在某宫，该年重点即在该宫之事。例：流年在财帛，一年重心在钱。

## 3. 十四主星

### 北斗系

| 星 | 星性 | 入命宫之相／特征 |
|---|---|---|
| 紫微 | 帝星、文武官带、贵人、正财，**有解厄制化**（凶星遇紫微可逢凶化吉） | 领袖气、不服管、多贵人 |
| 天机 | 文官带（公务、教师、银行）、正财 | 皮肤黑、个子矮、体格精壮、反应快 |
| 太阳 | 武官带（军警、外交、法官）、解厄、财禄（横财）、代表父／夫／子 | 红光满面、双目圆大、圆脸、肤白、中等身材壮 |
| 武曲 | 武官带、解厄、**财星王**、贵人 | 个性火爆但过得快；身材五短且壮（属富贵） |
| 天同 | 人和、解厄 | 温和、享福体质、动力偏慢 |
| 廉贞 | 次桃花、武官带 | 迷迷眼、见美女未言先笑、长相清秀 |

### 南斗系

| 星 | 星性 | 入命宫之相／特征 |
|---|---|---|
| 天府 | 南斗君主、性温和、文官带或教职、心眼较多 | 稳重保守、善守不善攻；**不可解厄制化** |
| 太阴 | 文官带、正财 | 女命太阴坐命者漂亮；太阴在子、丑、亥时最好 |
| 天梁 | 食神（口福）、文武双全官带 | 男相英俊潇洒、精壮 |
| 天相 | 佐才星（秘书、助理） | 瘦高、厚道、性温和 |
| 巨门 | 凶星：口舌、是非、官司、牢狱；亦主豪宅大院 | 庙旺则口才好；形小音高音量大，或毛发旺而肥胖 |
| 贪狼 | 桃花星：酒色财气赌、武官带 | 身材魁梧、毛发多 |
| 七杀 | 武官带 | 目大、性急、多疑 |
| 破军 | 武官带 | 孤僻、体瘦、不重利 |

**杀破狼三方会命**：七杀、破军、贪狼三方会照，主刚愎自用、易被人利用。七杀破军主劳耗奔波不聚财，贪狼主财与桃花。

### 忌讳的相
浓眉、四白眼、三角眼。

## 4. 六吉、六煞、四化

### 六吉
| 星 | 主事 |
|---|---|
| 左辅、右弼 | 辅佐紫微 |
| 文昌 | 科甲、读书考试 |
| 文曲 | 才艺、博学、斯文 |
| 天魁、天钺 | 科甲、贵人 |

- 昌曲同会 + 魁钺 → 读书奇才
- 文昌坐命无文曲来会 → 学而不思，书呆子
- 文昌坐命会文曲 → 男则文采风流，女则桃花

### 六煞
| 星 | 主事 |
|---|---|
| 擎羊、陀罗 | 身边看不见的小人、疾病血光 |
| 火星、铃星 | 火厄、个性冲突、口角 |
| 地空、地劫 | 生意、流年逢之必赔 |

### 四化
| 化 | 性 |
|---|---|
| 化禄 | 财，性守（守财奴） |
| 化权 | 性刚，官印 |
| 化科 | 科名、名气大 |
| 化忌 | 劫杀、想不开 |

**禄存**：同化禄。禄存遇天马 → 禄马交驰，是发大财的组合。

### 亮度
庙、旺、得、利、平、闲、陷。庙旺为吉，利为小吉，平闲无用，陷主凶；**杀星在陷为大凶**。

## 5. 批盘总格（先看这四条）

1. **日月夹财**：日月在命宫两侧
2. **紫微天府夹权**：紫微天府在命宫两侧
3. **天钺天魁夹贵**：魁钺在命宫两侧

## 6. 与八字的接口（团队分工用）

| 事项 | 用哪套 |
|---|---|
| 定旺衰、取用神、断财富事业层次 | 八字打分法（`01`–`03`） |
| 看格局、看六亲、看流年重点宫位 | 紫微斗数（本文件） |
| 看长相、看性格外显 | 斗数星性 + 面相（`06`、`12`） |

**两套不冲突，是两把尺子量同一个人。** 结论一致时可以加强语气；不一致时，以八字定"力度"、斗数定"领域"。

## 7. 断语分寸

- 斗数讲"格局"不讲"宿命"。天纪原话：知命不是认命。
- 不断寿元、不断生死。命盘再凶也只讲"该注意什么"。
- 化忌不等于灾难，是"卡点"。讲清卡在哪一宫、卡多久。
- 星性入命宫的长相描述只作参考，不做人身评判。
