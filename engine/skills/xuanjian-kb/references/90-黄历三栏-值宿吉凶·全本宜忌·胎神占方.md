## 1. 三栏各管什么

| 栏 | 一句话 | 管的层次 | 不当什么用 |
|---|---|---|---|
| **值宿吉凶** | 这一日轮值哪一宿，该宿在通行本里属吉属凶、歌诀怎么说 | 日子的**底色** | 不当成"这天的总评分" |
| **全本宜忌** | 这一日通书列了哪些宜、哪些忌（年、月、日三叠神煞的结果） | 日子的**事类清单** | 不当成"许可证" |
| **胎神占方** | 这一日胎神在屋内何处、屋外何方 | 日子的**方位提示** | 不当成"禁令" |

三者与建除十二神、黄黑道并列，**各管一段，不许互相抵消**（`83` §4）。

## 2. 值宿吉凶

### 2.1 是什么

二十八宿按日轮值：角、亢、氐、房、心、尾、箕、斗、牛、女、虚、危、室、壁、奎、娄、胃、昴、毕、觜、参、井、鬼、柳、星、张、翼、轸，二十八日一循环。每宿在通行本里标吉或凶，并配一首歌诀，讲这一宿宜造作、宜埋葬、宜开门之类。

本馆表：**吉宿十四、凶宿十四**，恰好各半。

| | 宿 |
|---|---|
| **吉** | 角、房、尾、箕、斗、室、壁、娄、胃、毕、参、井、张、轸 |
| **凶** | 亢、氐、心、牛、女、虚、危、奎、昴、觜、鬼、柳、星、翼 |

### 2.2 算法

- **宿名**：以二〇二六年十一月二日值「毕」为锚，按二十八日循环推算。这条不是估的：与依协纪那一路连比六十一日全合，与另一路六语言库比二〇二五年全年三百六十五天（含闰六月）也全合，累计四百二十六天一天不差（`88` §4、§5）。
- **吉凶与歌诀**：取通行本二十八宿吉凶表与二十八首歌诀，已随包固化为数据表（源自六语言历法库，MIT 许可）。歌诀每首六十四字，八句。
- **进不了引擎**：只进知识库脚本，不进排盘工具引擎（`36` §2.4 的分工不变）。

### 2.3 依据与它的性质

- 宿名是**历法事实**，可复算、可对拍。
- 吉凶与歌诀是**通行本之说**，**非倪师所授**。倪师讲二十八宿，讲的是「各宿管每一个方位的东南西北」，是罗盘配宿（册八十五 §0 第八条）；他**不讲值日吉凶**。
- 所以本馆给这一栏，是**应主人之命开出来的通书栏**，标注清楚来源，不冒充师授。罗盘配宿仍归册十七、册二十，不在此断。

### 2.4 怎么用（三条）

1. **凶宿不是"不能办事"**。它只是底色；先看建除、看冲不冲命主。破日加凶宿才建议另择，平日加凶宿照常办事。
2. **吉宿不与黄道相加**。破日、青龙、吉宿同日，仍是破日为主（`83` §4 第一条：硬忌不因软吉而抵消）。
3. **歌诀只取"事类倾向"，不取字面吉凶**。歌诀里"徒刑""伶丁""药毒""田地被退"是古诀的修辞与押韵，**不许照字面吓人**，也不许拿它断生死病讼。要转，就转成一句"此日不宜开创新局、宜守成"。

### 2.5 边界

- 不判生死、不判病名、不判官司胜负。
- 不因"凶宿"劝人推迟治疗、退票、毁约。
- 客户问"这宿是不是大凶"，答"凶宿是底色，不是判决；要看它跟建除、跟你生年合不合"。

## 3. 全本宜忌

### 3.1 是什么

通书一页上那几十条「宜祭祀、宜结婚姻、忌出行、忌破土……」。这一栏不是简单查表：它是**年神煞、月神煞、日神煞三层叠加**之后再按宜忌等第表取舍的结果，依《钦定协纪辨方书》一路。

### 3.2 算法：为什么不能只按日干支查表

本馆起初想省事，做一张「日干支乘十二支」的七百二十格查表。实测发现不行：

> 取二〇二〇至二〇三〇年逐日结果，按（日干支，月支）归并，**七百二十个键里有六百三十九个键出现冲突**——同一日干支、同一月支，在不同年份给出的宜忌不同。

原因就是年神煞。所以本馆改为**按整日算**：随包内置依协纪那一路的实现（MIT 许可，仅标准库依赖，离线可跑），每次按年月日现算，不查预生成表。

还有一处工程细节：宜忌条目出自集合，跨进程顺序会变。本馆按该库自带的通书次序表排定，**同一日连跑三次输出完全一致**（校验过指纹）。否则同一页两次印出来不一样，客户会以为算错了。

### 3.3 条目有多少

六十一日样本（二〇二六年十一月一日至十二月三十一日）：

| | 条目数范围 | 平均 |
|---|---|---|
| **本馆（依协纪，全本）** | 一至四十八项 | 十七点二项 |
| 另一路（六语言库，简本） | 二至二十六项 | 十二点二项 |
| 两路集合完全相同的天数 | **零天** | — |

**这就是"全本"与"简本"的分野。** 主人要"全本"，本馆取条目全的那一路；另一路不废，留作对拍与异文参照（§5）。

### 3.4 怎么用（四条）

1. **宜忌是清单，不是许可**。宜里有"结婚姻"，遇上破日、危日仍不办大事；忌里有"出行"，不等于不能坐飞机（`85` §5）。
2. **合看次序不许倒**：先走 `83` §4 六级（离日决日 → 冲命主 → 岁破月破 → 建除与用事 → 黄黑道 → 三煞方），再看宜忌是否覆盖该事类。**建除定性，宜忌列事。**
3. **事类匹配法**：要办的事，先在宜里找、再在忌里找；两边都没有，就是中性，看别的条件。**不许拿"宜"里的无关条目凑数**（宜祭祀不等于宜签约）。
4. **「诸事不宜」照旧解**：宜守，不是凶日（`85` §3）。通书里它常同时出现在宜忌两栏，本馆合并成一行印"诸事不宜（宜守，不是凶日）"，不重复吓人。

### 3.5 通书用词对照（客户看不懂时照这条念）

| 通书语 | 今语 | 通书语 | 今语 |
|---|---|---|---|
| 结婚姻 | 嫁娶、订婚 | 开张 | 开业、开市 |
| 平治道涂 | 修路、铺路 | 修置产室 | 装修产房、待产房 |
| 安碓硙 | 安磨、装碾磨 | 启攒 | 拾骨、迁葬 |
| 覃恩 | 颁恩、行赏 | 恤孤茕 | 抚恤孤寡 |
| 雪冤 | 申冤、平反 | 上册 | 上奏册、报批 |
| 临政 | 理政、上任 | 裁制 | 裁衣、制物 |
| 畋猎 | 打猎 | 取鱼 | 捕鱼 |
| 补垣 | 修补墙 | 塞穴 | 堵洞、填穴 |
| 鼓铸 | 铸造 | 营建 | 建房、动工 |
| 竖柱上梁 | 立柱上梁 | 搬移 | 搬家 |
| 纳畜 | 买牲畜 | 牧养 | 放牧、饲养 |

> 用词异写也按老规矩：异文并列，不裁断（`81` §5）。客户拿别家通书的"结姻"来对"结婚姻"，说"指同一件事"即可。

### 3.6 边界

- **不承诺成败**：给了宜忌，也不说"这天办事必成"。
- **不代退行程**：机票、签证、工期不等人（`85` §4）。
- **医疗不让路**：手术与用药听医生的；"忌针刺"不许拿来推迟针灸治疗（`83` §6）。
- **不替人挑事**：客户问"我该不该在这天离婚"，去留由当事人定（册五十四、册二十八 §6）。

## 4. 胎神占方

### 4.1 是什么

按日推出「胎神」当日所在：一段是**屋内所佔**（某房、某床、某灶、某门、某碓磨、某仓库），一段是**屋外方位**（外正东、外东南……）。民俗据此生出「此处不可动土、钉钉、动刀、搬迁」一类禁忌，多用于孕产与安胎语境。

例：二〇二六年十一月三日，「厨灶床　外正西」——屋内指厨灶与床，屋外正西。

### 4.2 算法

六十甲子一表，按日干支取。本馆取依协纪那一路（与宜忌同源），随包内置。

与另一路（六语言库）逐日比六十一日：**四十七日相同、十四日不同**。不同的不是错位，是版本异文：

| 日期 | 另一路 | 本馆（依协纪） | 差在哪 |
|---|---|---|---|
| 11-01 | 占大门 外正西 | 房床炉 外正西 | 所佔之物不同 |
| 11-17 | 碓磨厕 房内北 | 碓磨门 房内北 | 厕／门 |
| 11-25 | 房床门 房内西 | 房床门 房内南 | 方位不同 |
| 11-26 | 占门栖 房内东 | 门鸡栖 房内东 | 所佔之物不同 |
| 11-30 | 房床炉 房内中 | 房床炉 房内东 | 方位不同 |

> 这类出入在通书里本来就常见（胎神表各本有差）。**异文并列，不裁断**（`81` §5）：客户拿别本来对，说"写法不同，指同一件事"，**不说人家错，也不现场改口径**。

### 4.3 怎么用（三条）

1. **只作提醒，不作禁令**。知道今天胎神在厨灶，就"这处少动、要动先清场"，不是"今天不能开火"。
2. **孕产家庭尤其别被它牵着走**。真要修水管、装柜子，关水阀、断电、清场、避开孕妇，比看黄历有用得多（`85` §5）。
3. **不替客户解**。不推"胎神冲了要安一安""得做场法事"；若客户自己提，走科仪线：只评、只转、不代做，不承诺效果（册七十三）。

### 4.4 边界

- 不制造恐慌，不把"占方"说成"凶方"。
- 不涉医疗判断：孕期任何不适，交给产科医生，不看黄历。
- 不动土类硬忌仍归 `83` §5（岁破月破、三煞方），**胎神不进硬忌层**。

## 5. 对拍与口径（凭什么敢给）

六十一日逐日比，三项：

| 项 | 与依协纪那一路（同源核对） | 与另一路（六语言库） |
|---|---|---|
| 值宿宿名 | **六十一／六十一** | **六十一／六十一** |
| 胎神占方 | **六十一／六十一** | 四十七同、十四异（异文，§4.2） |
| 宜忌集合 | **六十一／六十一** | 零天相同（体系不同，§3.3） |

三条结论：

1. **值宿是硬事实**：三路同值，四百二十六天无差。吉凶与歌诀只有一路有表，故标"通行本"，不冒充多源互证。
2. **胎神是同源一表两写**：差异全在写法与所佔之物，不在算法。
3. **宜忌是两套体系**：一套全（依协纪，三层神煞），一套简（只到日层）。本馆取全，另一路留作参照。**两套都自称通书，谁也不能说谁错**——所以并列，不裁断。

> 一句话：**能对拍的说"对得上"，不能对拍的说"这是通行本之说"。两样都不许含糊。**

## 6. 合看规则（本册最要紧的一节）

三栏开出来之后，最大的风险不是算错，是**客户拿一栏压另一栏**——"通书说宜结婚姻，你凭什么说危日不办"。所以合看次序必须写死。

### 6.1 七层次序（前六层照旧，第七层是本次新增）

| 级 | 项 | 判法 | 处理 |
|---:|---|---|---|
| 1 | **离日／决日** | 二分二至、四立的前一日，共八天 | **避**，大事另择 |
| 2 | **冲命主** | 日支冲命主生年支 | **避**，换人主事可解 |
| 3 | **岁破／月破** | 日支冲太岁／冲月建 | **慎**，大事不宜 |
| 4 | **建除与用事** | 破日忌立新、开日忌葬、危闭不办大事 | **慎／避**，按事类 |
| 5 | **黄黑道** | 黑道降一档 | **慎**，作底色 |
| 6 | **三煞方** | 年支三合所煞之方（动土用） | **慎**，此方不动土 |
| 7 | **三栏（本册）** | 值宿吉凶作底色、宜忌作事类清单、胎神作方位提示 | **只作参考层，不进硬忌层** |

### 6.2 三条冲突处理

1. **硬忌不因软吉抵消**。破日加黄道加吉宿，仍是破日为主；忌里没有"嫁娶"，也不因此可办。
2. **宜忌与建除冲突，以建除定性为准**。通书说"宜结婚姻"而当日值危，答："宜忌列的是事类，建除定的是这天的性质；危日不办大事，婚娶另择。"
3. **胎神与动土冲突，胎神让路**。真要动土，先看岁破月破与三煞方；胎神只提示"该处少动"，不是硬忌。

### 6.3 一句总纲

> **建除定性质，宜忌列事类，值宿作底色，胎神指方位。四样各说一句，谁也不替谁下结论。**

## 7. 客户问答（新增与改写）

| 客户说 | 本馆怎么答 |
|---|---|
| 「今天是凶宿，能不能办事」 | 凶宿是底色，不是判决。先看建除与冲不冲你生年；破日加凶宿才建议另择，平日照常。 |
| 「通书说宜结婚姻，你却说危日不办大事」 | 两套话不冲突：宜忌列事类，建除定性质。危日不办大事，婚娶另择；若实在改不了，把仪式简办。 |
| 「胎神在厨房，我今天能不能修水管」 | 能修。关水阀、断电、清场，比看黄历有用。 |
| 「你这栏到底是吉是凶」 | 给的是通书栏与合看结论，不给"必吉必凶"。**能对拍的对得上，不能对拍的标通行本。** |
| 「为什么跟某应用不一样」 | 两套口径：一套依协纪（条目全），一套简本。写法不同，指同一类事；本馆取全的那一路，不裁断别家。 |
| 「你能不能保证这天顺利」 | 不能。择日只降低"日子本身的别扭"，不制造结果（`83` §7）。 |
| 「凶宿是不是要出大事」 | 不是。歌诀里那些话是古人的押韵修辞，不是预言；要听，就听"此日宜守不宜攻"。 |

## 8. 边界（开门之后仍然有效）

| 不做 | 为什么 |
|---|---|
| 不承诺成败、不给"必吉" | `43` §4：敢打包票的只有骗子 |
| 不代退行程、不改手术日期 | `85` §4、`83` §6：现实约束优先，医疗听医生的 |
| 不判生死、病名、官司胜负 | 三栏都不载这些，硬断即越界 |
| 不借凶宿、胎神吓人 | 一吓就变恐慌源，`85` §5 已写明 |
| 不推科仪 | 胎神冲了要"安一安"之类，只评、只转、不代做（册七十三） |
| 年过六十降档 | `40`：只讲气势，不讲"哪一年会怎样" |

**三句声明照旧必带**：供参考；不承诺效果；涉身就医。

### 10.4 接口与开关

```ts

```

- `withSanLan: false` → 退回只报事实的克制档（`sanlan: null`，`suppressed` 填三项）。
- `yiJiBrief` 是**另一路（六语言历法库）的简本**，并列给出、**不裁断**（§5 同一条）。
- 界面固定标注："吉凶系通行本之说、非师授，只作参考层""胎神只报方位，不给禁忌指令""三栏不与建除、黄黑道互相抵消"。

### 10.5 下引擎时守的那条线

**只出条目，不出结论。** 引擎印"今天值什么宿、吉凶怎么说、胎神在哪个方位、通书列了哪些宜忌"，**不印"今天宜不宜办事"**——那是 §6 合看规则与 §7 话术的事，得由人接。允许加字段，不允许加结论；一旦做成打分或推荐，就把红线挪进了代码里（册三十六 §2.4）。
