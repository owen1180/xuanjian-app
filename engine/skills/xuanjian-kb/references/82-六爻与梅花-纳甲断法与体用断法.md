# 八十二、六爻与梅花：两套卜法的断法结构

> 这一册填的是一个结构性空洞：**引擎早就能装卦**（`36` §2：本卦互卦变卦、世应六亲六神），
> **册页却一个字没讲怎么断**。`70` §4 教了起课，`62` 讲了卦义，中间的"装卦→取用神→看旺衰→定应期"整段是空的。
> 本册补这一段，并把两套卜法的边界划清：**六爻重六亲旺衰，梅花重体用一象，不许混着说。**

## 0. 先分清四件事（混一件，全盘皆错）

| 层 | 六爻 | 梅花易数 | 谁做 |
|---|---|---|---|
| **① 起卦** | 三枚铜钱摇六次（或六枚一次撒） | 时间数、报数、声音、方位 | 人／脚本 |
| **② 装卦** | 纳甲、世应、六亲、六神、伏神 | 无（只排上下卦与动爻） | **引擎**（`36` §2） |
| **③ 断法** | 取用神 → 旺衰 → 动变 → 应期 | 体用生克 → 互变 → 时令外应 | **人**（本册） |
| **④ 分寸** | 不判生死、不判胜负、不落病名 | 一卦只断一象，不细断六亲 | **人**（`27`／`57`） |

**铁律**：②可以由程序做，③④不行。**引擎给的是爻位与六亲，不是结论。**

## 1. 起卦三法，不许混

| 法 | 做法 | 出处 | 用在哪 |
|---|---|---|---|
| **三枚六次**（传统六爻） | 三枚铜钱合扣摇，掷六次，由下往上记；一背为单（阳）、二背为拆（阴）、三背为重（老阳动）、三字为交（老阴动） | 通行之法 | 六爻正法 |
| **六枚一次**（倪师金钱卦） | 六枚铜板一次撒成一排，**由下往上读六爻**，人面为阳、数字面为阴；撒不整齐则作废重来 | `70` §4（原话 @00:45:19 起） | 天纪一路，**快** |
| **数起**（梅花） | 时间、报数、字数、声音 | 本册 §5 | 梅花 |

**为什么不能混**：三枚法六次独立、每次四种结果（老阳／少阳／少阴／老阴），概率 1:3:3:1；六枚法一次定六爻，**没有动爻的层次**（除非另定）。**同一件事，两法出的卦不同，不是谁错，是两套东西。** 客户拿"我撒了六个铜板"来问，先问是六枚一次还是三枚六次。

**六神只添色，不主吉凶**——与 `33` 六神占断同一纪律：**看神不看形**。

### 2.5 伏神：用神不上卦时

本卦六爻里没有该六亲，就从**本宫首卦**（八纯卦）同爻位取伏神，伏在本卦那一爻之下。
判法：**伏神能出则吉，不能出则事在暗处**。出伏三条件——伏神旺相、飞神生伏或空破、日月生扶伏神。

## 3. 六爻断法四步

### 3.1 第一步：取用神（定"谁"）

先问清问的是谁、什么事，再照 §2.3 取。**一事一用神**；两件事要分两卦，不许一卦断两事。

- 问财：妻财为主，子孙（财源）为辅
- 问工作：官鬼为职位，父母为文书／单位
- 问婚（女）：官鬼为夫，应爻为对方态度
- 问婚（男）：妻财为妻
- 问病：**官鬼为病，子孙为药**（只讲"宜早查"，不落病名）
- 问房、车、文书：父母
- 问失物：妻财为物，看伏与动

### 3.2 第二步：看旺衰（定"有没有力"）

**四看，缺一不算**：

| 看什么 | 怎么判 |
|---|---|
| **月建** | 用神临月令为旺；月生为相；月克为死；月冲为**月破**（破则无力，待出月或逢合） |
| **日辰** | 日生为有气；日克为受制；日冲静爻为**暗动**；日冲旺爻为冲起；日辰可生克任何一爻 |
| **动爻** | 动爻生用神为助，克用神为阻；**动爻优先于静爻** |
| **变爻** | 看回头生／回头克（见 §3.3） |

**旺衰口诀**：得月得日者强，失月失日者弱；**月管一月，日管一日**，问近期看日，问远期看月。

### 3.3 第三步：看动变（定"怎么变"）

| 形态 | 判 |
|---|---|
| **回头生** | 变爻生本爻 → 越变越有，事后得力 |
| **回头克** | 变爻克本爻 → 越变越差，后手翻车 |
| **化进神** | 如寅化卯、巳化午 → 前进、加码 |
| **化退神** | 如卯化寅、午化巳 → 退、减、散 |
| **化空** | 变爻落旬空 → 中途落空 |
| **化破** | 变爻被月冲 → 变而无力 |
| **化墓** | 变爻入墓 → 困住、拖着 |
| **反吟／伏吟** | 卦变相冲／本卦重现 → 反复、原地打转 |

**旬空**：以日柱定空亡两支。空爻**不是没有**，是"现在不实"——待填实（值日／值月）或冲空之时才起用（与 `45` 四柱空亡同一读法）。

### 3.4 第三步补：七种最容易漏判的形态

> 这一段是照开源技能包 `Johnson-Jia/liuyao-divination` 的十一章目录**回头审自己**补的——它把"暗动、日破、三合、墓库、四神、反伏"单列成册，本册初稿漏了。**别人的目录，可以当自己的检查表用。**

| # | 形态 | 判法 | 断意 |
|---|---|---|---|
| 1 | **暗动** | 静爻**旺相**又被**日辰冲** | 有动之力、无动之象：事在暗中动，人未觉而势已变 |
| 2 | **日破** | 静爻**休囚**又被日辰冲 | 当日无力，逢生扶才起；**与暗动只差一个旺衰**，最容易看反 |
| 3 | **三合局** | 申子辰水、亥卯未木、寅午戌火、巳酉丑金；三爻俱全（或两爻＋日月一支） | 成局则合力大，看局之五行与用神生克；**缺一不成局**，只作半合 |
| 4 | **六合** | 子丑、寅亥、卯戌、辰酉、巳申、午未 | 合则**绊住**：事缓、人被牵、走不开；合处逢冲则解 |
| 5 | **墓库** | 辰水库、戌火库、丑金库、未木库 | 用神入墓主困、主藏、主拖；**出墓**靠冲墓之支或冲墓之月日 |
| 6 | **四神** | 用神（所问）／原神（生用神）／忌神（克用神）／仇神（生忌神、克原神） | 先看哪一神**有力**，再定走向：原神有力则事可成，忌神有力则受阻 |
| 7 | **反吟伏吟** | 卦变相冲为反吟；本卦重现／内外卦不变为伏吟 | 反吟主反复来回，伏吟主原地停滞；**都不主吉凶，主"动不了"** |

**三条提醒**：

- **暗动与日破，只差旺衰**。同一个日冲，旺爻是"暗中动"，衰爻是"当日破"。判错这一个字，结论正好相反。
- **合不都是好事**。六合是"绊"，问走动、问脱身、问分手时，合住就是坏事。**合要看问什么**。
- **墓库不是死**。入墓是"收起来"，出墓有时。断"没了"是越界。

### 3.5 第四步：定应期（定"什么时候"）

**三法，按用神状态选**：

1. **旺相** → 待**值**：值日、值月，或逢冲而动。
2. **休囚** → 待**生扶**：生它的月日，或出空、出破之后。
3. **受制**（空、破、墓、合住）→ 待**解**：空待填实／冲空，破待合／出月，墓待冲墓，合待冲开。

**口径**：应期只给**区间与月令**（"这个月内／下个月"），不给具体日；问远期给节令节点，不给年月日。与 `16` 奇门应期同一条纪律。

## 4. 六爻的分寸

1. **不判生死寿夭。** 官鬼持世、白虎临爻，只能讲"这一段身体要当心，宜先查"，**不许接"能不能过"的话**（`46`、`24`）。
2. **不判官司胜负。** 官鬼与世应只能讲"文书上容易卡、宜先备材料"，**不说"能赢／必输"**。
3. **不落病名。** 六爻问病只给方向（哪一系统宜查），不给诊断。
4. **一事一卦，不重占。** 同一事当日重占取第一卦；要复核换日，并说明"这是第二卦"（与 `74` §5 小六壬同律）。
5. **不动就问"你希望它成还是不成"。** 占卜最容易被拿来求安慰；先问清所求，再取用神，**不许替客户选一个他爱听的结论**（`27` §2）。
6. **与奇门分工**：六爻问**人事细节**（谁、什么关系、成不成），奇门问**时间与方位**（何时动、往哪边）。两样都要时，各起一局，**不许一卦兼答两问**。

## 5. 梅花易数：起卦与体用

### 5.1 先天卦数（起卦用先天，不用后天）

| 数 | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
|---|---|---|---|---|---|---|---|---|
| 卦 | 乾 | 兑 | 离 | 震 | 巽 | 坎 | 艮 | 坤 |

> 后天数（坎1坤2震3巽4中5乾6兑7艮8离9）用于**方位与九宫**，不用于梅花起卦。**两套数不许混**（与 `34` 四柱命卦的取数各是一套，见 `34` §1）。

### 5.2 时间起卦（最常用）

```
上卦 = (年支数 + 农历月 + 农历日) mod 8      # 余 0 作 8
下卦 = (年支数 + 农历月 + 农历日 + 时支数) mod 8
动爻 = (年支数 + 农历月 + 农历日 + 时支数) mod 6   # 余 0 作 6
```

年支数：子1、丑2、寅3……亥12；时支数同法。
**下卦数已含上卦数**，即"再加时支"——这是通行法，不是重复计算。

### 5.3 数字与其它起卦

- **报数**：两数各 mod 8 取上下卦，两数之和 mod 6 取动爻。
- **字数**：字数为上卦、笔画或字义为下卦（各派不一，**用哪派要说明**）。
- **声音、方位、外应**：见物起卦，属"心易"，**只在无法取数时用，且必须记下所取之物**。

### 5.4 体用、互卦、变卦

| 项 | 取法 |
|---|---|
| **体** | 不动的那一卦（无动爻之卦） |
| **用** | **动爻所在之卦** |
| **互卦** | 本卦 2·3·4 爻为下互，3·4·5 爻为上互（**互卦看过程**） |
| **变卦** | 动爻阴阳一变（**变卦看结果**） |

### 5.5 断法：体用生克为主

| 关系 | 判 |
|---|---|
| **用生体** | 吉，有外力相助，事顺 |
| **体生用** | 耗，自己出力、付出多 |
| **比和** | 吉，同类相合，平稳 |
| **体克用** | 吉但费力，能成，要使劲 |
| **用克体** | 凶，受制、受阻；**克得重则事难成** |

再看三层修正：**互卦看中间出了什么**、**变卦看最后落在哪**、**时令看体之旺衰**（春木旺、秋金旺……体旺则任克，体衰则一克即倒）。

**梅花的边界**：一卦只断**一象、一事**。**不许拿梅花断六亲、断一生、断具体金额**——那是六爻与命盘的活。梅花的长处是"当下这一件事的势"，短处是"细不下去"。

## 6. 两法怎么分工（一句话记住）

> **六爻像查账**：一条一条爻、一层一层六亲，能查到"谁、什么关系、卡在哪一爻"。
> **梅花像看云**：一眼取象，讲的是"这件事的势头往哪边倒"。
> **查账要准，看云要快；查账别嫌慢，看云别求细。**

| 客户问 | 用什么 |
|---|---|
| 这笔钱能不能回来、这个人靠不靠得住、这份工作成不成 | 六爻（六亲可定位到人） |
| 眼下这事顺不顺、今天去谈行不行、这东西找不找得回 | 梅花（快，一象） |
| 什么时候动、往哪个方向 | 奇门（`16`） |
| 这一生的格局 | 四柱／紫微（`01`–`03`、`11`） |
| 一件小事、人在外面、连卦都不想摇 | 小六壬（`74` §5） |

## 7. 与天纪的关系（不许冒充）

- **倪师讲的是金钱卦**：六枚一次撒、由下往上读（`70` §4）。那是**六爻起卦的一种简法**，讲得粗、讲得快。
- **天纪没有讲纳甲、世应、六亲、六神的完整断法**。本册 §2–§4 是**通行六爻之法**，不是倪师所传。
- 对外表述：**"起卦法是倪师讲的（金钱卦），断法走通行六爻"**，两件事分开说。**不许把纳甲断法说成倪师秘传**（与 `35` 谱系、`64` 结论七同一条纪律）。

| 梅花组 | **40/79 ＝ 50.6%**，与抛硬币无异 |
| 对照组 | 57/79 ＝ 72.2%，但其 96.2% 的判断跟随市场共识；单靠共识本可得 73.4% |
| 两组分歧的 37 例 | 对照组赢 27、梅花组赢 10（精确二项检验 p < 0.01） |
| 置换检验 | 卦象属性与结果无显著相关（p ＝ 0.6059／0.9433／0.9482） |
| 报告的自我限定 | AI 起卦**没有真实问卦人**、无外应、只机械套体用、单一领域（二元市场）、n＝79 |

**本馆怎么用这一条**（按 `66` 证据分层，这是**第四层"外部参考"**，不是本馆验证）：

1. **不拿它证明"梅花是假的"。** 它测的是"把体用生克机械化套到二元市场上"，不是测"梅花这门学问"。报告自己也写了"at least as operationalized here"。
2. **也不许装作没看见。** 客户问"你这算得准吗、敢不敢打包票"，这是现成的答案：**有人认真做过，机械化判吉凶接不近抛硬币**；所以我们只讲倾向、条件与可观察信号，不承诺结果（`43` §4、`27` §2）。
3. **它反过来支持本册的分寸**：梅花只断"一象之势"，**越把它当预测机，越不准**；六爻能细到人，也不等于能断生死胜负。
4. **引用时要带三条限定**：单域（二元市场）、小样本（79）、无真实问卦人。**去掉这三条，就成了拿别人的实验做自己的广告。**

> 这件事本身值得记一笔：**一个做梅花的项目，亲手发布了自家方法"不灵"的报告。** 在 `74` §2 那个"星数不等于质量"的判断之外，这是另一种稀缺——**敢公开负结果**。本馆的 `66` 证据分层与 `72` 钢人反方，要的正是这种态度。

## 9. 一句话结论

> **装卦可以交给程序，取用神与分寸不能。**
> 六爻的力气在"六亲能落到人"，梅花的力气在"一象能落地"；**两样都不许越级去断生死、断胜负、断一生**。
> 起卦三法各有其形，**混着摇，卦就不是那个卦**。
