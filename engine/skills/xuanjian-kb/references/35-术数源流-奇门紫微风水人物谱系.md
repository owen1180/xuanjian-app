# 三十五、术数源流与传承谱系：奇门遁甲 · 紫微斗数 · 风水堪舆

> 本册把三套系统的传承脉络与代表人物蒸馏成"一张谱"。用途：客户问"你这一门出哪本书、尊谁为祖、哪一派"时，按本册给出准确、不夸口的回答。**只讲谱系与各家定位，不把某一家冒充成另一家的源头，不替任何一家做疗效/准确率的背书。**

> **诚实声明**：本册的素材是一份"源流与传承脉络"综述，覆盖的是**各人物的理论定位与历史贡献**，而非逐条实战案例。文中除注明者外，**没有可逐字复述的实战案例**——凡标"（案例未载）"者，对外只能说到"该人物以何见长"，不能编造具体断例。需要补实战，须回到原始著作（见各节"原始出处"）。

## 一、奇门遁甲：从"帝王之学"到现代研究

**本馆定位**：我们用的奇门是"主流时家奇门"（`16`）。下面这些人物是**源流背景**，不是我们直接师承的链条——对外说"奇门"要讲清：源头是传说，明清定型，当代靠张志春等人通俗化。

## 二、紫微斗数：传承脉络最清晰

**本馆定位**：我们用的是"倪海厦三合派"紫微（`11`/`15`/`22`）。下面这些人物说明紫微"尊谁为祖、现代怎么传"，尤其**紫云的"太岁入卦法"和"打破十二宫固定看法"**对我们读盘有直接启发。

### 2.1 与本馆读盘直接相关的两点
- **紫云"太岁入卦法"**：把流年太岁纳入卦位推演，是"流年怎么引动"的进阶技法。我们 `15` 的四化飞星已含流年，若客户问"为什么同宫不同年反应不同"，可引"太岁入卦"作为思路补充，**但只用思路，不自行发明排法**。
- **"打破十二宫固定看法"**：与我们 `22` 逐宫解析时"先看三方四正、再看暗合、不单宫下结论"的做法一致——可引紫云佐证"宫位不是死的"。

### 2.2 落地规则
- 客户问"紫微出自谁" → 答："尊北宋陈希夷为创术人，明代罗洪先作序传世，现代靠王亭之公开中州派、紫云做技术突破。"
- **不许**把紫微说成"倪海厦独创"——倪师是传授者之一（三合派），不是创术人。

## 三、风水堪舆：形峦派对理气派

**本质一句话**：形峦派看"长什么样"（龙穴砂水形态，可不用罗盘），理气派算"在什么方位"（八卦九星干支 + 时间元运 + 罗盘）。两派**不是对立**，好风水要峦头理气兼备（章仲山即主张并重）。

### 3.1 形峦派（形势派 / 江西派）：以"眼"观形
**核心理念**："有形必有灵，有象必有应"——观龙、穴、砂、水形态定吉凶，可不依赖罗盘。

### 3.3 与本馆堪舆（`08`–`10`、`17`–`20`）的对应

- **不许**把倪海厦的地脉道说成"自创一派"——它是理气框架下的应用，谱系上归玄空/三元脉络。

## 四、四柱八字：从李虚中到子平术

> 前三节讲的是奇门、紫微、风水。四柱这一支另有谱系，**我们日常用的打分法与取用神，正出自这一支**。
> 来源：四柱理学第一课「四柱简史 五行解意」。

| 阶段 | 人物与著述 | 要点 |
|---|---|---|
| 源头 | 唐·李虚中《李虚中命书》（署「鬼谷子撰，虚中注」） | 公元 761 年生。墓志铭载其「以人之始生年月日所值日辰支干，相生胜衰死王相斟酌，推人寿夭贵贱」，**百不失一二**。公认四柱鼻祖，最早以年月日干支论命（**尚无时柱**） |
| 成型 | 南宋·徐大升编《渊海子平》 | 据徐子平理论编纂。**徐子平其人事迹无可考**——《四库全书》评：「子平事迹无可考，独命学为世所宗。」算命术统称「子平术」由此而来。我们这一路就是子平术的发展 |
| 明代五家 | 张楠《神峰通考》（晚年所成，继承子平） | 全名《神峰张先生通考命理辟谬大全》 |
| | 万明英《三命通会》《星学大成》 | 进士，二书入《四库全书》，属权威认可的一路 |
| | 刘伯温注《滴天髓》 | 原作者为宋·京图，因刘注而扬名 |
| | 余春台注《穷通宝鉴》 | 由民间抄本《栏江网》加注更名，**开创调候论命**——等于给格局层次打了个补丁 |
| | 西窗老人《兰台妙选》 | 李虚中模型的继承者，**专论纳音**，是纳音派的经典 |
| 清代 | 陈素庵《命理约言》等 | 子平派继承者 |

### 4.1 纳音派为什么不再发展

纳音＝六十组干支两两赋予一种属性（甲子乙丑海中金、庚午辛未路旁土……）。**纳音是四柱与易学唯一的交集**。

课里给的判断很直白：纳音派自明代《兰台妙选》之后基本停滞，原因有三——

1. 纳音**不参与八字计算**。「路旁土怕大林木」这类说法，在八字运算规则里用不上；
2. 同一纳音覆盖两年（1990 庚午、1991 辛未皆路旁土），**一个班的同学几乎同命**，显然解释不了个性差异；
3. 纳音是李虚中时代的旧模型，后人另起炉灶后，它只在旧框架里打补丁，跟不上新体系。

**所以我们只用日元五行论命，不用年柱纳音论命。** 客户说「算命的讲我是土命、路旁土」，要说明：那是年柱纳音的旧说法，我们按日元五行算。

### 4.2 对外怎么讲

> 〔本馆归纳〕"四柱从唐代李虚中起头，那时只论年月日；到南宋《渊海子平》才定型为今天的四柱，这一路叫子平术，我们学的就是它。明代又有《三命通会》《滴天髓》《穷通宝鉴》几部，《穷通宝鉴》专门补了调候这一块。至于'您是什么命'，我们按日元的五行算，不按年柱纳音——纳音那套明代以后就不再发展了，两年一个命，一个班的同学全一样，说不通。"

## 五、一句话总览（对外应答模板）

> 〔本馆归纳〕"这四门里，**紫微的传承最清楚**（陈希夷创、罗洪先传世、王亭之公开、紫云突破）；**奇门从传说源头到当代通俗化**有一条线（风后姜子牙传说 → 张良简化 → 张志春《神奇之门》）；**风水分形峦（杨筠松看形）和理气（蒋大鸿算方位）两派，我们两样都看**；**四柱从李虚中到《渊海子平》成子平术，我们这一路就是它**。这些是我们的'家谱'，但具体断事用的是主流通行之法，不是某一位古人的独家秘传。"
