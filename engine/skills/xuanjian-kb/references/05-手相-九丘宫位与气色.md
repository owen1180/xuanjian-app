# 五、手相：九丘、八卦宫位与气色

> 分工：**九丘看性格，宫位看运势，气色看近期**。三纹看长期趋势（见 `04`）。四者叠起来才出结论。

## 1. 九丘（掌丘）

掌丘是手掌上隆起的肌肉，共九类：

| 丘 | 五行归属 | 位置 | 主事 |
|---|---|---|---|
| 木星丘 | 木 | 食指根部 | 志向、领导欲、进取心 |
| 土星丘 | 土 | 中指根部 | 责任感、耐性、思虑 |
| 太阳丘 | — | 无名指根部 | 名声、才华外显、人缘 |
| 水星丘 | 水 | 小指根部 | 表达、机敏、商业感 |
| 金星丘 | 金 | 拇指根部 | 生命力、情欲、亲和 |
| 月丘 | — | 小指侧下方 | 想象、直觉、外缘 |
| 地丘 | — | 掌根中央偏下 | 根基、家宅、体力底盘 |
| 第一火星丘 | 火 | 虎口处 | 勇气、斗志 |
| 第二火星丘 | 火 | 小指侧中段 | 忍耐、抗压 |

### 饱满度怎么判

课程特别提示：**丘位饱满是立体概念，照片是平面，天然有折损**。判断基准是"以自己手掌比例为参照"——某丘相对其他丘明显隆起、有肉、不塌陷即为饱满；凹陷、见骨、纹乱即为弱。

- 饱满：该丘所主之事有力、外显
- 平塌：该事平平，不显
- 凹陷／见骨：该事为弱项，易受挫
- 纹多杂乱：该事多波折、多思虑

## 2. 八卦宫位

手相分八个宫位，即乾、坎、艮、震、巽、离、坤、兑八卦。**宫位比丘位更偏运势预测**。

| 宫 | 卦象 | 主事 |
|---|---|---|
| 乾 | 天 | 父、君、权威、事业高度 |
| 坎 | 水 | 险、智、流动、奔波 |
| 艮 | 山 | 止、积蓄、田宅、阻力 |
| 震 | 雷 | 动、起、长子、变动与开创 |
| 巽 | 风 | 入、顺、长女、文书与流通 |
| 离 | 火 | 明、显、中女、名声与情绪 |
| 坤 | 地 | 母、承载、包容、家宅 |
| 兑 | 泽 | 悦、口、少女、口才与人缘 |

看点：**宫位饱满明亮、无恶纹恶痣者，该宫所主之事顺**；凹陷、青筋、恶纹、暗滞，则该事有阻。

## 3. 气色

手相气色与面相气色同源，主**近期**，一般看一至两个节气（约两到四周）。

| 掌色 | 含义 |
|---|---|
| 明润、白里透红 | 气顺，近期吉 |
| 黄润 | 平和，注意脾胃 |
| 白而枯 | 气血虚，精力不足 |
| 红赤／泛红点 | 火旺、急躁，注意心与血压 |
| 青暗／青筋浮 | 寒滞、气郁，注意肝胆与情绪 |
| 灰黑／暗滞 | 近期运势低、易有事，宜守不宜进 |

**看气色的位置**：以掌心（明堂）为主，兼看各丘与指尖。气色变化快，**断近期不断终身**。

## 4. 综合分析怎么做（课程第五讲的做法）

课程用"特征叠加法"：把同一张手上多个特征指向同一结论时，才敢下判断。

示例（课程原例）：
- 上停饱满、天仓宽阔 → 年少运顺、分析力记忆好
- 但驿马宫宽阔 → 一生东奔西走
- 眉浓、鼻漏、嘴厚 → 好享受、重情欲
- 合起来断：少年得志、才华外露、一生奔走、花销大存不住钱

**一个人的结论，至少要三个特征互相印证才出口。** 单个特征只作提示。

## 5. 手相与八字的接口

- 手相看"当下与走势"，八字看"格局与阶段"，二者出现矛盾时：以八字定阶段、以手相定状态。
- 例：八字走财运而掌色灰暗 → 财在但当期不顺，宜守。
- 例：八字无官而事业线强 → 靠自身经营而非平台，属"自谋"型。

## 6. 看照片的实操要求

| 需要 | 原因 |
|---|---|
| 双手掌心正拍，光线均匀 | 看三纹、丘位、气色 |
| 双手手背 | 看指节、指甲、肤色 |
| 侧面微侧光 | 看丘位立体饱满度 |
| 拇指自然展开 | 看金星丘与生命线弧度 |

拍不全就说明"以下判断只覆盖掌面，丘位与气色待补"。

## 7. 三宫：福、禄、寿（宫位看运势，丘位看性格）

丘位偏重性格，宫位偏重运势。八宫之中，巽、离、坤三宫合称**三峰纹**，对应一生的财、官、福禄。

| 宫 | 位置 | 主事 | 对应丘位 |
|---|---|---|---|
| **巽宫** | 食指下方（若凸起在食指与中指指缝下，以该隆起定位） | **财运**；饱满主事业心强、对财富欲望强 | 木星丘 |
| **离宫** | 中指下方 | **官运／事业发展与学历文凭** | 土星丘 |
| **坤宫** | 小指侧下方一带 | **母亲缘分与身体、子女关系、夫妻关系**（此区含婚姻线与子女线） | 太阳丘、水星丘 |

要点：

- **没有事业线不等于没有事业。** 多数人并无事业线，看事业须并看离宫饱满度。
- 离宫厚实、有弹性 → 事业运佳；平坦 → 平顺而已；出现一圈套一圈的环形纹，主反复。
- 巽宫见三角纹，传统主财运连绵。

**杂纹与身体（只作提醒，不作诊断）**：巽宫的反射区对应肝。见十字纹，传统认为该处负担偏重但尚未成形，多无明显感觉；见米字纹，认为负担已较明显；见三角纹，影响更重。**这类提示只能说"建议做一次该系统的常规检查"，病名一个字不说。**

## 8. 丘位饱满度的三步法（照片也能判）

饱满度是立体概念，平面照片容易看错。按三步走，可把误差压下来：

1. **定区域**：先圈出该丘的完整范围（如木星丘＝食指下方整片）。
2. **找参考面**：在该区域附近找一处较平坦的部位作为水平基准。高于基准＝凸起，齐平＝平，低于＝低陷。**最好把手机侧过来看**，让丘位与水平面做比较。
3. **看比例**：凸起部分在该区域内占多大面积。
   - 约占一半 → 饱满
   - 几乎占满 → 过度发达
   - 几乎无凸起 → 低陷

**话术**：说"这个丘看着饱满／偏平"，不说"你的财运很好／很差"。丘位只是其中一象，须与三纹、宫位、气色合看（见第 4 节三条互印原则）。
