## 1. 双手分工：哪只手看什么，比"男左女右"细一层

| 手 | 男 | 女 | 主什么 |
|---|---|---|---|
| 先天手 | 左手 | 右手 | 35 岁之前的命运；**父辈祖辈的福德**；婚姻、子女等**命中注定之事** |
| 后天手 | 右手 | 左手 | 35 岁之后；**后天努力**；思想、健康、感情等**总在变化之事** |

课程原话的分工：

> **"看婚姻、子女等命中注定之事，主要看先天手；看思想、健康、感情等总在变化的事情，要看后天手更准。"**

三条实操推论：

1. **先天掌纹难改，后天堂纹容易变**。所以"这两年他想通了很多事"这类变化，要到后天手上找证据（杂纹减少、锁链纹变浅）。
2. **问婚姻**：先看先天手的婚姻线与感情线定"底色"，再看后天手看"这几年怎么走"。
3. **问健康**：反过来，以后天手为主，先天手只作体质底盘参考。
4. 双手差异大 → 后天改变明显。**差异本身就是一条结论**，不只是"两手都看一下"。

## 2. 三奇线：三条都成，才算助力

掌上向中指、无名指、小指三个方向延伸的三条纵线，分别是**事业线、太阳线、财运线**。

| 状态 | 判定 |
|---|---|
| 三条**都清晰、都连续** | 成"三奇线"，主事业、名声、财源三者互相助力 |
| 任一条断续、模糊 | **不成三奇**，该线不发挥助力——**不是"有这条线就有这个运"** |

课程原例：某人三条线都有，但太阳线与财运线都不够清晰连续，故判"三奇不成，助力发挥不出来"。实际此人事业尚可、财上平常。

> 这一条纠正一个常见误读：**有线 ≠ 有力**。线要"清晰连续无杂纹"才算成。

## 3. 三角纹：封闭才有效

由**生命线、智慧线、健康线**三条围成的三角形，主财运与抗风险能力。

| 状态 | 判定 |
|---|---|
| 三条边封闭、清晰 | 成三角纹，传统主"能存住钱、有意外之助" |
| 健康线不连续、缺口 | **不封闭，则助力不发挥**（课程原例即此） |

另有**元宝纹**（掌心封闭的梯形／元宝形纹），与三角纹同列财运象征，同样要求封闭。

> 与 `05` §7"巽宫见三角纹主财运连绵"是一套东西的两个位置：**巽宫的三角纹看"有没有财路"，掌心三角纹看"存不存得住"。**

## 4. 分项抓手：问什么，就看这几处

这是本册最实用的部分。课程把"看事业看哪里"直接给了清单，不必每次从掌型重新推。

| 问什么 | 主看 | 参看 | 判定要点 |
|---|---|---|---|
| **事业** | **离宫** + **事业线** | 太阳线（有无助力）、乾宫（饱满度） | 离宫厚实有弹性 → 事业佳；平坦 → 平顺；环形纹 → 反复。事业线断续 → 中途转折多 |
| **财运** | **巽宫** + **太阳丘** | 小指长短、太阳线与财运线、掌心三角纹／元宝纹 | 巽宫饱满 + 太阳丘饱满 + 小指长 → 财路与守财俱佳；三奇成 → 财源多路 |
| **健康** | **金星丘** + **坎宫** | 健康线 | 金星丘饱满 → 生命力强；坎宫低陷 + 杂纹 → 体力与抵抗力偏弱（只作提醒，见 `29`） |
| **婚姻** | **水星丘** + **婚姻线** | 感情线（锁链／岛纹／末端分叉）、生命线末端支线 | 只断"婚动强弱、宜早宜晚"，**不断次数、不断离**（`04` §7） |
| **性格** | 掌型 + 手指 + 各丘 | 掌纹杂乱程度 | 掌纹整体偏乱 → 思虑重、心事多（这是课程反复用的判语） |
| **整体运势** | **拇指 + 中指 + 三大主纹** | 三宫饱满度 | 拇指好主有决心，中指好主有自控力；三大主纹清晰连续 → 一生大致顺当 |

### 4.1 拇指与中指，为什么排在掌纹之前

课程把拇指比作"手相里的眼睛"：

- **拇指**主决心与意志力。"拇指出得好，可以弥补其他手相大部分不足"——**这是一条兜底判据**：手相再乱，拇指圆润有力者，遇事能扛、能翻身。
- **中指**主自我控制力与耐性；中指向哪边偏，主其人重心在家庭还是事业（偏食指 → 偏事业，偏无名指 → 偏家庭）。

> 用法：先看拇指中指，再看三纹。**顺序反了，容易拿一条杂纹吓人。**

## 5. 共振法则：一个象不算，几个象同指才提概率

课程原话（案例一的分析逻辑）：

> "像这样有好几个点都是共同象征一个问题的时候，就会增加问题发生的概率。"

这一句是手相断事的**总阀门**，与 `05` §4"三个特征互相印证"、`14` 合参"三盘同指"同源，但这里给了更清楚的层次：

| 象的数量 | 可以说到什么程度 |
|---|---|
| 1 个 | 只作**提示**，不出口断语 |
| 2 个 | 说"这一块要多留意" |
| **3 个及以上同指** | 才可说"这一块大概率是弱项" |
| 3 个以上且分布在**不同部位**（如丘位 + 线纹 + 气色） | 分量最重，可进报告正文 |

课程案例一即用此法：感情线锁链纹 + 末端分叉 + 岛纹 + 生命线末端支线 + 中指无名指间隙大 → 五点同指婚姻，才下"婚姻不顺"的判断。

**反向纪律**：若只有一处不利、其余俱佳（如案例二：三宫平坦但三大主纹清晰、拇指很长），结论是"整体不会太差，肯努力就有机会"，**不许因为宫位平就断衰**。

## 7. 课程两个原例的判法骨架（只用结构，不用人事）

**例一（男，32 岁，左手为先天）**：水型手、掌软纹细 → 聪明圆滑、承受力强；拇指圆润有原则、中指直长自控好 → 事业底子好；巽离坤三宫皆饱满 → 财官禄三项皆顺；但三奇不成、三角纹不封闭 → 助力发挥不出来；掌纹偏乱 → 思虑重；感情线锁链纹 + 末端分叉 + 岛纹、生命线末端支线 → 五点同指婚姻；艮宫凹陷带杂纹、坎宫低陷、智慧线有岛纹 → 三点同指体力与脑力易疲。合断：**事业财运不错，婚姻与健康是弱项。**

**例二（女，34 岁，右手为先天）**：木型手、掌硬指节大 → 有主见、直来直去；拇指长过食指第三节中线 → 敢冒险、决断强；中指第一指节弯 → 情绪控制弱；三宫皆平、太阳丘平 → 财官禄一般，做事易半途而废；事业线断续 → 工作常换。**但三大主纹清晰连续、拇指很长 → 整体不至于差，肯努力就有机会。**

> 两个例子的对比正好说明第 5 节：**例一是"局部好、多象同指弱项"，例二是"局部平、主线好"**。结论的方向完全相反，靠的不是记性好，是先数象、再看主线。

## 8. 分寸

- **不判寿夭**：生命线长短与寿命无关，课程本身不用这种断法（`04` §7）。
- **不判次数**：婚姻线只断婚动强弱与早晚，不断结几次、离不离。
- **报病名级排查**：艮宫、坎宫、金星丘的弱象，按 `OB100` §3.2 给 2–3 个病名＋检查项（"需排查慢性胃炎、贫血，查血常规＋幽门螺杆菌"）；**不给诊断**（`29` §2）。
- **丘位饱满度须说明折损**：照片是平面，"饱满"只能判个大概，须请对方补侧光图（`05` §8）。
- 每条结论出口前问一次：**这个象我有几个？够三个吗？**

> 以上为传统术数文化分析，供参考。
