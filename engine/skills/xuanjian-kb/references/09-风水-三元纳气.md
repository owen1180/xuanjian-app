# 九、阳宅：三元纳气

> 形家看"看得见的形势"（`08`），这一份看"看不见的气"。**纳气是理气派的核心动作：一间房收到什么气，决定住的人顺不顺。**

## 1. 基本概念

| 概念 | 含义 |
|---|---|
| 立极点（太极点） | 判方位与收气的基准点。**不是房子几何中心，是人实际待的位置。** |
| 内气口 | 宅内空气流动的入口（房门、通道、窗的开口） |
| 外气口 | 宅外气进入的开口（大门、大窗、阳台） |
| 纳气 | 立极点收到哪一方来的气 |
| 收气／衰气 | 收到旺气为收气，收到衰气为纳衰 |

## 2. 立极点怎么定（课程答疑明确的三条）

1. **卧室**：以**床位**为立极点，取人躺下后胸口到头部之间的位置。**是人躺下的位置，不是让人躺着测。**
2. **办公桌／书桌**：以**人坐的位置**为立极点，一般站在座位上方测方位。
3. **客厅／其它空间**：以人常驻的活动点为准。

**罗盘用法**：平置于太极点，水平测向。测的是"从太极点看出去，气从哪个方位来"。

> 这一步最容易做错。用房子几何中心定太极，是市面上最常见的错误做法——人不在那个点上生活，那个点的气与人无关。

## 3. 纳气的判定

### 3.1 气从哪来

- 外气口（大门、大窗、阳台）方向 → 主要纳气方
- 内气口（房门、走道、隔断缺口）→ 次要纳气方，但会**叠加**影响
- 一个房间可以同时受多个气口影响，需逐一列出再加权

### 3.2 遮挡不等于断绝

课程答疑里一个关键判断：

> 卫生间墙挡住内气口，**内气依然会绕行影响床位立极点**，只是路径改变，计算时要按"实际能通到立极点的那片区域"来算，不能因为被挡住就判"不纳气"。

推论：**判纳气要看气流实际可达路径，不是看开口正不正对。**

### 3.3 光线也纳气

- 光线是纳气的一部分，约占四成作用
- 晚上有月光与环境光，**拉上厚窗帘则气与光同时被挡**；只关窗不拉帘，气流减弱而光线影响仍在
- 实操结论：夜间休息时拉厚帘，等于主动切断该气口的纳气

### 3.4 关窗还有没有气

有。窗户关闭后仍从缝隙进气，只是流量小。**所以"关窗"不等于"不纳这个方位的气"。**

## 4. 断纳气的步骤

1. 确认房屋坐向（以主要采光面／大门定，与户主核对）
2. 定立极点（卧室取床位、书房取座位）
3. 列出所有能到达立极点的气口（外气口 + 内气口）
4. 逐个测方位（罗盘平置太极点）
5. 判各方所纳之气为旺为衰
6. 交叉验证：与形家（`08`）结论比对，两套都指向同一处才敢下重断
7. 给调整方案：**优先改位置，其次改遮挡，最后才谈其它**

## 5. 与形家的关系（必须说清的边界）

- 形家（`08`）与三元纳气（`09`）**同属一套课程体系**，可以互相印证，结论通常一致。
- 但**天纪的地脉道是按"名位／六十四卦"断的（见 `10`），与三元纳气是两套不同理气**。三方同时上桌会打架。
- 团队规则：**判一间房，主线只能选一条**（三元纳气或天纪名位，二者取一），另一套只作交叉提示，且必须把分歧讲给用户。详见 `14`。

## 6. 断纳气的分寸

- 没有准确坐向不判。手机指南针误差大，最好现场罗盘复测。
- 不承诺"调到某方位必发财"。纳气调整是改善概率，不是开关。
- 命与宅的关系：**命里没有的病，风水一般不单独造出来**；风水更多是把命里已有的倾向放大或削弱。这句话是课程原话，断案时要守住。
- 出租房、临时住所不必大动，讲清"权重大幅下降"即可。
