# 二十二、紫微盘面识读与逐宫解析（图片分析作业手册）

> 用途：用户不发八字、只发来**一张紫微盘截图**（先天盘／大运盘／流年盘／流月流日流时盘／中州地盘人盘），要求"照这个规格讲一遍"。
>
> 这一份给的是**两件事**：① 怎么把图读准；② 怎么按同等颗粒度出报告。`15` 讲格局与四化，`11` 讲星性，这一份讲**作业流程与输出结构**。

---

## 1. 先定边界：图能给你什么，不能给你什么

| 图能给的 | 图给不了的 |
|---|---|
| 命宫位置、十二宫星曜、庙旺、生年四化 | 出生时刻的精确分钟（影响时辰） |
| 大限区间、当前运限落宫 | 出生地（真太阳时校正） |
| 性别、五行局、命主身主 | 用户当前真实处境、已发生的事 |
| 盘型与流派（三合／飞星／中州） | 四化的流派差异（庚干等） |

**铁律：图只提供盘面事实，不提供人生事实。** 所有推断必须能指回"哪一宫、哪颗星、哪个四化"。用户若问"你看我去年发生了什么"，图答不了，要先问。

> **读图直接取引擎结果，不手推**：本馆排盘工具（`36` §2.1）已落地紫微"五层"——格局库（36 条，带 `required`／`bonus`／`breaking`）、十二神煞、六层四化（本命／大限／流年／流月／流日／流时＋宫干自化）、大限 12 步＋童限、多层合成。读图时**格局条件、四化层次、神煞**一律以工具输出为准，不要凭记忆补。
>
> **判语级溯源**：凡把倪师原话写进报告（如某格局的取象示范），须带 `册·h2·h3 @时:分:秒` 锚点（见 `65`）；星曜—宫位—病症的实体对应见 `67`。

## 2. 第一步：认盘型

先看标题栏与中间信息块，判断这是哪一张盘。**盘型认错，全篇作废。**

| 盘型 | 识别特征 | 断什么 |
|---|---|---|
| **先天命盘** | 中宫写"命宫解析"入口；十二宫为本命宫名 | 一生底色、格局、各领域先天条件 |
| **大运命盘** | 顶部/侧栏有"第×大运"，中宫标"虚岁 ××" | 这十年的主题、机会与卡点 |
| **流年命盘** | 中宫标公历年（如 2026），"流年斗君" | 这一年应什么事 |
| **流月／流日／流时／流分** | 中宫标月份/日/时辰/分钟 | 短期择时，权重最低 |
| **中州地盘／人盘** | 标题直接写"中州地盘/人盘" | 中州派看法，只作交叉 |
| **飞星盘** | 有宫干飞化箭头、四化连线 | 飞星派，只作补充（见 `15` 第 5 节） |

**判断口诀**：看中宫那一行"虚岁／流年／流月"标签，比看标题可靠。

## 3. 第二步：抓基础信息（先抄成核对表）

按顺序抄下面九项，抄完先回读一遍给用户确认。**这一步做对，后面才谈得上准。**

```
① 性别：男／女
② 五行局：水二局／木三局／金四局／土五局／火六局
③ 阳历：××××年××月××日 ××时
④ 农历：××年××月××日（闰月要标）
⑤ 命宫地支：子／丑／……／亥（同时记宫干）
⑥ 身宫地支：同上
⑦ 命主：××　身主：××
⑧ 生年四化：×化禄、×化权、×化科、×化忌（图上小字标在星曜旁）
⑨ 当前运限：第×大运（×–× 岁）／流年 ××××
```

### 图片识读的三个高频错点

1. **庙旺平陷的小字最容易漏。** 星名后面那个小字（庙／旺／得／利／平／不／陷）决定这颗星"有力无力"，漏了等于没读。**必须逐宫放大核对。**
2. **四化标记最容易错位。** 四化通常标在星名右上或下方小字（禄／权／科／忌），且**生年四化与运限四化会同时出现**，必须分清哪个是本命、哪个是大限/流年。
3. **宫名与宫位不要串。** 紫微盘十二宫是"宫名跟着命宫走"，同一格位在不同盘里宫名不同。**先找命宫，再顺时针排十二宫名。**

### 看不清时的处理（必须执行）

- 只报**确定看清**的项；模糊的写"图上不清，待你确认"。
- 整张糊到读不出主星 → 直接说"这张图分辨率不够，麻烦重发或截大一点"，**不许猜**。
- 图被裁掉一两个宫 → 声明"缺×宫，该宫结论不给"，其余照常。
- 图上信息与用户口述冲突（如性别、年份）→ **以用户口述为准**，并说明"图上显示为×"。

## 4. 第三步：定位十二宫（固定格位图）

紫微盘是固定 4×4 格，十二宫永远在这些位置：

```
巳  午  未  申
辰  ［中宫］  酉
卯  ［中宫］  戌
寅  丑  子  亥
```

**用法**：先在地支圈上找到"命宫"落在哪一格，然后**顺时针**（巳→午→未→申→酉→戌→亥→子→丑→寅→卯→辰）依次排：
命宫 → 兄弟 → 夫妻 → 子女 → 财帛 → 疾厄 → 迁移 → 交友（仆役）→ 官禄 → 田宅 → 福德 → 父母。

> 有些盘逆排或标注不同，**以图上印的宫名为准**，别用口诀硬套。

## 6. 第五步：读三方四正

**三方四正 = 本宫 + 对宫 + 两个三合宫**（本宫起，隔三跳一个）。

以命宫在**子**为例：
- 本宫：子（命）
- 三合：申（官禄）、辰（财帛）
- 对宫：午（迁移）

**读法三条：**

1. **对宫是"外面给不给"**：对宫吉 → 外力相助；对宫煞重 → 外面扯后腿。
2. **三合是"自己有没有"**：三合吉 → 内在资源足；三合空 → 靠对宫与外运。
3. **夹宫是"旁边压不压"**：两邻宫皆煞 = 夹忌；皆吉 = 夹贵。**夹比冲更缠人。**

## 7. 第六步：算综合能量级（本馆口径）

截图里常见"负能量 中强""正负能量 7:3"。这是各家 应用 自建算法，**没有统一古法**。本馆用下面这套，**必须在报告里注明"此为本馆量化口径，用于同一张盘内横向比较，不可跨盘比大小"**。

### 7.1 计分表

| 项 | 分值 |
|---|---|
| 主星**庙／旺** | +1.5 |
| 主星**得／利／平** | +0.5 |
| 主星**不／陷** | −0.5 |
| 该宫**无主星** | 0（借对宫主星，按其庙旺×0.7 计） |
| 六吉每颗 | +1（庙旺 +1.2；落陷 +0.5） |
| 禄存／天马 | +1 ／ +0.5 |
| 六煞每颗 | −1（庙旺 −0.8；落陷 −1.5） |
| 化禄 | +1.2 |
| 化权 | +1.0 |
| 化科 | +0.8 |
| 化忌 | −2.0 |
| 天刑／孤辰／寡宿 同宫 | 各 −0.3 |

### 7.2 算法

1. 取**三方四正四宫**，把四宫的分数**相加**（不是平均）。
2. 得正分 P 与负分 N（N 取绝对值）。
3. 比率 R = P ÷ (P + N)。

| R | 表述 |
|---|---|
| ≥ 0.72 | **正能量 · 强** |
| 0.62–0.72 | **正能量 · 中强** |
| 0.54–0.62 | **正能量 · 中** |
| 0.46–0.54 | **正负均衡** |
| 0.38–0.46 | **负能量 · 中** |
| 0.28–0.38 | **负能量 · 中强** |
| < 0.28 | **负能量 · 强** |

同时给比例式：`正 7 : 负 3`（P、N 归一化到 10）。

### 7.3 三条使用限制

- **能量级只说明"这一局顺畅还是费劲"，不说明"命好不好"。**
- 负能量高 ≠ 会出事，只等于"同样的目标，你要多花力气，且更容易半途松手"。
- **不许用能量级吓人。** 报"负能量·中强"时，必须同时给出"这股内耗的具体形状"和"怎么用"。

## 8. 星曜库（判断用）

### 8.1 十四主星在命宫

> 格式：**取象** → 性格底色 → 正能量 → 负能量 → 适合方向。
> 星曜入命只讲倾向，不作人身评判，不讲长相吉凶。

**紫微**｜取象：皇帝。
尊贵、要面子、有格局感。正：能扛事、有主见、自然得人拥戴。负：自负、耳根软、好大喜功、听不进逆言。适合：管理、公职、品牌、平台型角色。
**关键**：紫微最怕"孤君"——无左右魁钺则为"孤家寡人"，位高而无人扶。

**天机**｜取象：谋士、齿轮。
脑子快、善策划、机变。正：聪明、学得快、能设计路径。负：多虑、善变、心神不宁、钻牛角尖。适合：参谋、企划、技术、教研。
**关键**：天机最怕"想而不动"，化忌时尤甚——想法很多，落地很少。

**太阳**｜取象：日。
博爱、担当、要名声。正：光明磊落、肯付出、有公众缘。负：劳碌、施而不受、好面子、易透支。适合：教育、政法、传媒、外贸、公共事务。
**关键**：太阳落陷（酉戌亥子）为"日落"，主付出多回报少，宜转向"专业深耕"而非"台前曝光"。

**武曲**｜取象：刀币、将军。
务实、果断、重执行。正：能理财、敢决断、抗压强。负：刚硬、寡合、重利轻情、易因直伤人。适合：金融、工程、军警、实业。
**关键**：武曲最忌"孤"——加擎羊陀罗则刚而折，宜以专业立身，不宜硬碰人际。

**天同**｜取象：福星、孩子。
温和、随缘、懂生活。正：人缘好、心态稳、有生活情趣。负：懒散、缺干劲、情绪化、想多做少。适合：服务、文教、餐饮、文艺、生活类行业。
**关键**：天同坐命最需要"一个外部节律"（固定上班、固定客户），否则容易停在原地。

**廉贞**｜取象：囚、规矩、次桃花。
原则强、能担责、手腕灵活。正：守规矩、能扛、公关能力强。负：固执、易冲动、易涉是非官非。适合：法务、行政、业务、公关、军警。
**关键**：廉贞见擎羊为"刑"，见火铃则急；**宜在有明确规则的组织内发挥**。

**天府**｜取象：库房。
稳重、能守、有包容。正：稳健、善积累、能承载。负：保守、爱面子、缺开创、易拖延。适合：财务、行政、地产、供应链。
**关键**：天府是"守成星"，宜守不宜攻；配煞则"库破"，要看财帛与田宅。

**太阴**｜取象：月、母亲、田宅。
细腻、体贴、重感受。正：审美与直觉好、善理财置产、能照顾人。负：多愁、被动、内耗、想太多。适合：文教、设计、财会、家宅相关。
**关键**：太阴落陷（卯辰巳午）主"月晦"，情绪起伏大，宜以规律作息与环境稳定来托住。

**贪狼**｜取象：欲望、才艺、桃花。
生命力旺、多才多艺、交际强。正：学习力强、能跨界、人脉广。负：贪多、纵欲、耗散、难收尾。适合：业务、娱乐、艺文、五术、跨界整合。
**关键**：贪狼遇火铃为"火贪/铃贪"，主暴发，也主暴起暴落——**要提前讲清"来得快也去得快"**。

**巨门**｜取象：大门、口舌。
口才、追根究底、善研究。正：能说能写、钻研深、适合专业发声。负：是非多、多疑、暗昧、易招怨。适合：传播、法律、医疗、教研、咨询。
**关键**：巨门庙旺是"开着的门"（医院、法院、媒体），落陷是"关着的门"（封闭、暗处、是非）。

**天相**｜取象：印玺、宰相。
稳重、协调、有服务心。正：公正、善协调、能辅佐也能自立。负：犹疑、怕得罪人、易被牵连。适合：秘书、行政、公职、客服、法务助理。
**关键**：天相最怕"夹忌"（两邻宫煞重）——替人背锅之象，宜留书面痕迹。

**天梁**｜取象：老树、荫、医。
厚道、有原则、能庇人。正：有长辈缘、能解厄、宜专业助人。负：孤高、爱说教、操心过度、易累。适合：医、教、法、宗教、保险、公益。
**关键**：天梁是"先难后解"之星——**过程多磨，但多能化解**，这一点要主动讲，能安人心。

**七杀**｜取象：将、刀。
果断、能独当一面、抗压。正：执行力强、敢承担、临危不乱。负：孤刚、冲动、易伤、不圆融。适合：军警、工程、创业、外科、危机处理。
**关键**：七杀宜"有制"（见禄、见吉），无制则刚而折；**最忌与擎羊、陀罗、火星同宫**。

**破军**｜取象：耗、破旧立新。
开创、敢破敢立、不安于现状。正：改造力强、能开新局、不怕重来。负：破耗、反复、不安定、难守成。适合：创业、改造项目、业务开拓、军警。
**关键**：破军主"先破后成"——**要讲清"破"是过程不是结局**，否则用户只听到"耗"。

### 8.2 六吉星

| 星 | 主 | 落宫读法 |
|---|---|---|
| **左辅** | 助力、众人 | 得同辈与部属之助；单见力薄，双见力厚 |
| **右弼** | 助力、暗助 | 多暗中帮忙的人；与左辅同宫最佳 |
| **文昌** | 文书、科名、条理 | 考试、公文、专业资格有利 |
| **文曲** | 才艺、口才、灵感 | 表达与创作有利，忌与煞同宫（华而不实） |
| **天魁** | 阳贵（明面上的贵人） | 长辈、上级、男性贵人 |
| **天钺** | 阴贵（暗中的贵人） | 平辈、女性、后台贵人 |

### 8.3 六煞星

| 星 | 取象 | 具体形状 | 化解方向 |
|---|---|---|---|
| **擎羊** | 刀、刑 | 冲动、外伤、争执、手术 | 把"刀"用在专业上（外科、机械、竞技、执法） |
| **陀罗** | 缠、拖 | 拖延、反复、犹豫、暗耗 | 设外部截止时间，把"拖"变成"磨细节" |
| **火星** | 急火 | 突发、爆脾气、急事 | 提前预案，把"急"用在抢时机 |
| **铃星** | 阴火 | 焦虑、慢性消耗、疑虑 | 规律运动与作息，把"焦虑"转成风险排查 |
| **地空** | 空 | 想得多做得少、落差感、精神性 | 走研究、创作、哲学、宗教路线；忌投机 |
| **地劫** | 劫 | 破财、被夺、投机失手 | 不做不懂的投资；把钱变资产不变量化 |

> **煞星不是"坏星"，是"高能量但方向危险的星"。** 报告里必须给"这股劲往哪使"，不能只说"你有煞"。

### 8.4 四化入宫

> **十干四化表见 `15` 第 4 节。看图时一律以图上实际标注为准，不要用表去改图。** 若图上的四化与表不符，先怀疑自己看错行，再看是否庚干这类有分歧的年份。

| 化 | 落宫含义 | 断法 |
|---|---|---|
| **禄** | 资源入口、人缘、得 | "这件事上有得拿"，也主"从这里来钱/来人" |
| **权** | 掌控、扩张、刚性 | "这里想说了算"，也主"这里的争执" |
| **科** | 名声、文书、体面 | "这里容易被看见"，也主"这里要面子" |
| **忌** | 卡点、执念、耗 | "这里总放不下"，**不是灾，是执念** |

**读忌三步**：① 落哪宫 → 哪件事上放不下；② 与哪颗星同宫 → 用什么方式放不下；③ 有无禄权科同宫 → 得而復失 / 争而不得。

### 8.5 其它常用星

禄存（守财、孤、忌被夹）｜天马（动、迁移、驿马）｜红鸾天喜（婚喜、添丁）｜天刑（纪律、刑、自律）｜天姚（风流、人缘）｜孤辰寡宿（孤、独）｜天哭天虚（情绪低）｜龙池凤阁（才艺、品味）。

## 9. 十二宫含义（一句话版）

| 宫 | 管什么 | 断的时候注意 |
|---|---|---|
| 命宫 | 我是谁、底色、体质倾向 | 一切的基准，先看它 |
| 兄弟 | 手足、同辈、合伙 | 也看"平辈竞争" |
| 夫妻 | 配偶形象、婚恋模式 | 看"关系里的自己"，不只配偶 |
| 子女 | 子女、创作、下属 | 也看"作品与产出" |

【主星】
  ×× ／ ××（附庙旺）

【星象】
  吉星：××、××
  煞星：××、××
  四化：×化禄、×化权、×化科、×化忌

【综合能量级】
  正能量（强／中强／中）｜负能量（中／中强／强）｜均衡
  比例：正 × : 负 ×
  （注明：本馆量化口径，仅同盘内横向比较）

【分析】
  1. 格局：×格（吉／凶／条件格）—— 成格依据 + 判意 + 破格条件
     （可列多个，吉格凶格分开写；每条都要讲"为什么成这个格"）
  2. 性格底色：以命宫主星取象起手，落到具体行为
  3. 人格类型：一句话定性（如"合作型·敏感力强""开创型·执行力强"）

  6. 正能量：3–5 条，每条都是"能用的劲"
  7. 负能量：3–5 条，每条都配"怎么化"
  8. 逐星细解：把煞星／关键辅星一颗颗讲透（形状 + 关键词 + 建议）

### 逐星细解的写法（照截图的手感）

> 例：擎羊星入命 —— 性情形凶刚毅、果断；又性格激烈、冲动，所以无论是亲情、事业、感情方面，须小心惹祸上身。**正面**：有奋斗不懈的精神，能产生积极的执行力。**建议**：遇事三思而行，不冲动浮躁，尽量结交人脉，可化解负能量。

**公式**：`星性（一句）` → `负面形状（具体）` → `正面用法（具体）` → `一句可执行建议`。

## 16. 分寸（图片分析尤其要守）

1. **不吓人。** 看到"负能量·强"必须同时给"这股劲的形状"和"往哪使"，否则就是拿恐惧换钱。

3. **不给长相打分。** 星曜入命的长相描述一律不用。

## 19. 附：命宫／身宫／天府安星口诀（手排核验兜底）

> 正常流程排盘一律走工具引擎（`36`）或派斗枢（`ziwei-qimen-master`），**本节只作「手排核验」时的兜底标准**，防止再踩命宫安星错。
> **2026-11-03 教训（R-034）**：主理人手排把命宫误作「寅」，实为「卯」，整盘作废、斗枢独立重排才纠回。错在把「从生月宫起子时逆数到生时」误算成「生月宫减生时地支序号」。

### 19.1 命宫与身宫（安星第一步，错了全盘废）

口诀：**「寅起正月，顺数生月；月起子时，逆数到生时为命宫，顺数到生时为身宫。」**

1. **定生月宫**：从寅起正月，顺数到生月。例：四月 → 寅(正)卯(二)辰(三)巳(四)，生月宫在**巳**。
2. **定命宫**：从生月宫起**子时**，逆数到生时。例：巳(子时)→辰(丑时)→卯(寅时)，命宫在**卯**。
3. **定身宫**：从生月宫起**子时**，顺数到生时。例：巳(子时)→午(丑时)→未(寅时)，身宫在**未**。

> **反例（本次错盘）**：生月宫巳、生时寅，命宫是**卯**不是寅。「生月宫地支序号 − 生时地支序号」是错误捷径，会把 5−2=3 再减一步得出寅，实为卯。命宫安星必须「起子时」逐位逆数，不许用序号相减。

### 19.2 天府定位（天府不是紫微对宫）

口诀：**天府与紫微关于「寅申线」对称**，不是隔六宫。

| 紫微落 | 寅 | 卯 | 辰 | 巳 | 午 | 未 | 申 | 酉 | 戌 | 亥 | 子 | 丑 |
|---|---|---|---|---|---|---|---|---|---|---|---|---|
| 天府落 | 寅 | 丑 | 子 | 亥 | 戌 | 酉 | 申 | 未 | 午 | 巳 | 辰 | 卯 |

> 紫微在未 → 天府在**酉**（不是丑）。误用「紫微对宫」会把整组天府星系（太阴、贪狼、巨门、天相、天梁、七杀、破军）全部错位。

### 19.3 读盘前四查（逐星复核，缺一不可）

1. **命宫、身宫、五行局**三者是否自洽（命宫纳音定五行局，再定起运）；
2. **紫微星系逆排间隔**：紫微→天机（隔一）→太阳（隔一）→武曲（紧邻）→天同（紧邻）→廉贞（隔二）；
3. **天府星系顺排间隔**：天府→太阴→贪狼→巨门→天相→天梁→七杀（紧邻），破军（隔二）；
4. **生年四化落宫**与十干四化表（`15` §4）一致。

四项有一处对不上，先回头查排盘，不要急着下断语。
