## 2. 可信度四问

判断一个"倪海厦项目"靠不靠谱，问四句就够：

1. **是排盘、是语料、还是转述？** 三者价值不同：排盘看口径，语料看出处，转述看人品。
2. **能不能回看到原话？** 不能回看的，一律降级为"整理者的话"，不是倪师的话。
3. **有没有勘误机制？** 敢公开勘误账本的，可信度立刻高一档；只删不改、错了悄悄改的，要警惕。
4. **有没有越界？** 给不给剂量、断不断生死、说不说"必好必坏"——越界的项目，专业度要打折。

## 3. 五条真伪结论

**结论一：六十四卦的"七言绝句断语"，全量语料里没有。**
天纪 `09-hexagrams` 2139 条，逐条是讲课口述（人间道、阳宅、卜筮、爻辞口述、卦象），**成文的四句七言一次都没出现**。
→ 说明那是**书面教材**的内容，不在课堂上。所以 `34` §6.3 的限制继续有效；市面上把"某卦四句断语"说成"倪师课堂原话"的，多半转手自书商整理本，**不能当口述引用**。

**结论二：值年卦的"断语"有，"排法"没有。**
`12-tieban` 册 96 条专论把六十四卦的流年断语几乎讲全了（如"25 岁逢水雷屯，事态不明、阻力大，秋逢贵人发文书"）。
但排法只留两句：「排法是死的」「我后面写在书里面给你们看」（@00:17:58、@00:24:45），**算式一句没讲**。
→ 所以：**能查"某卦在流年是什么样"，不能算"某年是哪一卦"。** 谁声称能算，要么他有那本书，要么他在编。

**结论三：讲义原表有笔误，口述可以纠。**
`10` §4.2 那条编者注悬了很久：原表写"山风蛊｜少男居西南"，与"上卦＝人、下卦＝位"的规则不符。
语料原文（`09-hexagrams` 山风蛊・阳宅 @00:26:28）说的是：

> 「山风蛊，少男居**长女**的位置……这个第三个儿子跑到**大女儿**的位置。」

**长女位＝东南。** 所以 `36` §3.12 按卦名规则登记的"三子居东南"是对的，**讲义原表的"西南"是笔误**。本条可销案。

**结论四：倪师有几处与古籍明文不合，语料库自己标了。**
该库公开的勘误里记了两类：① 主星南北斗归属——倪师把紫微一组称北斗、天府一组称南斗，与《紫微斗数全书》卷一、卷二不合者有六颗（天机、太阳、天同、太阴、破军、贪狼）；② 辛丑年女命"文昌化忌在田宅"系排盘笔误（文昌应在子宫）。
→ 本馆 `11` 号册涉星曜分野处，宜加一句"此系倪师讲法，与《全书》有出入，标注不改原文"。**不改结论，只加注。**

**结论五：`jangviktor` 的剂量体系是"整理"，不是"原话"。**
它把「古方一两＝临床一钱」固化为开方直换铁律，并附三套度量衡的边界。这套东西在执业语境里有价值，但：
① 它是**整理者的归纳**（虽引了源文件行号），不是倪师逐字原话；
② 它直接给克数、给加减、给疗程，**与本馆 `24`／`57` 的红线正面冲突**。
→ 本馆**只取六经六步与诊断公式的写法，不取药柜**（详见 `63` §6）。

**结论六：《地纪》没有完整版，世上不存在。**
`hoverfu/NiShiSanJi` 记明："倪师 2012 年辞世时《地纪》只写了序言和极少量开篇，共 8 篇存世文稿 PDF"，并专设 `地纪/README.md` 说明。三纪中**天纪、人纪已完成，地纪未完成**。
→ 本馆 `31-地纪-倪师实地勘验案例.md` 收的是**倪师现场勘验的判语与案例**，不是《地纪》这部书。对外若被问"《地纪》全书讲了什么""有没有完整版"，须如实说明，**不许把案例冒充《地纪》原文，不许接"完整版"的话**。此结论已同步到主理人、知微、青囊三个角色文件与 `68` §1.2。

**结论七：App 里那些术数功能，不是倪师天纪理论。**
`jangviktor-web/nihaixia-app`（Apache-2.0）在"同一知识库"之外，另捆了子午流注取穴、灵龟八法、小六壬、梅花易数、周公解梦、小儿关煞、每日黄历、玉匣记身体占等功能。这些**多数是通用术数 App 功能，不是倪师《天纪》／《人纪》课程理论**：
- 本馆 `30` 已定"不涉子午流注取穴"，`24` 不给穴位操作——**不采**；
- 其余按 `66` §1 标"外部参考"，**独立标记、不混入倪师体系**、不冒充倪师亲授；
- 若客户拿这类 App 的说法来问，按 `64` §2 四问判：是转述、不能回看、无勘误、无越界声明 → 降级为"整理者的话"。

> 结论六、七为**第二轮**（2026-11-02）新增；逐项目定位见 §1.6 与 `68` §9。

## 4. 交叉验证的三个实例

### 实例一：水风井＝次子居东南（三处互证）

| 来源 | 说的是什么 |
|---|---|
| `10` §4 规则 | 上卦＝人、下卦＝位；坎＝次子、巽＝东南 |
| `19` §1.2 办公速查表 | 内卦巽（座位东南）× 门朝坎（北）＝水风井 |
| 语料原文（阳宅 @00:08:48） | 「二子居长女位……成格水风井」 |

三条独立路径同指一处，**可作定论**。且原文补齐了断语：妻长、二婚、带丧服、颈部病、从商吉从官招陷（`62` §3.6）。

### 实例二：山风蛊的"西南"是笔误（规则 vs 原文）

规则推"三子居东南"，讲义写"西南"，口述说"长女位"。**三方之中两方一致，判讲义为笔误。** 这是"拿原话去校讲义"的正例——不是拿新说法去压倒旧结论，而是找到更靠上游的证据。

### 实例三：先天卦"唯官是贵" vs 阳宅"从官招陷"

同一卦，两处说法相反。核下来不是矛盾，是**两层两用**：卦说一生的贵气从名分来，宅说这一处位置招是非。
→ 这类"看似打架"的地方，绝大多数是**层没分清**，不是谁错。判真伪之前，先判层。

## 6. 许可与引用规程（照这个来，别踩线）

1. **两份语料是 CC BY-NC-SA 4.0，非商用。** 自用、学习、内部研究可以；**不得商用、不得二次分发**。
2. **本馆做法**：全量 jsonl 只放工作区 `.workbuddy/data/nihai/`，**不进插件包**；插件里只放索引、摘录与查询脚本。
3. **引原话必须带出处**：`book · h2 · h3 @时:分:秒`，能拼出 B 站链接。
4. **口语转写有错字**（"荓井卦""无失叉无得""招陷"），照抄可标〔sic〕，**不许改顺**——改顺就成了伪造。
5. **不许把整理者的话说成倪师的话。** 转述要写"某项目整理认为……"，并说明它不是原话。
6. **不许用倪师口吻。** 可以说"倪师讲这一条时提到"，不可以说"我（倪海厦）告诉你"。
