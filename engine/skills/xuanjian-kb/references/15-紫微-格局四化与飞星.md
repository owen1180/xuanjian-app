# 十五、紫微斗数：格局、四化与飞星（天纪为骨，诸家为辅）

> `11` 讲的是天纪原味的星性。这一份往下走一层：**怎么看一张盘的结构**，以及天纪之外还有哪些可用的技法。
>
> **立场**：以倪海厦《天纪》的三合派为骨——重格局、重星曜组合、重"取象"；飞星派只作补充，不作主线。两派结论冲突时，以三合派为主，飞星只作提示。

## 1. 天纪解盘的核心手法：取象

倪海厦解盘最大的特点不是背口诀，是**把星曜读成一幅画**。

原例（天纪讲巨门）：
- 巨门是"很大的门"
- 巨门落陷 → 大门一直关着 → 什么样的门一直关着？**监狱**
- 巨门庙旺 → 大门一直开着 → 什么样的门一直开着？**医院、法院**

这个手法要学：**先取象，再落到具体场景，最后才回到吉凶。** 不要一上来就"巨门主口舌"。

同类取象示范：
| 星 | 取象 | 落陷 | 庙旺 |
|---|---|---|---|
| 巨门 | 大门 | 监狱、封闭、暗昧 | 医院、法院、传播 |
| 天梁 | 荫、老树 | 荫不及、孤 | 庇护、医药、宗教 |
| 太阳 | 日光 | 日落、父缘薄、眼疾 | 普照、名望、公职 |
| 太阴 | 月光、母、田宅 | 月晦、母缘薄、积蓄难 | 田产、细腻、财库 |
| 七杀 | 刀、将 | 肃杀、伤、孤 | 独当一面、军警 |
| 贪狼 | 欲望、桃花 | 纵欲、耗 | 才艺、交际、多元 |

## 2. 看盘顺序

1. **定命宫与身宫**（身宫看后天着力点）
2. **看命宫主星与庙旺**：先定这个人的"底色"
3. **看三方四正**：命—财—迁—官，四宫合看，定一生的"舞台"
4. **看四化落宫**：禄权科忌落在哪一宫，就是这一生着力与卡点所在
5. **看大限**：每十年一宫，看该宫星曜与四化
6. **看流年**：流年宫 + 对宫
7. **取象落事**：把星曜组合读成具体场景

**大限看三方四正为主，流年只看本宫与对宫为辅。** 这与八字"大运为主流年为辅"是同一条原则。

## 3. 常见格局（三合派常用）

| 格局 | 结构 | 大意 |
|---|---|---|
| 紫府同宫 | 紫微天府同宫（寅申） | 稳、能守、格局大，宜掌权 |
| 君臣庆会 | 紫微 + 左辅右弼 + 天魁天钺 | 得众助，一生贵人多 |
| 府相朝垣 | 天府天相分守命身或三方 | 稳重有靠，宜辅佐亦能自立 |
| 日月同宫 | 太阳太阴同宫（丑未） | 阴阳兼具，父母缘与情绪起伏并存 |
| 日月夹命 | 日月在命宫两侧 | 得父母荫，早年顺 |

| 杀破狼 | 七杀破军贪狼三方会 | 变动大、能开创也易破耗 |
| 巨日同宫 | 巨门太阳同宫 | 口才与名声，宜传播、法律、医 |
| 石中隐玉 | 巨门在子午 | 早年埋没，中年后显 |
| 极向离明 | 紫微在午 | 格高，宜领袖位 |
| 英星入庙 | 破军在子午 | 开创力强，起伏亦大 |
| 马头带箭 | 擎羊在午 | 威猛、边地功名，亦主伤 |

用法：**格局只管"盘子大不大"，不管"具体发生什么"。** 格局高而四化差，是"有大舞台但演砸"；格局平而四化顺，是"小日子过得稳"。

### 3.5 格局的结构化判定法（借 `ziwei-doushu` 的 1100+ 格局组织方式）

`Renhuai123/ziwei-doushu` 把格局整理成"结构条件 + 评分"的写法，本馆引擎（`36` §2.1）移植为 **36 条三合派格局库**，每条带三类条件：

| 条件类型 | 含义 | 命中与否的影响 |
|---|---|---|
| `required` | 成格的硬条件（如"紫微天府必须同宫于寅申"） | 不满足即不算此格 |
| `bonus` | 加分条件（如"得左右魁钺来会"） | 命中则格局更稳、气象更足 |
| `breaking` | 破格条件（如"逢空劫冲破"） | 命中则格局打折甚至不成立 |

**读法升级**：看盘时不要只在表上点名"这是某某格"，要能说出"此格满足了哪些 required、吃到哪些 bonus、是否被 breaking 冲掉"。引擎已算好，成员**直接从工具取该格的三类标注**，不要手推。

**格局按结构归类**（便于记忆与检索，不限于上表 13 行）：
- **同宫格**：两星同宫（紫府同宫、日月同宫、巨日同宫、英星入庙）
- **夹格**：两星夹命宫（日月夹命、紫府夹权、魁钺夹贵、羊陀夹杀）
- **会照格**：三方四正会齐（机月同梁、府相朝垣、君臣庆会）
- **三方冲格（杀破狼）**：七杀破军贪狼分居三方
- **暗格／陷格**：巨门在子午（石中隐玉）、擎羊在午（马头带箭）、羊陀夹命
- **特殊格**：极向离明（紫微在午）、日月夹财

归类后用处：用户问"我是什么格局"，先定类，再定具体哪一格、满足哪几条条件。

### 四化的读法

- **化禄**：资源、入口、人缘。落哪宫，哪宫"有得拿"
- **化权**：掌控、扩张、刚性。落哪宫，哪宫"想说了算"
- **化科**：名声、文书、贵人。落哪宫，哪宫"体面"
- **化忌**：卡点、执着、耗损。落哪宫，哪宫"过不去"

**化忌不是灾，是执念所在。** 天纪讲"想不开"，讲得很准。断化忌要问："你在这件事上是不是总放不下？"

### 双化与叠化

- 大限四化叠本命四化 → 该十年重点极明确
- 流年四化再叠 → 该年应事
- **禄忌同宫**：得而又失，或"因得招损"
- **权忌同宫**：争而不得，或"硬扛到底"

### 4.5 四化的多维读法（借 `ziwei-doushu` 的 13 维组织）

四化不是"一张表查完就完"，`ziwei-doushu` 的写法启示是：**把四化沿"时间层 × 化性 × 宫位互动"三个轴拆开读**，本馆引擎已落地为"六层四化 + 宫干自化 + 多层合成"（`36` §2.1）。

**轴一：时间层（本馆六层）**

| 层 | 锚点 | 问的问题 |
|---|---|---|
| 本命四化 | 生年干 | 一生的着力与卡点 |
| 大限四化 | 大限宫干 | 这十年被哪一化挑动 |
| 流年四化 | 流年干 | 今年 |
| 流月／流日／流时四化 | 五虎遁／农历日干／五鼠遁 | 这个月／今天／此刻 |
| 宫干自化 | 本宫宫干 | 这宫自己向外散什么、收什么 |

> 流月以下四层锚在"当下这一刻"的农历，每次排盘随日期变，属正常（详见 `36` §2.1 口径二）。

**轴二：化性（禄权科忌 × 落宫）** —— 见 §4 四读。
**轴三：宫位互动** —— A 宫飞某化入 B 宫，A 对 B 的关系（给／欠／纠缠），即飞星派的三句话（见 §5）。

**结构化读法（出结论前自检）**：① 定是哪一层四化；② 定化性与落宫；③ 看有没有叠化（本命叠大限、大限叠流年）；④ 看有没有自化牵动；⑤ 单层只作倾向、多层同见才作强断。**层次数一目了然**——引擎"多层合成"已把同被引动的星并排列出，直接引用。

## 5. 飞星派（补充技法，不作主线）

飞星派以**宫干飞四化**看宫与宫的互动，核心是三句话：

1. **忌**看"亏欠与纠缠"：A 宫飞忌入 B 宫，A 对 B 有亏欠或执着
2. **禄**看"给予与来处"：A 宫飞禄入 B 宫，A 给 B 好处
3. **忌转忌**：一层层追下去，找到问题的根宫

用法限制（团队规定）：
- 只在三合派结论已定、需要"追根"时用飞星补一层
- **不用飞星推翻三合派的结论**
- 报告里若用了飞星，必须注明"此为飞星派看法，与三合派侧重不同"

## 6. 紫微与八字的接口

| 问题 | 用哪套 |
|---|---|
| 一生层次高低、富贵贫贱的程度 | 八字（打分法定力度更准） |
| 一生走什么路、什么性格、六亲关系 | 紫微（十二宫分工更细） |
| 某十年重点在哪 | 紫微大限 + 八字大运互校 |
| 某一年具体应什么事 | 八字流年 + 紫微流年宫互校 |

**紫微擅长"分领域"，八字擅长"定力度"。** 两盘指向同一结论时，可以说得确定；不一致时，各说各的侧重，不强行统一。

## 8. 亮度七档的功能义（读盘时的"有力无力"）

`11` §4 列出 庙、旺、得、利、平、闲、陷 七档，这里补"每档在断盘里到底意味着什么"：

| 档 | 功能义 | 断盘语气 |
|---|---|---|
| 庙 | 星性发挥最足，得其位 | "此星当家做主" |
| 旺 | 有力，略逊于庙 | "此星得力" |
| 得 | 有根气，可用 | "此星站得住" |
| 利 | 小吉，勉强够用 | "此星有帮助但不强" |
| 平 | 无功无过 | "此星中性" |
| 闲 | 无用，像没这颗星 | "此星基本不参与" |
| 陷 | 失位，凶星在此为大凶 | "此星在此反成拖累／隐患" |

**用法**：吉星陷＝该领域有短板；凶星（羊陀火铃空劫）陷＝反而没那么凶；杀星在陷＝大凶，须重点提示但不铁口。
