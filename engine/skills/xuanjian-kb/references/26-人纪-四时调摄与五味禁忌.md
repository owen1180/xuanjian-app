# 二十六、人纪·四时调摄与五味禁忌

> 出处：用户资料库《倪海厦人纪篇·黄帝内经（原文+白话+实录）》四气调神大论、五藏生成篇、宣明五气篇；《金匮要略》脏腑经络先后病篇。
>
> **这一份讲"做"**——不靠药、不靠针，只靠作息、饮食、情绪三件事。这是本馆能安全给出的全部健康建议。

## 1. 总纲：治未病

《金匮要略·脏腑经络先后病脉证第一》开篇：

> 问曰：上工治未病，何也？
> 师曰：夫治未病者，见肝之病，知肝传脾，当先实脾。

白话：**高明的医生不等人病，看到肝有问题，就先护住会被牵连的脾。** 五行相克，病会顺着克的方向传。

**这句话对本馆的意义**：我们能做的是"未病"那一半——**在还没成病的时候，把生活的方向调对**。已病那一半，交给医生。

## 2. 四时调摄（原文 + 落地）

### 2.1 春——发陈

> 春三月，此谓发陈……夜卧早起，广步于庭，被发缓形，以使志生，生而勿杀，予而勿夺，赏而勿罚。此春气之应，养生之道也。逆之则伤肝，夏为寒变，奉长者少。

| 项 | 古义 | 落地建议 |
|---|---|---|
| 睡 | 夜卧早起 | 相对冬天略晚睡、早起；不超过 23:30 上床 |
| 动 | 广步于庭、被发缓形 | 慢走、拉伸，**不做爆汗的剧烈运动** |
| 衣着 | 缓形 | 不穿绷紧的衣服，让身体松开 |
| 情绪 | 生而勿杀，予而勿夺 | 多做"给出去"的事，少做"夺回来"的事；春天不宜大动干戈 |
| 逆之 | 伤肝，夏为寒变 | 春天透支，夏天容易怕冷、易感 |

### 2.2 夏——蕃秀

> 夏三月，此谓蕃秀……夜卧早起，无厌于日，使志无怒，使华英成秀，使气得泄，若所爱在外。逆之则伤心，秋为痎疟。

| 项 | 古义 | 落地建议 |
|---|---|---|
| 睡 | 夜卧早起 | 仍可晚睡早起，但**午间小睡 20 分钟** |
| 日 | 无厌于日 | 不要整天躲空调；适当见太阳、出点汗 |
| 情绪 | 使志无怒 | 夏天最忌"憋火"，怒气在夏天最伤人 |
| 汗 | 使气得泄 | 该出汗就出，别用冰饮与冷气把汗逼回去 |
| 逆之 | 伤心，秋为痎疟 | 夏天贪凉，秋天易发寒热、咳 |

### 2.3 秋——容平

> 秋三月，此谓容平……早卧早起，与鸡俱兴，使志安宁，以缓秋刑。收敛神气，使秋气平，无外其志，使肺气清。逆之则伤肺，冬为飧泄。

| 项 | 古义 | 落地建议 |
|---|---|---|
| 睡 | 早卧早起 | 开始提前睡，**22:30 前**为宜 |
| 情绪 | 使志安宁、无外其志 | 秋天宜收心，不宜大规模扩张、不宜大喜大悲 |
| 活动 | 收敛神气 | 减少通宵与外放型娱乐 |
| 逆之 | 伤肺，冬为飧泄 | 秋天耗散，冬天易腹泻、吸收差 |

### 2.4 冬——闭藏

> 冬三月，此谓闭藏……早卧晚起，必待日光，使志若伏若匿……去寒就温，无泄皮肤，使气亟夺。逆之则伤肾，春为痿厥。

| 项 | 古义 | 落地建议 |
|---|---|---|
| 睡 | 早卧晚起，必待日光 | **早睡、等天亮再起**，冬天可以多睡一小时 |
| 动 | 无泄皮肤 | 不做大汗淋漓的运动；以微汗为度 |
| 保暖 | 去寒就温 | 尤其护腰、护脚、护颈 |
| 情绪 | 若伏若匿 | 冬天宜藏，不宜张扬、不宜大动干戈 |
| 逆之 | 伤肾，春为痿厥 | 冬天耗损，春天易乏力、四肢冷 |

### 2.5 四季通用三条

1. **顺时**——睡起时间跟着日照走，是这套体系里最省力的一条。
2. **不过**——运动到微汗、吃到七分、工作到能收住。**"过"就是病的起点。**
3. **有节**——饭点、睡点、动点固定。**节律比强度重要。**

> 倪师原话（实录）："破坏的力量永远大于建设的力量。" 养生的重点不是加什么，是**先别破坏**。

## 3. 五味：所合与所伤

原文（《素问·五藏生成篇》）：

> 故心欲苦，肺欲辛，肝欲酸，脾欲甘，肾欲咸。此五味之所合也。

原文（《素问·阴阳应象大论》，五味过则伤）：

| 过食 | 伤 | 制约 |
|---|---|---|
| 酸 | 伤筋（肝） | 辛胜酸 |
| 苦 | 伤气（心） | 咸胜苦 |
| 甘 | 伤肉（脾） | 酸胜甘 |
| 辛 | 伤皮毛（肺） | 苦胜辛 |
| 咸 | 伤血（肾） | 甘胜咸 |

### 3.1 倪师实录里最实用的一条

> 讲"甘伤肉"时他说：甜的吃太多，**骨痛而发落**。并说"破坏的力量大于建设"——一边帮他生发，一边还在吃甜，就无解。

**落地话术**：
> 〔话术示例〕"你掉头发、腰膝酸，先别急着补。**把甜的停一停**，比补什么都有用。这不是我说的，是《内经》里'甘伤肉'四个字。"

### 3.2 五味建议的边界（重要）

- **只说方向**：少甜、少咸、少冰、少油；不列具体食谱、不给"吃什么补什么"的方子。
- **不说"吃××能治××"**。食物不是药。
- **不推荐保健品、中成药、代茶饮**。
- 有慢性病（糖尿病、高血压、肾病）的用户，**任何饮食建议都要加一句"以你的主治医生和营养师的意见为准"**。

## 4. 调摄处方模板（只开习惯，不开药）

给客户的"处方"固定四行，每行都要能当天执行：

```
【调摄建议】（生活方式，非医疗处方）

一、睡
   目标：××:×× 前入睡，××:×× 起
   依据：你属××偏旺／偏弱，当前季节宜"××（夜卧早起／早卧晚起）"

二、食
   减：××（甜／咸／冰／夜宵，选一到两项，不要全禁）
   加：××（温热／规律三餐／早餐吃实）
   一句提醒：有慢性病请以主治医生意见为准

三、动
   ××（快走／拉伸／力量，每周 × 次，每次 × 分钟，微汗为度）

四、情绪
   按五志相胜：你现在偏××（怒／思／忧／恐），
   用××去化（悲胜怒／怒胜思／喜胜忧／思胜恐），具体动作：……

以上为传统术数文化分析，不构成任何医疗建议。
```

**四条硬规矩**：一次只改一到两项（改多了必然做不到）；不给具体药名与剂量；不承诺疗程；不替代就医。

## 5. 与阳宅的接口

调摄讲"时间"，阳宅讲"空间"，两者可以合成一套"环境处方"：

| 调摄需求 | 阳宅可配合的动作 |
|---|---|
| 入睡难（心火偏旺） | 卧室避正南强光、床头不靠窗、夜间遮光 |
| 晨起困难（阳气不足） | 卧室宜朝东／东南，早晨能见光 |
| 湿气重（脾偏弱） | 卧室避低层潮湿、加强通风与除湿 |
| 情绪郁（肝偏郁） | 居住空间留出"可活动"的空地，不做满柜满墙 |
| 长期疲惫（肾偏弱） | 卧室宜静、宜暗、远离电梯与主干道 |

**注意**：阳宅建议只到"改位置、改遮挡、改动线"，**不推销摆件、不承诺疗效**。

## 6. 分寸

1. **不诊断、不开方、不给穴位**——与 `24` 同一条红线。
2. **不承诺"调了就好"**。只讲"通常两到四周会感到变化，若无改善请就医"。
3. **不因客户焦虑而加码**。客户越急，越要给少而明确的两条，而不是列十条。
4. **儿童、孕妇、老人、慢病患者**：只给最保守的通用建议（规律作息、清淡饮食、适度活动），其余一律建议问医生。
5. **不做"节气养生营销"**。节气可以讲，不借节气卖东西。

## 7. 六健康标准（自测用，借 `jangviktor-web/nihaixia` 的归纳）

倪师讲"健康有六个标准"，是**日常自测**用的，不是诊断标准。本馆把它放进调摄，作为"什么时候可以放心、什么时候该去查"的尺子：

| # | 标准（整理层·精确版） | 对外说法 |
|---|---|---|
| 1 | 一觉到天亮，无失眠 | "睡得沉、醒得爽，是底气足" |
| 2 | 胃口正常，三餐有饱饿感 | "吃饭香、知饥饱，是脾胃在转" |
| 3 | 每天晨起大便 | "每天定时排便，是身体在清" |
| 4 | 一天小便 5–7 次，淡清黄色 | "小便清利、次数匀，是水道通" |
| 5 | 头面冷、手足温热（四季皆然） | "头面凉、手脚暖，是阳气到末梢" |
| 6 | 晨起阳反应 | **只作自测，不对客户展开、不作评判** |

**用法**：
- 六条都达标 → 只做维持性调摄，不渲染、不吓人。
- 某几条长期不达标（尤其睡眠、大便、手足温）→ 这是"该去查"的明确信号，落到 `25` §7 的"身体提醒"，并提示就医。
- **这六条是"状态尺"，不是"病名"**。措辞只用"偏弱／不达标／宜留意"，不说"你×××虚"。

> 注意：六健康标准是**归纳性结论**（证据层＝"整理"，见 `66` §1），引用时标"倪师归纳／整理认为"，不与某条视频原话混同。它用来"指方向"，不用来"下诊断"。
>
