# 四十七、十神心性与取用路线

> 本册管两件事：同一个十神，为用和为忌是两种人；十神撞在一起，是内耗还是成器。
> 体例来源：第二十六课「十神组合特征」、第九课「用神形象论」、第三十二课「大运与流年的关系」中的男女差异。

## 1. 一个十神两副面孔

十神是十种能量，每种都有正面与负面。**为用，显正面；为忌，显负面。** 断性格只讲"这条能量在他身上往哪边走"，不讲"他是好人坏人"。

| 十神 | 为用的样子 | 为忌的样子 |
|---|---|---|
| 正印 | 有靠山、体面、稳 | 拖延、逃避、纠结、怕不体面 |
| 偏印 | 独处、专精、想得深 | 孤、疑、钻牛角尖 |
| 正财 | 务实、守成、算得清 | 抠、短视、被钱牵着走 |
| 偏财 | 大方、活络、会来事 | 怕付出、贪享受、想偷懒 |
| 食神 | 温和、有品位、会享受 | 幻想、逃避沉闷、不愿紧张 |
| 伤官 | 才华、表达、敢破 | 狂傲、偏激、不守规矩 |
| 正官 | 自律、担当、有分寸 | 怕事、拘谨、被压 |
| 七杀 | 果断、能扛、有杀气 | 见怂就上火、招小人、惹是非 |
| 比肩 | 独立、有主心骨 | 固执、争、不合群 |
| 劫财 | 讲义气、敢拼 | 破财、被人拖累 |

### 三种"懒"不是一回事

这一条最能显功夫，客户一听就知道你懂不懂：

- **正印为忌的懒**：拖延、逃避、小事上纠结。根子是**怕不体面**——怕做得不好看，索性不做。
- **偏财为忌的懒**：怕付出、不想勤快，但又放不下享受。根子是**想占便宜又不想付代价**。
- **食神为忌的懒**：喜欢幻想、喜欢舒服，逃避沉闷。根子是**不愿进入紧张状态**。

### 印为忌与财为忌，苦法完全不同

| | 印为忌 | 财为忌 |
|---|---|---|
| 表现 | 衣食不缺，心里憋 | 手头紧、破财 |
| 本质 | 保障过头，没有出口 | 资源不足，被现实追着跑 |
| 话怎么说 | "你不缺吃穿，缺的是能让你使劲的地方" | "钱上容易漏，先把口子堵住" |

课程原话最传神：印为忌的人往往要看心理医生、觉得虚度光阴——**不是穷，是闷**。

**印为忌的对话识别（2026-11-03 补自第二十四课）**：印忌之人对负面事实会**答非所问、把现实美化成自己理想中的样子、下意识逃避**——问「父母关系是不是不好」，他答「我妈通情达理」；问「腿上有伤」，他答「胳膊有」。**断事三法**：①迂回——不正面问，换角度问同一件事；②三次追问——含糊确认后必有具体例子，问到具体为止；③笃定——别被对方节奏带跑，否则会自我怀疑。问到第三遍仍答非所问，**最好就此打住，不继续预测**（这种盘对话效率极低，且容易带偏判断）。

## 2. 印为用的人长什么样

- 最需要的是**自己的生存环境**：家、父母、房子、舒适圈。
- 不愿得罪人，宁可委曲求全，也要人和人之间和气。
- 会跟身边每个人处得不错，但**协调不了身边人之间的矛盾**——老婆和妈妈不和，他躲。
- 依赖心重，人际上偏被动。所谓"妈宝"，多是这一型。

对外讲法：不说"你没主见"，说"你擅长跟人相处，但不擅长处理别人之间的冲突，这类事要交给更合适的人"。

## 3. 十神撞车：轻重有别

| 组合 | 性质 | 轻重 |
|---|---|---|
| 伤官见官 | 是非、矛盾、丢官失位 | 重 |
| 伤官见七杀 | 两个极端力量对撞 | **最烈** |
| 食神制杀 | 可制，成器 | 吉，但有条件 |
| 食神见正官 | 有是非，比伤官见官轻 | 轻 |

**食神制杀有条件**：食神要比七杀稍强，或两者相当。食神远弱于七杀，就成"七杀逆克"，反主生病、官司。这一条最容易被套用错——看见食神和七杀就断"制杀成贵"，是硬套。

**能不能制，还要看原局有没有这个结构。** 原局本无食神制杀，只是流年凑出一个食神，那不叫制杀，只叫是非。

## 4. 取用路线不能并用

- 取官为用，就不要用食伤；取食伤为用，就不要用官。
- 两路并用，用神互克，等于请两个有仇的人一起办事，事必耽误。
- 原局用神只有一个方向；能找到"最有力的那一个"，就不要贪多。

**虚透与实透**：天干有字而地支无根，叫虚透，力量不足，是"空头承诺"；有本气根，叫实透，才有实质吉凶。用神虚透的盘，只能断到温饱安稳，断不了大发。

## 5. 太旺的盘，印到底算不算忌

- 原局有食伤 → 印破坏顺势，**为忌**。
- 原局无食伤 → 印不显凶，**不算忌神**。
- 原局比劫太旺，有印也算顺势，**不吉不凶**。
- 原局有官克比劫，印还可作**用神**，反显吉。

一句话：太旺的盘先看顺不顺势，别一见印就喊"忌印"。

## 6. 男女不同路

课程讲得很直白，现代社会仍然成立：

- **男命食伤旺**：会宠妻子，想法多，会变着法让人开心。食伤生财，食伤不影响感情。
- **女命食伤旺**：下意识想驾驭对方，希望对方听话；关系再好，心里也常吐槽。若要关系稳，靠的是修养克制，不是命。
- **女命用官**：事业感情可两全；但官要清纯一位，混杂则乱。今日社会不必照古法强套。
- **男命用神到位**：往往事业起来之后，婚姻感情才跟着建立。

对外讲法：只讲"你这一型在关系里习惯怎么做"，不讲"你该找什么样的人"，更不替人决定去留。

## 7. 用神到位是什么感觉

课程借四个虚构人物把这层说透了：

- 用神到位，说的是**能力、眼界、人脉、成就**在提升；
- 不等于舒服。进入用神运常常"扒皮拆骨"，忙到生病也是常事；
- 也不等于感情和睦。事业极好而婚姻不顺的人，一抓一把。

所以断"这步运好"，必须紧跟一句"好在哪、要付什么代价"。只说好，是骗人；只说苦，是吓人。

## 8. 落到嘴边

- 不说"你伤官旺，克夫"，说"你这一型在关系里容易想主导，对方若是同样强势，摩擦就多"。
- 不说"你印重，没出息"，说"你靠山不缺，缺的是把自己推出去的那一步"。
- 不说"你七杀多，犯小人"，说"你见不得窝囊事，容易当场顶上去，是非多半从这儿来"。
- 不说"你食神制杀，必贵"，说"你这一局有以技制压的结构，但要看食神够不够力，不够就只是辛苦"。
