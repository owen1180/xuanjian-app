# 二十、风水·罗盘使用与现场作业流程

> 这一份是**作业手册**，不是理论。所有断法都建立在"方向测对了"这个前提上。**方向错一度，全套推断作废。**

## 1. 罗盘三盘：各管一件事

罗盘上有三圈 24 坐山，叫**三盘**。初学者最容易在这里搞混。

| 盘 | 别名 | 用途 | 记忆 |
|---|---|---|---|
| **地盘** | 正针 | **格龙**（测来龙、定坐向） | 最正统，一切以它为准 |
| **人盘** | 中针 | **消砂**（判四周山峰吉凶） | 比地盘慢半格 |
| **天盘** | 缝针 | **测水**（看来水去水） | 最早出现，比地盘快半格 |

来源逻辑（倪海厦的讲法）：**先有天，后有地，再有人**。所以天盘最早，地盘比天盘慢半格，人盘比地盘再慢半格。

> 三盘各差半格（7.5°），**不能混用**。测龙用地盘，测砂用人盘，测水用天盘。用错盘，吉凶全反。

### 2.1 二十四山五行（拨砂用，见 `17` §4.5）

> 子午卯酉太阳火，甲庚丙壬太阴火，
> 乾坤艮巽本属木，乙辛丁癸便属土，
> 辰戌丑未即是金，寅申巳亥皆属水。

### 2.2 阴阳龙

24 山中**12 个标红为阳龙，12 个为阴龙**。**阴龙立阴向，阳龙立阳向**（见 `17` §6.1）。

> 各版本罗盘的红黑标注略有差异，**以手上这只罗盘的标注为准，不背口诀**。这也是为什么必须用实体罗盘，不能用手机软件。

## 3. 罗盘圈层速认（由内到外）

| 圈 | 内容 | 干什么 |
|---|---|---|
| 天池 | 指南针（磁针） | 定南北，一切之基 |
| 内圈 | 先天／后天八卦 | 定位八卦宫 |
| 主圈 | **24 山（地盘正针）** | 定坐向、格龙 |
| 第三圈 | **黄泉煞**（八煞黄泉） | 立向禁忌，直接查 |
| 中圈 | **人盘中针 24 山** | 消砂 |
| 外圈 | **天盘缝针 24 山** | 测水 |
| 倒数第三 | **穿山七十二龙**（红底金圈＝吉） | 优中选优，见 `17` §6.4 |
| 倒数第二 | **天罡二十八宿** | 配坐山论五行（如坐乾山＝奎木狼） |
| 最外 | **透地六十龙**（正／七三／三七） | 定棺位（阴宅） |
| 最外缘 | 360° 刻度 | 精确读数 |

**「太」与「少」**：罗盘一度分 100 分。接近 100 分叫**太**（如"奎十八度太"），接近 50 分叫**少**。这是精度标注，判吉凶时用不到，但读盘要认得。

## 4. 测向的方法

### 4.1 定坐向

- **坐**＝背后所靠之方；**向**＝正面所朝之方。坐与向相差 180°。
- 传统说法：**"丁山癸向"＝坐丁（南偏西）、朝癸（北偏东）**。**"山"是坐山，也就是来龙方向。**
- 公寓／写字楼：以**主要采光面**或**大门所对方向**为向，**必须与户主确认**（很多人会把南北看反——倪海厦专门点过这个错：客户紧张之下把罗盘看反，结果买到东边是厨房的房子）。

### 4.2 罗盘怎么拿（含倪师原话的一处细节）

> 天纪实录：「罗经拿起来，实际上应该怎么看呢？实际上**罗经是透明的，把罗经放上去，由下往上看**……你不能从上面看，刚好就反的。」

道理：罗经对应的是天上 28 宿的布列，是**从地往天看**，所以要"由下往上看"（把罗盘举到眼前、透过去看对面），而不是俯视盘面。**这一条与"平置测向"不矛盾**：平置定南北，抬头看方位。


1. 罗盘**平置**于腰高，**远离**手机、钥匙、钢筋柱、配电箱、汽车（磁干扰会让指针偏 5–15°）。
2. 转动盘面，使**天池指针与底盘红线重合**（或使磁针与天池底线平行）。
3. 读**地盘正针**上"向"所在的字，即为向；对面 180° 为坐。
4. **同一位置测三次**，读数一致才算数。

### 4.3 阳宅的三个测量点

| 测什么 | 在哪测 | 用哪盘 |
|---|---|---|
| **房屋坐向** | 大门内一步，面向门外 | 地盘 |
| **纳气方向** | 立极点（卧室取床位、书桌取座位） | 地盘 |
| **周边砂（高楼、山、塔）** | 立极点或窗口 | 人盘 |

> 立极点的定义见 `09-风水-三元纳气.md` §2：**是人实际待的位置，不是房子几何中心。**

### 4.4 阴宅测量点

| 测什么 | 在哪测 | 用哪盘 |
|---|---|---|
| **来龙** | 过峡处（无峡则在入首后方与来龙连线处） | 地盘 |
| **立向** | 穴前（或碑前） | 地盘 |
| **砂** | 穴上 | 人盘 |
| **水** | 穴上或水口 | 天盘 |
| **透地龙** | 碑前（碑与棺成 90°，可直接反推棺位） | 透地六十龙 |

## 5. 现场作业 作业流程

### 第一步：预约与信息预采（不到现场就能做的）

发给客户一张表，**填不全就不出结论**：

```
【阳宅】
1. 详细地址、楼层／总层数
2. 建筑面积、户型图（标注门、窗、厨、卫、床、桌）
3. 房屋朝向（客户自测，注明用什么测的）
4. 家庭成员：出生年份、性别、排行、各住哪间
5. 入住时间（年月）
6. 最想解决的问题（一句话）
7. 周边环境照片：楼前、楼后、左右、窗外各一张

【阴宅】
1. 墓园名称、区位（第几排第几号）
2. 坐向（碑向）
3. 安葬时间（年月）
4. 墓主与申请人的关系
5. 现场照片：正面、左、右、后、前方远景
6. 要解决的问题（家族运势／健康／求子／事业）
```

### 第二步：外局（到场先绕一圈，30 分钟）

- 站在楼／墓前，**先不看罗盘**，用眼睛看：明堂开不开、左右高不高、后面有没有靠、前面有没有冲。
- 再拿罗盘测向，**用眼睛的结论去验证罗盘的读数**。两者矛盾，先怀疑罗盘（磁干扰）。

### 第三步：内局（逐间走）

- 每间房：测床位／桌位的立极点，记录可达气口方位。
- 拍照：每间房从门口往里拍一张，从窗口往外拍一张。
- **画草图**：手画平面图，标 24 山方位线、门、窗、厨、卫、床、桌。

### 第四步：回办公室纸上作业

- **现场不下结论。** 倪海厦的规矩：测完回来，把整个局想清楚，**纸上作业**才定方案。
- 依次过：形家（`08`）→ 纳气（`09`）或名位（`10`／`18`）→ 交叉验证（`14`）。
- 阴宅另加：真假龙 → 结穴七条件 → 砂（人盘）→ 水（天盘）→ 立向（八煞、分金、72 龙）→ 土色。

### 第五步：出报告

报告结构（固定七段）：

```
一、基本信息与测量记录（含测量工具、时间、天气）
二、外局所见（形煞逐条，标距离与遮挡）
三、坐向与卦（含 64 卦或内外卦）
四、主线判断（走哪条线、为什么）
五、核心结论（3–5 条，每条标置信度：高／中／低）
六、调整方案（按"改人 > 改隔断 > 改动线 > 改强度 > 其它"排序，标周期与成本）
七、未解决项与需补充信息
```

## 6. 误差处理（专业与业余的分界）

| 问题 | 处理 |
|---|---|
| 磁干扰（钢筋、电器、车） | 换 2–3 个位置复测，取一致值；必要时离开建筑 10 米外测环境向 |
| 手机指南针 | **只作参考，不作依据**。必须说明"建议实体罗盘复测" |
| 坐向看反 | 让客户**站在门内面向门外**再测一次；两次差 180° 即知看反 |
| 分金线（骑线） | 24 山之间有分界线，骑线为**分金煞**，需微调 1–2°避开；住宅可忽略 0.5° 内误差，但要说明 |
| 三盘读数不一致 | 正常（差半格）。**用地盘定坐向**，人盘测砂、天盘测水 |
| 无法到场 | 只作**初步判断**，报告首行注明"未现场定盘，结论仅供参考" |

## 7. 工具清单

**必备**

- 实体罗盘（三盘齐全、有 72 龙与 28 宿圈层）
- 卷尺（激光测距更好）
- 指南针（备用交叉验证）
- 手机（拍照、录音、记方位）
- 方格纸与笔（手绘平面图）
- 户型图／墓园平面图打印件

**阴宅加配**

- 小铲（取土看色，**须征得管理方同意**）
- 手电（看穴形、看排水）
- 雨靴、防滑鞋、长袖（山地）
- 望远镜（看远朝山）

**不需要**

- 八卦镜、石敢当、貔貅、水晶、五帝钱、罗盘挂件
- **本体系不靠这些。带了也别用。**

## 8. 现场安全与伦理

1. **阴宅现场必须先取得墓园管理方与家属同意**，不擅自挖掘、不移动碑石、不拍照外传。
2. **不在墓地评论他人墓**（"那家墓不好"这类话，会引发纠纷）。
3. **不制造恐惧。** 现场说"这里犯了很凶的煞，你们家要出大事"是最恶劣的做法，也是本馆明令禁止的。
4. **不越界。** 房屋结构安全找结构工程师，地质灾害找专业机构，法律问题找律师。
5. **未成年人与重症患者不在场时更谨慎**：健康问题一律先建议就医。
6. **报告与照片属客户隐私**，不外传、不作案例宣传（除非客户书面同意并脱敏）。
