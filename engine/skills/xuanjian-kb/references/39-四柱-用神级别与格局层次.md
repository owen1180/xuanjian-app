# 三十九、用神级别与格局层次

> `02` 讲"取哪个用神"，这一篇讲"**这个用神值几分成色**"。
> 同样是"用火"，有的火能让人做到行业顶层，有的火只够温饱。差别就在功能性与力度。课程第 27、41 讲。

## 1. 用神的三项功能与权重

| 功能 | 作用 | 权重 |
|---|---|---|
| **扶抑** | 强抑弱补，平衡日元 | **6 分** |
| **调候** | 调寒暖燥湿 | **3 分** |
| **通关** | 两强相战，取中间物 | **1 分** |

一个用神同时具备几项，就能拿几分。**扶抑是地基（6 分），调候是加分（3 分），通关是锦上添花（1 分）**——因为一旦需要通关，说明原局已有两股力量打起来了，外力能补的其实有限。

## 2. 四等用神层次（断格局高低的直接标尺）

| 层次 | 特征 | 现实表现 |
|---|---|---|
| **最低** | 只有扶抑，但扶抑的同时又加重了原局的病；或只有调候、通关其中一项。找用神要么找不到，要么"治一个病添一个病" | 无原则无底线、缺上进动力；好运也能赚到钱，但留不住，走着走着就走回原路 |
| **中低** | 只有扶抑，或只有调候+通关，对扶抑帮助不大 | 明白事理、也肯努力，但常动摇、常放弃；好运小富小贵，差运收入偏低；"常立志者无常志" |
| **中等** | 扶抑+调候，或扶抑+通关，**且扶抑有力、贴身** | 务实、思路宽；差运生活一般但不至于很差，好运中等富贵、衣食无忧 |
| **高等** | 扶抑+通关+调候全涵盖，**且有力** | 能化解矛盾、平衡强弱、调好温度；大小兼顾、有大局观；多出大成就者 |

用法：先判层次，再决定断语的"封顶高度"。**层次不定就报"必发大财"，是越界。**

## 3. 两个维度：功能性 × 力度

- **功能性**：囊括几项功能（6／3／1）。
- **力度**：该用神在原局旺不旺、有没有根、贴不贴身。

**功能性强 + 力度大 = 格局高。** 反过来，用神名义上在场却虚浮无力，只能算"有这个心思，没这个本事"。

从局多富贵，是因为从局时用神往往极旺极纯；但**不是所有从局都富贵**——还要看用神有没有被伤、流通顺不顺。

## 4. 流通性：比"有什么十神"更重要

看格局不看"有几个财、几个官"，看的是：

1. 用神有没有力、贴不贴身
2. 忌神有没有被制
3. **忌神有没有被转化成用神**（忌神化用神，是最好的流通）
4. 用神有没有反被转成忌神（好的力量转着转着变成坏能量，最不理想）

## 5. 《千里命稿》口诀（课程第 41 讲注释版）

### 5.1 富

| 口诀 | 前提与注释 |
|---|---|
| 财星生官，官星卫财 | 仅限**身旺或从局**；偏弱、太旺、专旺不适用 |
| 忌印而财能坏印 | 必须是**强势**坏印，普通克不算；忌神被制死，人显现实甚至偏冷 |
| 喜印而财能生官，官能生印 | 身弱用印而财不坏事，走成"财→官→印→身"的流通，少见但极佳 |
| 食伤重，而财神流通 | 食伤重则诉求转向求财，有财可流通才富；食伤旺而无财，不体现富 |
| 财神重而食伤有限 | **须身旺**；食伤过旺反而生财太过，反生为克 |
| 身旺财旺，有食伤，或有官杀 | 两条路线：食伤生财，或财生官 |
| 身旺官衰，印绶重，而财星当令 | 财须有力，能在月令或分量足 |
| 身旺劫旺，无财印，而有食伤 | 偏旺、太旺可用，**专旺不行** |
| 身弱财重，无官印，而有比劫 | 比劫破财帮身 |

### 5.2 贵

忌比劫而官能去比劫／喜比劫而官能生印、印能生身／财旺而官星通达（须身旺或从局）／官旺而财有节／身旺官弱有财生官／官旺身弱官能生印／印旺官衰财能坏印／劫重财轻官能去劫／财星坏印官能生印／用正官而无偏官混杂（清纯为贵）／用偏官而无正官混杂（偏官主实权）／偏官旺过于身而有食神制住（须身旺，身弱食神反噬）。

### 5.3 吉（非富贵，但少风波）

身旺用财而有食神生财、官杀卫财／身旺用官而有财生官／身旺有食伤而有财流通／身弱用印而有官杀助印／身弱用比劫：官重有印泄官生身，财重有官泄财生印／身弱用印，有官生印或比劫卫印。

### 5.4 寿

五行停匀（金木水火土都有，力量分散，多长寿但难成大业）／四柱无冲无克／冲去者皆忌神／留存者皆相神／日主旺而得气（沐浴、冠带、临官）／身旺官弱而逢财、身旺财轻而遇食／身旺而食伤吐秀／身弱而印绶当权。**行运皆与用神喜神不悖。**

> 注意：此处"寿"讲的是**抗打击能力与身体恢复条件**，不作寿数推断。

### 5.5 贫

身轻财重／财轻官重／伤重印轻身弱／财重劫轻身弱／财轻喜食伤而印旺／财轻劫重食伤不现／喜印而财星坏印／喜财而财神被合（财被忌神合住＝被夺）。

**身弱财旺者贫穷，多半不是赚得少，而是破得多**：诱惑多，容易做自己驾驭不了的事。

### 5.6 贱（第四十二课·韦千里原话）

上流社会的人未必无贱，底层的人未必都贱；伪君子、假小人是「最不容易辨别的」。

| 口诀 | 前提与注释 |
|---|---|
| 官轻印重而身旺 | 印化官生身为忌，贵气被泄走，反复无常、内心压抑、心态易扭曲、过于纠结；纠结让人把机会从身边放走 |
| 官重印轻而身弱 | 印化不掉官，官越旺越使小聪明、易被欺负、得势后欺负别人；「官旺身弱有印而印无力，没有慈悲在心里」 |
| 官轻劫重无财（身旺） | 用神被逆克、无财；鲁莽、嫉妒心重、贪婪、恩将仇报；违法是表象，内在是不自律 |
| 官旺喜印，财星坏印（身弱） | 需印化官生身而财破印，市侩、势利、无慈悲，控制不住心魔就干损人不利己的事 |

### 5.7 凶（第四十二课）

凶者逆也，多险恶风波。

| 口诀 | 前提 |
|---|---|
| 财旺身弱无劫印（偏弱） | 一生为财困苦，易作奸犯科，发凶快 |
| 杀重身轻，无食伤印绶（偏弱） | 七杀攻身无制无化，易受伤、遇横祸 |
| 用官多伤而无财 | 伤官克官又无财通关，易惹是非 |
| 官多身弱无印（偏弱） | 易被欺负；有印来化则有贵人，无印全是是非麻烦 |
| 满局比劫而无官杀（太旺） | 太旺格局遇官杀财运易犯众怒，波折比一般人大 |
| 用食而多枭 | 偏印夺食，压抑、多败少成、注意力难集中 |
| 喜官而杀混 | 一仆二主，无法跟一个靠山，仕途坎坷（不算大凶） |

### 5.8 夭（第四十二课）

> 分寸：此节原话谈「夭折」，**只取「抗打击能力弱、体质偏枯、心气易散」这层，不作寿数推断**（同 `46` 红线）。

| 口诀 | 前提 |
|---|---|
| 印绶太旺，日主无着落 | 太旺印旺、从印之格，反生为克，印多而无着落 |
| 财杀太旺，日主无依倚（偏弱） | 非从局；财杀太旺无依靠，易消极、厌世、抑郁 |
| 忌神与用神杂而战 | 用神制不住忌神、忌神略胜一筹，命途坎坷 |
| 日主失令，用神浅薄而忌神深重（偏弱） | 身弱用神弱忌神旺，最怕再遇忌神运，易失斗志、浑浑噩噩 |
| 行运与用神喜神无情，反与忌神结党 | 大运泄耗用神、生助忌神 |
| 身旺而克泄全无（太旺） | 偏枯，遇官杀财运坎坷不顺 |
| 金寒水冷而土湿 | 金日元无火、有水有湿土，身体问题、血瘀气滞 |
| 火炎土燥而木枯 | 肝气不足、肾阴心阴虚 |

## 6. 两气成象与三合成局

- **两气成象**：只有两种五行，且两股力量都成气候。此时食伤可为第一用神（顺势）。三种以上不算。
- 身强食伤强但**未到两气成象**：第一用神仍是财。此时若再走食伤运，人易懒散、理想主义、才华变现不了。
- **三合成局的条件**：三个字必须挨着，且**月令不能逆中神的五行**。中神被大运合走（如寅午戌遇未土运，午被未合），三合即不成立。

## 7. 晚年走"好运"的特殊性

同样是用神运，落在晚年和落在壮年，效果相反。

- 好的大运在早年，人还没有能力运作事业。
- **晚年（七十以后）走用神财运**：欲望被点起来，身体机能却在退化。男人尤其明显——精力旺盛、好奇心强、欲望充沛，格局好的硬撑事业，格局不好的耗损身体。也常见社交活动骤增、婚姻变动。
- **晚年走忌神印运**：偏孤僻、不爱社交、精神寂寞、琐事缠身；若原局食伤为用而被印克（枭神夺食），则劳碌不安。

**断晚年运不能只看喜忌，必须叠加年龄与体力。** 这是最容易被忽略的一条。

## 8. 十神皆可为用，也皆可为忌

不要把七杀、伤官、劫财、偏财一律当"凶神"。用正官正印正财的人，一样坎坷——即便原局没有凶神，大运也有。

**看结果，不看标签。** 用七杀者也许波折多，但结果照样可以富贵；用正官者顺当些，一样躲不过坎。

## 9. 常见误用

- ❌ 找到扶抑用神就以为完事。扶抑只占 6 分，还有 4 分在调候与通关。
- ❌ 把调候当万能。冬生一律用火是错的，要看扶抑是否也需要火。
- ❌ 断格局只数十神个数，不看流通。
- ❌ 拿晚年财运当吉断，不看体力。
- ❌ 用"吉神凶神"标签定好坏。

## 10. 用神重心与关键字（第三十一课）

分析八字要抓住用神重心去围绕。两条落点：

- **关键字＝用神**：偏弱八字看生扶之字（如甲寅甲戌甲申庚午，关键字在寅，寅受申酉流年冲即不顺——当事人壬申年车祸）。**用神重心一旦被冲击，麻烦波折就会出现。**
- **用神不好找就看忌神**：普通命局、格局低者，最旺的往往是忌神，在忌神大运里找忌神流年，忌神流年叠加必然不顺或有灾。

**岁运力量的重现折扣（第三十一课重点窍门）：**

| 情形 | 力量 |
|---|---|
| 原局有此用神/忌神，岁运再遇同字 | **百分之百**加入原局（吉凶都明显） |
| 原局无此用神/忌神，岁运出现 | **只折半**加入原局 |

例：原局有午火（为忌），大运再遇午火，力量百分之百加入、午子冲剧烈；若原局无午火，大运才出现午火，只有一半力量作忌。**这一条决定断大运吉凶时话能说多重。**

## 11. 命好不如运好（第三十三课）

- **格局好＋大运差＝层次降低**。格局差＋大运好＝「自己没多少钱，但会认识有钱人，生活质量不差」。
- **连续多年好运（哪怕格局一般）＝固定资产积累**（房产、祖辈资产），维持不错的生活质量。连续四十年好运，普通人也能通过积累活得体面。
- 对多数人，「运比命格还重要」——一般人求的是丰衣足食、安稳日子。
- **晚年与早年的用神运效果相反**（同 §7）：早年走好运，人还没能力运作事业。

### 11.1 反生为克：木多火塞（第三十三课）

- **身弱印旺，第一用神取比劫，不取印**（同 `01` §5）。印过旺而根气不足，就成「木多火塞／木多火熄」——印化官生身看着合理，实则火被塞住，化成反生为克。
- 木多火塞的人「想堕落又不愿失去体面，想努力又找不到方法」，内心拧巴、窒息式纠结。
- 第一用神不现（天干地支都没有明确的第一用神），格局一般。
