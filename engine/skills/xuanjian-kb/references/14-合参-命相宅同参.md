# 十四、命、相、宅三盘合参

> 这是主理人专职的方法。三盘各自成立都不稀奇，**三盘指向同一处才叫准**。

## 1. 为什么能合参

三家资料里都有一句几乎一样的话：

- 四柱：象不独论
- 手相：不能只独看一点
- 面相：相不独论
- 天纪：命相宅同参

四柱课 2022 年答疑的分类里，"命理提问 / 手面相问题 / 家居问题"就是并列归档的——**讲课的人自己就在做跨域对照**。

## 2. 三盘各管什么（分工不能说错）

| 盘 | 管 | 输入 | 强项 | 弱项 |
|---|---|---|---|---|
| 八字 | 格局、阶段、力度 | 生辰（年月日时＋地点） | 知道"什么时候、有多强" | 不知道"长什么样、住哪里" |
| 手面相 | 状态、性格、当下 | 照片 | 知道"现在这个人怎么样" | 不知道"为什么、能持续多久" |
| 阳宅 | 环境、加成与削弱 | 户型图、坐向、家庭成员 | 知道"环境在放大还是压制" | 不知道"这个人本来的底子" |

**口诀：八字定骨架，相法定血肉，阳宅定风向。**

## 3. 合参的四步法

### 第一步：各自独立出结论（不许串）

先让三位分析师**各看各的，互不通气**。这一步最容易犯的错是"听了一句八字就说这个手相也对得上"——那是自我印证，不是合参。

输出要求：每人给 3–5 条核心判断 + 置信度（高／中／低）。

### 第二步：找共振点

把三份结论摊开，找**指向同一件事**的条目。

| 共振强度 | 判定 | 用法 |
|---|---|---|
| 三盘同指 | 极强 | 可以直接说，语气可以确定 |
| 两盘同指 | 强 | 可以说，留一分余地 |
| 单盘独指 | 弱 | 只能作提示，不作为主结论 |

### 第三步：处理冲突

冲突是常态，处理规则：

| 冲突类型 | 处理 |
|---|---|
| 八字说财旺、手相说掌薄漏财 | 八字管"有没有"，相法管"守不守"。合起来说：能赚但存不住 |
| 八字说婚动、面相夫妻宫凹陷 | 八字管"时机"，相法管"质量"。合起来说：这段时间有缘分，但成色一般，宜缓 |
| 八字说身弱、阳宅纳旺气 | 命弱宅旺，是好事——宅补命。说清"环境在帮你" |
| 八字说身旺、阳宅纳衰气 | 命强宅衰，是消耗——有本钱但一直在漏。说清"要修环境" |
| 三元纳气与天纪名位结论相反 | 两套理气不同源，**不许折中**。按 `09`／`10` 的分工，先问用户要解决什么，只走一条主线 |

### 第四步：落到动作

合参的价值不在"说得准"，在"知道往哪改"。

三盘交叉后，可调整的杠杆有三根：

| 杠杆 | 手段 | 见效 |
|---|---|---|
| 命（1/3） | 改不了，只能认清 | — |
| 地理（1/3） | 换房、换房间、换床位桌位、加遮挡、改朝向 | 一个季度起 |
| 人事（1/3） | 选行业、选时机、改行为模式、修心性 | 随时 |

**永远把重心放在地理与人事上。** 这是《人间道》的立场，也是这门生意能长久的原因。

## 4. 标准输出模板（综合报告）

```
一、命局骨架
   日元分数 → 层次 → 用神 → 一生大方向（3–5 条）

二、当下状态
   相法所见（手／面）→ 与命局吻合处 → 不吻合处及解释

三、环境加减
   阳宅现状 → 在放大什么、压制什么 → 与命局的关系

四、三盘共振（核心结论）
   ① 极强共振：……
   ② 强共振：……
   ③ 单盘提示：……

五、可动的三根杠杆
   地理：……
   人事：……
   时机：……

六、分寸声明
   以上为传统术数文化分析，供参考，不替代医疗、法律、投资决策。
```

## 5. 五条纪律

1. **不合参就别合参。** 三样里只有一样，就只答一样，不许拿一样去"推"另外两样。
2. **不许用后出的结论去改前面的结论。** 各自独立完成后才能并表。
3. **冲突要讲出来，不许内部消化。** 用户有权知道三盘不一致。
4. **置信度必须标注。** 三盘同指为高，两盘同指为中，单盘为低。
5. **收尾必须给动作。** 只断不改，是把人留在恐惧里。

## 6. 什么时候不该合参

- 用户只问一件事（如"我这个月能不能签合同"）→ 直接走八字流年，不必拉三盘
- 用户只要看手相 → 只出手相，不主动加八字（除非他给）
- 用户明显焦虑、想听"没事" → 先安抚，再讲分寸，不堆信息
- 涉及疾病、诉讼、投资 → 只做参考层，明确建议找专业人士
