# 三十一、地纪：倪师实地勘验案例（峦头判断的实战样本）

> 出处：`倪海厦地纪日记 0–7`（2007–2008 年亲历大陆所记），收在你的 移动硬盘「倪海厦电子文案／天纪 人纪 地纪」。
>
> **这是全套资料里最难得的一份**——不是讲理论，是他站在现场一处一处断出来的。`17`（阴宅寻龙点穴）讲的是方法，这一份是**方法用出来的样子**。

## 1. 他看地的顺序（从案例里反推）

把这十处案例排在一起，能看出他每次都按同一个顺序看：

```
① 能不能藏风纳气（第一票否决）
② 明堂：广不广、聚不聚水、有没有被破坏、是不是人工勉强做的
③ 案山：高过坐山没有（高过就是"外来欺主"）、秀不秀丽
④ 龙虎：白虎是不是太低
⑤ 来龙：是不是支脉、发力久不久、山势有没有情
⑥ 坐向：坐北朝南还是坐西朝东
```

**注意第①条**：明圣宫、药王山、茂陵、恒山、紫霄宫，他每一处都先讲"藏风纳气"。——这跟 `17` 里"结穴七条件"的第 6 条（站上去要寂静无声、清风徐来）是同一件事。

## 2. 六条判据与他的原话

### 判据一：藏风纳气是门槛，过不了什么都不用谈

> 秦始皇陵建在骊山之下……**由于这位置无法藏风纳气**，加上秦始皇的暴虐无道……所以秦代只传二世就亡国了。

> 耀县药王山……一代药王的隐居处所，果然不同凡想，**藏风纳气，山势平稳有情**，无怪乎可以出圣人，真是灵山啊。

### 判据二：明堂要广、要聚水、忌太深、忌人工勉强

> 武当山紫霄观……有靠山又有明堂，**明堂中又有水来聚会，殿前又出水**，真正是非常难得的风水佳地。

> 北岳恒山……**虽然可以藏风纳气，但是明堂太深**，对面的案山也不够秀丽宏伟……并不兴旺后代。

> 黄帝陵……**明堂中的水池是后来人工修建的，制做的非常免强**……

**"人工做的明堂"不算明堂。** 这条在今天的公墓里天天用得上——水泥砌的景观池，不是水聚天心。

### 判据三：案山高过坐山＝外来欺主（他断得最狠的一条）

> 黄帝陵……**对岸的案山高过于坐山，这是外来欺主的格局**，实在不配做为黄帝的陵寝布局，**真是很差的风水布局**。

**用法**：站在穴上（或墓前）平视，对面的山（或高楼）如果比背后所靠的还高，就是欺主。城市公墓里"对面一排更高墓碑"同理。

### 判据四：白虎忌太低

> 昭陵，这是唐太宗的陵寝，**是九龙来朝的大格局，风水之宝地无疑**……但是这昭陵的**右侧白虎位置太低，所以较无法藏风纳气，这是唯一的败笔**。

**注意他的表述方式**：先说"宝地无疑"，再说"唯一败笔"。**先给格局，再点缺陷**——这是断语的分寸，值得学。

### 判据五：来龙要看"发力久远"与"有情"

> 骊山是**秦岭的支脉，所以发力久远**，此寺位置必有高人先鉴定过。

> 药王山……**山势平稳有情**。

### 判据六：穴位的精准与否，看它后面出不出人

> 五台山，当地的风水真是很旺，**许多寺庙都盖在龙穴之上，位置精准**，想当年必有得道高僧或是风水名师来先鉴定过后才兴建的，**难怪香火鼎盛**。

**这是他判断"位置对不对"的验证法**：不看理论，看结果——香火、出人、兴旺与否，反过来证明当初点得准不准。

## 3. 十处案例总表（可直接当教学素材）

| 地点 | 他的判语 | 依据 |
|---|---|---|
| 骊山·明圣宫 | 不可多得的好风水 | 藏风纳气、明堂未破、龙虎位置好、秦岭支脉发力久远 |
| 秦始皇陵 | 位置无法藏风纳气 | 藏风纳气不过关（并由此论秦二世而亡） |
| 汉诸陵（杜陵、茂陵等） | 帝王之格局 | 坐北朝南、前临渭水环绕、背靠秦岭、明堂为渭水平原 |
| 宋太祖赵匡胤陵 | 正坐北朝南 | 坐向 |
| 黄帝陵 | 很差的风水布局 | 明堂水池人工勉强、**对岸案山高过坐山＝外来欺主** |
| 耀县·药王山 | 灵山，可出圣人 | 藏风纳气、山势平稳有情（孙思邈隐居处） |
| 昭陵（唐太宗） | 宝地无疑，唯一败笔 | 九龙来朝大格局；**右侧白虎太低→不能藏风纳气** |
| 武侯墓（定军山脚） | 并非佳穴 | 坐西朝东；但他补一句"诸葛亮必有其顾忌" |
| 北岳恒山 | 藏风纳气但不明堂，不旺后代 | **明堂太深**、案山不秀丽宏伟、山形呈圆 |
| 武当山·紫霄宫 | 难得的风水佳地 | 有靠山、有明堂、**明堂聚水、殿前出水** |

## 4. 与 `17` 的互证：他用的就是那七条

| `17` 的结穴七条件 | 地纪里对应的案例 |
|---|---|
| 左右有水 | 紫霄宫"明堂聚水、殿前出水" |
| 出水口有砂 | —（他看的多是帝陵，未细论水口砂） |
| 不见水来水去 | 茂陵"前临渭水环绕" |
| 有案山朝山 | 黄帝陵"案山高过坐山"、恒山"案山不秀丽" |
| 龙虎环抱 | 昭陵"白虎太低"、明圣宫"龙虎位置非常好" |
| **藏风纳气** | 秦陵、药王山、恒山、紫霄宫，每处都提 |
| 明堂平广、水聚天心 | 恒山"明堂太深"、紫霄宫"明堂聚水" |

**结论**：`17` 不是从书上抄来的框架，是他真在看的东西。**讲课时可以拿这些案例给客户听，比讲理论有说服力。**

## 5. 三处不能照搬（重要）

### 5.1 不把"地理"直接接到"国运"

他写"秦陵不能藏风纳气，所以秦二世而亡"。这是他的感慨，**不是可用的断法**。

对外只能说：
> "秦始皇陵这个位置，按峦头的看法藏不住气，主后代守不住。至于是不是因此亡国，那是历史学家的事，不是风水能定的。"

### 5.2 不说"葬此必出富贵"

昭陵那条他写"举凡能靠近它而下葬的人，后代必有富贵之人出现"。**这句话不能对客户说**（`17` §10 已定：不承诺发贵）。

### 5.3 不点评现存的他人陵墓

地纪里他评的都是历史陵寝。**现代公墓里别人家的墓，一律不评**（`20` §8）。

## 6. 怎么用这份材料

| 场景 | 用法 |
|---|---|
| 客户问"什么是好风水" | 用明圣宫／药王山讲"藏风纳气"，用紫霄宫讲"明堂聚水" |
| 客户问"我家祖坟对面有高楼" | 用黄帝陵"案山高过坐山＝外来欺主"讲，再给遮挡或调整方案 |
| 客户问"风水真能影响后代吗" | 用五台山"寺庙盖在龙穴上所以香火鼎盛"讲"位置对不对，看结果" |
| 教学／写文章 | 十处案例表可直接当案例库 |

## 7. 顺带记下的两条天纪事实（供 `11`／`21` 引用）

日记里他自述：

> "目前我已经完成的天纪部份是**以易经的象为解释主力**……将来再传天纪，这时的天纪是**以术数为主力**，像是易经的大衍之数、奇门金章遁甲 4320 局数的排列与参同契，还有邵康节的皇极经世之学等等。"

> （在古寺）"找到我国宋朝邵康节写的**河洛神数与铁板神数**二书，还有一些关于风水的书籍。"

**两条用处**：
1. 说明《天纪》现有内容偏"象"，**术数那半（大衍之数、奇门 4320 局、皇极经世）他没讲完**——所以本馆讲奇门时要说明是"通行时家奇门"，不是天纪原传（`16` 已有此立场，这里多一条佐证）。
2. 他明确把**河洛神数、铁板神数**列为搜集目标，属"再传天纪"范围——本馆若被问到，如实说"倪师计划讲、未及讲完"。

## 8. 分寸

1. **案例只能用来说明"判据"，不能用来断客户的命。**
2. **帝陵是帝陵，民墓是民墓**，格局量级不同，别拿"九龙来朝"套客户的公墓。
3. **不神化"龙穴"**。他讲五台山"盖在龙穴上"，是事后验证，不是事前承诺。
4. **引用标出处**：`倪海厦地纪日记`，2007–2008 年。
