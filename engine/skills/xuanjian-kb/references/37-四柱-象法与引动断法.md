# 三十七、象法与引动断法

> 理法管"富贵层次"，象法管"什么时候、应在谁身上"。这是四柱理学课程第 48、50、51、52 讲的核心，原先只在 `03` 第 8 节留了六行概述，此篇补全。
>
> **象法不是另一套算命法**，它是在分数、用神都判准之后的**第二层读法**：原局是一个既定状态，大运流年把这个状态改掉了，事情就发生。

## 1. 象法的本质

原局是一块已经雕好的玉，状态固定。大运流年一改这个状态，对应的**人**与**事**就显出来。

- 理法问的是"这个命富不富、贵不贵"。
- 象法问的是"哪一步运、哪一年、应在哪个六亲身上"。
- 象法**不独立于用神体系**，它是用神体系之上的表达层。跳过打分直接谈象，就是玄谈。

## 2. 总口诀（八句）

> 无者怕出现，纯者怕混见。有根怕无根，无根怕有根。
> 假格喜变真，真格怕假从。太旺怕犯怒，弱极怕有根。

这八句讲的是**状态的脆弱点**，不是喜用神。喜用决定富贵，象法决定事态——包括六亲、也包括自己。

| 口诀 | 含义 | 关键限定 |
|---|---|---|
| 无者怕出现 | 原局没有的十神，大运出现了，状态被改 | **必须大运出现作前提**；"没有"指天干无、地支本气无。单个中气不算无，两个及以上中气算有，余气几个都不算 |
| 纯者怕混见 | 只有正财无偏财、只有伤官无食神的"纯"，大运出现混杂 | 对该十神所对应的六亲不利；只算天干与地支本气 |
| 有根怕无根 | 日元或六亲星唯一根气被冲、被合走 | 例：禄神为唯一根气又是寿元星，大运冲禄，此运必有健康关口 |
| 无根怕有根 | 天干虚透无根，大运给根，状态就变 | **两个中气根相当于一个本气根**；一个中气或几个余气都不算有根 |
| 假格喜变真 | 假从遇泄耗大运转真从，是好事 | 从格喜顺势 |
| 真格怕假从 | 真从遇生扶，降格 | 从格最怕生扶 |
| 太旺怕犯怒 | 专旺、太旺怕泄耗大运 | 逆势即犯怒 |
| 弱极怕有根 | 真从格怕比劫通根透干 | —— |

## 3. 十四种引动形式（状态怎么被改）

前八句讲"怕什么"，这十四种讲"**怎么动**"。都是引动的形式，动了才应事。

| 形式 | 定义 | 判别要点 |
|---|---|---|
| 藏透而动 | 本气藏、或两个中气藏在地支，大运透出 | 藏而有力，一透即动 |
| 浮遇根动 | 天干虚浮，遇根即动 | 与"无根怕有根"同义 |
| 独见重动 | 原局某十神在地支只有**一个本气**，大运伏吟重复 | **只针对大运**，流年重现无妨 |
| 无待现动 | 即"无者怕出现" | 大运作前提 |
| 有待无变 | 原局有的干支被大运流年合去 | 主要论被合走的那一个十神 |
| 合遇冲动 | 原局三合三会，被大运冲破 | 冲散合局，该局所主十神有事 |
| 冲待合变 | 原局六冲，大运六合三合解冲 | **不是所有冲遇合都能解**——只有被制住主克方才算解开（见下） |
| 墓待动开 | 墓库遇六合六冲三合三会 | 墓是哪个十神的墓，就应在谁 |
| 局待成动 | 大运流年让原局成三合三会六合局 | 成什么势，就出什么事 |
| 局待冲破 | 大运流年冲破原局合局 | —— |

**冲待合变的关键分辨**（易错）：

- 子午冲，大运丑土 → **解开**。子水占主克位，丑合走子、丑又害午，主克方被制，冲的实质消失。
- 卯酉冲，大运亥水 → **不解**。亥生卯只是加力，酉金照样克卯，克的本性没变。
- 判据一句话：**主克方有没有被制住**。只加被克方之力，不算解冲。

## 4. 十干入墓（墓运）

| 天干 | 墓支 | 天干 | 墓支 |
|---|---|---|---|
| 甲 | 未 | 己 | 丑 |
| 乙 | 戌 | 庚 | 丑 |
| 丙 | 戌 | 辛 | 辰 |
| 丁 | 丑 | 壬 | 辰 |
| 戊 | 戌 | 癸 | 未 |

**用法**：大运走日元之墓，主不得志、阻碍多、才华施展不开，**纵是喜用神运也一样压抑**。阳日干最明显（阳主活跃，入墓如困），阴日干稍轻；阳日干身弱再逢墓运，更觉提不起力。

**墓只论大运，流年不论墓。** 大运是月柱的延展，流年不是。

## 5. 空亡出空

原局里的空亡可以由大运解开：大运走到该字出空，**此后永久出空**，后面的大运不再按空论。出空之前，空亡持续生效。

## 6. 交运与脱运

- 一步大运的**最后一年**叫脱运年；新大运的**第一年**叫交运年。
- 两个年份都主动荡、多变数、六亲感情起变化。
- 断法上：交脱运之年**不说吉凶**，只说"易有变动，宜稳不宜决"。这时给的建议是具体动作——体检、行善、不杀生、不与人争、不签大额、不做伤害他人之事。

## 7. 寿元星（分寸最敏感的一节）

**核心寿元星：禄神、正印、食神、正财。** 偏印、偏财、伤官一般不作寿元星（从偏财、从伤官时可作）。寿元星多现，共同参考。

**太强的六亲星不能作寿元星**——太旺已不是"守"的状态。

引动级别：

| 情形 | 级别 |
|---|---|
| 原局一个寿元星都没有，大运出现 | 最高 |
| 原局有寿元星，大运引动（冲、合走、墓开） | 次之 |
| 两个寿元星同时被引动 | 比单个明显 |

**对外表述铁律**（此处比任何技术细节都重要）：

- 一律说"**健康关口**""**这一年宜有人陪伴、宜先做检查**"，**绝不说死、夭折、大限、必凶**。
- 必须同时给出可做的事：体检项目、陪伴、避免远行、避免手术择期、避免饮酒与高空。
- **命理不判寿数**。同八字者众，个体差异极大，把象法读成判决书就是越界。课程原话："我们学的命理不是塑造权威，是找一个规律。"

## 8. 多重引动才应事

**一个象法成立不叫应期，两到三个信息同时指向才叫。** 这是全篇最实用的一条纪律。

判定流程：

1. **大运先动**：哪一步大运把原局的某个状态改掉了（无者出现／藏者透出／墓被冲开／合被冲散／冲被合解）。
2. **锁定这十年**：这一步运里，事情是"蓄势待发"。
3. **流年引动**：在这十年里找把同一信息再加重的年份——伏吟、天克地冲、反吟、合解冲、冲解合、宫位被冲。
4. **数点数**：两点以上算大概率，三点以上算很明显。只有一点，不下断语，只作提示。

**流年力量高于一切**：流年可以冲动原局任何一个地支（前提是本来有地支关系）。但流年改不了格局，只有大运能改——这句话在整个体系里反复出现。

## 9. 地支关系的力量层级

三合三会 > 六合六冲 > 刑害。

但注意：**这只是影响大小之别，不是"谁占有了谁"**。原局内的地支是同时发生关系的，没有哪个字有绝对占有权（"月令生扶就一定偏强"是谬论）。该发生的关系都会发生，只是轻重不同。

大运流年的级别高于原局，所以大运流年能合走、冲开、扭转原局的地支——这也是"贪合忘冲"只在**大运流年对原局**时才成立的原因。

## 10. 常见误用

- ❌ 只凭一个象就断年。没有大运作前提、没有流年加重，就是猜。
- ❌ 把"无者怕出现"当成"缺什么补什么"。它讲的是**状态被改变会出事**，不是"缺财就要补财"。
- ❌ 见墓运就说不好，不看是不是专旺、太旺——专旺太旺不怕墓。
- ❌ 把象法当万能钥匙，绕过打分直接用。分数不准，象法全歪。
- ❌ 用象法断生死。这是红线，不是分寸问题。
- ❌ 见"合"就说解冲。要看主克方有没有被制住。
