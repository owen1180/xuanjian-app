# 十六、奇门遁甲：起局框架与断法

> **先说清楚边界**：倪海厦《天纪》没有传授奇门遁甲。天纪的五块是紫微斗数、易经占筮、堪舆、推命、人相。地脉道借用了奇门的九宫布列作底层结构，但那是"借架"，不是"传术"。
>
> 所以这一门走**主流时家奇门**，技法上取诸家通行之法；但**思维方式仍以倪海厦的"取象、以果决行"为纲**——先看清局面之象，再定进退。这就是本馆"以倪为师、诸家为辅"在奇门上的落法。

## 1. 奇门是什么，能干什么

奇门遁甲是**时空决策模型**：把时间（节气、时辰）与空间（九宫方位）叠在一张盘上，用盘面结构判断一件事的**成、败、迟、速、方向**。

三个实际用途：

| 用途 | 问法 |
|---|---|
| **断事** | 这件事能不能成？什么时候成？卡在哪？ |
| **择时** | 什么时候去谈、去签、去动身最好？ |
| **择方** | 往哪个方位走、坐哪个位置有利？ |

**不能干什么**：不能替代尽人事。天纪讲"天命三分之一、地理三分之一、人事三分之一"，奇门属于"地理与时机"这一层，占不到全部。

## 2. 盘的四个层次

| 层 | 内容 | 读什么 |
|---|---|---|
| **地盘** | 六仪三奇按局数排入九宫 | 事的"底子" |
| **天盘** | 九星随时干转动 | 事的"动能" |
| **人盘** | 八门 | 人的"作为与通道" |
| **神盘** | 八神 | 事的"隐性情势" |

四层叠在同一宫，**同宫的信息互相加持或抵消**，这是断奇门的基本功。

## 3. 基本元件

### 九宫（洛书方位）

```
巽四(东南)  离九(南)   坤二(西南)
震三(东)    中五       兑七(西)
艮八(东北)  坎一(北)   乾六(西北)
```

### 三奇六仪

- **六仪**：戊、己、庚、辛、壬、癸
- **三奇**：乙（日奇）、丙（月奇）、丁（星奇）
- 排布顺序按"戊己庚辛壬癸丁丙乙"，阳遁顺布、阴遁逆布

## 4. 起局：方法与边界

**起局是机械活，必须准确，不能凭记忆报局数。**

步骤框架：

1. **定阴阳遁**：冬至后至夏至前用**阳遁**；夏至后至冬至前用**阴遁**
2. **定局数**：由节气 + 上中下元决定（阳遁一至九局，阴遁九至一局）
3. **定上中下元**：由**符头**（甲子、己卯、甲午、己酉等）决定，涉及**超神、接气、置闰**的处理
4. **布地盘**：六仪三奇按局数入九宫
5. **定值符值使**：旬首所在宫
6. **转天盘**：九星随时干转
7. **布八门**：值使门按时辰数飞布
8. **布八神**：值符起，阳遁顺、阴遁逆

> **规矩**：局数与时元必须查局数表或用排盘工具，**不许凭记忆口算**。报错一个局，整盘全废。这是团队硬规矩，与四柱"不打分不下断语"同一条纪律。

## 5. 断法

### 5.1 先定用神

| 问什么 | 取什么用神 |
|---|---|
| 求测人本人 | **日干**（落宫即本人处境） |
| 所问之事 | **时干**（落宫即事的现状） |
| 求财 | 生门 + 戊（资本）+ 日干 |
| 事业、官运 | 开门 + 值符 |
| 婚姻 | 六合 + 乙（女）庚（男） |
| 疾病 | 天芮（病）+ 天心（医）+ 日干 |
| 官司 | 惊门 + 白虎 + 值符 |
| 出行、迁移 | 九天 + 开门 + 所往之方 |
| 考试、文书 | 景门 + 天辅 + 丁 |

**日干是我、时干是事**，这一对是通盘的主轴。先看两宫的生克关系，定"我能不能拿下这件事"。

### 5.2 判旺衰

三看：

1. **落宫生克**：用神落宫得生则旺，受克则衰
2. **月令**：该宫五行当令则旺
3. **同宫加持**：同宫的星、门、神是否相助（如开门＋值符＋九天，极旺）

### 5.3 看格局

**吉格**（举要）：
| 格 | 结构 | 主 |
|---|---|---|
| 青龙返首 | 戊＋丙 | 大吉，事成且快 |
| 飞鸟跌穴 | 丙＋戊 | 大吉，得而有成 |
| 三奇得使 | 三奇临吉门吉星 | 得贵人助 |
| 玉女守门 | 丁奇临开门／值使 | 宜密谋、宜暗事 |
| 天遁／地遁／人遁 | 三奇配特定门神 | 各有专宜 |

**凶格**（举要）：
| 格 | 结构 | 主 |
|---|---|---|
| 伏吟 | 星门不动 | 停滞、拖延、内耗 |
| 反吟 | 星门对冲 | 反复、翻覆、事与愿违 |
| 五不遇时 | 时干克日干 | 此时不宜举事 |
| 六仪击刑 | 六仪落刑宫 | 主刑伤、官非 |
| 门迫 | 门克宫 | 吉门减力，凶门更凶 |
| 入墓 | 用神落墓宫 | 事被困住，难出头 |
| 空亡 | 用神落空亡宫 | 事虚、不实、落空 |

**伏吟反吟是奇门里最常用的两个断语**：伏吟主"拖"，反吟主"翻"。问事遇伏吟，答案是"慢，急不得"；遇反吟，答案是"会变，别定死"。

### 5.4 定应期

- 用神落宫的地支，对应月或日
- 值符值使所临之宫，定快慢
- 空亡逢冲、入墓逢开，是"出头"之时

**应期只给区间，不给日子。** 奇门定到日已是极限，多数情况只能定到旬或月。

## 6. 择时择方的实操

### 择时（办一件事选时辰）

1. 取该事的用神
2. 找用神旺相、临吉门吉星、无凶格的时候
3. 避开：五不遇时、伏吟反吟、用神入墓空亡
4. 给出 2–3 个候选时段，说明各自强弱，让用户自己定

### 择方（选方位）

1. 取事的用神
2. 找用神所在或所生之方
3. 避开门迫、击刑、空亡之方
4. 说明"方位是加分项，不是决定项"

## 7. 分寸（这一门最容易出问题，规矩要死守）

1. **不起局不断事**。没有准确时间（年月日时）不起局。时间存疑就说存疑。
2. **局数必须查表或用工具**。不许口算报局。
3. **不只报凶不给出路**。断出凶格必须同时给"怎么办"（改时、改方、改法）。
4. **不用奇门断生死、断病情、断官司胜负**。这三样越界最严重。
5. **不承诺具体金额与具体日期**。
6. **奇门与其他盘冲突时**：奇门管"此时此方成不成"，八字管"这一生有没有"，紫微管"这一领域顺不顺"。三者层次不同，**不是谁对谁错，是不一样的问题**。
7. **标明流派**。时家奇门为主，转盘／飞盘／阴盘各家有异，用到哪家说哪家。
