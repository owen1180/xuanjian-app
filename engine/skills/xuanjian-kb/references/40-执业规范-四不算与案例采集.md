# 四十、执业规范：四不算与案例采集

> 这一篇不讲解盘，讲**什么盘不该解**。
> 课程第 34 讲的原题是「案例收集 禁忌须知」，讲者把话说得很重：这一门最宝贵的东西不是断得准，是**尊重事实**。

## 1. 四不算

| # | 情形 | 为什么不算 |
|---|---|---|
| 1 | **隔着人的不算** | 话传到第二个人嘴里就变了味。亲戚的同事、朋友的朋友，你既不了解中间人，也无从验证终点的人。信息不对称，算出来的必然是错的 |
| 2 | **来意不明的不算** | 拿别人八字来问的，本身带着企图；试探你、考你、借你之口证明自己想法的，都不在此列 |
| 3 | **对方诚恳，可当案例探讨** | 愿意给真实反馈、叙述有逻辑、能对上现实，这样的盘值得深谈，也是最可能长出经验的一类 |
| 4 | **言行不一、逻辑不符、有所隐瞒的，不必再算** | 说几句得体的话送走即可，不必拆穿，也不必较真 |

## 2. 尊重事实高于尊重理论

讲者原话：**「我们这个流派最宝贵的东西，就是尊重事实，实事求是。」**

- 若断"用财"而对方父子关系淡漠、父亲一生窝囊 → 改判为"以财为忌"。
- 若断"这步是用神运"而对方实际压力大、竞争多、收入一般、压抑迷茫 → 那就是**忌神运**，不许拿理论压事实。
- 硬把一个对不上的盘讲圆，是把自己的面子放在客户前面。

## 3. 八字源头问题：前提错了，全错

命理师唯一依靠的是那一组干支。所以先要问一句：**这八字可靠吗？**

常见源头问题：

- 抱养、送养，孩子不知道自己的生日，养母另编了一个
- 只记得大概日子，时辰是猜的
- 农历与公历混报、闰月没换算

处理原则：

1. 用万年历独立复算（`xuanjian-archive` 的 `pillar.py`），不采信口述直接落笔。
2. 时辰不明的，写明"待补时"，结论降一档，不硬凑。
3. 若同时出现多处与事实矛盾，先怀疑源头，不要先怀疑方法。
4. 连续遇到三个对不上的盘，也不必推翻自己的体系——继续扩样本，但要记录。

## 4. 反馈的逻辑校验

对方叙述里出现下列信号，先停一停：

| 信号 | 说明 |
|---|---|
| 数字对不上 | 收入两千多、有房贷、养孩子、配偶无业——这不成立，说明叙述被修饰过 |
| 全是抱怨、只讲对方不好 | 常见于"用贬低对方来给自己的选择找理由"，信息已经失真 |
| 前后矛盾 | 一会说很勤奋，一会说一直没有正式工作 |
| 只求安慰、不求真相 | 对方要的是一个情绪出口，不是判断 |

**校验的目的不是拆穿，是不让自己的结论建在假数据上。** 一旦发现失真，可以照常聊，但不落断语、不写进档案、不当案例。

## 5. 三条职业纪律

1. **不塑造权威**：讲者反复强调，"一定发生"本身就是误区。同八字的人越多，越能看到差异。命理找的是规律，不是判决。
2. **不为难自己**：有些事无解（抱养、编造生日、家族隐秘），承认无解比强行圆上更专业。
3. **不留把柄**：涉及第三人隐私、家庭隐秘、未证实的指控，一律不写进档案、不在对外文本里出现。

## 6. 年过六十，断语要降一档

课程原话（第十一课）：「六十岁以后的八字不是十分准确了，会有前面的自己的因果所影响，最直观的，就是寿命根据自己的善恶、生活习惯等等，已经偏离了命运的范畴。五十知天命，六十岁七十岁就不要再执着于命理。」

这不是客套，是这门技术自己划的边界。落在服务上：

| 对象 | 怎么讲 |
|---|---|
| 六十岁以下 | 按盘讲，力度、时机、方向都可以说 |
| 六十岁以上 | **格局与六亲可以讲，具体的「哪一年会怎样」要收**。这一段的变量主要不在命盘上，在几十年的生活习惯、心态与医疗条件上 |
| 被问寿元、关口 | 一律转体检与陪伴，不谈终点（`46`） |

**为什么重要**：当下在办的 1957 坤造已经六十九岁，正落在这段里。她的流年断语必须比同龄盘更保守——能说的是「这一年宜静不宜动」，不能说的是「这一年有事」。同一条判语，对四十岁的人和七十岁的人，出口的分量不一样。

## 8. 一句话总结

**先问八字可不可靠，再问来意正不正，再问事实对不对，最后才轮到技术。** 顺序反了，技术越好越危险。
