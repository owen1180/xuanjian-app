# 五十三、分项断法 · 财富与事业

> 来源：第十七课（财富方向）、第十八课（事业简析）、第十九课（事业案例）。
> 分工：本册是**流程与判据**，不是断语。断语封顶看 39 用神级别，分寸看 24 与 40。
> 一句话主干：**先定旺衰取用神 → 用神五行定行业大类 → 用神十神定性质 → 位置定级别 → 力度定高低 → 最后叠大运与时代。**

## 1. 财富：先分实财虚财

老师说得很直白：「拥有财富不等于实财。拥有驾驭财富的本领，和实践经验，才是真正的拥有财富。」

- **实财**：格局好，现实中也有钱。
- **虚财**：格局一般而现实中有钱——拆迁、赔偿、资源开发，「这种财富和本人的格局无关，而是与时代挂钩」。

断财富不给数字，只给区间与浮动，且必须说明它与时代环境绑定：同一八字在民国是富甲一方，换了时代未必对得上。

## 2. 财富判据（按用忌四档走）

| 情形 | 判据 |
|---|---|
| 财为用神，旺而受生 | 富 |
| 财为忌神，弱或受制 | 有钱，但不会花、享受不到 |
| 财为忌神，原局不现 | 小富 |
| 用神在原局有力 | 富——**并非一定看财** |
| 官为第一用神而无财 | 有名气官位但不富，或官位不久 |
| 财为用而无食伤（无生财之源） | 来去匆匆，大来大去 |
| 用神受制、忌神有力又贴身 | 贫困 |
| 比劫为用而财又出现 | 该财即定为忌神 |
| 印为用而得财 | 名气得财，心情不好，与家人不合 |
| 食伤为用而得财 | 产品作品技术得财，肠胃或体重易出问题 |

「旺而受生」要拆开看：**旺**是有实透、或有完整地支不被克泄；**受生**是在旺的前提下被喜神所生。两条都成立才算。

破财路线要专门追一遍：忌神是否贴身、是否伤官生财为忌。老师举过一个例：食伤与财同为忌神，断语是「投资多，收益少」「把钱花出去，花到小人那里了」。

**传统派「财为忌旺必贫」「财为用不出现必贫」这类口诀，老师明说过「过于极端」，不照搬。** 财为忌很旺确实容易紧，但大运来比劫帮扶，仍能富贵。

## 3. 真从与假从的一条细线

分数四十五以下的盘，判真从假从看印与比劫：

- 本气为印、或天干透印、或地支有比劫根气 → **不能算真从**。
- 只是地支藏干的中气余气有印或比劫 → 可以算真从。

另有一条：偏弱而印多，取比劫为用——印已经够多，再加就「反生为克」了。

## 4. 事业：六步取象

第一步，定旺衰分数、取用神。**分数必须用月令校正**：月令通透、干支比和一气的盘，不能拘泥于分数，按偏强论。

第二步，看用神在原局有没有力。原局里有的先用——「原局里有的先拿来使用」；原局没有的，从大运里再找。原局用神虚透且路线还生到忌神，仍「权衡利益以后，还是要以最大利益为主」，但层次要降。

第三步，**用神五行定行业大类，且分阴阳干**。庚金是肃杀、对抗、激烈、坚定；辛金是美好、漂亮、展示、观赏。同一个金，取庚还是取辛，方向完全不同。

第四步，**用神十神定性质**。先分动静：七杀、伤官、劫财、偏财为动；正官、正印、食神、正财为静。再分体力/非体力、体面与否。

第五步，**位置定级别**：用神在年月级别更大，尤以月令为最佳；在日支则自己支配权更多。

第六步，**力度定高低**：用神越旺越流通，工作级别越高；越被制约、力量越不足，级别越低。

## 5. 事业判据

1. 身旺、比劫旺又构不成专旺，且官杀印财弱 → 多从事体力劳动。
2. 七杀无制化 → 容易给人当副手。
3. 财虚透在天干 → 会来事、会表达；官星虚透 → 有名气、头脑聪明。
4. 印星为用而虚透 → 没文凭；为忌虚透 → 有文凭。
5. 食伤虚透 → 爱说话能说会道；食神不透 → 内秀。
6. 食伤在地支被冲 → 容易自闭、不擅沟通。
7. 七杀伤官劫财偏财旺 → 不安于现状，跳槽换工作常见。
8. 正官正印食神正财旺 → 安全感要求高，主动选体面工作，不愿抛头露面。
9. 官为用旺而得生 → 有官职（指职务职位，不一定是公务体系）。
10. 伤官为用而伤官伤尽 → 有官位，但有名气有身份而**不利管理**。
11. 官为忌而弱、明显被制 → 有官位（食神制杀，前提是官弱食神强）；七杀强过食神则容易招是非小人。
12. 官为忌而被印化、印再生身 → 有官位。
13. **无论官印是喜是忌，只要官生印、印生身，就是有官职**，级别看格局。
14. 财在年上有力为用、财在时上有力为用、地支食神为用有力 → 经营店铺或企业。
15. 地支正财为用 → 多经营实体；地支偏财为用 → 喜欢投资，挂名参股的公司多。
16. 四者为用而力量不足 → 靠工资赚钱。
17. 大运与用神冲克 → 事业体现不出来，甚至走到忌神方向的工作上去。
18. 不在体制内的，最终会回到用神职业；体制内的，在行业内调整岗位方向。

## 6. 两气成象：三个条件缺一不可

1. 只有两种五行，且是相生关系；
2. 两种五行要均衡；
3. 以天干地支论，不算藏干。

老师举反例：己酉 己丑 己丑 己丑 不算，因为两种五行不均衡。两气成象的盘一般不是体力劳动者，效率高，脾气也不小。

## 7. 分寸四条

- **不能一下定性**。原话：「我们只能从五行上靠，不能一下子就绝对定义这人是什么工作。」行业在变，没有一个方向是长久不变的。
- **要承认降级**。用庚金却做着辛金性质的事，是在自己用神级别上的降级——竞争激烈、不得已而内卷，这是常事，不是断错了。
- **不能脱离年代与地域**。同一个八字生在九十年代的农村，很难往领导方向断。
- **不给负面标签**。老师断一个发廊洗头妹之后专门补了一句：不能说是不好的洗头妹，有可能她就是正经做头发的。断职业是断能量走向，不是给人分级。
