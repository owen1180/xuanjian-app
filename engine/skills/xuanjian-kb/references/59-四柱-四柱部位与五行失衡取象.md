# 五十九、四柱部位与五行失衡取象

> 来源：第二十三课（健康取象一节）。
> 分工：本册是**取象素材与部位坐标**，不是诊断。工具只把「哪一柱、哪一行」翻成「留意哪一块、宜查什么方向」，
> **永不出病名**（`24` §4、`46` §8 同一条纪律）。真要落到身体，必须过 `24` 的就医触发清单。

## 1. 四柱部位：一张要背下来的坐标

老师要求背下来的四句：

| 柱 | 部位 |
|---|---|
| 年柱 | 头部 |
| 月柱 | 胸部、腹部（上焦中焦） |
| 日柱 | 腹部以下、下体 |
| 时柱 | 腿脚 |

再叠一层内外：

- **天干主外**——外在的、表象的、看得见的。
- **地支主内**——内在的、内部的、查出来才知道的。

所以「年干被冲克」与「年支被冲克」不是同一件事：前者偏头部外在（如视力、神经衰弱一类的外显），
后者偏头部内部。这是取象的粗细之分，不是诊断精度之分。

## 2. 五行失衡的三档

同一行出问题，有三种成因，取象不同：

| 档 | 情形 | 取象方向 |
|---|---|---|
| **缺** | 原局不见该行 | 该行所主系统偏弱，**且要看大运补不补得进来**——「八字缺水，大运也缺水」，才是长期偏弱 |
| **弱而被制** | 该行出现但被重克 | 比「缺」更明显——「不怕不出现，就怕出现了又被重重克制」 |
| **太旺** | 该行过旺或得生太过 | 旺极反伤其所生所克，走的是「过」的路子 |

**「重克」的量尺是本馆定的，不是讲义原文**（讲义只说「被重重克制」）：引擎取
**克它者 ≥3 处，且不少于自身三倍**。这样「水一处、土两处」不报，「水一处、土三处」才报——
否则一张寻常盘里五行各一两处，处处都成了「弱而被制」，等于没说。此阈值可调，调了就同步改本节。

**只缺不被制，往往不严重；缺而岁运也不补，才是长期课题。**

## 3. 五行与系统（取象用，不作病名）

| 五行 | 所主 |
|---|---|
| 木 | 肝胆、筋骨、神经、眼目 |
| 火 | 心血、小肠、眼目、精神 |
| 土 | 脾胃、肌肉、消化吸收 |
| 金 | 肺、呼吸道、皮肤、鼻 |
| 水 | 肾、泌尿、生殖、耳、脑 |

课程另给了十四条细目（如「木被金伤，筋骨腰肋疼痛」「火太弱或死绝，易患心脏方面」
「水旺辛金弱，支气管、鼻塞、咳嗽」等）。**这些细目一律不进引擎输出**，理由有三：

1. 它们多为症状与病名的混合体，直接出口就是诊断。
2. 同一组五行失衡在不同年龄、不同体质上表现差异极大，脱离问诊必错。
3. 本门对客户的话只到「宜留意哪一块、宜安排哪项检查」，再往下是医生的活。

十四条留在册页作**成员内部辨识用**：听完问诊、看完气色，用它反查「这个方向合不合理」，
而不是拿它去告诉客户「你会得什么病」。

## 4. 三条分寸

1. **部位不等于病灶**。年柱主头，不等于年柱有问题就是头有病；只说明这一块的象在那里。
2. **不叠加成结论**。三处都指向同一行，也只说「这一块宜留意」，不说「一定会怎样」。
3. **年龄与症状时长优先**。同样一个「水弱」，二十岁与六十岁的话完全不同；有症状先问多久、看过没有。

## 5. 接口

排盘工具 `src/analysis/buwei.ts`：

- `zhuWei(pillars)` 出四柱部位与内外（天干主外、地支主内），只作坐标。
- `shiHeng(pillars, wxCount)` 出五行三档（缺／弱而被制／太旺）与该行所主系统。
- 二者合成 `tiJianTiShi(...)`：输出形如「年柱（头部）· 水偏弱——宜留意肾与泌尿方向，宜安排常规检查」，
  **措辞固定、不含病名、不含「会」字**，并附「不作诊断」的边界句。
