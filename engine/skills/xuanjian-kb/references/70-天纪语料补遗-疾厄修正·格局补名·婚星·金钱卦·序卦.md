# 七十、天纪语料补遗：疾厄修正·格局补名·婚星·金钱卦·序卦

> 这一册把 `69` 地图里"语料有、册页无"的五块，按**语料实物**补进来。全部据天纪语料（4886 条）抽样归纳，标秒级出处，可回放核对。
> **总红线不变**：疾厄与凶格一律转成"提醒／去查／关口"，**不落病名、不断寿元**（`24`、`57`、`46`）；卜法只讲原理与伦理，不替人下判决（`27`）。

## 1. 疾厄宫断法：一条"重大修正"（`05-illness`）

### 1.1 倪师自己标了"重大修正"

语料里这一节的小标题就叫"核心方法论（重大修正）"。原话（@00:44:35 起）：

> 「诸位看斗数上面的疾厄宫，参考可以。但是你真的批的时候他就没有用。」
> 「七杀在疾厄宫代表痔疮，这个不重要。」
> 「我们算命要讲致命伤。」

**这意味着什么**：市面上"某星在疾厄宫＝某病"的逐星断法，倪师明确说**不准、不重要**。本馆 `67` 早年那套"疾厄宫→脏腑"的简略映射，属于需要修正的旧写法（按 `65` §4 勘误闭环，原写法保留、此处加注修正）。

### 1.2 正确顺序（据语料归纳）

1. **先看全盘，不单看一宫**（@00:09:19"通盘要兼看，不能光看一个宫"）。
2. **找"最差的宫"**（@00:48:18"先看哪一个宫最差"）；**两个宫都差，则两脏一起病**（"肝肾一起病"）。
3. **疾厄宫无星 ≠ 无病**（@00:47:19"没有星那就没有病，你就完了，自己给自己卖了"——反讽：无星不能当没病）。
4. **用"地支→脏腑"歌诀定位脏腑**，而不是用星性直接对病。

### 1.3 地支→脏腑歌诀（`05-illness` @00:45:45，原文照录）

> **肺寅大卯胃辰宫，脾巳心午小未中，申膀酉肾心包戌，亥焦子胆丑肝通。**

展开：

| 地支 | 脏腑 | 地支 | 脏腑 |
|---|---|---|---|
| 寅 | 肺 | 申 | 膀胱 |
| 卯 | 大肠 | 酉 | 肾 |
| 辰 | 胃 | 戌 | 心包 |
| 巳 | 脾 | 亥 | 三焦 |
| 午 | 心 | 子 | 胆（另说膀胱） |
| 未 | 小肠 | 丑 | 肝 |

**用法**：疾厄宫落在哪一地支，就先看该地支对应的脏腑；再看该宫星曜与四化的"轻重"，**只作"这一块宜留意、建议查××方向"**，不说"你这是××病"。

### 1.4 几个可用的细点（都只到"提醒"）

- **心包 vs 心**（@00:47:49）：心包多主"后天"（后天发的心脏问题），心主"先天"。只说"心脏这一块宜早查"，不分病名。
- **三焦与糖尿病**（@00:48:03）：三焦是"人身上的油网"，三焦有问题者代谢类偏多——只说"代谢方向宜查"，不诊断。
- **女命妇科**（@00:51:10）：女命疾厄一带偏差，多提示妇科方向；**男女同格，女多一妇科**。仍只到"建议妇科检查"。
- **煞星入疾厄**（`05-illness` 12 条）：主"开刀、血光、意外伤"之类——**一律转成"注意外伤与定期体检"，不断生死**。
- **化忌入疾厄 / 冲疾厄**（3 条）：作"这一段身体要留意的时点"，配合大限流年，**给关口年**（区间＋主年，`61` §3.4）；**不提的是寿元与死关**，不是关口年（`46` §1 条 2 的本馆读法）。

> **本馆把这段写进 `67` §2 的修正注**：疾厄宫不再逐星对病，改走"全盘找最差宫 + 地支脏腑歌诀 + 只作提醒"。

### 2.2 凶格（补名，**全部转风险语言**）

| 格局 | 结构 | 原话判意 → 本馆说法 |
|---|---|---|
| **半空折翅** | 廉贞贪狼落陷冲命（尤在福德/中年限） | 原话断"中年夭折" → **"中年（约 30 岁上下）是这一生要重点留意的健康与重大变动关口，宜定期体检、宜有人陪伴"**；**不断寿元、不给年份** |
| 孤鸾命 | 特定星曜组合（孤寡之象） | "婚缘宜迟、聚少离多"；不说"克夫/克妻" |
| 杀夹杀 | 七杀破军贪狼遇羊陀火铃 | "变动剧烈、易外伤"；建议"稳字当头" |
| 天罗地网 | 辰戌/巳亥受限之局 | "施展受限、宜守正待时"；不说"困死" |
| 水中作冢 | 水局凶象 | "出行/水域宜慎"；不说"淹死" |
| 刑夫克子 | 女命特定组合 | **"与配偶子女缘薄、宜聚少离多"**；禁用原文"刑克"二字（`57` 禁词） |

> **纪律**：凶格名可以讲（"常见排盘软件/天纪称××格"），**判意必须落地为"留意什么、怎么避"**，不给"必凶""夭折""死"（`22` §16、`57`）。`15` 已加"语料补名见 `70` §2"。

## 3. 红鸾、天喜（`01-stars` 44 条）

`11`/`15` 未收，补上。要点（据原话归纳）：

- **两星永远相对**（@00:31:16"天喜在这边红鸾星一定在对面"）。
- **定性**：喜庆之星，主婚恋、喜事（"红鸾心动"一词即出斗数）。
- **落宫断"婚姻的来由"**（这是最实用的一层）：
  | 红鸾落宫 | 婚姻来由（原话归纳） |
  |---|---|
  | 父母宫 | 受父母之言，结婚早（约 22 岁前） |
  | 子女宫 | 因子女之命而结婚 |
  | 朋友宫 | 被朋友怂恿促成 |
  | 命宫 | 主见强，自己决定婚姻 |
- **分寸**：只说"姻缘成于何处、宜早宜迟"，**不断"必婚必离"、不指具体人**（`54`、`57`）。

## 4. 金钱卦起课（`10-divination` 14 条，补 `33` 未及）

`33` 讲了六神、测字、临机，但**没讲金钱卦的起课**。补上（据原话 @00:45:19 起归纳）：

1. **心要诚**（第一句就是"第一个心要诚"）。
2. **六枚铜板**：人面为阳、数字面为阴（"一铜板即分阴阳"）。
3. **摇**：放竹筒摇，上下摇、勿横摇（防飞钱），**摇五六下以上**。
4. **撒成一排**，**由下往上**读六爻（"从下往上直接走"）。
5. **撒不整齐则作废重来**（"顺序不好，这个卦就作废，重来过"）。
6. 这叫"起课"。

> **本馆态度**：金钱卦是**六爻起卦法**（引擎 `36` §2 也支持六爻）。**可以讲原理、可以教怎么起，但不替客户"断死断生"**；断卦归 `33` 六神与 `62` 卦义，**结论一律是"提示"，不是判决**（`27` §2）。

## 5. 序卦总义（`08-yili` 69 条）

`62` 讲"一卦四用"的断语，但没讲**六十四卦为什么是这个顺序**。补上（据 @00:10:30 起归纳）：

- **卦序如环**：天地定位（乾、坤）之后，像手表一圈走下来，一卦接一卦。
- **以"人的成长"为喻**（@00:16:47）：
  `乾为天/坤为地`（父母成婚）→ `水雷屯`（物之始生，如胎儿在母腹）→ `山水蒙`（初生，需要启蒙）→ `水天需`（物之始生必待养成，等待）→ …
- **用处**：讲"六十四卦的次序逻辑"、给客户讲"为什么这一卦接那一卦"时用；**不作流年断语**（流年回 `62`）。

> 这一节是"易理"，不是"断法"。**讲理可以，断事仍回 `62`／`13`。**

**四条红线（本册重申）**：
1. **疾厄不断病名、不断寿元**——只说"宜留意、建议查、关口"。
2. **凶格不铁口**——"半空折翅""天罗地网"等名可讲，判意转成"留意什么、怎么避"。
3. **不给穴位、不给剂量**——针灸/本草只回原话、只讲角色（`69` §7）。
4. **卜法是提示不是判决**——"算算看、听听看，不可全信"（`27`）。
