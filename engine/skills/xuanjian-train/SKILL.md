# 数据训练、守门模型与全量研习工坊

**这一层不训练会断命的模型。** 它只把外部数据集里**确定性、可核验、不产断语**的那部分抽出来，训练守门模块；并把开源项目里值得学的机制，落成**本馆自撰、可运行、可自检**的工具。断语仍由对应成员各自出，交叉核对仍由主理人主持。

## 一、先给定论

| 问题 | 定论 |
|---|---|
| 能不能拿 v4.0 数据集训练？ | **能**。`DATASET-LICENSE` 原文允许「模型微调（开源与闭源模型均可）」＋商用，唯一要求署名。 |
| 能不能把 8,774,688 段解读直接做 SFT？ | **不能**。全量实测 **674,976 / 674,976 盘（100%）** 内嵌倪师《天纪》原话与古籍引证，属 CC BY-NC-SA 4.0 非商用且不在数据授权范围；成批入语料即违约。且那是别人的断语库，学它＝搬实现。 |
| 那训练什么？ | **守门模块**：盘面校验＋口径卡、引文剥离、四化白名单、事实／解读分层。四类任务都不产断语。 |
| 会不会破坏「各安其位」？ | 不会。模型**不是成员**，只产出工具层候选，须经 `source_gate.py` 复核；禁止把多门断法融进一个权重（真一 27B 的做法在本馆禁止）。 |
| 本机能不能训？ | M4 Pro / 24GB 统一内存 → 只适合小模型 LoRA；**全量预训练、27B 权重、把 56.6GB 文本塞进语料都不做**。 |
| 「照单学习全部」学到哪一步？ | 全 77 分片已取到本机并 SHA-256 全通过；清单项目逐个源码级研读；五项提升价值各有一个可运行脚本，全包 15 个脚本自检合计 **234/234**；三阶段逐项交账见 `TR107`，查漏补缺见 `TR108`。 |

**两条训练路线**：① 主路线＝小模型 LoRA（`mlx-lm` + 0.5B 底模），需下载底模；② 保底路线＝`train_guard.py` 纯 numpy 守门头，**不依赖任何下载**，秒级产出真实权重与跨年评测。两条都只用同一份零泄漏语料，产物都只是工具层候选。

## 四、十一条硬规矩

1. **语料只从 GitHub Releases 取**，保留 SHA-256 与 `MANIFEST.json` 内容版本；`ouranic.cn/terms` 第 3 条明禁训练并设索赔条款，与其 `DATASET-LICENSE` 冲突——两者必须分库、分来源标记，**不得抓页面、不得调其 API、不得用线上 AI 输出**。
2. **倪师原话正文一律剥离**，只留出处元数据（集数／时间码／书名）与脱敏骨架；古籍 Public Domain 也一并剥离，换取审计口径单一。语料里出现一句原话即判闸门失败。
3. **不许拿解读文本当 target**。数据集的 `c` 字段是他人断语库确定性输出，`DATASET-LICENSE` 自述「文本演绎…不构成预测、诊断或建议」；把它当权威标签既违约又造幻觉。
4. **合成负例必须显式标注**（`synthetic_negative`），评测单列统计；gold 全部由规则确定性生成，不许用模型生成的题考模型自己（`OB98` §2）。
5. **安全闸门优先于准确率**。`eval_train.py` 的 `safety.verdict=FAIL`（出现本人寿元／六亲存亡／绝对化措辞／他人断语）时，即使 `exact_match=1.0` 也判不合格。**禁止清单里的「本人寿元」不算越界**，评测器已做否定语境剔除。
6. **模型不许填事实（2026-11-04 实测定案）**。0.5B LoRA 实测把 `hour_index=0` 写成「戌」、把 `ming_star` 换成别的星、把书名扩写成「紫微斗数全书·卷二·八奴仆」、把 `timestamp` 编成「00:00:02」——**格式学会了，事实没学会**。因此 `chart_key / hour_index / hour_branch / ming_star / episode / timestamp / classic_books / topic_lengths` 一律由确定性工具回填，模型只负责动作与结构字段。
7. **全量数据只做结构统计与守门语料**（`TR101`）：877 万段不进 SFT；统计数字不得对外称作「模型准确率」或咨询效果；内容层固定串命中**先查语境再定性**——古籍引证里的「紫微七杀化权」是逐字可查的引文，不是四化违规。
8. **流派预设只读，判档唯一**（`TR103`）：`judging_basis` 恒锁 `score-py`；`reference_schools` 必须标「参考对照·不参与判档」；只读参考技法不派单、不出结论；成员只挂自己专长那条线。
9. **派单不许带他人结论，交叉核对须后于独立交卷**（`TR104`）：`no_peer_results=True`；`cross_check()` 检测到 `peer_results_seen` 立即 `BLOCKED`；分歧对主理人全量保留，不隐藏、不加权互证。
10. **图不许把命运量化、案例不许答对但越界**（`TR105`／`TR106`）：不许 1–100 分、OHLC、吉凶、寿元、具体应期、财富数额、疾病诊断；`evidence_valid` 与 `boundary_ok` 任一为 false 即判错，已知经历不计命中。
11. **模型输出必须逐字段对拍后才准进工具层**（`TR100` §6）：`fact_align.py` 把 gold 的确定性字段全量回填，模型自造字段丢弃并记录、输出截断不硬凑解析；全量 test 另跑 `scan` 查引文残留与越界。**禁止清单里的「本人寿元」不算越界**——禁令本身与合规声明都属否定语境，检测器须先剔除。
