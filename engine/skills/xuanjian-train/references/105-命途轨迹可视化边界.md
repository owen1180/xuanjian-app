## 一、真实读到的编码方式（可借）

`life-kline/types.ts:29-41` 按年一点：

`KLinePoint{age, year, ganZhi, daYun, open, close, high, low, score, reason, events}`；
`TimelineEvent{type, title, description, sentiment, icon, isFuture, verificationStatus}`
（`pending / verified / unverified`）；另有 `peakYears/troughYears`、`CaseHighlight`、
`AnalysisData` 各主题分。

归一化：`Math.max(1, Math.min(100, baseScore + modifiers))`、`baseScore=50`、
MA5/MA10 为 `score` 简单均值；档位 `>70 high / <40 low`（三套量表并存：
`AnalysisData.*Score` 0–10、`overall_score` 1–100、`CelebrityScores` 0–100）。

画法（`LifeKLineChart.tsx`）：Recharts `ComposedChart`，`Bar(bodyRange)` 自画影线/实体，
`close>=open` 判涨跌着色，大运用 `ReferenceArea` 交替背景 + `ReferenceLine` 分界，
极值发光、`Brush` 缩放、点击下钻月度。

**可取**：时间轴按年、大运编码成视觉层而非文字层、极值/转折结构化数组、
`verificationStatus` 支持回写、`reason` 与数值分离、下钻可读性。
**不可核实**：13 个 K 线提示词被 Base64+XOR 加密、明文不提交 Git，
OHLC/score 的生成口径不可复现、不可审计。

## 二、与本馆冲突、必须改造的四点

| life-kline 做法 | 本馆裁决 |
|---|---|
| 命运量化成 1–100 分并贴「吉/凶」「牛市/熊市」 | **剔除**；本馆只用「倾向、常见、容易、建议关注」 |
| `cryptoYear` 暴富流年、`sudden_downfall`、`healthBodyParts` | **剔除**；涉及具体事件/身体/意外断言，**本人终点永不可断** |
| OHLC/score 由加密 LLM 提示词生成 | **剔除**；改为确定性结构事实 + 可引证规则，或明确标「示意值/文化参考」 |
| 三套量表并存 | **冻结单一口径**：用／喜／忌／病／平五类运段（用忌神落地） |

## 三、本馆实现（`mingtu_kline.py`）

输入每年一点：`{age, year, ganzhi, dayun, band, tendency, reason, source_ref, events[]}`，
其中 `band ∈ {用神运, 喜神运, 忌神运, 病神运, 平运}`。

- **不打分、不画 K 线、不算均线、不判吉凶**：纵轴是运段类别，不是数值。
- 大运分区背景 + 分界竖线保留；**转折年**只标「运段切换」，不写「大吉/大凶」。
- 每点 `reason` 与 `source_ref` 分离：数值结构可复算、文本可引证。
- 事件三态 `● 已核验 / ○ 待核验 / × 未证实`，直接对接 `TR106` 的修正案例库回写。
- 输出**自包含静态 SVG**（无外部依赖、无脚本、可归档），浅底深字。
- 输入闸门机械拒绝：`score/open/close/high/low/overall_score/healthBodyParts/cryptoYear`
  字段、绝对化措辞、寿元表述、缺 `source_ref`、非倾向措辞、非法验证状态。

```bash
python3 mingtu_kline.py demo --out mingtu_demo.svg
python3 mingtu_kline.py render --input <json> --out <svg>
python3 mingtu_kline.py --selftest       # 19/19
```

## 四、硬规矩（新增，定案级）

1. **可视化不得把命运量化成分数或吉凶标签**；只表达阶段倾向与转折。
2. **每个点必须有出处**；没有 `source_ref` 不给渲染。
3. **不许出现本人寿元、死亡、具体应期、财富数额、疾病诊断**。
4. 图表标题／图注必须写明「仅供文化研究与阶段回顾，不代表咨询效果」。
5. 图是**表达层**，不是第十二位成员；不得由图反推断语、不得替成员改结论。
