# 118 · 判据要能承受到「错了会放过什么」

> 承接 `TR117`（引证上闸）。那一轮把引证库接进闸门，四条判据上线。
> 本轮做的是**回头量它到底误杀多少**——结果是 86%，这个闸门差点把正常引用全拦掉。

## 一、一个「合理」判据，实测误杀 86%

`TR117` 的判据是：草稿出现《书名》，引证库里查不到 → error。

听起来天经地义。实测：从册页与规格册里抽出真实出现过的书名 **204 个**，
拿引证库（358 种）去对——**176 个查不到，占 86%**。

查不到的都是什么：

```
撼龙经 青囊经 催官篇 疑龙经 赤霆经 青乌经 雪心赋 地理五诀
协纪辨方书 钦定协纪辨方书 三命通会 滴天髓 渊海子平 穷通宝鉴
月波洞中记 玉管照神局 太清神鉴 麻衣神相 相理衡真 罗经透解 …
```

**这些是真古籍。** 引证库只覆盖网盘里那五类语料——我们根本没有它们的电子本，
所以它们永远进不了引证库。**判据把「本馆没有这本书」当成了「这本书不存在」。**

> 一个判据写下去之前，要先问：**它错了会放过什么、会误杀什么。**
> 「查不到就报错」在「查不到 86%」的现实面前，不是一个判据，是一堵墙。

## 二、扩类只解决一小半

先把引证库从「只收倪师书系一类」扩到「全库五类」，358 → **1,532 种**。
误拦只从 86% 降到 78%。

因为册页引的古籍**从来不在**网盘里——扩类补的是「中医电子书／曾仕强／命理课程」
这几类，跟古籍无关。**扩类是对的，但它不是这个问题的解。**

## 三、真正的解：把「《》里装的东西」分开

`《》` 里并不都是书。实测那 160 个名字里至少有五种：

| 类别 | 例子 | 处置 |
|---|---|---|
| 典籍 | 《撼龙经》《滴天髓》《协纪辨方书》 | 允许引用；本馆无电子本，**引原文不可反查**，要篇／卷 |
| 丛书 | 《四库全书》《正统道藏》《续修四库全书》 | 同上 |
| 篇名／卦名 | 《乾为天》《系辞上》《素问·脉要精微论》 | 同上 |
| 非书 | 《满城尽带黄金甲》《红番区》《神奇燕尾服》 | 不按书判（梦里出现片名不是引书） |
| 馆内文件 | 《档案卡片》《命主记录》《分析记录》 | 不按书判 |

于是加一层 **书目白名单**（`命理档案/引证库/书目白名单.json`，195 条）：

- 种子只从**册页里出现过**的书名取——不从外部凑。凑出来的书单没人核过，比没有更危险；
- 分类**人工可改，重跑不覆盖**（`建白名单` 保留已有条目的分类）；
- 判据变成三段：引证库 → 白名单 → 才 `CITATION_UNKNOWN`。

改完误拦 **86% → 0%**（204 个书名：引证库命中 44、白名单典籍类放行 146、
白名单非书类跳过 14、两处都无 0）。

**关键取舍**：白名单里的典籍，引原文只报 `CITATION_CLASSIC_UNVERIFIED`（warning），
**不报 error**。理由：报 error 会逼人删掉正经的古籍引用——为了防假引文，把真引用也删了，
那是更坏的交换。

## 四、又一类「看着有字、其实是垃圾」

定版时逐字看《零起点学中医》的两版，发现 PDF 版正文长这样：

```
/G3C/G3D/G95/G40/G9D/G39
/GE5/GE8
```

**86.5% 是 CID 码**——PDF 内嵌字体没有 ToUnicode 映射，解出来就是这些。
而它一直挂在「可逐字引」档上：字数 61,530，看着像本书，**引它等于引垃圾，
闸门还会说「可引」**。

加了 `乱码` 档：`/G[0-9A-F]{2}` 与 Unicode 私有区字符占比超 20% 即判乱码、不可引。
全库扫出 12 份超 2%，其中 1 份超 20%（就是它）。

> 一类是「字数够、格式对、内容全错」。这和采集那次「196 页扫描本抽出 69 个页码字」
> （`TR115`）是同一型：**判据落在「有没有内容」，不落在「内容对不对」。**

## 五、行号校验：从「给了没有」到「给的对不对」

上一轮只查「引原文有没有给 `#L行号`」。本轮补上：按行号去产物里回读，核那句话在不在那一带。

| 结论 | 依据 | 级别 |
|---|---|---|
| 对 | 引文最长连续汉字（≥8）出现在该行 ±2 行内 | 放行 |
| 不符 | 找不到 | `CITATION_LOCATOR_MISMATCH`（error） |
| 读不到 | 产物不在盘上／行号越界 | `CITATION_LOCATOR_UNREADABLE`（warning） |

三个设计细节：

1. **带 ±2 行上下文**。语料按 30 字左右硬换行，一句话常被拆两三行，只看单行会大面积误报。
2. **取最长连续汉字做键**（≥8），标点、书名号、括注都不影响比对；**不足 8 字不比**，
   否则「短句六字」这种会天天误报。
3. **校验对象要挑对版本**。同名两版都标「可逐字引」时，原先取列表第一个——
   可能正好是乱码版或插空格版。现在优先 `取舍=首选`（见 `待定版清单`）。

真库验证（《神农本草》第 44,184 行「石恶盐水，其色真珠光色如云母，可折者良。又名朱砂。」）：

```
行号对      → 放行
行号错 50 行 → CITATION_LOCATOR_MISMATCH
没给行号    → CITATION_NO_LOCATOR
```

## 六、本轮四次「测试是空的」

这一节比上面五节都重要。四次都是**看着绿、其实没测**：

| # | 情形 | 怎么发现的 |
|---|---|---|
| 1 | 用 `s.replace(old, new)` 改代码，原文没命中，**静默什么都没改** | 自检仍全绿，但新判据一条都没生效（5 条用例全红才暴露） |
| 2 | 「引文太短不做比对」用例用了 4 字引文 | `QUOTED_RE` 要求 ≥6 字，**引文根本没被识别**，用例恒真 |
| 3 | 改成 5 字再试，仍然恒真 | 5 < 6，还是进不去。数汉字要数准 |
| 4 | `标取舍` 用了 `汉字片`，而 `quote_index.py` 里没这个函数 | 只在真数据（取舍表非空）时才炸；自检里取舍表为空，走不到 |

四条同一型：**代码没跑到，测试却报绿。** 收口做法：

- **改代码必须 `assert 原串 in s`**，不许裸 `replace`（本轮第 1 条就是这么发现的）；
- **用例要能证伪**：写完反问「把实现改坏，这条会红吗」，红不了就是空用例；
- **变异测试查漏**：本轮 `最长键` 阈值改 1 应红而没红 —— 才挖出第 2、3 条。

## 八、硬约束（不许改）

1. **判据错了会放过什么、会误杀什么，写下来再上闸。**
2. **引证库只收采集语料，古籍另立白名单**；两者都不在才判未知。
3. **白名单只从册页已引书名取种子**，不从外部凑。
4. **白名单分类人工可改，重跑不覆盖。**
5. **古籍引原文只警告、不拦**——防假引文不能靠删真引用。
6. **乱码档不可引**：字数够不等于内容对。
7. **校验行号要挑「首选」那版**，否则核的是错文件。
8. **改代码必断言命中；用例必能证伪。**
