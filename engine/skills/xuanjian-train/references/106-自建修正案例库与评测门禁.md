## 三、本馆独占的双门禁（开源侧都没有）

`casebook.py` 在单字母精确匹配之外，加两道布尔门禁：

- `evidence_valid`：引文必须随包可查（`quote / locator / verification` 齐全）；
- `boundary_ok`：题目、选项、回答文本不得触碰 `forbidden_outputs`。

**任一为 false 即判错**——避免「答对但越界」。
再加两条：`known_before=True` 的已知经历**不计命中**；
`status ∈ {case_only, disputed}` 或 `evidence_grade ∈ {B,C}` 或 `engineering_only`
一律**不进生产**（只留候选与 metadata）。

评分输出：`overall_accuracy / exact_match_rate / boundary_failures /
evidence_failures / category_stats / logs`，并附「测的是评测闭环与守门，
不是命理断得准不准」。

## 四、硬规矩（新增，定案级）

1. **不把开源题目／命例答案直接当本馆结论**；题目只作分类与结构参考。
2. **引证不可查即判错**，即使答案字母碰对。
3. **越界即判错**，即使答案字母碰对；健康、灾劫、官非类题目仅作历史语境与文化研究。
4. **已知经历不计命中**；用户纠正时保留原判断和修订理由。
5. **分歧分别说明、全量保留**，不加权互证、不替成员抹平。
6. **本人终点永不可断**，且不得出现在案例库的任何可输出字段里。

## 五、用法

```bash
python3 casebook.py validate --input case.json
python3 casebook.py evaluate --cases cases.jsonl --predictions preds.json --report report.json
python3 casebook.py --selftest      # 23/23
```
