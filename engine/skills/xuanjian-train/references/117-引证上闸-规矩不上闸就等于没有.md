## 二、四条判据，方向都是「不许编」

| 判据 | 触发 | 级别 |
|---|---|---|
| `CITATION_UNKNOWN` | 出现《书名》，引证库里查不到 | error |
| `CITATION_INVENTED` | 该版是「仅指认／近空／散图」，却出现引号内原文 | error |
| `CITATION_NO_LOCATOR` | 可逐字引、确实引了原文，却没给 `#L行号`／页号／册号 | error |
| `CITATION_AMBIGUOUS` | 同名多版本、档位不同 | warning |

### 2.1 为什么不管「只提书名」

第一版设计时想过：凡出现《书名》就要求给定位。试跑立刻发现会把正常行文全拦掉——
「《针灸大成》讲过这个取穴思路」是**叙述**，不是引文。

**判据要落在「引号内的内容」上**，不是落在书名号上。所以：
- 只提书名、没有引号 → 放行（提一本书不需要定位）；
- 有引号内原文 → 受 ②③ 约束（这才是「引」）。

这一条与 `TR116` 的四档是配套的：档位回答「这本书有没有原文」，
判据回答「有了原文你有没有给出处」。

### 2.2 为什么「索引找不到」只给 warning

闸门要能在没有库的环境里跑（另一台机器、CI）。但**不能静默跳过**——
「草稿引了书名却没库可核」必须出一条 `NO_QUOTE_INDEX`。
这与 v1.58「红线挂召回」是同一课：**没跑 ≠ 通过。**

## 三、最值钱的一条：没跑到就等于没测

这个函数第一版改完，藏着一个 `NameError`：

```python
for 名 in [x[0] for x in 书名们]:      # 循环变量从「行」换成了「名」
    ...
    引文 = [q for q in QUOTED_RE.findall(行)]   # ← 行 已经不存在了
```

**而自检 11/11 全绿。** 因为旧自检的合规草稿只引了《天纪》，
那是课程语料，在 `continue` 处就跳走了——**这整段代码从未被执行过一次。**

发现方式不是自检，是我手动拿真引证库跑了一遍。这说明两件事：

1. **自检要覆盖分支，不是覆盖函数名。** 「`source_gate` 有自检」不等于
   「`核对引证` 被测过」；
2. **变异测试只能证明「测到的部分灵敏」，证明不了「没测的部分不存在」。**
   补测试时要问的不是「再加哪条断言」，而是「**哪条分支还没走过**」。

现在每条判据都有独立用例（16 条），另做 7 组变异。

## 四、两处实现细节

### 4.1 书名号会嵌套，正则不行

库里有一批卡片书名自带书名号：`倪海厦《神农本草》(神州医料库）`。
`《([^》]{2,40})》` 遇到 `《倪海厦《神农本草》…》` 只能截到 `倪海厦《神农本草`，
名字被切断，匹配和报错都指错地方。

改成栈式扫描取**最外层**：

```python
for i, ch in enumerate(text):
    if ch == "《": 栈.append(i)
    elif ch == "》" and 栈:
        s = 栈.pop()
        if not 栈: 出.append((text[s+1:i], s, i+1))
```

### 4.2 全等优先于包含

草稿写《神农本草》，库里叫「倪海厦《神农本草》(神州医料库）」——全等永远对不上，
所以要允许包含匹配。但**有全等键时必须只认它**：

「双版丁」与「双版丁扫描本」在库里是两本书，草稿写前者就该按前者算，
不该因为后者也叫这名而报歧义。

## 六、硬约束（不许改）

1. **引了书名就要能核**：查不到 → error，不许凭记忆引。
2. **没 OCR 的版不许出现引号内原文**：只能「据该书有此说」。
3. **引原文必须给定位**（`#L行号`／页号／册号），否则反查不回来。
4. **只提书名不受约束**——否则正常行文全被拦。
5. **课程语料（天纪／人纪／地纪）不按书核**，按集数+分秒核。
6. **索引缺失只警告，不静默。**
7. **新判据必须走遍分支**，不能只让函数被调用一次。
