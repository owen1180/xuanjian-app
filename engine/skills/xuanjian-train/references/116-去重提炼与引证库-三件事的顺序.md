# 116 · 三件事的顺序：去重、提炼、入引证库

> 承接 `TR115`（外接盘采集 1,297 份）。本册记三件后续：**去重怎么判**、
> **提炼到哪一层为止**、**整本书该去哪**。三件事都要回答同一个问题：
> 什么样的合并／入池／入册，代价是**永久丢内容**，而当场看不出来。

## 一、去重：能证明是同一份才合，只是像的不许合

外接盘 1,297 份里同名文件 116 组、388 份。《第47课 实践总结》在五个班级目录各一份，
内容一字不差。不去重的后果不只是白做五遍——**重复会被当成「多来源印证」**，
而本馆立新概念要求「≥2 个独立来源」，这条规矩当场失效。

### 1.1 两个键，各管一件事

| 键 | 管什么 | 地位 |
|---|---|---|
| 首段哈希（归一比后前 200 字） | 「这份是不是同一文」 | **主键**，去重靠它 |
| 书名（去副本号后归一） | 「这个题目有没有多个不同内容」 | **报警器**，不承担合并 |

### 1.2 四型

| 型 | 判据 | 处置 |
|---|---|---|
| `dup` | 同内容 + 同名 | 留一份，其余记别名 |
| `rename` | 同内容 + 异名 | 留一份，其余记别名 |
| `same_name_diff` | 同名 + 内容不同 | **全留**，单列待看 |
| `unique` | 独一无二 | 全留 |

实跑：**1,297 → 973 组，可省 324 份**（`dup` 95／`rename` 42）；同名异文 9 组，
全留；近文 2 对，未合并。

### 1.3 为什么「近似」只报不并（这条是踩出来的）

第一版加过一型 `near_dup`：同名、四元组重叠 ≥0.90、字数差 ≤25% 就合并。
跑真数据当场误合两份——

```
倪醫師病案紀錄 (229)   509 字        重叠 0.948
倪醫師病案紀錄 (230)   460 字
```

它们是**同一病人同日两诊**（184-1／184-2，3/11/2008），230 那张方多出
白芍五钱、丹皮三钱、补骨脂三钱、泽泻五钱、黄柏——**并掉就等于丢一张方**。
而病案这一整类（346 份）全是同一个模板开头，重叠天然很高。

> **判据要能承受到「错的代价是永久丢内容」，就不能用相似度。**

改成：只报不并，列出 `近文` 名单（近似度、两份字数）让人看。同一批的另一对
`倪海厦-人纪-黄帝内经`（146,596 字 / 168,074 字，重叠 0.997）同理——两份差 2.1 万字，
更不可能是重复。

### 1.4 归一要加强，不靠相似度兜

`打分方法` 有 7 份 1,075 字、1 份 1,211 字，首段哈希判成「两个内容」。
逐行看下去差别只是排版：一版 `- ` 列表、一版自动编号 `1 .`。
这是**归一不够狠**，不是需要相似度。

`归一比`（比对专用，不动 `归一`——`归一` 还要数字数、算书名）依次剥：

1. 行尾编号 `甲辰柱，甲木 36 分不变 1 .`（思维导图导出常见）
2. 行首列表标记 `- `／`* `／`1. `／`一、`
3. 半角标点

**边界（如实记）**：剥不掉「无空格粘连的行尾编号」——`1.2.1` 被导出成 `121`，
粘在正文末尾（`受盖头影响在3036分左右121`）。它与真数值无法区分，硬剥会伤真数据。
所以那两份仍判「两个内容」，都保留、都进提炼——**宁可重复一遍，不可错合一次**。

## 二、采集撞名：8 组 16 个源互相覆盖（`TR115` 的遗留）

`harvest.py` 原命名规则是「目录 + 去扩展名文件名 + `.md`」。于是：

```
打分方法.pdf   → 十字纹四柱理学2021/打分方法.md
打分方法.xmind → 十字纹四柱理学2021/打分方法.md    ← 盖掉前者
```

账上两条都记 `ok`、字数各是各的，**盘上只剩一份**。实测 8 组 16 个源：
伤寒论／神农本草经／针灸教程（`.doc` vs `.txt`）、零起点学中医（`.pdf` vs `.txt`）、
打分方法 ×3 处（`.pdf` vs `.xmind`）、打分（`.docx` vs `.xlsx`）。

处置：
- `定出()`：目标已存在且首部 `源：` 不是本文件，就加 `__扩展名`；
- `修撞名`：把已撞车的组按源各存一份，**全部重取成功才删那份有歧义的**；
- 重取后：伤寒论 .doc 143,969／.txt 144,299；零起点 .pdf 53,250／.txt 78,849
  ——**PDF 那版少 2.5 万字**，之前看的是哪一版根本不知道。

| 规程 × NEW | 4,283 | **不入池**，只存存量 |

`distill.py 合并` 把 `filtered_out` 写进产物——**挡下不是丢弃，是「不立提案」，要报数**。

### 3.1 为什么 4,283 条「新规程」也不入池

抽查「含新术语」的 119 条，所谓新术语是：

```
午亥 22、庚乙 12、子亥 12、辰未 9、癸卯 8、癸未 8、午丑 8、申亥 6…
```

**全是干支组合**，一个真概念都没有（唯一像的是「土多金埋」，而它本来就在概念表里）。
说明这 4,283 条绝大多数是**已有概念换个说法又说一遍**，不是新知识。
剩下的 4,164 条「术语全在库中」，更明确是复述。

> 判据不能只看「库里查不到」——查不到的原因可能是**换了词**，不是**换了事**。

### 3.2 指纹在这里救了命

上一轮（`TR113` §六·补）把提案 id 从位置号换成内容指纹 `D-<md5前8>`。
这次池子从 223 涨到 486，位置号会全体错位；指纹不动——
`ruling.py 核对`：**63 条裁决，错位 0 条**。

## 四、引证库：整本书不拆句进册页

### 4.1 为什么不能拆

册页（`xuanjian-kb/references/`）每条是「可复用、可裁、能归到某个十神／关系」的规则句。
整本书不是规则集合。拆了有三个后果：

1. **定位失效**——册页靠 `簿号#L行号` 定位，句子一散，`verify_quotes.py` 查不回原处；
2. **语境丢失**——「脉浮者，病在表」离了上下文就不是那个意思，而册页要拿去做断语依据；
3. **裁决淹死**——一本 60 万字的书能抽上万句，册页只有 99 册，99% 会被驳回。

所以整本书的位置是**引证库**：书在库里、卡片在索引里、引用时按 `书名 + 段号` 回查。

### 4.2 可引性四档（本册最要紧的一张表）

| 档 | 判据 | 能做什么 |
|---|---|---|
| `可逐字引` | 有文字层且正文 ≥500 字 | 可引原文，须附「书名 + `#L行号`」，可反查 |
| `仅指认` | 扫描件无文字层（需 OCR） | 只说「据《书名》有此说」，**不许出现引号内原文** |
| `近空` | 有页码层但正文近乎为零 | 同「仅指认」 |
| `散图` | 单张 .jpg／.bmp／.png | **不成书，不立书卡** |

实跑（倪师书系 358 份）：**可逐字引 237／仅指认 16／近空 24／散图 81**；
册页已引 21 种（判据：书名取汉字前 8 字，在册库全文中出现）。

**第二档不是保守，是必需**：扫描件没 OCR 就没原文，
「据《神农本草》第 88 页云……」在没看见那页之前就是编的。

### 4.3 两个当场抓到的假信号

- **纯数字题名撞键**：`1-14` 去掉题名号仍是 `1-14`，撞上正文任一处「1-14」，
  被判「册页已引」。改：只取汉字做键，少于 4 个汉字不判。
- **散图混进书卡**：81 张单页图文件名是 `10`、`11`、`12`，
  放进「仅指认」会让索引冒出几百个书名是数字的条目，把真书淹没。
  改：按扩展名先判 `散图`，不立书卡。
