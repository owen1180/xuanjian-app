# 六、风险分级与效果边界

> **本册是"可用"的前提。**
> 改运、科仪、符咒能做成数据技能，靠的不是胆子大，是**分级清楚、话说得准、责任划得开**。
> **一条总纲**：**能做的做到底，不能做的一步不越，越界的代价要先让客户知道。**

## 1. 四档分级（全技能的闸门）

| 档 | 定义 | 本馆做什么 | 不做什么 | 典型 |
|---|---|---|---|---|
| **甲** | 民俗通行、无效果承诺、低花费、不伤人 | 可建议、可帮安排、可陪同 | 不承诺效果、不按"灵验度"加价 | 安太岁、拜斗、点灯、净宅、谢土、祭祖、超度、拜忏 |
| **乙** | 有争议、需师承、花费大、易被包装 | 讲清条件与风险，**转介有师承者** | **不代做、不评估效果、不按数额报价** | 还阴债、补财库、送替身、开光、和合（双方知情）、禳星、安神位 |
| **丙** | 涉操控他人、涉伤害、伦理有问题 | **只解释源流与风险** | **不给做法、不评估、不转介** | 五鬼运财、锁心、迷魂、强制和合、诅咒、降头、蛊、拆散、借寿 |
| **丁** | 违法或伤害特定人 | **立即停止，必要时提示报警** | 一切 | 针对第三人、未成年人、许诺治病、包治包好、涉诈骗 |

### 1.1 为什么丙档"不转介"

转介等于参与。
客户要"锁住对方""让他回心转意"，这不是信仰需求，是控制欲。给做法、给师承、给渠道，都是帮凶。

**话术**：**"这一类我不做，也不介绍人做。原因不是它不灵，是它把另一个人当成了物件。"**

### 1.2 为什么乙档"不评估效果"

评估效果就要给判断（"这个做了会好"），一给判断就变成承诺。
乙档能做的是：**讲清它是什么、出哪本书、大概花多少、有什么风险、该问对方哪几句**。剩下的交给客户与道长。

## 2. 效果声明：三句必带，一句可选

任何一份涉及改运、科仪、符咒的方案，末尾必须带这三句：

```
一、以上为传统术数文化分析与民俗整理，供参考。
二、本馆不承诺任何效果，不替代医疗、法律、投资决策。
三、涉及身体不适，请及时就医。
```

可选第四句（凡涉转介必带）：

```
四、本馆不代收法事费用、不抽成、不指定合作方；转介仅供你自行判断。
```

> **不许改写成"心诚则灵""信则有"**——这类话看似谦虚，实则是把责任推给客户的"诚"。

## 3. 五条法律红线（保护馆主，不是吓唬）

| 红线 | 触犯形态 | 后果 | 本馆怎么防 |
|---|---|---|---|
| **诈骗** | 虚构"你被下咒／欠阴债百万贯"，据此收费 | 刑事 | 不虚构事实、不按数额收费、不承诺效果 |
| **非法行医** | 以符咒、法事"治病"并收费 | 刑事 | 医治类只作民俗记录，一律先转就医 |
| **精神控制／强制** | 锁心、迷魂、情降，针对特定人 | 民事至刑事 | 丙档一律拒绝，不转介 |
| **侵犯隐私** | 泄露客户生辰、病历、家庭情况 | 民事 | 建档脱敏，案例去标识（`40`） |
| **借宗教名义敛财** | 假冒宗教教职人员、私设道场收费 | 行政处罚至刑事 | 不冒充道长、不私设道场、不代收 |

> **一句话**：**这五条里，前三条靠"不承诺"就能避开大半，后两条靠"不代收、不冒名"。**

## 4. 收费伦理

| 规矩 | 具体 |
|---|---|
| **不代收** | 法事费用由客户直接付给道观／道长，本馆不经手 |
| **不抽成** | 转介不拿回扣；拿了就是利益冲突，断语不再独立 |
| **不指定** | 不说"只找我认识的那位"；客户自己找，本馆教他怎么问（`02` §4 七问） |
| **不按效果定价** | 不搞"灵了再付""不灵退款" |
| **不按数额定价** | 不查"欠多少"、不算"几颗凶星"、不按"几品超度"分级 |
| **先报价后做事** | 本馆自己的咨询费一次说清，不中途追加 |

## 5. 四类特殊情形：不接、缓接、转接

| 情形 | 识别信号 | 处理 |
|---|---|---|
| **精神疾病** | 幻听、被害妄想、"有人要害我"、长期失眠伴妄想 | **不接术数**。先转精神科；可说"这不是命的问题，是需要医生看的问题" |
| **未成年人** | 未满十八 | **只与监护人谈**；不做任何术数与科仪；只给"家长该做什么" |
| **重大疾病** | 癌症、心脑血管、术后 | 先就医；科仪只作心理支持；**不许建议停药、不许说"这是业障"** |
| **涉诉／涉刑** | 正在打官司、被调查 | 只讲走势与人事；**不承诺胜负**；建议找律师 |

> **精神疾病这一条最要紧**：把幻觉当"看到东西"，再卖"驱邪"，是把病人往深渊推。**遇到就停，不留余地。**

## 6. 记录与留痕

| 记什么 | 为什么 | 存哪 |
|---|---|---|
| 方案副本 | 客户事后说"你让我做的" | 交客户一份，本馆留一份 |
| 转介记录 | 谁、何时、说了什么、客户自己去的 | 档案附页 |
| 不承诺的话 | "我说过不承诺效果" | 方案末尾固定三句 |
| 客户原话（审名） | "他说财运差，具体是收入降了" | 档案（`72` §2） |
| 特殊情形处置 | 转精神科、转律师、报警 | 档案附页，注明时间 |

> **留痕不是防客户，是保护双方**。真出了纠纷，一份写清"不承诺"的方案，比一百句解释有用。

## 7. 一张速查表（落笔前扫一眼）

```
□ 这一条属甲／乙／丙／丁？丙丁有没有混进方案？
□ 有没有承诺效果？（"做了就好""包好""必灵"——一个字都不许有）
□ 有没有按数额／颗数／品级定价？
□ 有没有针对第三人？
□ 涉医的有没有先转就医？有没有建议停药？
□ 涉未成年人的有没有只与监护人谈？
□ 末尾三句声明在不在？
□ 转介有没有抽成、有没有指定？
```

> **八项过完再交付。** 过不了的，改；改不了的，停。

## 8. 收口

> **这一册不是限制，是营业执照。**
> 没有分级的"什么都能做"，做不长久；有分级的"知道什么不做"，才敢接活。
> **把边界讲清楚的人，客户才敢把事交给他。**
