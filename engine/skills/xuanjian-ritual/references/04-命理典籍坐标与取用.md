# 四、命理典籍坐标与取用

> **本册位置**：`01`–`03` 是本馆自己的打分法与断语体系，`37`–`59` 是各项专项断法。本册补的是**古书坐标**——哪本书讲什么、能用它做什么、不能用它做什么。
> **一句话**：**古书是参照系，不是判决书。**

## 1. 子平六书（按地位排）

| 书 | 作者·朝代 | 特点 | 本馆怎么用 | 可用度 |
|---|---|---|---|---|
| **渊海子平** | 宋·徐大升辑 | 子平术最早的系统汇编；十神、格局、神煞俱全，体例未纯 | 查术语来源、查神煞出处 | 充分 |
| **三命通会** | 明·万民英 | 十二卷集大成；搜罗最全，也最杂 | 查冷门断法与古例；**不整段照搬** | 充分 |
| **神峰通考** | 明·张楠 | "病药说"——先找病，再下药；猛烈批判神煞 | 校正"见煞即凶"的毛病 | 充分 |

**一句分工**：
- 判**旺衰** → 本馆打分法（`01`／`41`），古书只作校准；
- 判**格局** → 子平真诠；
- 判**调候** → 穷通宝鉴；
- 判**气象流通** → 滴天髓；
- 查**术语与古例** → 三命通会、渊海子平；
- 防**神煞迷信** → 神峰通考。

## 2. 本馆打分法与古法的关系（这一节最要紧）

**两套不是一回事，混用即错。**

| | 古法（子平等） | 本馆打分法 |
|---|---|---|
| 起点 | 月令 | 日元 |
| 判强弱 | 得令、得地、得势，靠"感觉＋经验" | 组合基准分＋生克加减＋根气折损，出数字 |
| 分档 | 身强／身弱／中和（粗） | 七档（`43`），中和档还要校对 |
| 取用 | 格局用神／调候用神／扶抑用神，三法并用 | 以扶抑为主，调候为辅，格局定层次 |
| 断语 | 直接给结论（"必主大贵"） | 给封顶（"这盘能断到哪一级"，`39`） |

**三条合用的规矩**：

1. **结论可以互相印证，依据不许互相替代。**
   古书说"身弱"，本馆说"八十一分偏弱"——结论一致，但你不能拿"古书说身弱"当分数依据，也不能拿分数去反驳古书的格局判断。
2. **古书断语必须转译。**
   "身弱财旺，富屋贫人"——不可原话出口；应转成"财星有力而日元承不住，进项大、留存难"。
3. **古书的分歧要摊开说。**
   同一盘，神峰通考重病药、子平真诠重格局，结论可能不同。**两说并写，标"古法分歧"，不许挑一个顺耳的说。**

## 3. 星命（七政四余）为什么不取

- **另一套盘**：七政（日月五星）＋四余（罗睺、计都、月孛、紫气），按黄道十二宫排，与子平的干支系统**完全不同源**。
- **代表作**：《张果星宗》《星学大成》《星命总括》《星命溯源》。
- **本馆态度**：**只考源，不排盘、不断事。** 原因：无可靠师承、无校准样本、现代软件排法分歧大。
- **对外表述**：**"七政四余是另一套体系，本馆不排。有人说它能断命，我不评价，但我不用它给你下结论。"**

## 5. 读古书三条纪律

### 一、不混体系

子平、星命、紫微、六壬、奇门，各有各的盘、各有各的用神。**混着断，必出矛盾。**
本馆的规矩：**一次只用一套主体系，其余作交叉提示，分歧讲给客户听**（`14` 铁律二）。

### 二、不照搬断语

古书断语多为极端表述，且有其时代语境：

| 古书原话 | 不许原样出口 | 转译 |
|---|---|---|
| "必主大贵" | ✗ | "这盘有做大的可能，但要看运与格局配合" |
| "克妻三重" | ✗ | "婚缘宜迟，早成易散" |
| "富屋贫人" | ✗ | "进项大、留存难" |
| "一生孤苦" | ✗ | "六亲缘薄，宜自建支持系统" |

> 转译规则见 `57`（禁词）与 `66`（安全表述）。

### 三、注意版本

- **四库本与坊刻本**：四库本经馆臣删改，坊刻本多有增补，同一句可能不同。
- **注本差异**：任铁樵注《滴天髓》与徐乐吾注，取向不同。
- **托名与真伪**：《太清神鉴》四库提要已明言"其为依托无疑"；《冰鉴》是后人辑曾国藩语录成书。
- **本馆引用规矩**：能说清版本就说，说不清就说"旧题某某"，**不许假装见过善本**。

## 6. 一条实用索引（客户问"该看哪本书"）

| 客户想干什么 | 推荐 | 提醒 |
|---|---|---|
| 想学八字入门 | 命理探源 → 子平真诠 | 先学规则，别先学断语 |
| 想搞懂自己为什么弱 | 滴天髓（气象）＋本馆打分报告 | 古书不告诉你分数 |
| 想查某个神煞 | 三命通会 | 查到不等于要用（`45` §4） |
| 想研究调候 | 穷通宝鉴 | 调候是参考，不是唯一 |
| 想看命理史 | 李虚中命书 → 渊海子平 → 三命通会 | 看清"从年到日"的演变 |
| 想学七政四余 | 张果星宗 | **本馆不教、不排、不评** |

## 7. 收口

> **古书给我们两样东西：一套语言，一堆案例。**
> 语言可以用，案例可以看，**结论不能照抄**。
> 命理这一行最容易犯的错，不是不读书，是**读了书就把书上的话当自己的判断**。
