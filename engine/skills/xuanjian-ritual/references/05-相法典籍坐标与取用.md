# 五、相法典籍坐标与取用

> **本册位置**：`04`–`06` 是本馆手相与面相的体例，`29` 是手诊（看身体），本册补**古书坐标与谱系**。
> **一句话**：相法书很多，能用的很少；**能用的是"怎么看"，不是"看出什么"**。

## 1. 相法谱系（据《公笃相法》）

《公笃相法》开篇自述源流：

> "查相术始于轩辕，为风后氏立法，故名风鉴……五代达摩复入中国，始立五来相法。麻衣宗之，希夷继之，以及柳庄、水镜、衡真、铁关刀、大清鉴等，先后共七十余家，各有见解之不同，而亦有偏陋之拘执。"

**谱系图**（本馆整理）：

```
风后（托）→ 唐举、许负（托）→ 管辂（托）
　→ 五代·达摩"五来相法"
　　→ 麻衣道者（《麻衣相法》）
　　　→ 陈抟（希夷，《心相篇》）
　　　　→ 明·袁珙（柳庄）→ 袁忠彻（《神相全编》）
　　　　→ 水镜（《水镜集》）
　　　　→ 衡真（《相理衡真》）
　　　　→ 铁关刀（《神相铁关刀》）
　　　　→ 大清鉴（《太清神鉴》一系）
```

> **七十余家，各有偏执**——这句话本身就是最重要的方法论：**没有一本相书是全对的。**

## 2. 五本主力（按可用度）

| 书 | 作者·朝代 | 特点 | 本馆怎么用 | 可用度 |
|---|---|---|---|---|
| **太清神鉴** | 旧题后周·王朴（四库考为宋人依托） | 六卷，论形神气色声行坐卧；体系最完整 | 讲"神气为先"；**引时须标依托** | 充分 |
| **神相全编** | 明·袁忠彻 | 相法汇编，最全；十二宫、五官、流年齐备 | 查部位与流年；**不全信其断语** | 充分 |
| **公笃相法** | 民国·陈公笃 | 重实证、重"相不独论"；批判迷信 | **方法论主力**：怎么看不误判 | 充分 |
| **柳庄相法** | 明·袁珙 | 重形神气色，简明 | 入门与快速判断 | 有限 |
| **神相铁关刀** | 清（托） | 重部位与流年，条目化 | 查具体部位 | 有限 |

**其余**（《鬼谷子神奇相法全书》《许负相法》《月波洞中记》《玉管照神局》《冰鉴》《心相篇》）：
- 《玉管照神局》南唐·宋齐丘，体系较古，可作参照；
- 《冰鉴》是后人辑曾国藩语，非曾亲著，**引时须说明**；
- 《心相篇》宋·陈抟，讲"心相"多于"形相"，属义理层；
- 托名鬼谷子、许负、月波者，**只考源**。

## 3. 相法十二宫 ≠ 紫微十二宫（最容易混的一处）

**两套东西，名字像，内容完全不同。**

| 相法十二宫（面部） | 位置 | 紫微十二宫（命盘） |
|---|---|---|
| 命宫 | 印堂至山根 | 命宫（按生时定） |
| 财帛 | 鼻头、鼻翼 | 财帛宫（按宫位排） |
| 兄弟 | 两眉 | 兄弟宫 |
| 田宅 | 眼睑、泪堂 | 田宅宫 |
| 男女 | 泪堂下方 | 子女宫 |
| 奴仆 | 地阁两傍 | 仆役宫 |
| 妻妾 | 眼尾 | 夫妻宫 |
| 疾厄 | 山根 | 疾厄宫 |
| 迁移 | 天仓、边地 | 迁移宫 |
| 官禄 | 中正 | 官禄宫 |
| 福德 | 天仓、地库 | 福德宫 |
| 相貌 | 全部 | 相貌宫（父母宫） |

> **铁律**：**看脸用相法十二宫，看盘用紫微十二宫，两者不许互相解释。**
> 常见错误："你财帛宫有痣，所以紫微财帛宫也破"——这是把两套系统硬接，**不成立**。

## 4. 相法能看什么、不能看什么

| 能看 | 怎么用 | 不能看 | 为什么 |
|---|---|---|---|
| 性格倾向 | 形、神、声、行 | 具体经历 | 相不载事 |
| 健康倾向 | 气色、部位、掌纹 | 具体病名 | 属医生；只转"查什么科" |
| 近期状态 | 气色（一至两节气） | 寿夭 | 本馆不判寿 |
| 格局气象 | 五岳四渎、神气 | 财富数额 | 相不载数 |
| 用人参考 | 眼神、语速、举止 | 是否犯罪 | 属司法；相法无此能力 |

> **相法最容易被滥用的两处**：一是断寿夭（"你这相活不过六十"），二是断婚姻次数（"你必二婚"）。**这两样本馆一个字不说。**

## 5. 相不独论：古书自己怎么说

《公笃相法》反复强调"相不独论"：一处好不算好，一处坏不算坏，须**形、神、气、色、声、行**合看。

本馆的落地（与 `04`／`06` 一致）：
1. **一条线不判终身**（手相）；
2. **一处部位不判吉凶**（面相）；
3. **至少两个特征同指**，才出一句判断；
4. **气色只看近期**（一至两个节气），不说长期。

## 6. 真伪与版本

| 书 | 问题 | 本馆处理 |
|---|---|---|
| 太清神鉴 | 四库提要明言"其为依托无疑"，疑出宋人之手 | 引时标"旧题王朴，四库考为宋人依托" |
| 冰鉴 | 后人辑曾国藩语录，非曾亲著 | 引时标"旧题曾国藩，实为后人辑" |
| 鬼谷子神奇相法全书 | 托名鬼谷子 | 只考源 |
| 许负相法 | 托名汉·许负 | 只考源 |
| 月波洞中记 | 唐（托） | 只考源 |
| 麻衣相法 | 托名麻衣道者，历代增补 | 讲谱系可以，引原文须谨慎 |

> **一条纪律**：**能说清版本就说，说不清就说"旧题某某"**。相法书托名极多，装懂最容易露怯。

## 7. 与手诊的分工（别混）

| | 相法（`04`–`06`） | 手诊（`29`） |
|---|---|---|
| 看什么 | 性格、格局、近期气色 | 身体状态（掌色、指型、指甲、褶纹） |
| 依据 | 形神气色、十二宫、流年 | 掌纹形态与气色 |
| 结论 | 倾向与气象 | 只能转"查什么科" |
| 红线 | 不判寿夭、不判婚姻次数 | 不出病名 |

> **两套可以互参，不许互相替代**。手相看性格是一回事，手诊看身体是另一回事。

## 8. 一条实用索引

| 客户想干什么 | 推荐 | 提醒 |
|---|---|---|
| 想学看相入门 | 公笃相法（方法论）→ 神相全编（部位） | 先学"不独论"，再学部位 |
| 想查某个部位 | 神相全编／铁关刀 | 查到不等于能断 |
| 想搞懂"神气" | 太清神鉴 | 最难看懂，也最有用 |
| 想知道流年部位 | 神相全编（流年百岁图） | 流年只作参考，不作断言 |
| 想学"观人" | 冰鉴（须说明非曾亲著）＋公笃 | 观人是观举止，不是看命 |

## 9. 收口

> **相法看的是"这个人现在是什么状态"，不是"这个人一生会怎样"。**
> 七十余家相书，没有一家能替你决定一个人的人生。
> **把相法当镜子可以，当判决书不行。**
