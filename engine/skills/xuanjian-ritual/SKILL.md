# 玄鉴·改运科仪数据技能

> **一句话定位**：**把"改运、法事、符咒"变成能查、能评、能组方案的数据能力——不是把馆主训练成法师。**
>
> 数据来自三个可核对的文本源（`daizhige-org/daizhigev20` 易藏术数一百五十五种、`DaimaRuge/daozang-text` 正统道藏一千五百零四篇、`LingTian/tao-kb` 科仪符箓二十部与功过格五种）。**条目可溯源，判断归本馆，承诺一句不给。**

## 一、这个技能解决什么问题

以前客户问"要不要做场法事"，本馆只能答"我不做科仪"。这句话守住了边界，也丢掉了一半生意，还没帮到人。现在改成三件事：

| 客户问 | 以前 | 现在 |
|---|---|---|
| "我要不要做场法事" | 不做，找道长去 | 查条目 → 判类型 → 定档位 → 给"做／不做／换个做法"的建议 + 该花多少钱 + 怎么识别骗局 |
| "这张符是干什么的" | 不知道 | 查符库：类别、用途、出处、法派、禁忌、风险级 |
| "我财运差怎么改" | 只讲命盘 | 六层方案：命（认清）→ 运（择时）→ 人事 → 地理 → 科仪 → 功德，逐层给动作与周期 |
| "还阴债／补财库有没有用" | 不接 | 讲清源流、属于哪一类、民俗依据是什么、哪些是商业包装、做了能得到什么（心理安顿）与得不到什么（改命） |

## 二、六层改运体系（总纲）

改运不是一个动作，是六层叠加。**层越靠下，见效越快；层越靠上，越改不动。**

| 层 | 改什么 | 见效 | 代价 | 本馆态度 |
|---|---|---|---|---|
| **一 · 命** | 改不了，只能认清 | — | — | 先讲清，不许骗客户"能改" |
| **二 · 运** | 择时、借运、避运 | 一年起 | 时间成本 | 主力建议 |
| **三 · 人事** | 换人、换做法、换信息源 | 随时 | 关系成本 | **最快最实，优先给** |
| **四 · 地理** | 搬家、布局、工位、床位 | 一季度 | 金钱成本 | 主力建议 |
| **五 · 科仪** | 祈福、拜斗、安太岁、超度、补财库 | 一场即办 | 金钱＋信仰 | **可建议、可评估、不代做** |
| **六 · 功德** | 功过格、行善、戒杀、孝亲 | 三年起 | 长期自律 | 收尾建议 |

> **排序铁律**：**先给三、四层，再谈五层。** 上来就推法事、不谈人事与地理的，是生意，不是咨询。
> 唯一的例外：客户明确只要科仪（如家里办丧事要超度），那就把科仪讲透，不硬塞别的。

## 三、四档风险分级（全技能的核心闸门）

| 档 | 定义 | 本馆怎么做 | 典型条目 |
|---|---|---|---|
| **甲 · 可直接建议** | 民俗通行、无效果承诺、低花费、不伤人 | 可建议、可帮安排、可陪同 | 安太岁、拜斗祈福、点灯、净宅、谢土、祭祖、超度、补财库（作民俗）、放生（劝阻式）、谢平安 |
| **乙 · 须讲条件、须转介** | 有争议、需师承、花费大、易被包装 | 讲清条件与风险，**转介有师承者**，本馆不代做 | 还阴债、送替身、开光、和合、冲喜、禳星、解厄、符咒绘制、安神位、动土 |
| **丙 · 只解释不承接** | 涉操控他人、涉伤害、伦理有问题 | **只解释源流与风险，不提供做法、不评估效果、不转介** | 五鬼运财、锁心、迷魂、和合强制、诅咒、降头、蛊、拆散、借寿、夺运 |
| **丁 · 一律拒绝** | 违法或伤害特定人 | **立即停止，必要时提示报警** | 针对第三人的法事、未成年人、许诺治病、包治包好、包复婚、涉诈骗 |

> **丙档为什么不转介**：转介等于参与。客户要"锁住对方""让对方回心转意"，这不是信仰需求，是控制欲。给做法、给师承、给渠道，都是帮凶。
> **话术**：**"这一类我不做，也不介绍人做。原因不是它不灵，是它把另一个人当成了物件。"**

## 四、怎么用（三步）

### 第一步：查

```bash
python3 scripts/query.py 场景 <财|婚|病|官非|学业|家宅|出行|丧葬|开业>
python3 scripts/query.py 科仪 <关键词>
python3 scripts/query.py 符 <关键词>
python3 scripts/query.py 典籍 <关键词>
python3 scripts/query.py 风险 <甲|乙|丙|丁>
```

数据表在 `data/`：`gaifu.json`（改运）、`keyi.json`（科仪）、`fulu.json`（符咒）、`gongguo.json`（功过格）、`dianji.json`（典籍）。

### 第二步：判档

查出条目后，先看 `风险级`：
- 甲 → 直接进方案
- 乙 → 进方案但标"须转介"，并给"该问哪三句"
- 丙 → 只答"是什么、为什么不能做"，不进方案
- 丁 → 停

### 第三步：组方案

```bash
python3 scripts/plan.py 财          # 按场景出六层方案
python3 scripts/plan.py 家宅 --命盘 偏弱   # 带命盘成色，方案会调整权重
```

输出结构：六层逐层给「做什么／依据／周期／花费区间／风险／不可承诺项」，末尾强制带效果声明。

## 五、分寸（可用的前提）

1. **不承诺效果。** 一句"做了就好"都不许说。可说"这一步能让你心安、把该做的做了"，不说"做了会转运"。
2. **不替代医疗。** 有病先看医生；科仪最多是"心理安顿"，**不许建议停药、不许说"这是业障不用治"**（`24` §4 就医触发清单优先）。
3. **不针对第三人。** 一切"让他回来""让他倒霉""拆散他们"的单，一律丙档。
4. **不碰未成年人。** 未成年人相关只做"家长该做什么"，不做任何术数与科仪。
5. **收费透明。** 本馆不代收法事费用、不抽成、不指定"合作道长"分成。要转介就说"我不认识可靠的，你自己找，我教你怎么问"。
6. **不否定信仰。** 不说"都是骗人的"；只说"我不做、我不能验证、这不在我能保证的范围"。
7. **条目有出处。** 每一条都能答"出哪本书、哪一派"；查不到就说"这是民间通行、无确凿出处"。

## 六、与其它技能的分工

| 技能 | 管什么 |
|---|---|
| `xuanjian-kb` | 体：命理、相法、堪舆、奇门的**断法**与伦理 |
| `shizhan-pai` | 用：起局、排盘、断事 |
| `xuanjian-archive` | 档案：查重、入库、规则沉淀 |
| **`xuanjian-ritual`（本技能）** | **改运、科仪、符咒、功德的条目与方案** |

> 断"有没有灾"归 `xuanjian-kb`；断出来之后"要不要做法事、做什么、花多少钱、靠不靠谱"归本技能。
> **不许拿本技能的条目去替代断法，也不许拿断法去替代本技能的分级。**
