# 玄鉴命理馆 · 离线本机版（iOS PWA）

把玄鉴命理馆的确定性引擎**完整内嵌进手机本地浏览器**，不联网、不连云、不传任何数据。
八字打分、紫微排盘、黄历、小六壬、五格取名**全部在 iPhone / iPad 本机运行**。

**https://owen1180.github.io/xuanjian-app/** —— 用 iOS Safari 打开，等进度条走到「就绪」，分享菜单「添加到主屏幕」即可安装。

## 一、支持的设备

- **iPhone 18 Pro Max / iPad Pro 11（型号 FU152CH/A）均正常支持。** iOS 是通用二进制，机型只在安装授权阶段起作用；FU152CH/A 是国行型号，功能与全球版完全一致，无需特殊处理。
- 系统要求：iOS / iPadOS 16.4 及以上（Service Worker 与 PWA 安装能力的最低版本）。
- 形态是 **PWA（添加到主屏幕的网页应用）**，不是从 App Store 下载的原生 App——这是 iOS 上"不依赖电脑、不装 Xcode、不交开发者费、能本机离线跑 Python 引擎"的唯一可行路径。

## 二、安全取舍（请先读）

原云端方案把引擎放在服务器、代码不落本地，是为了防山寨与防逆向。
本离线版**反其道而行**：引擎（Python 脚本 + Pyodide 运行时）随包下发给本机浏览器，**有技术能力的人可以读到源码**。

这是"个人本机自用"场景下的合理取舍，不是漏洞——它带来的是：

- ✅ 完全离线、断网可用、数据不出本机；
- ✅ 不依赖任何服务器存活；
- ⚠️ 不防逆向、不防盗用，**请勿作商业分发**。

### 资料暴露范围（已收紧）
本仓库公开的是**可运行的引擎代码**（Python 脚本 + Pyodide 运行时），这是离线自包含方案的必然代价。
但以下内容**不公开**：
- 全部知识库册页（`references/*.md`，上百篇馆内沉淀文档）已从 `engine.zip` 剔除，手机端不加载；
- 各 skill 的 `SKILL.md` / `FIDELITY.md` 等说明文档同样已剔除；
- 引文清单只保留**加密版** `quotes_manifest.json.enc`，明文 `quotes_manifest.json` 已从包内删除；
- 校准集等资产以 `.enc` 加密形式随包分发，无密钥无法读取。

换言之：算法可看，但馆内知识文本与核心资料清单已不在发布包中。若连算法也不想公开，需改用私有仓库或回云端架构（见 DEPLOY.md）。

## 三、部署（这一步必须有 HTTPS）

iOS Safari 的"添加到主屏幕"和离线缓存（Service Worker）**强制要求 HTTPS**（本机 localhost 除外）。
因此你需要把这整个文件夹放到任意支持 HTTPS 的静态托管上。

纯 `http://局域网IP` 或 `file://` 直接打开，**在 iOS 上无法安装成 App**，请勿走这条路。

### 方式 A：GitHub Pages（免费、最省事）
1. 新建一个公开仓库；
2. 把本目录**全部内容**推上去（含 `index.html`、`app.js`、`engine.zip`、`pyodide/`、`icons/`、`manifest.webmanifest`、`sw.js`）；
3. 仓库 Settings → Pages → 选 main 分支根目录 → 保存；
4. 得到形如 `https://你的用户名.github.io/仓库名/` 的 HTTPS 地址。

### 方式 B：Netlify / Vercel / Cloudflare Pages
拖拽本文件夹上传，平台会自动分配 HTTPS 域名，零配置。

### 方式 C：自有服务器
只要你的 Web 服务器支持 HTTPS 且能列目录/托管静态文件即可（Nginx、Caddy 等）。

> 部署到子路径（如 `https://域名/玄鉴/`）也支持，已做兼容。

## 四、安装到主屏幕（手机上操作）

1. 用 **Safari** 打开上一步得到的 HTTPS 地址；
2. 等待顶部进度条走到 **「就绪」**——**首次需要联网**，浏览器会下载约 16MB 的 Pyodide 运行时与引擎包并缓存（时间取决于网速，请耐心等）；
3. 点底部工具栏的 **「分享」按钮**（方框带向上箭头）；
4. 在弹出的菜单里下滑找到 **「添加到主屏幕」**；
5. 名称填「玄鉴」，点右上角「添加」；
6. 回到桌面，点「玄鉴」图标即可像原生 App 一样全屏打开。

## 五、离线使用与更新

- **离线**：首次成功打开并缓存后，之后**断网也能用**。Service Worker 已把运行时与引擎缓存到本机。
- **更新**：若你重新部署了新版本，在手机上用 Safari 打开一次该地址即可刷新缓存；或长按主屏图标 →「移除 App」后重新按第四步安装。
- 更新缓存的版本号在 `sw.js` 的 `CACHE = "xuanjian-v1"`——若你改了引擎想强制用户刷新，把 `v1` 改成 `v2` 即可。

## 八、文件结构

```
xuanjian-app/
├── index.html            # 应用入口（PWA 主页）
├── app.js               # 前端逻辑：启动 Pyodide、调用引擎、渲染
├── styles.css           # 移动端墨金主题
├── manifest.webmanifest # PWA 清单（名称/图标/全屏）
├── sw.js                # Service Worker（离线缓存）
├── engine.zip           # 确定性引擎（engine_bridge + 全部 scripts + 离线农历数据表）
├── pyodide/             # Python→WebAssembly 运行时（约 14MB）
├── icons/               # 各尺寸图标（含 apple-touch-icon）
└── engine/              # 引擎可编辑源码（仅用于二次开发/重建 engine.zip，运行时不用）
```

> 想改引擎后重新打包：修改 `engine/` 下脚本 → 在 `engine/` 所在目录执行
> `zip -r -q ../engine.zip engine_bridge.py && (cd engine && zip -q -r ../engine.zip skills)`
> 重新部署即可。
